# المرحلة الأولى: Project Discovery - قطاع البلديات في محافظة إب

> **التاريخ**:  يوليو 2026  
> **الملف**: 01_Project_Discovery.md

## 1.1 المشكلة (Problem Statement)

يعاني قطاع البلديات في محافظة إب من تحديات كبيرة رغم كونه قطاعًا حيويًا. لا توجد منصة موحدة تتيح للمستفيدين اكتشاف الخدمات أو مقارنتها. المشكلات الرئيسية:

1. **تراكم النفايات في الأحياء**
2. **ضعف صيانة الطرق**
3. **تأخر تنفيذ المشاريع الخدمية**
4. **غياب الشفافية**
5. **قنوات اتصال ضعيفة مع المواطنين**

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لقطاع البلديات في محافظة إب** تتكون من:

- **الإبلاغ عن مشكلة**: إبلاغ عن مشكلات النظافة والطرق
- **تتبع البلاغات**: متابعة حالة البلاغ ووقت المعالجة
- **خدمات البلدية**: دليل الخدمات البلدية ومواقعها
- **إعلانات المشاريع**: إعلان عن المشاريع الجديدة
- **الاستعلام عن المعاملات**: استعلام عن معاملات البلدية أونلاين

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستهلك/المواطن** | سهولة الوصول للمعلومات، مقارنة الخدمات، تقييمات حقيقية |
| **مزود الخدمة/البلديات** | وصول لشريحة أكبر، تحسين السمعة، إدارة رقمية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات، عمولات، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، مكاتب البلديات المحلية |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| حصر الجهات/البلديات | عدد المسجلين | 25++ |
| دقة البيانات | نسبة المعلومات المؤكدة | 90%+ |
| سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| رضا المستخدمين | تقييم المنصة | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن تكون المنصة الرقمية لقطاع البلديات في محافظة إب المرجع الأول الذي يعتمد عليه كل مواطن، محولة تجربة البلديات إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مزودي خدمات البلديات والمستفيدين في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - غطاء جغرافي كامل | - بيروقراطية |
| - موظفون بخبرة | - موارد مالية محدودة |
| - علاقات مع الجهات المركزية | - ضعف التحول الرقمي |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - الدعم الدولي للامركزية | - الوضع الأمني |
| - التحول الرقمي الحكومي | - نزوح سكاني |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: عدم استقرار سياسي | خطر على استمرارية الأعمال |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | ارتفاع التكاليف، حساسية السعر |
| **S - Social**: كثافة سكانية عالية، شرائح متنوعة | فرصة كبيرة، تنوع الاحتياجات |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم رقمي | فرصة لتوحيد المعايير |
| **E - Environmental**: تحديات بيئية مختلفة | فرصة لنشر التوعية |
