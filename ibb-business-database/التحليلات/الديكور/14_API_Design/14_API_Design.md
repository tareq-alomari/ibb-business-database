## 14.1 نظرة عامة على API (API Overview)

| الخاص | القيمة |
|--------|-------|
| النمط | RESTful API
| التنسيق | JSON |
| البروتوكول | HTTPS |
| الإصدار | v1 |
| التوثيق | Swagger/OpenAPI 3.0 |

## 14.2 نقاط النهاية (Endpoints)

### المصادقة (Auth)

| الطريقة | المسار | الوصف |
|--------|--------|------|
| POST | /api/v1/auth/register | تسجيل مستخدم جديد |
| POST | /api/v1/auth/login | تسجيل الدخول |
| POST | /api/v1/auth/verify-otp | تأكيد رقم الهاتف |
| POST | /api/v1/auth/refresh | تحديث التوكن |

### الخدمات (Services)

| الطريقة | المسار | الوصف |
|--------|--------|------|
| GET | /api/v1/services | قائمة الخدمات (مع بحث وفلترة) |
| GET | /api/v1/services/:id | تفاصيل الخدمة |
| POST | /api/v1/services | إضافة خدمة جديدة |
| PUT | /api/v1/services/:id | تحديث خدمة |
| DELETE | /api/v1/services/:id | حذف خدمة |

### الحجوزات (Bookings)

| الطريقة | المسار | الوصف |
|--------|--------|------|
| GET | /api/v1/bookings | قائمة حجوزات المستخدم |
| POST | /api/v1/bookings | إنشاء حجز جديد |
| PUT | /api/v1/bookings/:id | تحديث حالة الحجز |
| DELETE | /api/v1/bookings/:id | إلغاء حجز |

## 14.4 معالجة الأخطاء (Error Handling)

| رمز الحالة | المعنى | المثال |
|-----------|--------|--------|
| 400 | Bad Request | بيانات ناقصة أو غير صالحة |
| 401 | Unauthorized | توكن غير صالح أو منتهي |
| 403 | Forbidden | غير مصرح لهذه العملية |
| 404 | Not Found | المورد غير موجود |
| 409 | Conflict | تعارض (حجز مزدوج) |
| 422 | Unprocessable Entity | بيانات غير متوافقة مع القواعد |
| 429 | Too Many Requests | تجاوز حد الطلبات |
| 500 | Internal Server Error | خطأ في الخادم |
