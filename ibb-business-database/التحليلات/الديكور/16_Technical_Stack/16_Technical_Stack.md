## 16.1 مكدس التقنيات (Technology Stack)

| الطبقة | التقنية | الإصدار | السبب |
|--------|---------|--------|------|
| **Frontend** | React.js + Next.js | 14+ | أداء عالٍ، SSR، دعم RTL |
| **Mobile** | Flutter | 3.x | أداء أصلي، منصة واحدة للجوالين |
| **Backend** | Node.js + Express | 20 LTS | سرعة تطوير، مجتمع كبير |
| **Database** | PostgreSQL | 15+ | موثوقية، دعم JSON، مجاني |
| **Cache** | Redis | 7.x | سرعة عالية، جلسات، تخزين مؤقت |
| **Storage** | MinIO / S3 | - | تخزين آمن للصور والملفات |
| **Search** | Elasticsearch | 8.x | بحث متقدم، اقتراحات |
| **Message Queue** | RabbitMQ | 3.x | معالجة غير متزامنة للإشعارات |
| **Monitoring** | Prometheus + Grafana | - | مراقبة الأداء والتنبيهات |
| **CI/CD** | GitHub Actions | - | نشر آلي واختبارات مستمرة |

## 16.3 متطلبات التشغيل (Deployment Requirements)

| المكون | المواصفات |
|--------|-----------|
| خادم التطبيقات | 4 vCPU, 8GB RAM, 100GB SSD |
| خادم قاعدة البيانات | 8 vCPU, 16GB RAM, 200GB SSD |
| خادم التخزين | 4 vCPU, 4GB RAM, 500GB HDD |
| CDN | Cloudflare (مجاني/مميز) |
| النطاق الترددي | 100 Mbps على الأقل |
