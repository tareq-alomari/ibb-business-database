# الأمان - قطاع المعاهد (إب)

## تقييم المخاطر

| المخاطرة | الاحتمال | التأثير | الإجراء |
|----------|----------|---------|---------|
| اختراق حسابات المستخدمين | متوسط | مرتفع | مصادقة ثنائية (2FA) |
| سرقة بيانات الطلاب | منخفض | مرتفع جداً | تشفير كامل للبيانات |
| هجمات DDoS | متوسط | مرتفع | Cloudflare DDoS Protection |
| اختراق لوحة المعهد | متوسط | مرتفع | صلاحيات دقيقة، مراجعة سجلات |
| حقن SQL | منخفض | مرتفع | Prisma ORM (parameterized queries) |
| XSS | متوسط | مرتفع | إدخال منقى، Content Security Policy |
| تخمين كلمة المرور | مرتفع | متوسط | قيود محاولات الدخول، captcha |

## إجراءات أمنية

### في التطبيق
- تشفير HTTPS إلزامي (SSL/TLS)
- JWT مع توقيع آمن وانتهاء صلاحية قصير
- تخزين كلمات المرور: bcrypt (12 rounds)
- التحقق من صحة الإدخال (Input Validation) عبر Zod
- حماية من CSRF باستخدام SameSite cookies
- Content Security Policy (CSP) صارمة

### في قاعدة البيانات
- تشفير البيانات الحساسة (أرقام هواتف، بريد إلكتروني)
- نسخ احتياطي يومي آمن
- فصل صلاحيات قراءة/كتابة قاعدة البيانات
- تدقيق ومراقبة الاستعلامات

### في البنية التحتية
- Cloudflare Web Application Firewall (WAF)
- Rate Limiting على نقاط API
- مراقبة تسجيلات الدخول المشبوهة
- تحديث أمني شهري للمكتبات
- استخدام Docker مع سكان أمني للصور

## الامتثال
- الالتزام بقانون حماية البيانات اليمني (إن وجد)
- إشعار المستخدمين بجمع البيانات
- سياسة خصوصية واضحة
- حقوق المستخدمين في حذف بياناتهم
