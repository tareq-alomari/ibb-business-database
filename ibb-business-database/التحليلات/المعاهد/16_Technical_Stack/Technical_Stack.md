# التقنيات المستخدمة - قطاع المعاهد (إب)

## الواجهة الأمامية (Frontend)

| التقنية | الاستخدام |
|---------|-----------|
| Next.js 14 | إطار العمل الرئيسي (SSR + CSR) |
| React 18 | مكتبة بناء واجهة المستخدم |
| TypeScript | الكتابة الآمنة |
| Tailwind CSS | تصميم سريع ومتجاوب |
| shadcn/ui | مكونات جاهزة قابلة للتخصيص |
| React Query | إدارة حالة الخادم والتخزين المؤقت |
| Axios | طلبات HTTP |
| React Hook Form | إدارة النماذج |
| Zod | التحقق من صحة البيانات |

## الواجهة الخلفية (Backend)

| التقنية | الاستخدام |
|---------|-----------|
| Node.js | بيئة التشغيل |
| Express.js | إطار الخادم |
| TypeScript | الكتابة الآمنة |
| Prisma ORM | التعامل مع قاعدة البيانات |
| Passport.js / JWT | المصادقة والتفويض |
| Swagger | توثيق API |

## قاعدة البيانات والتخزين

| التقنية | الاستخدام |
|---------|-----------|
| PostgreSQL | قاعدة البيانات الرئيسية |
| Redis | تخزين مؤقت وجلسات |
| Cloudflare R2 | تخزين الملفات والصور |
| PgAdmin | إدارة قاعدة البيانات |

## النشر والاستضافة

| الخدمة | الاستخدام |
|--------|-----------|
| Vercel / Netlify | استضافة الواجهة الأمامية |
| Railway / Fly.io | استضافة الخادم |
| Cloudflare | DNS + CDN + حماية |
| GitHub Actions | CI/CD |
| Sentry | مراقبة الأخطاء |
