# التوثيق - قطاع المعاهد (إب)

## خطة التوثيق

| المستند | الجمهور | المحتوى |
|---------|---------|---------|
| README | مطورون | نظرة عامة، تثبيت، تشغيل |
| دليل الاستخدام | مستخدم عادي | كيفية البحث والمقارنة والتقديم |
| دليل المعهد | إدارة المعاهد | إضافة تخصصات، متابعة طلبات |
| دليل المشرف | فريق الإدارة | إدارة المستخدمين، تقارير |
| API Documentation | مطورون | نقاط النهاية، أمثلة، توثيق Swagger |
| دليل المساهمة | مطورون | معايير الكود، Pull Request |
| دليل النشر | DevOps | أوامر النشر، متغيرات البيئة |
| تقرير المرحلة | أصحاب المصلحة | تقدم المشروع، إنجازات، خطط |

## أدوات التوثيق
- **التوثيق الفني**: Markdown في مجلد `/docs` داخل المستودع
- **توثيق API**: Swagger UI (مدمج مع التطبيق)
- **توثيق المستخدم**: صفحات داخل التطبيق + فيديوهات تعليمية
- **توثيق المشروع**: Notion / Google Docs لأصحاب المصلحة

## معايير التوثيق
- اللغة: العربية (للمستخدمين)، الإنجليزية (للمطورين)
- تحديث التوثيق مع كل إصدار جديد
- استخدام الصور والشروحات المصورة
- وجود مثال عملي لكل وظيفة
- الاحتفاظ بسجل التغييرات (Changelog)
