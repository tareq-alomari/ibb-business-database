# التحليل الوظيفي - قطاع المعاهد (إب)

## الوظائف الأساسية

### للمتقدمين
| الوظيفة | الأولوية | الوصف |
|---------|----------|-------|
| بحث عن معاهد | عالية | فلترة حسب التخصص، الموقع، الرسوم |
| مقارنة معاهد | عالية | جدول مقارنة شامل للتخصصات والرسوم |
| ملف تعريف طالب | متوسطة | سجل الطلب، تفضيلات التخصص |
| تقديم إلكتروني | عالية | تقديم طلب التحاق مع رفع المستندات |
| تقييم معاهد | متوسطة | تقييم ومراجعة بعد الالتحاق |
| إشعارات | متوسطة | تنبيهات بمواعيد التسجيل والنتائج |

### لإدارة المعهد
| الوظيفة | الأولوية | الوصف |
|---------|----------|-------|
| لوحة تحكم | عالية | إحصاءات المتقدمين، تقارير |
| إدارة التخصصات | عالية | إضافة وتحديث البرامج والرسوم |
| إدارة الطلبات | عالية | مراجعة وقبول الطلبات |
| تواصل مع المتقدمين | متوسطة | رسائل وإشعارات داخلية |
| تقارير أداء | متوسطة | إحصائيات القبول والتخرج |

### للوزارة/المشرف
| الوظيفة | الأولوية | الوصف |
|---------|----------|-------|
| تقارير موحدة | عالية | بيانات إحصائية عن جميع المعاهد |
| متابعة أداء | متوسطة | مؤشرات أداء رئيسية لكل معهد |
| إدارة المستخدمين | متوسطة | صلاحيات الوصول والمصادقة |
