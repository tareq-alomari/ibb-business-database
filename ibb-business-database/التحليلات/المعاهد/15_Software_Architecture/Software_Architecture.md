# بنية البرمجيات - قطاع المعاهد (إب)

## الطبقات المعمارية

```
┌─────────────────────────────────────┐
│       طبقة العرض (Frontend)         │
│  React / Next.js (RTL + Arabic)     │
├─────────────────────────────────────┤
│       طبقة API (Backend)            │
│  RESTful API / Node.js Express      │
├─────────────────────────────────────┤
│       طبقة الخدمات (Services)       │
│  منطق الأعمال، المصادقة، التقارير   │
├─────────────────────────────────────┤
│       طبقة البيانات (Data)          │
│  PostgreSQL + Redis Cache           │
└─────────────────────────────────────┘
```

## المكونات الأساسية

| المكون | التقنية | الدور |
|--------|---------|-------|
| واجهة المستخدم | Next.js | صفحات الموقع، لوحات التحكم |
| الخادم | Express.js | نقاط النهاية، معالجة الطلبات |
| قاعدة البيانات | PostgreSQL | تخزين المعاهد، التخصصات، المستخدمين |
| التخزين المؤقت | Redis | جلسات المستخدمين، بيانات متكررة |
| التخزين الوسائط | Cloudflare R2 / S3 | صور المعاهد، مستندات الطلاب |
| البريد الإلكتروني | SendGrid / SMTP | إشعارات، تأكيدات التسجيل |
| الخرائط | Google Maps / OpenStreetMap | مواقع المعاهد في إب |

## نمط العمارة
- **العمارة**: RESTful Microservices (خدمات مصغرة)
- **التواصل**: HTTP/HTTPS مع JSON
- **المصادقة**: JWT (JSON Web Tokens) مع صلاحيات متعددة المستويات

## سير الطلب النموذجي
1. المتصفح ← Next.js (SSR/CSR)
2. Next.js ← Express API
3. Express ← PostgreSQL (قاعدة بيانات)
4. استجابة ← Next.js ← عرض في المتصفح

## التكاملات الخارجية
- بوابة دفع إلكتروني (للرسوم)
- واجهات وزارة التعليم الفني (إن وجدت)
- خدمات إرسال رسائل واتساب
- Google Analytics للتحليلات
