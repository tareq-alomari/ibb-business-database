# لوحات التحكم - قطاع المعاهد (إب)

## لوحة المشرف العام (Admin Dashboard)

### المؤشرات الرئيسية (KPIs)
| المؤشر | الوصف |
|--------|-------|
| إجمالي المعاهد المسجلة | عدد المعاهد في المنصة |
| إجمالي الطلاب المسجلين | عدد المستخدمين الطلاب |
| إجمالي الطلبات المقدمة | عدد طلبات الالتحاق |
| نسبة القبول | الطلبات المقبولة / المقدمة |
| التقييم العام | متوسط تقييمات جميع المعاهد |
| المعاهد الأكثر نشاطاً | ترتيب حسب التفاعل والتحديثات |

### الرسوم البيانية
- منحنى التسجيل الشهري (طلاب جدد)
- توزيع الطلاب حسب نوع المعهد (تقني، صحي، حاسوب، مهني)
- خريطة تفاعلية لمواقع المعاهد في إب
- مقارنة أداء المعاهد (تقييم، طلبات، قبول)

## لوحة المعهد (Institute Dashboard)

### إحصاءات المعهد
| المؤشر | الوصف |
|--------|-------|
| عدد زوار صفحة المعهد | مشاهدات الصفحة |
| عدد طلبات الالتحاق الواردة | طلبات جديدة |
| نسبة إتمام الطلبات | طلبات مكتملة / إجمالية |
| متوسط التقييم | تقييم الطلاب للمعهد |

### ميزات متقدمة
- إدارة التخصصات والبرامج
- جدول زمني للمواعيد النهائية
- تنبيهات المواعيد الهامة (بدء التسجيل، نهاية التقديم)
- تصدير تقارير (PDF, Excel)

## لوحة الطالب (Student Dashboard)
- طلباتي: عرض حالة الطلبات المقدمة
- المفضلة: قائمة المعاهد المفضلة
- إشعارات: تنبيهات المواعيد والنتائج
- ملف شخصي: تحديث البيانات والمستندات

## تقارير وزارية
- تقرير شهري: إحصائيات شاملة عن قطاع المعاهد في إب
- تقرير مقارن: أداء المعاهد الحكومية مقابل الأهلية
- تقرير تخصصات: التخصصات الأكثر طلباً ونسبة الالتحاق
