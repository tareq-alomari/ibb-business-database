## 6.2 تحليل المصلحة والتأثير

```
تأثير عالي
    │
    │   أبقي راضيًا              │   أدر بإحكام
    │   (Keep Satisfied)         │   (Manage Closely)
    │   • البنك المركزي         • الشركات                  
    │   • نقابة المحاسبين       • مكاتب التدقيق الكبرى     
────┼────────────────────────────┼─────
    │                            │
    │   راقب (Monitor)           │   أبق على اطلاع
    │   • نقابة المحاسبين       • مصلحة الضرائب            
```
