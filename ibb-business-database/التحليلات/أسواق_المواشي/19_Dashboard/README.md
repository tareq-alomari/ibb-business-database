# لوحة القيادة – منصة أسواق المواشي

## المؤشرات الرئيسية (KPIs)

### مؤشرات عامة
- عدد المستخدمين النشطين (يومي/أسبوعي/شهري)
- عدد الإعلانات المنشورة
- عدد الصفقات المكتملة
- إجمالي قيمة التداول

### مؤشرات الأسعار
- متوسط سعر الأبقار (حسب العمر والنوع)
- متوسط سعر الأغنام والماعز
- مخططات اتجاه الأسعار (شهر/ربع/سنة)
- مقارنة الأسعار بين المديريات

### مؤشرات المزادات
- عدد المزادات النشطة
- متوسط عدد المزايدات لكل مزاد
- نسبة نجاح المزادات
- أعلى سعر مزايدة

### مؤشرات الأداء الفني
- زمن تحميل الصفحات
- معدل التحويل (زيارة → صفقة)
- مصدر الزوار (مباشر/بحث/تواصل اجتماعي)
- عدد زيارات الصفحات

## تصاميم الشاشات

### لوحة المشرف العام
مخططات تفاعلية، تنبيهات، إدارة المستخدمين، مراجعة الإعلانات المبلغ عنها.

### لوحة التاجر
إحصائيات إعلاناتي، إشعارات، رسائل واردة، تقييمات العملاء.

### لوحة المربي
مبيعاتي، طلبات واردة، مواعيد الفحص البيطري، سجل التطعيمات.

### لوحة المشتري
إعلاناتي المفضلة، مزايداتي، مشترياتي السابقة، تقييماتي.

## أدوات التصدير
PDF، Excel، CSV، طباعة مباشرة مع إمكانية جدولة التقارير الدورية عبر البريد الإلكتروني.
