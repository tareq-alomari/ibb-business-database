# الأمان – منصة أسواق المواشي

## سياسات الأمان

### المصادقة والتفويض
- تسجيل الدخول برقم الهاتف وكلمة مرور + رمز تحقق SMS
- صلاحية الجلسة محدودة (24 ساعة) مع تجديد تلقائي
- أدوار وصول محددة: مشرف، تاجر، مربي، مشتري، بيطري
- رفض الوصول الافتراضي لأي مورد غير مصرح به

### حماية البيانات
- تشفير الاتصال عبر TLS 1.3
- تشفير البيانات الحساسة (كلمات المرور، أرقام الهواتف) في قاعدة البيانات
- إخفاء المعلومات الشخصية في الردود API
- عدم تخزين بيانات الدفع الحساسة محلياً، بل عبر بوابة دفع خارجية

### حماية التطبيق
- تطهير المدخلات (Input Sanitization) ضد XSS وSQL Injection
- حدود على عدد الطلبات (Rate Limiting) – 100 طلب/دقيقة
- حماية CSRF عبر توكنات عشوائية
- التحقق من صلاحية الملفات المرفوعة (الصور)

### الخصوصية
- سياسة خصوصية واضحة للمستخدمين
- إمكانية حذف الحساب والبيانات بالكامل
- عدم مشاركة بيانات المستخدم مع أطراف ثالثة
- إشعار المستخدم بأي خرق أمني خلال 72 ساعة

### الامتثال
- التوافق مع قوانين حماية البيانات اليمنية
- التوافق مع أحكام الشريعة الإسلامية في المعاملات المالية
- الإبلاغ عن الثغرات الأمنية عبر برنامج مكافآت

## خطة الاستجابة للاختراق
كشف، عزل، تحليل، معالجة، استعادة، توثيق، إبلاغ المتضررين.
