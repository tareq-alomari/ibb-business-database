# هيكلة المعلومات – منصة أسواق المواشي

## الهيكل التنظيمي للمحتوى

### المستوى الأول – الصفحات الرئيسية
1. الرئيسية – لوحة عرض عامة
2. السوق – تصفح الإعلانات
3. إضافة إعلان – نموذج البيع
4. المزادات – مزادات حية
5. الخدمات البيطرية – حجز استشارات
6. الأسعار – إحصائيات ورسوم بيانية
7. من نحن – معلومات عن المنصة
8. اتصل بنا – دعم ومساعدة

### المستوى الثاني – التفاصيل
- إعلان مفرد: صور، وصف، تقرير بيطري، موقع، تواصل مع البائع
- حساب المستخدم: إعلاناتي، معاملاتي، محفظتي، إعداداتي
- لوحة المشرف: إدارة المستخدمين، مراجعة الإعلانات، تقارير

### نظام التصنيف
- حسب نوع الماشية: أبقار، أغنام، ماعز، إبل، دواجن كبيرة
- حسب الغرض: تربية، تسمين، ذبح، حلابة
- حسب العمر: صغير (أقل من سنة)، متوسط (1-3 سنوات)، كبير (أكثر من 3)
- حسب الموقع: مدينة إب، جبلة، العدين، النادرة، السدة

### مسارات التنقل
شريط تنقل علوي ثابت، قائمة جانبية للمحمول، روابط سريعة أسفل كل صفحة، خريطة موقع كاملة، وأزرار عودة للخلف مع مسارات الخبز (Breadcrumbs).

## تدفق المستخدم (User Flow)

### تدفق البائع الجديد
التسجيل ← إضافة إعلان ← إدخال بيانات الماشية ← رفع الصور ← اختيار نوع الإعلان (مباشر/مزاد) ← تحديد السعر ← نشر الإعلان ← انتظار المشترين

### تدفق المشتري
البحث عن ماشية ← تصفية النتائج ← اختيار إعلان ← مشاهدة التفاصيل والتقرير البيطري ← التواصل مع البائع ← التفاوض ← إتمام الصفقة ← التقييم

## نظام التصنيف الداخلي
كل إعلان يصنف بحسب: الحالة (نشط، معلق، محجوز، مباع، محذوف)، الأولوية (عادي، مميز، موصى به)، والثقة (متحقق، غير متحقق).

## خريطة الموقع الثانوية
صفحات الدعم الفني، سياسة الخصوصية، شروط الاستخدام، مدونة الأخبار والنصائح، أعلن معنا، وظائف، خريطة الموقع الكاملة (HTML وXML).
