# تصميم واجهة المستخدم – منصة أسواق المواشي

## النظام البصري

### الألوان
- الرئيسي: أخضر داكن (#2D6A4F) – يرمز للثروة الحيوانية والطبيعة
- الثانوي: برتقالي (#E76F51) – للدعوة إلى الإجراء
- الخلفية: أبيض (#FFFFFF) ورمادي فاتح (#F8F9FA)
- النصوص: أسود (#212529) ورمادي (#6C757D)
- ألوان التصنيف: أزرق للأبقار، أخضر للأغنام، بني للماعز

### الخطوط
- العناوين: خط "Noto Kufi Arabic" سميك (Bold)
- النصوص: خط "Noto Sans Arabic" عادي (Regular)
- أحجام: العنوان الرئيسي 32px، العنوان الفرعي 24px، النص 16px

### الأيقونات
أيقونات بسيطة ثنائية الأبعاد تعبر عن أنواع المواشي والخدمات، بلون واحد (Monochrome) مع إمكانية التلوين حسب السياق.

### الشاشات الرئيسية
1. الصفحة الرئيسية: شريط بحث بارز، إعلانات مميزة، إحصائيات سريعة
2. قائمة الإعلانات: عرض شبكي (Grid) مع صورة مصغرة ومعلومات أساسية
3. تفاصيل الإعلان: معرض صور، وصف كامل، تقرير بيطري، موقع على الخريطة
4. نموذج إضافة إعلان: نموذج متعدد الخطوات مع معاينة
5. لوحة التحكم: رسوم بيانية وحجوزات وإعلانات المستخدم
6. صفحة المزاد: عداد زمني، سعر حالي، مدخل مزايدة

## التوافق مع المحمول
تصميم متجاوب (Responsive) بثلاثة أحجام: هاتف، جهاز لوحي، حاسوب مكتبي.

## مكونات واجهة المستخدم

### البطاقة (Card)
صورة الماشية (16:9)، اسم النوع، السعر، الموقع، حالة الماشية (متوفرة/محجوزة/مباعة)، زر تواصل. حجم البطاقة يتكيف مع الشاشة.

### شريط البحث
حقل نصي مع أيقونة بحث، إمكانية التصفية المتقدمة بالضغط على زر التصفية، نتائج فورية مع اقتراحات بحث ذكية حسب نوع الماشية والموقع.

### نموذج الإضافة
مقسم إلى 3 خطوات: (1) المعلومات الأساسية (النوع، العمر، الوزن)، (2) الصور والموقع، (3) السعر ونوع الإعلان. شريط تقدم يظهر الخطوة الحالية.

### نافذة الدردشة
نافذة عائمة في الزاوية السفلية، رسائل نصية وصور، مؤشر كتابة، إشعارات صوتية عند وصول رسالة جديدة.

## نظام الشاشات المختلفة
شاشة البداية (Splash Screen) بهوية المنصة، شاشة فارغة مع رسالة ترحيب عند عدم وجود نتائج بحث، شاشة خطأ مخصصة بدلاً من الشاشات البيضاء، شاشة تحميل مع مؤشر تقدم مخصص.
