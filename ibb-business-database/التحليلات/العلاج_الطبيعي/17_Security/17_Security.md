# المرحلة السابعة عشرة: Security - قطاع العلاج الطبيعي في محافظة إب

> **التاريخ**: يوليو 2026  
> **الملف**: 17_Security.md

---

## 17.1 نموذج التهديدات

| المكون | التهديد | الاحتمالية |
|--------|--------|-----------|
| واجهة المستخدم | XSS, CSRF | متوسطة |
| API | SQL Injection, DDoS | متوسطة |
| قاعدة البيانات | تسرب بيانات | منخفضة |
| التخزين | وصول غير مصرح | منخفضة |
| الاتصالات | اعتراض البيانات | منخفضة |

## 17.2 إجراءات الأمان

| المجال | الإجراء |
|--------|--------|
| المصادقة | JWT + OTP |
| التحقق | 2FA للحسابات المهمة |
| التشفير | TLS 1.3, AES-256 |
| API | Rate Limiting |
| المدخلات | تعقيم المدخلات |

## 17.3 سياسة الخصوصية

1. جمع البيانات الضرورية فقط
2. استخدام البيانات لتحسين الخدمة
3. لا مشاركة مع أطراف ثالثة
4. الاحتفاظ 3 سنوات ثم الحذف
5. حق المستخدم في تصدير/حذف البيانات

## 17.4 خطة الاستجابة للاختراق

| المرحلة | الوقت المستهدف |
|---------|---------------|
| اكتشاف | < 5 دقائق |
| تحليل | < 30 دقيقة |
| احتواء | < ساعة |
| إزالة | < 4 ساعات |
| استعادة | < ساعتين |
| توثيق | < 24 ساعة |

---

## المصادر

1. الجهاز المركزي للإحصاء اليمني
2. غرفة تجارة وصناعة محافظة إب
3. مسح ميداني تقديري لـقطاع العلاج الطبيعي في محافظة إب
4. مقابلات محلية مع مقدمي الخدمة والمستفيدين
