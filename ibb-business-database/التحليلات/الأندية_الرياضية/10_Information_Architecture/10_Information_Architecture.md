## 10.1 هيكل المعلومات العام

تطبيق رياضة إب → [الصفحة الرئيسية | قائمة الجهات | صفحة جهة | العروض | لوحة التحكم]

## 10.2 نظام التصنيف

| المستوى | التصنيف |
|---------|---------|
| حسب النوع | أندية رياضية (كرة قدم) | تخصص أندية رياضية (كرة قدم) |
| حسب النوع | مراكز لياقة (جيم) | تخصص مراكز لياقة (جيم) |
| حسب النوع | أندية فنون قتالية | تخصص أندية فنون قتالية |
| حسب النوع | نوادٍ صحية وسباحة | تخصص نوادٍ صحية وسباحة |
| حسب النوع | أكاديميات رياضية | تخصص أكاديميات رياضية |

## 10.3 Sitemap

/ ← الصفحة الرئيسية
/list ← قائمة الجهات
/list/:id ← صفحة جهة
/list/:id/reviews ← تقييمات
/favorites ← المفضلة
/offers ← العروض

## 10.4 User Flow

فتح التطبيق → بحث/تصفح → اختيار جهة → عرض التفاصيل → تواصل → تقييم
