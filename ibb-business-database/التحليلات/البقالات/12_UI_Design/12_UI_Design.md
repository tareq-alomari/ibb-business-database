# تصميم واجهة المستخدم: البقالات في مدينة إب

## هوية التصميم
- ألوان رئيسية: الأخضر (للبقالة) والأبيض والرمادي
- ألوان ثانوية: الأصفر للتحذيرات والأحمر للتنبيهات
- خط: خط عربي واضح ومناسب للشاشات

## الشاشات الرئيسية

### شاشة تسجيل الدخول
- شعار النظام في الأعلى
- حقلين لإدخال رقم الهاتف وكلمة المرور
- زر دخول بارز

### لوحة التحكم
- بطاقات ملخصة: مبيعات اليوم، عدد العملاء، المخزون المنخفض
- رسم بياني للمبيعات آخر 7 أيام
- قائمة بأحدث المبيعات
- أزرار سريعة للإجراءات المتكررة

### شاشة المخزون
- شريط بحث وتصفية
- جدول المنتجات مع صورة مصغرة
- أزرار تعديل وحذف لكل منتج
- زر إضافة منتج جديد في الأسفل

### شاشة المبيعات
- حقل إضافة منتج بالباركود أو البحث
- قائمة المنتجات المضاف مع الكميات
- إجمالي الفاتورة بشكل بارز
- أزرار: إتمام البيع، إلغاء، طباعة

### شاشة التقارير
- خيارات الفترة: يوم، أسبوع، شهر، سنة
- رسوم بيانية تفاعلية
- جداول بيانات مع إمكانية التصدير

## مكونات الواجهة
- أزرار دائرية أو مربعة مع زوايا منحنية
- أيقونات بسيطة وواضحة
- بطاقات معلومات مع ظل خفيف
- حقول إدخال مع تسميات واضحة

## تجربة الاستجابة
- تصميم متجاوب مع جميع أحجام الشاشات
- قوائم انزلاقية في الأجهزة المحمولة
- أزرار لمس كبيرة للاستخدام السهل
