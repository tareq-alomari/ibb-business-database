# هيكلة المعلومات: البقالات في مدينة إب

## هيكل التنقل العام

### المستوى الأول: لوحة التحكم
- ملخص المبيعات اليومية
- إشعارات المخزون المنخفض
- أخر المبيعات
- مؤشرات الأداء الرئيسية

### المستوى الثاني: إدارة المخزون
- قائمة المنتجات
- إضافة منتج جديد
- تصنيفات المنتجات
- جرد المخزون

### المستوى الثاني: المبيعات
- تسجيل بيع جديد
- فواتير اليوم
- تقارير المبيعات

### المستوى الثاني: العملاء
- قائمة العملاء
- إضافة عميل
- سجل العميل
- برنامج الولاء

### المستوى الثاني: الموردون
- قائمة الموردين
- طلبيات التوريد
- حسابات الموردين

### المستوى الثاني: التقارير
- تقارير المبيعات
- تقارير المخزون
- تقارير الأرباح
- تقارير الأداء

## تصنيف المنتجات
- المواد الغذائية الأساسية
- المشروبات
- الحلويات والوجبات الخفيفة
- منتجات النظافة والعناية الشخصية
- منتجات الأطفال
- الخضروات والفواكه (حسب الموسم)

## هيكل البيانات
- المنتج: اسم، سعر، تصنيف، كمية، تاريخ انتهاء
- العميل: اسم، رقم تواصل، عنوان، سجل مشتريات
- المورد: اسم، رقم تواصل، منتجات مورد، رصيد
- الفاتورة: رقم، تاريخ، عميل، منتجات، إجمالي

## مسارات التنقل
- لوحة التحكم ← مبيعات ← فاتورة جديدة
- لوحة التحكم ← مخزون ← إضافة منتج
- لوحة التحكم ← تقارير ← تقارير المبيعات
