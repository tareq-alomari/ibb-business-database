## 15.2 مكونات النظام (System Components)

| المكون | التقنية | المسؤولية |
|--------|---------|----------|
| تطبيق الجوال | Flutter / React Native | واجهة المستخدم للجوال |
| تطبيق الويب | React.js + Next.js | واجهة المستخدم للويب |
| API Gateway | Nginx / Kong | توجيه الطلبات، Rate Limiting |
| خدمة المصادقة | Node.js / Express | إدارة المستخدمين والتوكنات |
| خدمة الخدمات | Node.js / Express | إدارة الخدمات والتصنيفات |
| خدمة الحجوزات | Node.js / Express | إدارة الحجوزات والمواعيد |
| قاعدة البيانات | PostgreSQL 15 | التخزين الرئيسي للبيانات |
| التخزين | AWS S3 / MinIO | تخزين الصور والملفات |
| CDN | Cloudflare / CloudFront | تسريع تحميل المحتوى |

## 15.3 تدفق البيانات (Data Flow)

```
Client Request
  -> API Gateway (مصادقة + توجيه)
    -> Service (معالجة منطق الأعمال)
      -> Database (قراءة/كتابة)
    <- Service (استجابة JSON)
  <- API Gateway (استجابة مشكلة)
Client Response
```

## 15.4 استراتيجية التوسع (Scaling Strategy)

| المستوى | استراتيجية التوسع |
|---------|-----------------|
| أفقي (Horizontal) | إضافة نسخ من الخدمات المصغرة |
| عمودي (Vertical) | ترقية موارد الخادم |
| قاعدة البيانات | Read Replicas + Sharding |
| التخزين | CDN + Compression |
| API | Caching (Redis/Memcached) |
