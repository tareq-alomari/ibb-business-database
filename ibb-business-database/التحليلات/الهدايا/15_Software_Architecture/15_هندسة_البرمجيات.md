# هندسة البرمجيات: منصة الهدايا في إب

## نمط العمارة
- **العمارة:** Monolithic (للبساطة في البداية) مع إمكانية الانتقال إلى Microservices
- **النمط:** Model-View-Controller (MVC)

## المكونات الرئيسية

### الطبقة الأمامية (Frontend)
- تطبيق ويب: React.js + TailwindCSS (RTL)
- تطبيق جوال: React Native (مع مشاركة المكونات)
- دعم كامل للغة العربية والاتجاه RTL

### الطبقة الخلفية (Backend)
- Node.js مع Express.js
- ORM: Prisma (PostgreSQL)
- مصادقة: JWT + OTP
- تخزين الصور: Cloudinary أو تخزين محلي

### قواعد البيانات
- PostgreSQL - البيانات الرئيسية
- Redis - التخزين المؤقت والجلسات

### الخدمات المساعدة
- خدمة التوصيل: Google Maps API لحساب المسافات
- خدمة الإشعارات: Firebase Cloud Messaging
- خدمة الدفع: واجهة مع شركات الدفع المحلية

## تدفق البيانات
مستخدم ← React App ← Express API ← PostgreSQL
مستخدم ← React Native ← Express API ← PostgreSQL
بائع ← لوحة تحكم ويب ← Express API ← PostgreSQL

## Deployment
- استضافة: VPS (DigitalOcean أو Linode)
- Container: Docker + Docker Compose
- CDN: Cloudflare للصور والملفات الثابتة
- Monitoring: Sentry + UptimeRobot
