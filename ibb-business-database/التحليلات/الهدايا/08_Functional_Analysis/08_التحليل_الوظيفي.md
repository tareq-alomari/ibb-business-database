# التحليل الوظيفي: وظائف منصة الهدايا في إب

## الوظائف الأساسية (MVP)

### للمستخدمين
1. تسجيل الدخول (رقم جوال / بريد إلكتروني)
2. تصفح محلات الهدايا حسب الفئة
3. البحث عن المنتجات (اسم، فئة، سعر، محل)
4. عرض تفاصيل المنتج (صور، وصف، سعر، تقييمات)
5. إضافة إلى السلة وإدارة الطلب
6. اختيار طريقة الدفع (نقدي عند الاستلام / محفظة إلكترونية)
7. اختيار عنوان التوصيل
8. تتبع حالة الطلب
9. تقييم المنتج والمحل
10. إضافة هدايا إلى المفضلة

### لأصحاب المحلات
1. إنشاء وإدارة المتجر الإلكتروني
2. إضافة وتعديل المنتجات (صور، أسعار، كميات)
3. إدارة الطلبات (قبول، رفض، تجهيز)
4. لوحة تحكم بالمبيعات والإحصائيات
5. إدارة العروض والتخفيضات
6. التواصل مع العملاء

### لفريق التوصيل
1. عرض الطلبات المتاحة للتوصيل
2. تحديث حالة التوصيل (قيد التوصيل، تم التوصيل)
3. عرض خريطة المسار الأمثل

### للإدارة
1. لوحة تحكم مركزية
2. إدارة المحلات والمستخدمين
3. تقارير المبيعات والأداء
4. إدارة التوصيل والموزعين
