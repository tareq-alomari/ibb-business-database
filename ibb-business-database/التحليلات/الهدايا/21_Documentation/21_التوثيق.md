# التوثيق: منصة الهدايا في إب

## قائمة الوثائق

### توثيق التقني
1. **دليل التثبيت** - كيفية تشغيل المنصة محلياً
   - متطلبات النظام (Node.js 20+, PostgreSQL 16+, Redis)
   - خطوات التثبيت (clone, install, env, migrate, seed)
   - الأوامر الأساسية للتشغيل

2. **دليل الـ API** - توثيق كامل لواجهات البرمجة
   - Swagger UI متاح على /api/docs
   - جميع نقاط النهاية مع أمثلة الطلبات والاستجابات
   - رموز الأخطاء وكيفية معالجتها

3. **دليل قاعدة البيانات** - هيكل الجداول والعلاقات
   - ERD diagram
   - شرح كل جدول وحقول
   - قواعد البيانات المساعدة (Redis)

### توثيق المستخدم
4. **دليل المشتري** - كيفية استخدام المنصة
   - التسجيل وتسجيل الدخول
   - البحث عن المنتجات
   - تقديم الطلب والتوصيل
   - التقييم والمراجعة

5. **دليل البائع** - إدارة المتجر الإلكتروني
   - إنشاء المتجر وإضافة المنتجات
   - إدارة الطلبات
   - قراءة التقارير والإحصائيات

6. **دليل المندوب** - إدارة التوصيل
   - استلام الطلبات
   - تحديث حالة التوصيل
   - التواصل مع العملاء

### توثيق المشروع
7. **دليل المساهم** - للمطورين الجدد
   - بنية المشروع
   - معايير الكود
   - سير العمل (Git workflow)
