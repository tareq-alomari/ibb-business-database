# الرصة التقنية: منصة الهدايا في إب

## التقنيات المختارة

### الواجهة الأمامية (Web)
- **React.js 18** - إطار العمل الرئيسي
- **TailwindCSS** - تصميم سريع ومتجاوب
- **React Query** - إدارة حالة البيانات من السيرفر
- **React Router v6** - التوجيه والتنقل
- **Axios** - طلبات HTTP

### الواجهة الأمامية (Mobile)
- **React Native 0.73+** - تطبيق جوال عبر منصات
- **Expo** - تسريع التطوير
- **React Navigation** - التنقل بين الشاشات

### الخلفية (Backend)
- **Node.js 20 LTS** - بيئة التشغيل
- **Express.js 4** - إطار الخادم
- **Prisma** - ORM لقاعدة البيانات
- **PostgreSQL 16** - قاعدة البيانات
- **Redis 7** - تخزين مؤقت
- **JWT** - المصادقة
- **Socket.io** - اتصالات فورية (تتبع التوصيل)

### البنية التحتية
- **Docker + Docker Compose** - الحاوية
- **Nginx** - خادم وكيل عكسي
- **VPS (Ubuntu 22.04)** - استضافة
- **Git + GitHub** - التحكم بالنسخ
- **Cloudflare** - CDN وحماية

### أدوات التطوير
- **VS Code** - المحرر
- **ESLint + Prettier** - جودة الكود
- **Postman** - اختبار API
- **Figma** - التصميم والنمذجة
