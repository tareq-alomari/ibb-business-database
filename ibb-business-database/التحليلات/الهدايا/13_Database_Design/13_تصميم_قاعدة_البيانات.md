# تصميم قاعدة البيانات: منصة الهدايا في إب

## نظام إدارة قواعد البيانات
- PostgreSQL (قاعدة البيانات الرئيسية)
- Redis (تخزين مؤقت وجلسات)

## الجداول الرئيسية

### 1. Users (المستخدمون)
- id, name, phone, email, password_hash, role, address, created_at

### 2. Shops (المحلات)
- id, owner_id, name, description, logo, cover, phone, address, is_active, rating

### 3. Categories (الفئات)
- id, name, icon, parent_id, sort_order

### 4. Products (المنتجات)
- id, shop_id, category_id, name, description, price, images, stock, is_available, created_at

### 5. Orders (الطلبات)
- id, user_id, shop_id, total, status, payment_method, delivery_address, notes, created_at

### 6. Order Items (عناصر الطلب)
- id, order_id, product_id, quantity, price, wrapping_option

### 7. Reviews (التقييمات)
- id, user_id, shop_id, product_id, rating, comment, created_at

### 8. Deliveries (التوصيل)
- id, order_id, driver_id, status, pickup_time, delivery_time, fee

### 9. Payments (المدفوعات)
- id, order_id, amount, method, status, transaction_id, created_at

## العلاقات
- User 1→N Shop
- Shop 1→N Product
- User 1→N Order
- Shop 1→N Order
- Order 1→N OrderItem
- Product 1→N OrderItem
- Order 1→1 Delivery
