# لوحة التحكم: نظام التأمين الرقمي

## الصفحة الرئيسية (Dashboard Overview)
| العنصر | النوع |
|--------|-------|
| إجمالي الوثائق النشطة | Card Number |
| إجمالي المطالبات المعلقة | Card Number |
| إجمالي الإيرادات (شهريًا) | Card Number |
| عدد شركات التأمين | Card Number |
| الوثائق حسب النوع | Pie Chart |
| المطالبات حسب الحالة | Bar Chart |
| الإيرادات الشهرية | Line Chart |
| أحدث المطالبات | List |

## إدارة الوثائق
- قائمة الوثائق (جدول + بحث + فلتر)
- إصدار وثيقة جديدة (نموذج متعدد الخطوات)
- تفاصيل الوثيقة (عرض وتعديل)
- تجديد وثيقة
- إلغاء وثيقة

## إدارة المطالبات
- قائمة المطالبات المعلقة
- تفاصيل المطالبة (مستندات، تتبع)
- الموافقة على المطالبة أو رفضها
- صرف التعويضات

## إدارة العملاء
- قائمة العملاء
- ملف العميل (وثائقه، مطالباته)
- التواصل مع العميل

## إدارة الشركات والمنتجات
- قائمة شركات التأمين
- إضافة/تعديل شركة
- إدارة المنتجات التأمينية
- تعديل الأسعار والتغطيات

## التقارير
| التقرير | الوصف |
|---------|-------|
| تقرير الوثائق | عدد الوثائق المصدرة حسب النوع والفترة |
| تقرير المطالبات | عدد وقيمة المطالبات حسب الحالة |
| تقرير الإيرادات | الإيرادات الشهرية والسنوية |
| تقرير العملاء | عدد العملاء الجدد والنشطين |
| تقرير الأداء | أداء شركات التأمين (مقارنة) |
