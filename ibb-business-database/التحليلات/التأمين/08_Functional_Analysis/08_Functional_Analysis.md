# التحليل الوظيفي: نظام التأمين الرقمي لمحافظة إب

## قائمة الميزات المقترحة
| الرقم | الميزة | الأولوية | الوصف |
|-------|--------|----------|-------|
| F01 | إدارة الوثائق | عالية | إصدار وتجديد وإلغاء وثائق التأمين إلكترونيًا |
| F02 | حاسبة الأقساط | عالية | حساب تكلفة التأمين بناءً على نوع المركبة أو التغطية |
| F03 | تقديم المطالبات | عالية | تقديم مطالبات التعويض إلكترونيًا مع رفع المستندات |
| F04 | تتبع المطالبات | عالية | متابعة حالة المطالبة خطوة بخطوة |
| F05 | دليل شركات التأمين | عالية | معلومات عن جميع شركات ووكلاء التأمين في إب |
| F06 | مقارنة المنتجات | متوسطة | مقارنة أسعار وشروط التأمين بين الشركات |
| F07 | تنبيهات التجديد | عالية | إشعارات باقتراب موعد تجديد الوثيقة |
| F08 | ملف المستخدم | عالية | إدارة الوثائق والمطالبات الخاصة بالمستخدم |
| F09 | بوابة الدفع الإلكتروني | عالية | دفع الأقساط عبر الإنترنت |
| F10 | منصة توعية تأمينية | متوسطة | مقالات وإرشادات حول أهمية التأمين |

## الوحدات الأساسية
```
نظام التأمين الرقمي
├── وحدة إدارة العملاء
├── وحدة إدارة الوثائق
├── وحدة المطالبات
├── وحدة الدفع الإلكتروني
├── وحدة التقارير والإحصائيات
└── وحدة التوعية والإرشاد
```

## قواعد العمل
| الرقم | القاعدة |
|-------|---------|
| BR01 | يجب أن تحتوي كل وثيقة على نوع التغطية وقيمتها |
| BR02 | المطالبة تتطلب رفع مستندات الإثبات |
| BR03 | تجديد الوثيقة يتم قبل 30 يومًا من انتهائها |
| BR04 | مدة معالجة المطالبة لا تتجاوز 15 يوم عمل |
