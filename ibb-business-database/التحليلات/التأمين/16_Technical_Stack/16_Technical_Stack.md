# المجموعة التقنية: نظام التأمين الرقمي

## الواجهة الأمامية (Frontend)
| التقنية | الاستخدام |
|---------|-----------|
| React.js 18 | إطار عمل واجهة المستخدم |
| TypeScript | لغة البرمجة |
| Tailwind CSS | تصميم الواجهات |
| React Query | إدارة حالة البيانات |
| React Router | التنقل بين الصفحات |
| Axios | التواصل مع API |

## الواجهة الخلفية (Backend)
| التقنية | الاستخدام |
|---------|-----------|
| Node.js + Express | خادم API |
| TypeScript | لغة البرمجة |
| Prisma ORM | التعامل مع قاعدة البيانات |
| Zod | التحقق من صحة البيانات |
| JWT + bcrypt | المصادقة والتشفير |
| Nodemailer | إرسال الإشعارات البريدية |

## قاعدة البيانات
| التقنية | الاستخدام |
|---------|-----------|
| PostgreSQL 16 | قاعدة البيانات الرئيسية |
| Redis | التخزين المؤقت والجلسات |
