# بحث المستخدمين: شخصيات مستخدمي التأمين في إب

## الشخصية 1: علي - سائق سيارة أجرة
| الصفة | القيمة |
|-------|--------|
| العمر | 40 سنة |
| المهنة | سائق أجرة |
| المؤهل | ثانوية عامة |
| الموقع | مدينة إب |
| مستوى التقنية | منخفض (يستخدم واتساب فقط) |

### الأهداف
- الحصول على تأمين إلزامي بأسعار مناسبة
- تجديد الوثيقة سنويًا دون تعقيدات

### نقاط الألم
- أسعار التأمين مرتفعة بالنسبة لدخله
- لا يفهم شروط الوثيقة جيدًا
- يتعرض لغرامات عند انتهاء الوثيقة

## الشخصية 2: مها - موظفة في منظمة دولية
| الصفة | القيمة |
|-------|--------|
| العمر | 32 سنة |
| المهنة | مساعدة إدارية |
| المؤهل | بكالوريوس |
| الموقع | مدينة إب |

### الأهداف
- الحصول على تأمين صحي يغطي العائلة
- سهولة تقديم المطالبات واسترداد التكاليف

### نقاط الألم
- لا توجد تغطية صحية جيدة للأفراد
- إجراءات المطالبات معقدة وتستغرق وقتًا طويلاً

## الشخصية 3: أبو بكر - تاجر جملة
| الصفة | القيمة |
|-------|--------|
| العمر | 55 سنة |
| المهنة | تاجر مواد غذائية |
| المؤهل | دبلوم |
| الموقع | سوق إب التجاري |

### الأهداف
- تأمين بضائعه في المخازن ضد الحريق والسرقة
- تأمين شاحنات النقل

### نقاط الألم
- لا توجد خيارات تأمين مناسبة للتجار
- أقساط التأمين غير مرنة
