# تصميم واجهة المستخدم: بوابة التأمين الرقمية

## نظام التصميم

### لوحة الألوان
| الاستخدام | اللون | الكود |
|-----------|-------|-------|
| Primary | أزرق تأميني | #1565C0 |
| Secondary | أخضر | #2E7D32 |
| Accent | ذهبي | #FF8F00 |
| Background | أبيض | #FFFFFF |
| Text Primary | أسود داكن | #212121 |
| Text Secondary | رمادي | #757575 |
| Error | أحمر | #D32F2F |
| Success | أخضر فاتح | #4CAF50 |

### الخطوط
| الاستخدام | الخط | الحجم |
|-----------|------|-------|
| العناوين | Noto Kufi Arabic (Bold) | 24-36px |
| النصوص | Noto Sans Arabic (Regular) | 14-18px |
| التوضيحات | Noto Sans Arabic (Light) | 12px |

### المسافات
- الوحدة الأساسية: 8px
- Padding: 16px (افتراضي)، 24px (كبير)
- Margin بين الأقسام: 32px

### دعم RTL
- تصميم متكامل للغة العربية
- محاذاة النصوص والقوائم لليمين
- عكس اتجاه الأيقونات بما يتناسب مع RTL

### مكونات الواجهة
- أزرار بشعارات تأمينية واضحة
- بطاقات لعرض منتجات التأمين
- جداول لمقارنة الأسعار
- نموذج متعدد الخطوات لإصدار الوثائق
- شريط تقدم يُظهر حالة الإجراء
