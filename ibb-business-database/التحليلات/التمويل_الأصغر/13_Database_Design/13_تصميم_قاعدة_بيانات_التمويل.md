# تصميم قاعدة بيانات التمويل الأصغر في محافظة إب

## نموذج البيانات

### جدول العملاء (customers)
- customer_id (PK, INT)
- full_name (VARCHAR 100)
- national_id (VARCHAR 20, UNIQUE)
- phone_number (VARCHAR 15)
- gender (ENUM: male/female)
- date_of_birth (DATE)
- address (TEXT)
- district (VARCHAR 50)
- occupation (VARCHAR 50)
- monthly_income (DECIMAL 12,2)
- family_members (INT)
- registration_date (TIMESTAMP)

### جدول القروض (loans)
- loan_id (PK, INT)
- customer_id (FK, INT)
- product_type (ENUM)
- loan_amount (DECIMAL 12,2)
- interest_rate (DECIMAL 5,2)
- duration_months (INT)
- start_date (DATE)
- end_date (DATE)
- status (ENUM)
- collateral_type (VARCHAR 100)
- disbursement_date (DATE)
- created_at (TIMESTAMP)

### جدول الأقساط (installments)
- installment_id (PK, INT)
- loan_id (FK, INT)
- due_date (DATE)
- amount_due (DECIMAL 12,2)
- amount_paid (DECIMAL 12,2)
- payment_date (DATE)
- status (ENUM)
- late_days (INT)
- penalty_amount (DECIMAL 12,2)

### جدول المتابعات (follow_ups)
- follow_up_id (PK, INT)
- loan_id (FK, INT)
- officer_name (VARCHAR 100)
- visit_date (DATE)
- notes (TEXT)
- business_status (ENUM)

### جدول المستخدمين (users)
- user_id (PK, INT)
- username (VARCHAR 50, UNIQUE)
- password_hash (VARCHAR 255)
- role (ENUM)
- branch_id (FK, INT)
- last_login (TIMESTAMP)

## العلاقات
- customer 1 → N loans
- loan 1 → N installments
- loan 1 → N follow_ups
- branch 1 → N users

## فهارس مقترحة
- INDEX على national_id, phone_number
- INDEX على loan_status, start_date
- INDEX على installment_status, due_date
- INDEX على district, occupation
