# التوثيق - المدارس الأهلية في إب

## وثائق المشروع

### وثائق فنية
- **دليل العمارة:** شرح لهيكلة النظام والمكونات
- **دليل API:** توثيق كامل لجميع نقاط النهاية (Swagger)
- **دليل قاعدة البيانات:** ERD ونماذج البيانات والعلاقات
- **دليل النشر:** خطوات تثبيت وتشغيل النظام

### وثائق المستخدم
- **دليل المستخدم (ولي أمر):** كيفية التصفح والتسجيل والاستعلام
- **دليل المستخدم (إدارة المدرسة):** إدارة الطلاب والكوادر والرسوم
- **دليل المستخدم (مشرف المحافظة):** التقارير والإحصائيات والمتابعة

### وثائق المشروع
- **مخطط المشروع:** خطة العمل والجدول الزمني
- **تقرير التحليل:** تحليل السوق والمنافسين والمستخدمين
- **تقرير التصميم:** قرارات التصميم وهيكلة المعلومات
- **تقرير الاختبار:** نتائج الاختبارات وحالات الاستخدام

### معايير التوثيق
- اللغة: العربية (مع إمكانية الترجمة للإنجليزية للمصطلحات التقنية)
- التنسيق: Markdown للوثائق الداخلية، PDF للوثائق الرسمية
- التحديث: شهرياً أو عند إجراء تغييرات جوهرية
- التخزين: مجلد docs/ في مستودع المشروع

### قوالب التوثيق
- قالب لوصف API
- قالب لحالة استخدام
- قالب لتقرير خطأ
- قالب لتحديث النظام

## أدوات التوثيق
- Swagger للتوثيق التلقائي للـ API
- Storybook لمكونات الواجهة الأمامية
- JSDoc لتوثيق الكود
- Notion أو Confluence للوثائق الداخلية
