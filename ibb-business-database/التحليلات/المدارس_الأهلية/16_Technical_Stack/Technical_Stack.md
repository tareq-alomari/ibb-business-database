# التقنية المستخدمة - المدارس الأهلية في إب

## الواجهة الأمامية (Frontend)
- **الإطار:** Next.js 14 (React)
- **اللغة:** TypeScript
- **التصميم:** Tailwind CSS + shadcn/ui
- **الرسوم البيانية:** Chart.js أو Recharts
- **الخرائط:** Leaflet.js (خرائط تفاعلية للمدارس)

## الواجهة الخلفية (Backend)
- **الإطار:** Node.js + Express.js / NestJS
- **اللغة:** TypeScript
- **المصادقة:** JWT + bcrypt
- **التوثيق:** Swagger/OpenAPI

## قاعدة البيانات
- **قاعدة بيانات علائقية:** PostgreSQL
- **قاعدة بيانات غير علائقية:** Redis (للتخزين المؤقت)
- **أداة ORM:** Prisma أو TypeORM

## الاستضافة والبنية التحتية
- **السحابة:** خادم VPS في اليمن أو أقرب موقع (السعودية/مصر)
- **نظام التشغيل:** Ubuntu 22.04 LTS
- **الحاويات:** Docker + Docker Compose
- **خادم الويب:** Nginx (عكس وكيل)
- **CDN:** Cloudflare (تسريع المحتوى)

## أدوات إضافية
- **إدارة الإصدارات:** Git + GitHub
- **إدارة المشاريع:** Jira أو Trello
- **CI/CD:** GitHub Actions
- **المراقبة:** Sentry (تتبع الأخطاء)
- **البريد الإلكتروني:** SendGrid أو SMTP محلي

## متطلبات الأجهزة
- **RAM:** 4-8 GB
- **CPU:** 2-4 vCPU
- **Storage:** 100-200 GB SSD
- **نطاق ترددي:** غير محدود أو حسب الاستخدام
