# عمارة البرمجيات - المدارس الأهلية في إب

## نمط العمارة
MVC (Model-View-Controller) مع فصل كامل بين الطبقات

## الطبقات المعمارية

### طبقة العرض (Presentation Layer)
- واجهة مستخدم ويب (React/Next.js)
- لوحة تحكم إدارية
- واجهة متجاوبة للجوال
- تصيير من جانب الخادم (SSR) لمحتوى ثابت

### طبقة منطق الأعمال (Business Logic Layer)
- خدمات إدارة المدارس
- خدمات الطلاب والتسجيل
- خدمات الرسوم والتحصيل
- خدمات الامتحانات والدرجات
- خدمات التقارير والإحصائيات

### طبقة الوصول للبيانات (Data Access Layer)
- ORM للتعامل مع قاعدة البيانات
- مخبأ (Cache) للاستعلامات المتكررة
- طبقة تجريد لقواعد البيانات

### طبقة التكامل (Integration Layer)
- REST API نقاط نهاية موحدة
- Webhooks للتنبيهات والإشعارات
- واجهات تكامل مع أنظمة خارجية

## مخطط التفاعل بين المكونات

```
[المستخدم] ←→ [واجهة الويب]
                     ↓
              [REST API Gateway]
                     ↓
       ┌────────────┼────────────┐
       ↓            ↓            ↓
 [خدمات]    [خدمات]      [خدمات]
  المدارس    الطلاب       الرسوم
       ↓            ↓            ↓
  ┌─────────────────────────────────┐
  │       طبقة الوصول للبيانات      │
  │   [ORM] ←→ [Cache] ←→ [DB]    │
  └─────────────────────────────────┘
```

- Dependency Injection

- Service Layer Pattern
- Single Responsibility
