# تصميم واجهة المستخدم - المدارس الأهلية في إب

## هوية بصرية

### الألوان
- اللون الأساسي: أزرق داكن (#1B3A5C) - يرمز للثقة والمعرفة
- اللون الثانوي: أخضر (#2E7D32) - يرمز للنمو والتعليم
- لون الخلفية: أبيض (#FFFFFF) ورمادي فاتح (#F5F7FA)
- ألوان توضيحية للتصنيفات المختلفة

### الخطوط
- الخط العربي: أميري أو كايرو للعناوين
- الخط العربي: تاج أو كفا للنصوص
- أحجام متدرجة للعناوين (H1-H6)

## تصميم المكونات

### بطاقة المدرسة
```
[صورة المدرسة]
[اسم المدرسة] - [المنطقة]
⭐ 4.5 | 🎓 3 مراحل | 💰 150,000 ريال
[عرض التفاصيل]
```

### نموذج البحث
- حقل بحث بنص تلميحي
- فلاتر: المنطقة، المرحلة، الرسوم
- زر بحث بارز

### شريط التنقل
- شعار الموقع على اليسار
- روابط رئيسية في المنتصف
- زر دخول/تسجيل على اليمين

## الشاشات الرئيسية

### لوحة المعلومات (Dashboard)
- تصميم كروتي لمؤشرات الأداء
- رسوم بيانية ملونة
- جدول بيانات تفاعلي

### صفحة تسجيل طالب
- نموذج متعدد الخطوات
- شريط تقدم (1/4, 2/4, ...)
- أزرار "التالي" و"السابق"
- مراجعة قبل الإرسال

## الأنماط (Patterns)
- استخدام الأيقونات مع النصوص
- أزرار بحواف دائرية
- بطاقات مع ظلال خفيفة
- تحميل تدريجي (Skeleton screens)
