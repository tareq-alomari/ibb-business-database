# الأمن - المدارس الأهلية في إب

## سياسات الأمن

### إدارة الهوية والوصول
- تسجيل دخول آمن باستخدام JWT مع وقت انتهاء محدود
- صلاحيات وصول متدرجة (أدمن، مدير مدرسة، معلم، ولي أمر)
- تفعيل المصادقة الثنائية (2FA) للحسابات الحساسة
- سياسة كلمات مرور قوية (8+ أحرف، أحرف كبيرة وصغيرة، أرقام، رموز)

### تشفير البيانات
- تشفير البيانات أثناء النقل باستخدام HTTPS (TLS 1.3)
- تشفير البيانات الحساسة في قاعدة البيانات
- تشفير كلمات المرور باستخدام bcrypt
- إخفاء معلومات الدفع والفاتورة

### حماية التطبيق
- حماية من SQL Injection عبر ORM والاستعلامات المعدة مسبقاً
- حماية من XSS عبر تعقيم المدخلات
- حماية من CSRF عبر رموز مميزة
- تحديد معدل الطلبات (Rate Limiting)
- التحقق من صحة المدخلات من الطرفين (Client + Server)

### إدارة الجلسات
- جلسات آمنة مع وقت انتهاء محدد
- إبطال الجلسات عند تغيير كلمة المرور
- كشف الدخول غير المصرح به
- تسجيل جميع محاولات الدخول

### الخصوصية
- الامتثال لقانون حماية البيانات
- إخفاء المعلومات الشخصية الحساسة
- سياسة خصوصية واضحة للمستخدمين
- حذف البيانات بناءً على طلب المستخدم

### النسخ الاحتياطي
- نسخ احتياطي يومي لقاعدة البيانات
- نسخ احتياطي أسبوعي كامل
- تخزين النسخ في موقع منفصل
- اختبار استعادة البيانات شهرياً

### التدقيق والمراقبة
- سجل تدقيق لجميع العمليات الحساسة
- مراقبة آنية للاختراقات
- تقارير أمنية دورية
- تنبيهات عند اكتشاف نشاط مشبوه
