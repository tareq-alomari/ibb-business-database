## 6.1 قائمة الجهات المعنية (Stakeholders)

### أ. الجهات الأساسية (Primary Stakeholders)

| الجهة | الوصف | الدور في المشروع | مستوى التأثير | مستوى الاهتمام |
|-------|-------|------------------|--------------|---------------|
| **عملاء الخدمات** | سكان إب من مختلف الفئات | المستخدمون النهائيون للمنصة | عالي | عالي |
| **مقدمو الخدمة** | 50++ مقدم خدمة في المحافظة | مزودو الخدمة، شركاء المنصة | عالي | عالي |
| **العاملون في القطاع** | 300-500 عامل عامل | منفذو الخدمات | متوسط | عالي |

### ب. الجهات الداعمة (Secondary Stakeholders)

| الجهة | الوصف | الدور | مستوى التأثير |
|-------|-------|-------|--------------|
| **غرفة تجارة وصناعة إب** | دعم تجاري، تسهيلات | شريك استراتيجي | عالي |
| **مكتب الصناعة والتجارة - إب** | تراخيص، تنظيم | جهة تنظيمية | متوسط |
| **السلطة المحلية في إب** | المحافظ، المجلس المحلي | دعم سياسي | متوسط |
| **الجامعات المحلية** | جامعة إب، جامعة جبلة | دعم بحثي، تدريب طلاب | منخفض |

### ج. الجهات المساندة (Tertiary Stakeholders)

| الجهة | الوصف | الدور |
|-------|-------|-------|
| **شركات الدفع الإلكتروني** | باي موب، MTN Money | تكامل الدفع |
| **مزودو خدمة الإنترنت** | يمن نت، MTN، سبأفون | البنية التحتية |
| **المستثمرون المحليون** | رجال أعمال في إب | تمويل واستثمار |
| **وسائل الإعلام المحلية** | إذاعة إب، صحف محلية | تغطية إعلامية |

## 6.2 تحليل المصلحة والتأثير (Power-Interest Grid)

```
تأثير عالي
    │
    │   أبقي راضيًا              │   أدر بإحكام
    │   (Keep Satisfied)         │   (Manage Closely)
    │                            │
    │   • غرفة تجارة إب          │   • العملاء
    │   • مكتب الصناعة           │   • مقدمي الخدمة
    │   • السلطة المحلية         │   • العاملون
    │                            │
────┼────────────────────────────┼─────
    │                            │
    │   راقب (Monitor)           │   أبق على اطلاع
    │                            │   (Keep Informed)
    │   • شركات الدفع            │   • وسائل الإعلام
    │   • مزودو الإنترنت         │   • الجامعات
    │   • المستثمرون             │   • الجمعيات المهنية
    │                            │
    │                    مصلحة عالي
```

## 6.3 استراتيجية التواصل مع كل جهة

| الجهة | قناة التواصل | التكرار | المحتوى |
|-------|-------------|---------|---------|
| **العملاء** | إشعارات التطبيق، واتساب، فيسبوك | يومي | عروض، خدمات جديدة، تقييمات |
| **مقدمو الخدمة** | اتصال مباشر، واتساب بزنس، لقاءات | أسبوعي | تحديثات، إحصائيات، دعم فني |
| **غرفة تجارة إب** | اجتماعات شهرية، تقارير رسمية | شهري | تقدم المشروع، شراكات |
| **مكتب الصناعة** | خطاب رسمي، اجتماع | ربع سنوي | تراخيص، التزام بالقوانين |

## 6.4 متطلبات كل جهة من المنصة

| الجهة | المتطلبات الرئيسية |
|-------|-------------------|
| **العملاء** | سهولة الاستخدام، معلومات دقيقة، حجز سريع، أسعار محدثة |
| **مقدمو الخدمة** | وصول لعملاء جدد، تقارير أداء، إدارة سهلة للخدمات |
| **العاملون** | فرص عمل كافية، جدول مرن، أرباح عادلة، دعم فني |
| **غرفة تجارة إب** | إحصائيات القطاع، مساهمة في التنمية المحلية |
