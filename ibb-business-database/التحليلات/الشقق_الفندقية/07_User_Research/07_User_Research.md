## 7.1 شخصيات المستخدمين (User Personas)

### شخصية 1: أحمد - نزلاء (عائلات) (25 سنة)

| الخاصية | القيمة |
|---------|--------|
| **العمر** | 25 سنة |
| **المهنة** | موظف في القطاع الخاص |
| **المعيشة** | يسكن في مدينة إب |
| **الدخل الشهري** | 80,000 ريال |
| **استخدام التكنولوجيا** | عالي - هاتف ذكي، واتساب، فيسبوك |

**السلوكيات:**
- يبحث عن الخدمات عبر الإنترنت
- يقرأ التقييمات قبل الاختيار
- يفضل الحجز الإلكتروني

**الأهداف:**
- إيجاد أفضل الخدمات بأسعار مناسبة
- مقارنة الخيارات المتاحة
- حجز سريع بدون تعقيد

**الإحباطات:**
- صعوبة إيجاد معلومات كافية
- عدم وجود تقييمات موثوقة
- أسعار غير واضحة

### شخصية 2: خالد - أصحاب شقق فندقية (40 سنة)

| الخاصية | القيمة |
|---------|--------|
| **العمر** | 40 سنة |
| **المهنة** | صاحب منشأة |
| **الدخل الشهري** | يختلف حسب الموسم |
| **استخدام التكنولوجيا** | متوسط - واتساب وفيسبوك |

**السلوكيات:**
- يدير منشأته مع فريق صغير
- يستقبل الحجوزات عبر الهاتف
- يستخدم واتساب للتواصل

**الأهداف:**
- زيادة عدد الزبائن
- تنظيم الحجوزات
- تحسين السمعة

**الإحباطات:**
- صعوبة إدارة الحجوزات عبر الهاتف
- لا يعرف زبائنه الأكثر وفاءً
- صعوبة الترويج

## 7.2 رحلة المستخدم (User Journey)

| المرحلة | الإجراء | نقاط الألم | الفرصة |
|---------|--------|-----------|--------|
| **1. الاكتشاف** | يسمع عن منشأة من صديق | لا توجد معلومات كافية | منصة توفر بيانات كاملة |
| **2. البحث** | يفتح فيسبوك ويبحث | معلومات ناقصة | منصة بحث متكاملة |
| **3. التقييم** | يسأل أصدقاءه | آراء متضاربة | تقييمات حقيقية |
| **4. الاختيار** | يقرر الحجز | لا يعرف كيفية الحجز | حجز مباشر عبر المنصة |
| **5. الحجز** | يتصل بالمنشأة | الخط مشغول | حجز رقمي بدون اتصال |
| **6. الدفع** | يدفع نقدًا | نقد فقط | دفع إلكتروني |
| **7. التقييم** | يقول لصديقه | رأيه لا يؤثر | تقييم رقمي |
