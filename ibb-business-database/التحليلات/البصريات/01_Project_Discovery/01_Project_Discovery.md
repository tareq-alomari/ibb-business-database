# المرحلة الأولى: Project Discovery - قطاع البصريات في محافظة إب

> **التاريخ**:  يوليو 2026  
> **الملف**: 01_Project_Discovery.md

---

## 1.1 المشكلة (Problem Statement)

يعاني قطاع البصريات في محافظة إب من تحديات كبيرة رغم كونه قطاعًا حيويًا. لا توجد منصة موحدة تتيح للمستفيدين اكتشاف الخدمات أو مقارنتها. المشكلات الرئيسية:

1. **أسعار مرتفعة للنظارات الطبية**
2. **نقص أجهزة فحص النظر الحديثة**
3. **منافسة غير منظمة**
4. **غياب فحوصات مجانية**
5. **ضعف الوعي بصحة العين**

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لقطاع البصريات في محافظة إب** تتكون من:

- **دليل محلات البصريات**: قائمة بمراكز البصريات مع التخصصات
- **مقارنة الأسعار**: مقارنة أسعار النظارات والعدسات
- **حجز فحص نظر**: حجز مواعيد فحص النظر أونلاين
- **دليل العدسات**: أنواع العدسات اللاصقة ومميزاتها
- **تقييم المراكز**: تقييمات المستخدمين لجودة الخدمة

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستهلك/المواطن** | سهولة الوصول للمعلومات، مقارنة الخدمات، تقييمات حقيقية |
| **مزود الخدمة/البصريات** | وصول لشريحة أكبر، تحسين السمعة، إدارة رقمية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات، عمولات، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، مكاتب البصريات المحلية |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| حصر الجهات/البصريات | عدد المسجلين | 50++ |
| دقة البيانات | نسبة المعلومات المؤكدة | 90%+ |
| سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| رضا المستخدمين | تقييم المنصة | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن تكون المنصة الرقمية لقطاع البصريات في محافظة إب المرجع الأول الذي يعتمد عليه كل مواطن، محولة تجربة البصريات إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مزودي خدمات البصريات والمستفيدين في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - عدد كبير من مكاتب البصريات | - ارتفاع التكاليف |
| - طلب ثابت (حاجة طبية) | - معدات محدودة |
| - نمو الوعي بصحة العين | - غياب معايير جودة واضحة |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - توسع التأمين الصحي | - الوضع الاقتصادي |
| - الطلب على العدسات اللاصقة | - الاستيراد المباشر |
| - التجارة الإلكترونية | - عيادات متنقلة |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: عدم استقرار سياسي | خطر على استمرارية الأعمال |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | ارتفاع التكاليف، حساسية السعر |
| **S - Social**: كثافة سكانية عالية، شرائح متنوعة | فرصة كبيرة، تنوع الاحتياجات |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم رقمي | فرصة لتوحيد المعايير |
| **E - Environmental**: تحديات بيئية مختلفة | فرصة لنشر التوعية |
