## 21.2 دليل المستخدم

### للعميل:
1. تحميل التطبيق وإنشاء حساب
2. تفعيل الحساب عبر OTP
3. البحث عن الخدمة المطلوبة
4. حجز موعد وتأكيد الدفع
5. متابعة حالة الحجز
6. تقييم الخدمة

### لمزود الخدمة:
1. التسجيل كمزود خدمة
2. إضافة الخدمات وتحديد الأسعار
3. استقبال وإدارة الطلبات
4. تحديث حالة الطلبات
5. عرض التقارير

## 21.3 دليل النشر

```bash
npm install
cp .env.example .env
docker-compose up -d postgres redis
npx prisma migrate dev
npm run dev
```
