# تصميم API: الأسواق الموسمية في إب

## نمط التصميم
RESTful API مع JSON لتنسيق البيانات، ودعم التحديثات المباشرة عبر WebSockets.

## نقطة النهاية الأساسية
`https://api.ibbmarkets.ye/v1/`

## المصادقة
- JWT (JSON Web Tokens) للمصادقة.
- OAuth 2.0 للدخول عبر وسائل التواصل الاجتماعي.

## نقاط النهاية الرئيسية

### الأسواق
| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | /markets | قائمة بجميع الأسواق |
| GET | /markets/:id | تفاصيل سوق معين |
| GET | /markets/:id/vendors | بائعي سوق معين |

### البائعون
| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | /vendors/:id | تفاصيل بائع |
| POST | /vendors | تسجيل بائع جديد |
| PUT | /vendors/:id | تحديث بيانات بائع |
| GET | /vendors/:id/products | منتجات بائع معين |

### المنتجات
| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | /products | بحث عن منتجات |
| GET | /products/:id | تفاصيل منتج |
| POST | /products | إضافة منتج جديد |
| PUT | /products/:id | تحديث منتج |

### المبيعات
| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | /sales | تسجيل عملية بيع |
| GET | /sales/vendor/:id | مبيعات بائع معين |
| GET | /sales/buyer/:id | مشتريات مشتري معين |

### التقارير
| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | /reports/market-summary | ملخص سوق |
| GET | /reports/price-trends | اتجاهات الأسعار |
| GET | /reports/vendor-ranking | ترتيب البائعين |
