# الرصة التقنية: الأسواق الموسمية في إب

## الواجهة الأمامية (Frontend)
- **الويب**: React 18 مع Next.js 14 للتطبيق متعدد الصفحات وتحسين محركات البحث.
- **الموبايل**: React Native لتطبيق iOS وAndroid من قاعدة شيفرة واحدة.
- **إدارة الحالة**: Redux Toolkit لإدارة حالة التطبيق المعقدة.
- **التصميم**: Tailwind CSS مع مكتبة shadcn/ui للمكونات الجاهزة.
- **الخرائط**: Leaflet.js (مكتبة خرائط مفتوحة المصدر).

## الواجهة الخلفية (Backend)
- **لغة البرمجة**: TypeScript على Node.js.
- **الإطار**: Express.js لتطوير API سريع وقابل للتوسع.
- **المصادقة**: Passport.js مع JWT.
- **التوثيق**: Swagger/OpenAPI لتوثيق نقاط النهاية.
- **الاختبار**: Jest وSupertest لاختبارات الوحدة والتكامل.

## قاعدة البيانات
- **الرئيسية**: PostgreSQL 16 مع PostGIS للميزات الجغرافية.
- **التخزين المؤقت**: Redis لتسريع الاستعلامات المتكررة.
- **البحث**: Elasticsearch للبحث النصي عن المنتجات والبائعين.

## البنية التحتية (DevOps)
- **الحاويات**: Docker.
- **تنسيق الحاويات**: Kubernetes (Minikube للتطوير).
- **التكامل المستمر**: GitHub Actions.
- **مراقبة الأداء**: Prometheus وGrafana.
- **إدارة السجلات**: ELK Stack (Elasticsearch, Logstash, Kibana).

## الأدوات المساعدة
- **إدارة المشروع**: Jira أو Trello.
- **التصميم**: Figma للنماذج الأولية والتصاميم.
- **التعاون التقني**: GitHub مع Git Flow.
- **التخزين**: AWS S3 أو MinIO محلي للصور والملفات.

## اعتبارات خاصة بالبيئة المحلية
- دعم الاتصال بالإنترنت منخفض السرعة من خلال تحسين حجم الصفحات.
- إتاحة التطبيق بشكل غير متصل (Offline-first) للمناطق ضعيفة التغطية.
