# تصميم قاعدة البيانات: الأسواق الموسمية في إب

## نظام إدارة قواعد البيانات (DBMS)
سيتم استخدام PostgreSQL لقوته في التعامل مع البيانات الجغرافية المكانية واستعلاماتها.

## نموذج البيانات الرئيسي

### جدول الأسواق (markets)
- id (PK, UUID)
- name (VARCHAR, اسم السوق)
- day (VARCHAR, يوم السوق)
- location (GEOMETRY(Point, 4326), الموقع الجغرافي)
- district (VARCHAR, المديرية)
- description (TEXT)
- operating_hours (TIME[])
- status (ENUM: active, inactive)

### جدول البائعين (vendors)
- id (PK, UUID)
- user_id (FK, UUID)
- market_id (FK, UUID)
- stall_number (VARCHAR)
- category (ENUM)
- rating (DECIMAL)
- phone (VARCHAR)
- verified (BOOLEAN)

### جدول المنتجات (products)
- id (PK, UUID)
- vendor_id (FK, UUID)
- name (VARCHAR)
- category (ENUM: زراعي، حيواني، حرفي، غذائي)
- unit_price (DECIMAL)
- unit_type (VARCHAR)
- quantity_available (INT)
- description (TEXT)
- image_urls (TEXT[])
- created_at (TIMESTAMP)

### جدول المبيعات (sales)
- id (PK, UUID)
- vendor_id (FK, UUID)
- product_id (FK, UUID)
- buyer_id (FK, UUID)
- quantity (INT)
- total_price (DECIMAL)
- payment_method (ENUM)
- sale_date (TIMESTAMP)
- status (ENUM)

### جدول التقييمات (reviews)
- id (PK, UUID)
- vendor_id (FK, UUID)
- user_id (FK, UUID)
- rating (SMALLINT)
- comment (TEXT)
- created_at (TIMESTAMP)

## الفهارس (Indexes)
- فهرس مكاني على موقع السوق لتسريع البحث الجغرافي.
- فهرس مركب على (market_id, category) في جدول المنتجات.
- فهرس على تاريخ البيع في جدول المبيعات للتقارير الشهرية.
