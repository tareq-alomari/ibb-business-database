## 10.1 هيكل المعلومات (Information Architecture)

```
[تطبيق قطاع السباكة]
├── الصفحة الرئيسية
│   ├── بحث سريع
│   ├── خدمات مقترحة
│   ├── مقدمو خدمات مميزون
│   └── إحصائيات سريعة
├── الخدمات
│   ├── تصنيفات رئيسية
│   ├── تصنيفات فرعية
│   └── تفاصيل الخدمة
├── مقدم الخدمة
│   ├── بروفايل
│   ├── معرض أعمال
│   ├── تقييمات
│   └── جدول المواعيد
├── الحجوزات
│   ├── حجز جديد
│   ├── حجوزاتي
│   └── سجل الحجوزات
├── الملف الشخصي
│   ├── معلوماتي
│   ├── إعدادات
│   └── الإشعارات
└── لوحة التحكم (للمزود)
    ├── لوحة الإحصائيات
    ├── إدارة الخدمات
    ├── إدارة الطلبات
    └── التقارير
```

## 10.2 خريطة الموقع (Sitemap)

| المستوى | الصفحة | الوظيفة |
|---------|-------|--------|
| 1 | الرئيسية | عرض مميز، بحث سريع |
| 2 | نتائج البحث | عرض النتائج مع فلترة |
| 2 | تفاصيل الخدمة | معلومات كاملة عن الخدمة |
| 3 | ملف مقدم الخدمة | بروفايل وتصنيفات وأعمال |
| 3 | صفحة الحجز | اختيار موعد وتأكيد |
| 2 | ملف المستخدم | معلومات وحجوزات وتقييمات |
| 1 | لوحة التحكم | إدارة الخدمات والتقارير |

## 10.3 نظام التصنيف (Taxonomy)

| المستوى | المثال |
|---------|-------|
| **الفئة الرئيسية** | نوع الخدمة الأساسي |
| **الفئة الفرعية** | تخصص دقيق ضمن الفئة |
| **الموقع** | المنطقة/المديرية |
| **مستوى السعر** | اقتصادي / متوسط / متميز |
| **التقييم** | 1-5 نجوم |

## 10.4 تدفق المستخدم (User Flow)

### تدفق العميل:
```
فتح التطبيق -> الصفحة الرئيسية -> بحث/تصفح
  -> نتائج البحث -> اختيار مزود -> عرض البروفايل
  -> حجز موعد -> تأكيد الحجز -> إشعار
  -> تلقي الخدمة -> تقييم
```

### تدفق مزود الخدمة:
```
تسجيل الدخول -> لوحة التحكم -> استعراض الطلبات
  -> قبول/رفض طلب -> تحديث الحالة
  -> إضافة خدمات -> عرض التقارير
```
