## 8.1 قائمة المتطلبات الوظيفية (Functional Requirements)

### لمقدمي الخدمة (Provider Side)

- **F9**: ملف سباك
- **F10**: استقبال طلبات
- **F11**: إدارة مواعيد
- **F12**: فواتير
- **F13**: مخزون قطع
- **F14**: تقارير

### للعملاء (Customer Side)

- **F1**: تسجيل
- **F2**: طلب سباك
- **F3**: حجز عاجل
- **F4**: وصف المشكلة
- **F5**: تحديد موعد
- **F6**: متابعة
- **F7**: دفع
- **F8**: تقييم

## 8.2 حالات الاستخدام (Use Cases)

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة معينة باستخدام الكلمات المفتاحية أو التصنيفات
- **المتطلبات**: F1, F2, F3
- **النتيجة**: عرض قائمة بمقدمي الخدمة المطابقين لمعايير البحث

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز موعد مع مقدم خدمة معين
- **المتطلبات**: F2, F4, F5, F6
- **النتيجة**: تأكيد الحجز وإشعار الطرفين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مدير الخدمة الطلبات الواردة ويدير حالاتها
- **المتطلبات**: F9, F10, F11, F12
- **النتيجة**: تحديث حالة الطلب وإشعار العميل

## 8.3 تدفق البيانات (Data Flow)

```
عميل -> [تطبيق الجوال/الويب] -> API Gateway -> [خدمات المصادقة]
  -> [خدمة البحث] -> [قاعدة البيانات] -> نتائج البحث
  -> [خدمة الحجز] -> [قاعدة البيانات] -> تأكيد الحجز
  -> [خدمة الدفع] -> [بوابة الدفع] -> إشعار الدفع
مزود -> [تطبيق المزود] -> API Gateway -> [خدمة إدارة الطلبات]
  -> [خدمة الإشعارات] -> إشعار للعميل
```

| التقييمات | عالية | متوسط | P1 |
| الدفع الإلكتروني | متوسطة | عالي | P2 |
| الخريطة التفاعلية | متوسطة | متوسط | P2 |
