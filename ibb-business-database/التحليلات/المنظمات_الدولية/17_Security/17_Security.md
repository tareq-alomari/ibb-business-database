## 17.2 الإجراءات الأمنية
| المجال | الإجراءات |
|--------|----------|
| التشفير | HTTPS TLS 1.3, AES-256 للبيانات الحساسة |
| المصادقة | JWT, OTP للتحقق الثنائي |
| المدخلات | Sanitize, Prepared Statements |
| XSS | Content Security Policy |
| CSRF | CSRF Tokens, SameSite Cookies |
| النسخ | Backup يومي مشفر |
