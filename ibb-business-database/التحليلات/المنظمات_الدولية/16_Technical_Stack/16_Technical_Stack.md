## 16.1 التقنيات المقترحة
| الطبقة | التقنية | السبب |
|--------|---------|------|
| Frontend Web | React + Next.js + TS | أداء SEO |
| Mobile Android | Kotlin + Jetpack Compose | تطبيق أصلي |
| Mobile iOS | Swift + SwiftUI | تطبيق أصلي |
| Backend | Node.js (NestJS) | سرعة تطوير |
| Database | PostgreSQL | علاقات قوية |
| Cache | Redis | تخزين مؤقت |
| Search | Elasticsearch | فهرسة وبحث |
| Storage | MinIO/S3 | تخزين ملفات |
| Maps | OpenStreetMap | مجاني دون إنترنت |

## 16.2 متطلبات النظام
**الحد الأدنى للتطبيق**: Android 8+, iOS 13+, 2GB RAM, اتصال متقطع
**الخادم الأدنى**: 4 CPU, 8GB RAM, 100GB SSD, Ubuntu 22.04
