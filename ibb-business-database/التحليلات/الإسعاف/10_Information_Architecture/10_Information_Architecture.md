## 10.1 هيكل المعلومات العام

تطبيق إسعاف إب → [الصفحة الرئيسية | قائمة الجهات | صفحة جهة | العروض | لوحة التحكم]

## 10.2 نظام التصنيف

| المستوى | التصنيف |
|---------|---------|
| حسب النوع | سيارات إسعاف حكومية | تخصص سيارات إسعاف حكومية |
| حسب النوع | إسعاف خاص | تخصص إسعاف خاص |
| حسب النوع | مراكز طوارئ متنقلة | تخصص مراكز طوارئ متنقلة |
| حسب النوع | إسعاف المستشفيات | تخصص إسعاف المستشفيات |
| حسب النوع | نقل مرضى | تخصص نقل مرضى |

## 10.3 Sitemap

/ ← الصفحة الرئيسية
/list ← قائمة الجهات
/list/:id ← صفحة جهة
/list/:id/reviews ← تقييمات
/favorites ← المفضلة
/offers ← العروض

## 10.4 User Flow

فتح التطبيق → بحث/تصفح → اختيار جهة → عرض التفاصيل → تواصل → تقييم
