# التوثيق: السوبرماركت في إب

## دليل المستخدم

### للمتسوقين (تطبيق الجوال)
- كيفية إنشاء حساب جديد
- كيفية تصفح المنتجات والبحث عنها
- كيفية إضافة منتجات إلى سلة التسوق
- كيفية إتمام عملية الشراء والدفع
- كيفية تتبع طلب التوصيل
- كيفية التواصل مع الدعم الفني

### للموظفين (نظام نقاط البيع)
- تسجيل الدخول إلى النظام
- إتمام عملية بيع
- إدارة المرتجعات
- طباعة الفواتير
- إغلاق الوردية اليومية
- تقارير نهاية اليوم

### للإدارة (لوحة التحكم)
- نظرة عامة على المؤشرات
- إدارة المنتجات والمخزون
- إدارة العملاء والموردين
- إنشاء وعرض التقارير
- إدارة صلاحيات الموظفين
- إعدادات النظام

## التوثيق الفني

### دليل المطور
- بنية المشروع وهيكل المجلدات
- تعليمات تثبيت بيئة التطوير
- شرح قاعدة البيانات والعلاقات
- توثيق API (Swagger/OpenAPI)
- تعليمات النشر والتشغيل
- استراتيجية الاختبارات

### دليل الصيانة
- كيفية عمل نسخ احتياطي
- كيفية استعادة البيانات
- إجراءات حل المشكلات الشائعة
- قائمة جهات الاتصال للدعم الفني
- جدول الصيانة الدورية
