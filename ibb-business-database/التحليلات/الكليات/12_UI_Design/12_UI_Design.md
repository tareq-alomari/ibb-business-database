# تصميم واجهات المستخدم - منصة الكليات في إب

## الهوية البصرية

### الألوان الرئيسية
- اللون الأساسي: أزرق داكن (#1A237E) - يرمز للثقة والمعرفة.
- اللون الثانوي: أخضر (#2E7D32) - يرمز للنمو والتعليم.
- لون مميز: ذهبي (#FF8F00) - للعناصر التفاعلية والتقييمات.
- خلفية فاتحة: (#F5F7FA) للصفحات.
- نصوص داكنة: (#212121) للقراءة المريحة.

### الخطوط
- الخط الرئيسي: Amiri للنصوص العربية (مجاني وجميل).
- خط العناوين: Tajawal أو Cairo للعناوين.
- أحجام متناسقة: H1 (2rem)، H2 (1.5rem)، نص (1rem).

## تخطيط الصفحات

### الصفحة الرئيسية
```
+---------------------------------------------------+
| Header: شعار + بحث + قائمة تصفح                    |
+---------------------------------------------------+
| Hero: صورة بانر + شعار المنصة + شريط البحث الكبير  |
+---------------------------------------------------+
| تصنيفات سريعة (3 بطاقات: جامعة إب | جبلة | أهلية) |
+---------------------------------------------------+
| إحصائيات سريعة (عدد الكليات، التخصصات، الطلاب)     |
+---------------------------------------------------+
| أحدث الكليات المضافة (4 بطاقات في Grid)            |
+---------------------------------------------------+
| خريطة تفاعلية (مصغرة)                               |
+---------------------------------------------------+
| Footer: روابط، تواصل اجتماعي                     |
+---------------------------------------------------+
```

### صفحة الكلية
```
+---------------------------------------------------+
| Header + Breadcrumbs                               |
+---------------------------------------------------+
| اسم الكلية + التقييم + صورة رئيسية                |
+---------------------------------------------------+
| tabs: معلومات | تخصصات | تقييمات | صور             |
+---------------------------------------------------+
| المحتوى حسب التاب المحدد                          |
+---------------------------------------------------+
| شريط جانبي: معلومات الاتصال، خريطة الموقع          |
+---------------------------------------------------+
```

## حالة الجوال (Responsive)
- قائمة همبرغر للجوال.
- بطاقات بعرض كامل (بدون Grid للشاشات الصغيرة).
- أزرار لمس كبيرة ومناسبة للأصابع.
- تصغير حجم الخطوط مع الحفاظ على وضوح القراءة.

## عناصر واجهة محددة
- أيقونات: Font Awesome للمرافق والتخصصات.
- أزرار: ذات زوايا دائرية (border-radius: 8px).
- بطاقات: ظل خفيف (box-shadow) مع hover effect.
- تقييم نجمي: نجوم تفاعلية قابلة للنقر.
