## 5.1 التحليل التنافسي للمنصة المقترحة

### المنافسون المباشرون

| المنافس | الوصف | نقاط القوة | نقاط الضعف |
|---------|-------|-----------|------------|
| **مجموعات فيسبوك** | مجتمعات محلية | مجتمع نشط | غير منظمة، معلومات مبعثرة |
| **واتساب بزنس** | تواصل مباشر | بسيط، مباشر | محدودية، لا بحث |
| **Google Maps** | بحث عبر جوجل | مجاني | بيانات غير كاملة |

### المنافسون غير المباشرين

| المنافس | الوصف |
|---------|-------|
| **الإعلانات التقليدية** | إعلانات ورقية ومحلية |
| **التواصل المباشر** | المستخدم يتصل بالمنشأة مباشرة |

## 5.2 تحليل SWOT للمنصة مقابل المنافسين

| | |
|---|--------|
| **S (القوة)** | - تركيز حصري على إب<br>- فهم عميق للسياق المحلي<br>- دعم المجتمع المحلي |
| **W (الضعف)** | - تقنية محدودة مقارنة بالمنافسين<br>- ميزانية أصغر<br>- لا علامة تجارية معروفة |
| **O (الفرص)** | - لا منافس محلي في إب حاليًا<br>- طلب متزايد على الخدمات الرقمية |
| **T (التهديدات)** | - ظهور منافس محلي آخر<br>- تغير العادات الاستهلاكية |

## 5.3 Competitive Advantage

| الميزة | التفاصيل |
|--------|----------|
| **محلية كاملة** | منصة مخصصة لمحافظة إب فقط |
| **محتوى شامل** | دليل كامل مع تقييمات وصور |
| **مجانية للمنشآت (basic)** | نموذج Freemium |

## 5.4 تحليل المنشآت المنافسة

| المنشأة | نقاط القوة | نقاط الضعف | استراتيجية التميز |
|---------|-----------|------------|-------------------|
| مقهى الروز | سمعة قوية | أسعار مرتفعة | الجودة والثبات |
| مقهى القهوة التركية | خدمة جيدة | موقع غير مركزي | الخدمة المميزة |
| مقهى الشباب | خبرة طويلة | قديم نسبيًا | الأصالة |
| مقهى المكتبة | موقع ممتاز | محدودية | الموقع |
| مقهى الجامعة | أسعار مناسبة | خدمات محدودة | السعر |

## 5.5 استراتيجية المنافسة للمنصة

| الاستراتيجية | التطبيق |
|--------------|---------|
| **First Mover Advantage** | الدخول أولاً في سوق إب |
| **Local Focus** | التركيز على إب فقط |
| **Free Basic Listing** | تسجيل المنشأة مجانًا |
| **التوسع التدريجي** | البدء بمدينة إب ثم المديريات |
