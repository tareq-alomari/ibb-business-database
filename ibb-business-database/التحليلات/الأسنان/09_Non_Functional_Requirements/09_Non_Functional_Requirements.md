## 9.1 متطلبات الأداء

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| PERF1 | زمن تحميل الصفحة الرئيسية | < 1.5 ثانية |
| PERF2 | زمن تحميل التفاصيل | < 1 ثانية |
| PERF3 | زمن البحث | < 500ms |

## 9.2 متطلبات التوفر

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| AVAIL1 | uptime النظام | 99.5% |
| AVAIL2 | النسخ الاحتياطي | يومي، احتفاظ بـ 30 يومًا |
| AVAIL3 | دعم الأوفلاين (PWA) | تصفح بدون إنترنت |

## 9.3 متطلبات الأمان

| المعرف | المتطلب |
|--------|---------|
| SEC1 | تشفير البيانات (TLS 1.3 + AES-256) |
| SEC2 | المصادقة (JWT + OTP) |
| SEC3 | حماية API (Rate limiting) |
| SEC4 | صلاحيات الأدوار (RBAC) |

## 9.4 متطلبات الاستخدامية

| المعرف | المتطلب |
|--------|---------|
| USE1 | واجهة عربية 100% |
| USE2 | خط قابل للتكبير |
| USE3 | تباين عالي، وضع النهار والليل |
| USE4 | تجربة مستخدم جديدة < 3 خطوات |

## 9.5 متطلبات التوافق

| المعرف | المتطلب |
|--------|---------|
| COMP1 | Android 8.0+ |
| COMP2 | iOS 13+ |
| COMP3 | PWA متوافقة مع Chrome 80+ |
| COMP4 | إنترنت 3G/4G |
