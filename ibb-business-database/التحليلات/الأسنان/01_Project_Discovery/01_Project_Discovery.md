# المرحلة الأولى: Project Discovery - قطاع عيادات ومراكز الأسنان في محافظة إب

## 1.1 المشكلة (Problem Statement)

يعاني قطاع عيادات ومراكز الأسنان في محافظة إب من **تشتت وتنظيم معلوماتي ضعيف** رغم كونه قطاعًا حيويًا. تشتت معلومات عيادات الأسنان، صعوبة حجز المواعيد، غياب التقييمات الموثوقة. المشكلات الرئيسية:

1. **صعوبة الاكتشاف**: معلومات القطاع مبعثرة بين فيسبوك وواتساب والتواصل الشفهي
2. **غياب التقييمات الموثوقة**: لا توجد مراجع موثوقة لتقييم الجهات الفاعلة
3. **ضعف التسعير الشفاف**: الأسعار متفاوتة وغير موحدة
4. **ضعف التواجد الرقمي**: معظم الجهات ليس لها حضور على الإنترنت
5. **صعوبة المنافسة العادلة**: الجهات الجيدة لا تجد وسيلة للتميز

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لعيادات ومراكز الأسنان في محافظة إب** تتكون من:

- **دليل شامل** لجميع الجهات الفاعلة مع تصنيف حسب النوع والموقع والأسعار
- **نظام تقييم ومراجعات**: تقييمات موثقة من المستخدمين مع صور
- **منصة تواصل**: ربط العملاء بمقدمي الخدمات مباشرة
- **خريطة تفاعلية**: عرض الجهات على الخريطة مع مواقعها
- **لوحة تحكم**: إدارة متكاملة للجهات المسجلة

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **العملاء/المستهلكون** | اكتشاف جهات جديدة، مقارنة الأسعار، قراءة تقييمات حقيقية |
| **أصحاب الأعمال** | وصول لشريحة أكبر من العملاء، تحسين السمعة، إدارة العروض |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |
| **الباحثون** | بيانات عن أنماط القطاع في المحافظة |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات العيادات، حجوزات مدفوعة، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، الجهات المختصة بالقطاع |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| G1: حصر الجهات | عدد الجهات المسجلة | 100+ |
| G2: دقة البيانات | نسبة البيانات المؤكدة | 90%+ |
| G3: سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| G4: رضا المستخدمين | تقييم التطبيق | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن يكون دليل عيادات الأسنان الرقمي في محافظة إب المنصة الأولى لاختيار خدمات طب الأسنان."

### Mission
"بناء منصة رقمية تربط بين عيادات الأسنان والمرضى في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - كثافة سكانية عالية تضمن طلبًا مستمرًا | - ضعف البنية التحتية للإنترنت في الأرياف |
| - قطاع حيوي ومتنوع | - انقطاع الكهرباء يؤثر على القطاع |
| - انتشار الهواتف الذكية (95%+ في المدينة) | - ضعف الثقافة الرقمية لدى بعض الفاعلين |
| - وجود عدد كبير من الجهات الفاعلة | - محدودية خدمات الدفع الإلكتروني |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - تحول رقمي متزايد في القطاع | - الوضع الاقتصادي المتراجع |
| - طلب متزايد على الخدمات الرقمية | - عدم استقرار الأسعار |
| - شريحة شبابية كبيرة (60%+ تحت 30 سنة) | - دخول منصات من خارج إب |
| - السياحة الداخلية (مصايف إب في الصيف) | - صعوبة تغطية المناطق الريفية |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: محافظة إب تحت سيطرة الحوثي، عدم استقرار مؤسسي | خطر على استمرارية الأعمال |
| **E - Economic**: تدهور العملة، انخفاض القوة الشرائية | تأثير على الإنفاق في القطاع |
| **S - Social**: احتياجات متنوعة للسكان | فرصة لتلبية احتياجات متنوعة |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم واضح | فرصة لتوحيد المعايير |
| **E - Environmental**: ظروف بيئية متنوعة | فرصة لنشر التوعية |

| الخطر | الاحتمالية | التأثير | خطة التخفيف |
|-------|-----------|---------|------------|

| أمن بيانات المستخدمين | منخفضة | عالي | تشفير، خصوصية |
