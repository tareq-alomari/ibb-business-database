## 10.1 هيكل المعلومات العام

تطبيق أسناني في إب → [الصفحة الرئيسية | قائمة الجهات | صفحة جهة | العروض | لوحة التحكم]

## 10.2 نظام التصنيف

| المستوى | التصنيف |
|---------|---------|
| حسب النوع | عيادات عامة | تخصص عيادات عامة |
| حسب النوع | مراكز تجميل أسنان | تخصص مراكز تجميل أسنان |
| حسب النوع | عيادات أطفال | تخصص عيادات أطفال |
| حسب النوع | مراكز تقويم | تخصص مراكز تقويم |
| حسب النوع | عيادات جراحة فم | تخصص عيادات جراحة فم |

## 10.3 Sitemap

/ ← الصفحة الرئيسية
/list ← قائمة الجهات
/list/:id ← صفحة جهة
/list/:id/reviews ← تقييمات
/favorites ← المفضلة
/offers ← العروض

## 10.4 User Flow

فتح التطبيق → بحث/تصفح → اختيار جهة → عرض التفاصيل → تواصل → تقييم
