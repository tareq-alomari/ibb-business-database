# تجربة المستخدم - قطاع الأثاث في محافظة إب

---

## تدفق المستخدم - البحث عن أثاث

```
[دخول المستخدم]
    ↓
[الصفحة الرئيسية - شريط البحث أو التصنيفات]
    ↓
[اختيار تصنيف (مثل: أثاث منزلي) أو كتابة كلمة بحث]
    ↓
[نتائج البحث مع فلترة (سعر، نوع، موقع)]
    ↓
[اختيار منتج أو معرض]
    ↓
[صفحة المنتج / المعرض]
    ├── صور ومواصفات
    ├── السعر والتوفر
    ├── التقييمات
    └── موقع المعرض على الخريطة
    ↓
[إجراءات]
    ├── الاتصال بالمعرض
    ├── الحصول على الاتجاهات
    ├── مشاركة المنتج
    └── كتابة تقييم
```

## تدفق المستخدم - إضافة معرض جديد

```
[تسجيل الدخول كصاحب معرض]
    ↓
[لوحة التحكم]
    ↓
[إضافة معرض جديد]
    ├── اسم المعرض
    ├── التصنيف
    ├── معلومات الاتصال
    ├── الموقع (GPS)
    ├── صور المعرض
    └── أوقات العمل
    ↓
[مراجعة وإرسال]
    ↓
[الموافقة والنشر]
```

## إرشادات UX

- تصميم بسيط وواضح مع ألوان دافئة تناسب طابع الأثاث
- أيقونات بصرية للتصنيفات لتسهيل التصفح
- خاصية المعاينة السريعة للمنتجات بدون فتح الصفحة
- دعم كامل للغة العربية والكتابة من اليمين لليسار
- تحميل تدريجي للصور لتسريع التصفح
- أزرار واضحة للاتصال المباشر عبر واتساب
