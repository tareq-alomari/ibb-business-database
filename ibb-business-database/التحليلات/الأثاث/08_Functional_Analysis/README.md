# التحليل الوظيفي - قطاع الأثاث في محافظة إب

---

## قائمة الميزات

| الرقم | الميزة | الأولوية | الوصف |
|-------|--------|----------|-------|
| F01 | بحث متقدم | عالية | بحث بالاسم، النوع، السعر، الموقع |
| F02 | تصنيف الأثاث | عالية | 8 مجالات فرعية حسب النوع والاستخدام |
| F03 | ملف المعرض | عالية | صفحة كاملة بكل المعلومات والمنتجات |
| F04 | صفحة المنتج | عالية | صور، مواصفات، سعر، تقييمات |
| F05 | مقارنة المنتجات | متوسطة | مقارنة بين منتجين أو أكثر |
| F06 | التقييم والمراجعات | عالية | تقييم ومراجعة من المستخدمين |
| F07 | الخريطة التفاعلية | عالية | عرض المعارض على الخريطة |
| F08 | التقارير والإحصائيات | متوسطة | تقارير عن القطاع |
| F09 | المسارات | متوسطة | تحديد المسار إلى المعرض |
| F10 | API مفتوح | منخفضة | للتكامل مع الأنظمة الأخرى |

## قواعد العمل

| الرقم | القاعدة |
|-------|---------|
| BR01 | كل معرض يجب أن ينتمي إلى تصنيف فرعي واحد على الأقل |
| BR02 | يجب أن يحتوي المنتج على اسم، سعر، وفئة |
| BR03 | المستخدمون المسجلون فقط يمكنهم إضافة تقييمات |
| BR04 | كل تقييم يخضع للمراجعة قبل النشر |
| BR05 | يتم التحقق من المعارض بواسطة الفريق الميداني |
