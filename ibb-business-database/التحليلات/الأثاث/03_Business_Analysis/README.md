# التحليل التجاري - قطاع الأثاث في محافظة إب

---

## نموذج العمل

| العنصر | الوصف |
|--------|-------|
| الجمهور المستهدف | المواطنون، الشركات، الفنادق، المؤسسات الحكومية |
| مصادر الإيرادات | عمولات البيع، إعلانات المعارض، خدمات متميزة |
| القنوات | تطبيق ويب، تطبيق موبايل، وسائل التواصل الاجتماعي |
| الشركاء | معارض الأثاث، ورش النجارة، موردو المواد الخام |

## تحليل سلسلة القيمة

```
موردو المواد الخام
    ↓
مصنعو وورش الأثاث
    ↓
موزعو الجملة
    ↓
معارض ومحلات التجزئة
    ↓
المستهلك النهائي
```

## مصادر الإيرادات المقترحة

| المصدر | الوصف |
|--------|-------|
| إعلانات متميزة للمعارض | ظهور في أعلى نتائج البحث |
| اشتراكات شهرية للمحلات | إدارة ملفات رقمية وعروض |
| عمولة مبيعات | نسبة على المبيعات عبر المنصة |
| خدمات استشارية | دراسات سوق وتحليل منافسين |
