## الصفحات

### إدارة المعارض

- قائمة المعارض (جدول + بحث + فلتر)
- إضافة معرض جديد
- تعديل بيانات معرض
- حذف معرض
- التحقق من المعارض (توثيق)
- تفعيل / تعليق معرض

### إدارة المنتجات

- قائمة المنتجات
- إضافة / تعديل / حذف منتج
- إدارة صور المنتجات
- تحديد التوفر والسعر

### إدارة التصنيفات

- قائمة التصنيفات
- إضافة / تعديل / حذف تصنيف
- ترتيب التصنيفات
- إدارة التصنيفات الفرعية

### إدارة المستخدمين

- قائمة المستخدمين
- تعديل صلاحيات
- تعليق / تفعيل حساب

### إدارة التقييمات

- قائمة التقييمات المعلقة
- موافقة / رفض تقييم
- الإبلاغ عن تقييمات مخالفة

### التقارير

| التقرير | الوصف |
|---------|-------|
| تقرير المعارض | Excel/PDF حسب المديرية والتصنيف |
| تقرير المنتجات | قائمة المنتجات حسب الفئة والسعر |
| تقرير التقييمات | متوسط التقييمات لكل معرض |
| تقرير المديريات | تغطية كل مديرية |
