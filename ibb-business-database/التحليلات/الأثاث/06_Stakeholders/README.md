# أصحاب المصلحة - قطاع الأثاث في محافظة إب

---

## مصفوفة أصحاب المصلحة

| صاحب المصلحة | الدور | الاحتياجات | الأولوية |
|--------------|-------|------------|----------|
| **المواطن / المستهلك** | مستخدم نهائي | بحث سهل، مقارنة أسعار، تقييمات موثوقة | عالية |
| **صاحب معرض الأثاث** | مزود خدمة | تسويق منتجاته، وصول لزبائن جدد | عالية |
| **صانع الأثاث / النجار** | حرفي | عرض أعماله، جذب زبائن | متوسطة |
| **موردو المواد الخام** | مزود | وصول لورش النجارة | منخفضة |
| **الغرفة التجارية** | جهة تنظيمية | بيانات القطاع، إحصائيات | متوسطة |
| **المجلس المحلي** | جهة حكومية | تنظيم السوق، جذب الاستثمار | متوسطة |
| **المقاولون والمهندسون** | مستخدم متخصص | أثاث للمشاريع، عروض خاصة | متوسطة |
| **شركات الشحن والنقل** | مزود خدمة | توصيل الأثاث للزبائن | منخفضة |

## تحليل التأثير والاهتمام

| الربع | أصحاب المصلحة |
|-------|---------------|
| **اهتمام عال / تأثير عال** | أصحاب المعارض، المستهلكون |
| **اهتمام عال / تأثير منخفض** | صناع الأثاث، المقاولون |
| **اهتمام منخفض / تأثير عال** | الغرفة التجارية، المجلس المحلي |
| **اهتمام منخفض / تأثير منخفض** | موردو المواد الخام، شركات الشحن |

## استراتيجية التواصل

| صاحب المصلحة | قناة التواصل | التردد |
|--------------|--------------|--------|
| أصحاب المعارض | زيارات ميدانية، واتساب | شهرياً |
| المستهلكون | وسائل التواصل، الإعلانات | أسبوعياً |
| الغرفة التجارية | تقارير رسمية، اجتماعات | ربع سنوي |
| المجلس المحلي | خطابات رسمية | نصف سنوي |
