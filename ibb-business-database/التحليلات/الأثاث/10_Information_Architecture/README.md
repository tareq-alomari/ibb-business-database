# هيكلة المعلومات - قطاع الأثاث في محافظة إب

---

## خريطة الموقع

```
الصفحة الرئيسية
├── بحث سريع
├── تصنيفات الأثاث (8 أقسام)
├── أحدث المعارض
├── عروض وخصومات
└── إحصائيات سريعة

الصفحات الرئيسية
├── جميع المعارض
│   ├── حسب التصنيف
│   ├── حسب المديرية
│   └── الخريطة
├── جميع المنتجات
│   ├── حسب النوع
│   ├── حسب السعر
│   └── مقارنة
├── التصنيفات
│   ├── أثاث منزلي
│   ├── أثاث مكتبي
│   ├── أثاث معدني
│   ├── أثاث فندقي
│   ├── أثاث حدائق
│   ├── مفروشات
│   ├── مطابخ
│   └── ديكور وإكسسوارات
├── الإحصائيات
│   ├── تقارير القطاع
│   └── رسوم بيانية
└── عن المنصة

لوحة التحكم
├── Dashboard
├── إدارة المعارض
├── إدارة المنتجات
├── إدارة التصنيفات
├── إدارة المستخدمين
├── إدارة التقييمات
├── التقارير
└── الإعدادات
```

## هيكل صفحة المعرض

```
صفحة المعرض
├── الاسم + التصنيف + التقييم
├── معلومات الاتصال (هاتف، واتساب، عنوان)
├── صور المعرض
├── قائمة المنتجات
├── الخريطة
├── التقييمات والمراجعات
└── معارض مشابهة
```

## هيكل صفحة المنتج

```
صفحة المنتج
├── صور المنتج (معرض صور)
├── اسم المنتج + السعر
├── المواصفات والتفاصيل
├── معلومات المعرض (اسم، موقع)
├── التقييمات
└── منتجات مشابهة
```
