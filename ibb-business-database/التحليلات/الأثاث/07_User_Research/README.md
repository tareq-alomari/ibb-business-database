# بحث المستخدم - قطاع الأثاث في محافظة إب

---

## Persona 1: المواطن أحمد

| الصفة | القيمة |
|-------|--------|
| **العمر** | 30 سنة |
| **المهنة** | موظف حكومي |
| **الحالة الاجتماعية** | مقبل على الزواج |
| **المؤهل** | بكالوريوس |
| **الموقع** | مدينة إب |

### الأهداف
- شراء أثاث منزلي كامل بمواصفات جيدة وسعر مناسب
- مقارنة عروض المعارض المختلفة قبل الشراء

### نقاط الألم
- لا يعرف جميع معارض الأثاث في المدينة
- يضطر لزيارة معارض متعددة لمقارنة الأسعار
- لا توجد معلومات موثوقة عن جودة المنتجات

## Persona 2: صاحب المعرض (أبو محمد)

| الصفة | القيمة |
|-------|--------|
| **العمر** | 45 سنة |
| **المهنة** | صاحب معرض أثاث |
| **الخبرة** | 20 سنة في تجارة الأثاث |
| **الموقع** | شارع تعز - مدينة إب |

### الأهداف
- زيادة المبيعات والوصول لزبائن جدد
- عرض منتجاته بشكل منظم وجذاب

### نقاط الألم
- يعتمد على الزبائن المارين فقط
- لا يملك موقعاً إلكترونياً أو وجوداً رقمياً
- صعوبة منافسة المعارض الكبيرة

## Persona 3: النجار والحرفي (علي)

| الصفة | القيمة |
|-------|--------|
| **العمر** | 38 سنة |
| **المهنة** | صاحب ورشة نجارة |
| **الخبرة** | 15 سنة |
| **الموقع** | مديرية السيان |

### الأهداف
- عرض أعماله اليدوية والحصول على طلبات
- التنافس مع الأثاث المستورد

- لا توجد منصة تعرض أعمال الحرفيين
- صعوبة الوصول للزبائن المناسبين
- ضعف التسويق لمنتجاته اليدوية
