## المنافسون الحاليون

### 1. التطبيقات العامة (Facebook Marketplace - OpenSooq)

| العنصر | التحليل |
|--------|---------|
| الميزة | وصول واسع، مجاني، سهل الاستخدام |
| الضعف | غير متخصص، فوضوي، لا يوجد تصنيف محكم |
| الحصة السوقية | كبيرة في الإعلانات المبوبة |

### 2. مجموعات الواتساب وفيسبوك المتخصصة

| العنصر | التحليل |
|--------|---------|
| الميزة | نشاط مجتمعي، تفاعل مباشر |
| الضعف | غير منظمة، صعوبة البحث، بيانات غير موثوقة |
| الحصة السوقية | متوسطة |

### 3. معارض الأثاث التقليدية

| العنصر | التحليل |
|--------|---------|
| الميزة | معاينة المنتج مباشرة، تفاوض على السعر |
| الضعف | لا يوجد وجود رقمي، صعوبة المقارنة |
| الحصة السوقية | المهيمنة حالياً |
