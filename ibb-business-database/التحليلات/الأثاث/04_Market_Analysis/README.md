# تحليل السوق - قطاع الأثاث في محافظة إب

---

## حجم السوق

| المؤشر | القيمة |
|--------|--------|
| عدد سكان محافظة إب | ~3 ملايين نسمة |
| عدد الأسر | ~450,000 أسرة |
| حجم سوق الأثاث التقديري | $25-35 مليون سنوياً |
| معدل الإنفاق السنوي على الأثاث لكل أسرة | $55-80 |
| عدد المنافذ البيعية | ~250 منفذاً |

## اتجاهات السوق

1. **زيادة الطلب على الأثاث العصري**: توجه نحو التصميمات الحديثة والعملية
2. **الاعتماد على الأثاث المحلي**: ارتفاع تكاليف الاستيراد يشجع على الإنتاج المحلي
3. **التسوق عبر الإنترنت**: بداية ظهور طلبات الأثاث عبر وسائل التواصل
4. **الطلب على الأثاث المكتبي المنزلي**: بسبب العمل عن بعد
5. **الاهتمام بالجودة أكثر من السعر**: المستهلكون يبحثون عن المتانة

## تحليل الفجوات السوقية

| الفجوة | الفرصة |
|--------|--------|
| نقص المنصات الرقمية المتخصصة | بناء منصة شاملة للأثاث |
| ضعف توثيق معلومات المعارض | قاعدة بيانات دقيقة وموثوقة |
| عدم وجود نظام مقارنة | أداة مقارنة أسعار ومواصفات |
| غياب التقييمات والمراجعات | نظام تقييم للمنتجات والمعارض |
| نقص التصنيف الموحد | تصنيف لأنواع الأثاث والفئات |

## الشرائح المستهدفة

| الشريحة | الاحتياج |
|---------|----------|
| العائلات الجديدة (المقبلون على الزواج) | أثاث منزلي متكامل بأسعار مناسبة |
| أصحاب المكاتب والشركات | أثاث مكتبي عصري |
| أصحاب الفنادق والمطاعم | أثاث تجاري وفندقي |
| المؤسسات الحكومية | أثاث مؤسساتي بمواصفات محددة |
| أصحاب المنازل (تحديث وتجديد) | قطع أثاث فردية وتحديث الديكور |
