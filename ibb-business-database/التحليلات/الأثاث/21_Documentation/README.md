## أدلة المستخدم المطلوبة

### دليل المستخدم العادي
- كيفية البحث عن معرض أو منتج
- كيفية تصفح التصنيفات
- كيفية كتابة تقييم
- كيفية مشاركة منتج
- كيفية الاتصال بالمعرض

### دليل صاحب المعرض
- كيفية إضافة معرض جديد
- كيفية إدارة المنتجات
- كيفية تحديث البيانات
- كيفية الرد على التقييمات
- كيفية تحليل أداء المعرض

### دليل المشرف
- إدارة المعارض والمستخدمين
- الموافقة على التقييمات
- إعداد التقارير
- إدارة التصنيفات
- إعدادات النظام
