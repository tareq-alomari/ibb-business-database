## 12.1 دليل الأسلوب (Style Guide)

### الألوان

| اللون | الرمز | الاستخدام |
|-------|------|----------|
| الأساسي | #FF9800 | الأزرار، الروابط، الهيدر |
| الثانوي | #4CAF50 | أيقونات النجاح، تأكيد |
| تحذيري | #FF5722 | تنبيهات، أخطاء |
| خلفيات | #F5F5F5 | الخلفيات العامة |
| نص أساسي | #212121 | النصوص الرئيسية |
| نص ثانوي | #757575 | النصوص الثانوية |

### الخطوط

| العنصر | الخط | الحجم |
|-------|------|------|
| العناوين | Tajawal / Noto Kufi Arabic | 24-32px |
| النصوص | Tajawal / Noto Naskh Arabic | 14-18px |
| الأزرار | Tajawal Bold | 16px |
| التسميات | Tajawal Medium | 12-14px |

## 12.2 مكونات الواجهة (UI Components)

| المكون | الوصف | الحالة |
|--------|-------|-------|
| بطاقة الخدمة | صورة + اسم + تقييم + سعر | Normal, Hover, Selected |
| شريط البحث | إدخال نص + زر بحث + فلترة | Focus, Typing, Results |
| زر الحجز | زر رئيسي للحجز | Normal, Loading, Disabled |
| نافذة التقييم | نجوم + تعليق | Empty, Filled, Submitted |
| القائمة السفلية | أيقونات + تسميات | Active, Inactive |

## 12.3 شاشات التطبيق (App Screens)

| الشاشة | المحتوى الرئيسي | الإجراءات |
|--------|---------------|----------|
| الرئيسية | بحث، تصنيفات، مميزون | بحث، تصفح |
| النتائج | قائمة مقدمي الخدمة | فلترة، فرز، اختيار |
| التفاصيل | معلومات، صور، تقييمات | حجز، مشاركة |
| الحجز | تقويم، أوقات، تأكيد | اختيار موعد، دفع |
| الملف الشخصي | بيانات، حجوزات، تقييمات | تعديل، إعدادات |

## 12.4 نظام التجاوب (Responsive Design)

| الحجم | النطاق | التخطيط |
|-------|--------|--------|
| جوال | < 768px | عمود واحد، قائمة سفلية |
| جهاز لوحي | 768px - 1024px | عمودين، شريط جانبي |
| سطح مكتب | > 1024px | 3 أعمدة، هيدر كامل |
