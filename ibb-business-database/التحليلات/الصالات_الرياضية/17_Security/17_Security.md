## 17.2 إجراءات الأمان

### المصادقة والتفويض

| الإجراء | التفاصيل |
|---------|---------|
| JWT Authentication | توكنات قصيرة المدى (15 دقيقة) |
| OTP Verification | التحقق برقم الهاتف |
| Password Hashing | bcrypt (cost 12) |
| RBAC | أدوار: user, owner, admin |
| Rate Limiting | 5 محاولات/دقيقة |

### حماية البيانات

| الإجراء | التفاصيل |
|---------|---------|
| TLS 1.3 | جميع الاتصالات مشفرة |
| Encryption at Rest | AES-256 |
| SQL Injection Prevention | Parameterized queries |
| Input Validation | Zod schemas |

### حماية API

| الإجراء | التفاصيل |
|---------|---------|
| Rate Limiting | 100 طلب/دقيقة |
| CORS | تقييد النطاقات المسموحة |
| IP Whitelisting | للوحة الإدارة |

## 17.3 سياسة الخصوصية

| البند | التفاصيل |
|-------|---------|
| البيانات المجمعة | الاسم، رقم الهاتف، سجل الحجوزات |
| الغرض | تحسين الخدمة |
| مشاركة البيانات | مع المنشآت لغرض الحجز |
| حذف الحساب | يمكن حذف البيانات بالكامل |
| الاحتفاظ بالبيانات | 5 سنوات |

## 17.4 خطة الاستجابة للحوادث

| المرحلة | الإجراء | الوقت |
