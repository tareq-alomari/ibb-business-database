## 7.1 الشخصيات المستهدفة (User Personas)

- **أم خالد - ربة أسرة**: 38 سنة تحتاج عيادة لأطفالها في إب
- **د. منى - طبيبة**: 42 سنة تدير عيادة نسائية
- **أبو عبدالله - مريض مزمن**: 60 سنة يحتاج متابعة دورية لضغط السكر


## 7.2 رحلة المستخدم

| المرحلة | الإجراء | نقطة الألم |
|---------|--------|-----------|
| الوعي | يسمع عن المنصة | لا يعرف إن كانت موثوقة |
| التفكير | يبحث في المنصة | بطء التحميل |
| المقارنة | يقارن بين الخيارات | معلومات ناقصة |
| القرار | يحجز الخدمة | عملية معقدة |
| التقييم | يقيم الخدمة | نسيان التقييم |

## 7.3 احتياجات المستخدمين

| الفئة | الاحتياج | الأولوية |
|-------|---------|----------|
| العملاء | سهولة البحث | عالية |
| العملاء | مصداقية المعلومات | عالية |
| العملاء | توفر الأسعار | متوسطة |
| مقدمي الخدمة | وصول للعملاء | عالية |
| مقدمي الخدمة | إدارة الطلبات | متوسطة |

## 7.4 نقاط الألم

1. **صعوبة المقارنة**: لا توجد وسيلة سهلة للمقارنة
2. **الخوف من الاحتيال**: عدم الثقة بمقدمي الخدمة غير المعروفين
3. **إهدار الوقت**: البحث عن الخدمات يستغرق وقتاً طويلاً
4. **مفاجآت الأسعار**: اختلاف السعر المتفق عليه عن النهائي
5. **ضعف التواصل**: صعوبة التواصل بعد الاتفاق

## 7.5 اختبارات المستخدم

| السيناريو | معيار النجاح |
|-----------|-------------|
| بحث سريع | < 30 ثانية |
| حجز خدمة | < 3 دقائق |
| تقييم | < دقيقة |
| تسجيل مزود | < 5 دقائق |
| دفع إلكتروني | < دقيقة |
