## 20.1 خطة الإغلاق

| البوابة | المخرج | شرط الانتقال |
|---|---|---|
| استخراج | مرشحات موقع بمصدر ظاهر | لا تدعي تشغيلًا أو تخصصًا |
| تسوية | أسماء ومواقع غير مكررة | قرار مراجعة موثق |
| تحقق | حالة تشغيل وبيانات عامة | مصدر رسمي أو زيارة/اتصال مؤرخ |
| نشر محدود | سجلات بدرجات ثقة | لا مواعيد أو وصفات أو بيانات مرضى |

## 20.2 نطاق التنفيذ والمخاطر

تقتصر الدفعة على دليل تحقق ولا تلتزم بتطبيق أو حجز أو دفع أو موازنة. ويعالج خطر تقادم أو خطأ الموقع بتاريخ مراجعة وحالة `stale`، ويعالج خطر الخصوصية باستبعاد البيانات الطبية والشخصية من السجل.
