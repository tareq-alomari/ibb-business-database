## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: ملف العيادة
- **F10**: إدارة المواعيد
- **F11**: ملفات المرضى
- **F12**: إدارة الفواتير
- **F13**: تقارير يومية
- **F14**: إشعارات التذكير

### للعملاء

- **F1**: تسجيل دخول
- **F2**: بحث عن عيادة
- **F3**: تصفح تخصصات
- **F4**: حجز موعد
- **F5**: اختيار طبيب
- **F6**: متابعة الحجز
- **F7**: إلغاء الحجز
- **F8**: تقييم العيادة

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
