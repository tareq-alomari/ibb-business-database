## 1.1 تعريف المشكلة

توفر لقطة بيانات مفتوحة 173 موقعًا مرشحًا لعيادات في إب، لكنها لا تثبت أن هذه العيادات عاملة أو مرخصة أو أن تخصصاتها وبياناتها الاتصالية ما زالت صحيحة. المشكلة التي تعالجها هذه الدفعة هي قابلية التحقق من الدليل المحلي، لا حجوزات الرعاية أو مقارنة أسعارها [1].

## 1.2 نطاق الحل

الحل هو سجل تحقق للأماكن يبدأ بالاسم والموقع والمصدر وتاريخ المراجعة. ولا يشمل الحجز أو الدفع أو الاستشارات أو التقييمات أو المقارنات السريرية أو أي بيانات مرضى.

| الهدف | شرط القبول |
|---|---|
| شفافية المصدر | وجود مصدر وتاريخ وحالة لكل سجل |
| دقة النشر | عدم ترقية `public_candidate` قبل تحقق مباشر |
| الخصوصية | لا مواعيد أو وصفات أو سجلات مرضى |
| استمرار المراجعة | وسم السجل المتقادم عند انتهاء دورة التحقق |

## 1.3 المخاطر والضوابط

| الخطر | الضابط |
|---|---|
| موقع أو اسم مكرر | تسوية السجل قبل النشر |
| خلط الموقع بجودة الرعاية | لا ينشر تخصص أو تقييم أو اعتماد بلا دليل |
| تقادم حالة التشغيل | تاريخ تحقق وحالة `stale` |
| معلومات صحية حساسة | استبعادها من نموذج البيانات |
