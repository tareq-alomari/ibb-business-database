## 1.1 تعريف المشكلة

لا يوجد في الحزمة الحالية دليل عام يسمح بحصر المختبرات أو مقارنة جودة الفحوص أو أسعارها في محافظة إب. وتوفر طبقة مواقع مفتوحة أساسًا لمرشحات جغرافية فقط، مع تحذير صريح من المصدر أنها غير شاملة [1]. المطلوب هو سجل يبين مصدر الموقع وحالته وتاريخ تحققه، لا منصة معاملات صحية.

## 1.2 نطاق الحل

الحل المقترح هو **دليل تحقق للمختبرات** يبدأ بالاسم والموقع المرشح ومصدره، ثم يضيف بيانات عامة قابلة للنشر بعد تحقق مباشر. لا يشمل نطاقه الحجز، أو نتائج الفحوص، أو وصف الخدمات الطبية، أو مقارنة الأسعار أو التقييمات.

| الهدف | معيار القبول |
|---|---|
| قابلية التتبع | مصدر وتاريخ وحالة لكل سجل |
| حماية الخصوصية | عدم تخزين أي بيانات مريض أو نتائج فحوص |
| دقة النشر | عدم ترقية المرشح دون تحقق محلي أو رسمي |
| استدامة السجل | وسم السجل المتقادم وإعادة مراجعته |

## 1.3 المخاطر والضوابط

| الخطر | الضابط |
|---|---|
| اسم أو موقع غير دقيق | تسوية اسم وموقع قبل النشر |
| خلط الموقع بالجودة الطبية | منع أي تقييم أو ادعاء اعتماد بلا مستند |
| تقادم التشغيل | تاريخ تحقق وحالة `stale` عند انتهاء المراجعة |
| بيانات حساسة | استبعاد النتائج والعينات والإحالات من السجل |
