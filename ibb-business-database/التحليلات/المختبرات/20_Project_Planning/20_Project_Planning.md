## 20.1 خطة الإغلاق

| البوابة | المخرج | شرط الانتقال |
|---|---|---|
| اكتشاف المصدر | مرشحات موسومة ومصدرها | لا ادعاء بالشمول أو التشغيل |
| معالجة فجوة التغطية | قائمة جهات لاستقاء بيانات رسمية | لا تنشأ قائمة مختبرات من عدم وجود مرشحات |
| تحقق محلي | الاسم والموقع وحالة التشغيل | دليل مؤرخ وقرار مراجعة محفوظ |
| نشر محدود | سجلات عامة آمنة | لا تشمل نتائج أو عينات أو معلومات مريض |

## 20.2 نطاق التنفيذ

يتوقف نطاق الدفعة عند سجل الأدلة وأداة الاستخراج وقائمة التحقق. لا توجد موازنة أو جدول تطوير تطبيق أو التزام بإطلاق منتجات؛ إذ لا يتوفر بعد تقدير موثق لحجم العمل أو مصدر يتيح دليل مختبرات قابلًا للنشر.

## 20.3 سجل المخاطر

| الخطر | المعالجة |
|---|---|
| غياب مرشحات من المصدر المفتوح | تسجيل فجوة التغطية وطلب مصدر مخول بدل تخمين القائمة |
| خلط دليل الموقع بجودة المختبر | عدم نشر أي اعتماد أو اختبار أو تقييم بلا دليل مباشر |
| تسرب بيانات صحية | منع نتائج الفحوص والعينات وبيانات المرضى من النموذج |
