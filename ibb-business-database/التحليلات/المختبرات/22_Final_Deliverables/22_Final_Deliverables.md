## 22.1 التسليمات الحالية

| التسليم | الحالة | الحد |
|---|---|---|
| تحليل الأدلة وسجل المصادر | منجز | لا يثبت قائمة مختبرات كاملة |
| مخطط سجل وأدوات استخراج وفحص | منجز | يعمل على لقطة المصدر الخام |
| ملف مرشحات وملخص | منجز | عدد المرشحات الحالي صفر؛ فجوة تغطية معلنة |
| قائمة تحقق | منجز | لم تنفذ ببيانات تحقق محلي |
| تطبيق أو API أو قاعدة بيانات تشغيلية | غير موجود | خارج نطاق الحزمة |

## 22.2 شروط الإغلاق

ينتقل القطاع إلى دليل عام فقط بعد توفر مصدر محلي مخول أو تحقق مباشر يغطي الاسم والموقع وحالة التشغيل. وتبقى بيانات الاختبارات والأسعار وخدمات المختبر خارج النشر حتى يتوفر لكل ادعاء مصدر مؤرخ ومناسب.
