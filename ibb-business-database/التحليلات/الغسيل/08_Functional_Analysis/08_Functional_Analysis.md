## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: ملف المغسلة
- **F10**: استقبال طلبات
- **F11**: إدارة العمالة
- **F12**: جدولة التوصيل
- **F13**: فواتير
- **F14**: تقارير

### للعملاء

- **F1**: تسجيل
- **F2**: طلب غسيل
- **F3**: اختيار نوع الخدمة
- **F4**: اختيار مغسلة
- **F5**: جدولة استلام
- **F6**: تتبع الطلب
- **F7**: دفع
- **F8**: تقييم

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
