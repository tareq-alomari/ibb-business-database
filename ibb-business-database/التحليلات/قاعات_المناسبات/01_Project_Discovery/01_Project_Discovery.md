## 1.1 المشكلة (Problem Statement)

يعاني قطاع قاعات المناسبات في محافظة إب من **تشتت وتنظيم معلوماتي ضعيف** رغم كونه قطاعًا حيويًا. المشكلات الرئيسية:

1. صعوبة إيجاد قاعة مناسبة
2. معلومات محدودة عن الخدمات
3. غياب الحجز المسبق الموثوق
4. لا توجد صور حقيقية
5. أسعار غير شفافة

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية لحجز قاعات المناسبات في إب مع معلومات شاملة وصور وأسعار**:

- **دليل شامل**: قاعدة بيانات لجميع قاعات المناسبات في إب مع تصنيف حسب النوع والموقع والأسعار
- **نظام تقييم ومراجعات**: تقييمات موثقة من المستخدمين مع صور حقيقية
- **نظام حجز/طلب مدمج**: حجز إلكتروني مع تأكيد فوري
- **محتوى رقمي غني**: صور وفيديوهات ومعلومات محدثة
- **خريطة تفاعلية**: عرض المواقع على الخريطة مع مسارات الوصول
- **لوحة تحكم**: إدارة البيانات والعروض والإحصائيات

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستخدم/الزبون** | اكتشاف الخدمات، مقارنة الأسعار، قراءة تقييمات حقيقية |
| **صاحب المنشأة** | وصول لشريحة أكبر، تحسين السمعة، إدارة العروض |
| **الموظفون** | فرص عمل، تنظيم، جدولة ذكية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |
| **الباحثون** | بيانات عن أنماط الاستهلاك في المحافظة |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | المقبلون على الزواج في محافظة إب |
| **مصادر التمويل** | اشتراكات شهرية + عمولة حجوزات (10-15%) + إعلانات |
| **نموذج الإيرادات** | Freemium للقوائم الأساسية + مميزة مدفوعة + خدمات إضافية |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، الجهات المختصة، مقدمي الخدمات المساندة |

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|

| G2: الحجوزات | عدد الحجوزات الشهرية | 200+ |
| G3: المحتوى | صور وفيديوهات لكل قاعة | 15+/قاعة |
| G4: رضا المستخدمين | التقييم العام | 4.2+/5 |
| G5: التغطية | تغطية مناطق إب | 10+ مديريات |

## 1.6 Vision & Mission

### Vision
"أن يكون دليل قاعات المناسبات الرقمي في محافظة إب المنصة الأولى التي يعتمد عليها كل مواطن لاختيار الخدمة المناسبة، محولاً تجربة البحث والاختيار إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مقدمي الخدمات والمستخدمين في محافظة إب، وتوفر معلومات دقيقة ومحدثة مع خدمات حجز وتقييم، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - عدد كبير من القاعات | - شح المعلومات الرقمية |
| - تنوع الخدمات | - غياب الشفافية في الأسعار |
| - طلب دائم على الأفراح | - تفاوت في المستوى |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - ارتفاع معدلات الزواج | - الوضع الاقتصادي |
| - طلب على حفلات الزفاف المنظمة | - ارتفاع تكاليف التجهيزات |
| - التكامل مع خدمات الزفاف | - تقييدات اجتماعية |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: محافظة إب تحت سيطرة الحوثي، عدم استقرار مؤسسي | خطر على استمرارية الأعمال، يحتاج توافق مع السلطات المحلية |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | المنشآت تتأثر بارتفاع التكاليف، المستخدم حساس للسعر |
| **S - Social**: عادات اجتماعية راسخة، تفضيل التعامل المباشر | فرصة للترويج للمنصة كوسيلة موثوقة وسهلة |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first، واجهة خفيفة |
| **L - Legal**: غياب تنظيم رقمي واضح | فرصة لتوحيد المعايير، توثيق التراخيص |
| **E - Environmental**: ظروف بيئية متنوعة | فرصة لتصنيف المنشآت حسب الجودة والالتزام البيئي |

## 1.10 Risk Analysis

| الخطر | الاحتمالية | التأثير | خطة التخفيف |
|-------|-----------|---------|------------|
| انقطاع الإنترنت والكهرباء | عالية | عالي | PWA مع دعم Offline، خوادم محلية |
| توقف التمويل/الاستثمار | متوسطة | عالي | نموذج إيرادات متنوع |
| عدم إقبال المنشآت على التسجيل | متوسطة | متوسط | حوافز (قائمة مجانية، عروض ترويجية) |
| منافسة من منصات خارجية | متوسطة | متوسط | تركيز على السوق المحلي، ميزات مخصصة لإب |
| أمن بيانات المستخدمين | منخفضة | عالي | تشفير، خصوصية، تطبيق معايير الأمان |
