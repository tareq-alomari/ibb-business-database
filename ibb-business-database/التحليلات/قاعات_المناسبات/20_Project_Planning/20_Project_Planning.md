|---------|-------|----------|

| **2. التصميم** | 3 أسابيع | Figma designs |
| **3. التطوير الأساسي** | 6 أسابيع | MVP (API + ويب) |
| **4. لوحة المنشأة** | 3 أسابيع | لوحة تحكم كاملة |
| **5. الاختبار** | 3 أسابيع | نسخة Beta مستقرة |
| **6. الإطلاق** | أسبوعان | Launch رسمي |
| **7. التحسين المستمر** | مستمر | تحديثات شهرية |
