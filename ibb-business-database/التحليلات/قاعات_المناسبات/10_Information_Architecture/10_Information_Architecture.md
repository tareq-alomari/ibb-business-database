## 10.1 هيكل المعلومات العام

```
تطبيق قاعات إب
│
├── الشاشات الرئيسية (غير مسجل)
│   ├── الصفحة الرئيسية
│   │   ├── البحث
│   │   ├── التصنيفات السريعة
│   │   ├── المنشآت المميزة
│   │   ├── العروض الحالية
│   │   └── المنشآت القريبة
│   ├── قائمة المنشآت
│   │   ├── فلترة (نوع، موقع، سعر)
│   │   └── ترتيب
│   ├── صفحة المنشأة
│   │   ├── معلومات
│   │   ├── الخدمات والأسعار
│   │   ├── التقييمات والمراجعات
│   │   ├── الصور
│   │   └── العروض المتاحة
│   ├── العروض
│   └── تسجيل الدخول
│
├── الشاشات الرئيسية (مسجل دخول)
│   ├── الصفحة الرئيسية (مخصصة)
│   ├── حجوزاتي
│   ├── سجل الحجوزات
│   ├── المفضلة
│   └── إعدادات الحساب
│
├── لوحة تحكم المنشأة
│   ├── لوحة الإحصائيات
│   ├── إدارة الخدمات
│   ├── إدارة الحجوزات
│   ├── العروض
│   ├── التقارير
│   └── الإعدادات
│
└── لوحة الإدارة (Admin)
    ├── لوحة الإحصائيات
    ├── إدارة المنشآت
    ├── إدارة المستخدمين
    ├── مراجعة المحتوى
    ├── إدارة الإعلانات
    └── التقارير العامة
```

## 10.2 نظام التصنيف

| المستوى الأول | المستوى الثاني |
|--------------|---------------|
| حسب النوع | قاعات أفراح رجالية، قاعات أفراح نسائية، قاعات مناسبات متعددة |
| حسب السعر | اقتصادي، متوسط، مرتفع، فاخر |
| حسب الموقع | وسط المدينة، الأحياء، المديريات |

## 10.3 نظام التصفح والبحث

| الميزة | الوصف |
|--------|-------|
| **البحث الرئيسي** | بحث نصي حر |
| **فلترة** | النوع، الموقع، السعر، التقييم |
| **ترتيب** | الأقرب، الأعلى تقييمًا |
| **خريطة تفاعلية** | عرض المنشآت على الخريطة |

## 10.4 User Flow الرئيسي

```
فتح التطبيق → الصفحة الرئيسية
    → بحث / تصفح → اختيار منشأة
    → عرض التفاصيل → اختيار الخدمة
    → تأكيد الحجز → إرسال الطلب
    → شاشة التأكيد ← إشعارات
    → استلام الخدمة → تقييم المنشأة
```

## 10.5 Sitemap

```
/                           ← الصفحة الرئيسية
/list                      ← قائمة المنشآت
/list/:id                  ← صفحة منشأة
/list/:id/reviews          ← تقييمات
/bookings                  ← حجوزاتي
/bookings/:id              ← تفاصيل الحجز
/favorites                 ← المفضلة
/offers                    ← العروض
/profile                   ← الملف الشخصي
/notifications             ← الإشعارات
```

### لوحة تحكم المنشأة

```
/dashboard                 ← لوحة الإحصائيات
/dashboard/services        ← إدارة الخدمات
/dashboard/bookings        ← إدارة الحجوزات
/dashboard/offers          ← العروض
/dashboard/reports         ← التقارير
/dashboard/settings        ← الإعدادات
```
