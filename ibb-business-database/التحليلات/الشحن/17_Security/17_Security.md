## 17.1 نموذج التهديدات (Threat Model)

| المكون | التهديد | الاحتمالية | التأثير |
|--------|--------|-----------|---------|
| واجهة المستخدم | XSS, CSRF | متوسطة | عالي |
| API | SQL Injection, DDoS | متوسطة | عالي |
| قاعدة البيانات | تسرب بيانات | منخفضة | عالي جداً |
| التخزين | وصول غير مصرح | منخفضة | عالي |
| الاتصالات | اعتراض البيانات | منخفضة | متوسط |

## 17.2 إجراءات الأمان (Security Measures)

| المجال | الإجراء |
|--------|--------|
| **المصادقة** | JWT + OTP، توكن قصير الأمد (15 دقيقة للوصول، 7 أيام للتحديث) |
| **التحقق** | التحقق بخطوتين (2FA) للحسابات المهمة |
| **التشفير** | TLS 1.3 للاتصالات، AES-256 للبيانات الحساسة |
| **API** | Rate Limiting (100 طلب/دقيقة)، API Keys لكل خدمة |
| **المدخلات** | تعقيم المدخلات، Prepared Statements لـ SQL |
| **الجلسات** | HttpOnly Cookies, CSRF Tokens, SameSite=Strict |

## 17.3 سياسة الخصوصية (Privacy Policy)

1. **جمع البيانات**: فقط البيانات الضرورية للخدمة (الاسم، رقم الهاتف، الموقع)
2. **استخدام البيانات**: تحسين الخدمة، تخصيص التجربة، إشعارات الحجوزات
3. **مشاركة البيانات**: لا نشارك بيانات المستخدمين مع أطراف ثالثة دون موافقة
4. **الاحتفاظ**: نحتفظ بالبيانات لمدة 3 سنوات بعد آخر نشاط، ثم تحذف
5. **حقوق المستخدم**: طلب تصدير/حذف البيانات في أي وقت

## 17.4 خطة الاستجابة للاختراق (Incident Response)

| المرحلة | الإجراء | الوقت المستهدف |
|---------|--------|---------------|
| 1. اكتشاف | مراقبة تلقائية، تنبيهات أمان | < 5 دقائق |
| 2. تحليل | تحديد نوع ومصدر الاختراق | < 30 دقيقة |
| 3. احتواء | عزل النظام المخترق، وقف الخدمة المتأثرة | < ساعة |
| 4. إزالة | إزالة التهديد، تحديث الثغرات | < 4 ساعات |
| 5. استعادة | استعادة النظام من نسخة احتياطية | < ساعتين |
| 6. توثيق | تقرير ما بعد الحادثة | < 24 ساعة |
