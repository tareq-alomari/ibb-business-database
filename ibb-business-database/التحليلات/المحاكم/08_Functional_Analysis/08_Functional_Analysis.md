## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: إدارة القضايا
- **F10**: جدولة الجلسات
- **F11**: إدارة المواعيد
- **F12**: توثيق الأحكام
- **F13**: تقارير إحصائية
- **F14**: إشعارات

### للعملاء

- **F1**: تسجيل
- **F2**: استعلام عن قضية
- **F3**: متابعة مواعيد
- **F4**: حجز موعد
- **F5**: دفع رسوم
- **F6**: توثيق
- **F7**: استشارة
- **F8**: تقييم

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
