# هندسة البرمجيات: النظام المصرفي في إب

## النمط المعماري
اعتماد نمط العمارة متعددة الطبقات (Layered Architecture) مع إمكانية التوسع إلى خدمات مصغرة (Microservices) مستقبلاً.

## طبقات النظام

### طبقة العرض (Presentation Layer)
- تطبيق موبايل (Android و iOS)
- واجهة ويب للإدارة
- نظام الصراف الآلي
- واجهة موظفي الفروع

### طبقة الخدمات (Service Layer)
- خدمة إدارة الحسابات
- خدمة المعاملات المالية
- خدمة التمويل والائتمان
- خدمة التكامل مع البنك المركزي
- خدمة إشعارات العملاء
- خدمة التقارير والمؤشرات

### طبقة الأعمال (Business Logic Layer)
- محرك الموافقات والصلاحيات
- نظام حساب الفوائد والعمولات
- سياسات مكافحة غسل الأموال
- التحقق من هوية العملاء
- إدارة المخاطر الائتمانية

### طبقة البيانات (Data Layer)
- قاعدة البيانات الرئيسية (PostgreSQL)
- قاعدة بيانات المعاملات اليومية
- مخزن البيانات التاريخية
- نظام الملفات للمستندات

## التكامل مع الأنظمة الخارجية
- البنك المركزي اليمني (نظام المقاصة الإلكترونية)
- نظام المعلومات الائتماني
- بوابات الدفع الإلكتروني
- شركات تحويل الأموال (Western Union، MoneyGram)

## متطلبات البنية التحتية
- خوادم محلية داخل فروع إب
- سحابة خاصة للنسخ الاحتياطي
- اتصال إنترنت مخصص لكل فرع
- مولدات كهرباء احتياطية
