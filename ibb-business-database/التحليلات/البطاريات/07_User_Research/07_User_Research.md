## 7.2 رحلة المستخدم (User Journey)

### رحلة اكتشاف الخدمة

```
[الوعي] -> [البحث] -> [المقارنة] -> [الاختيار] -> [الاستخدام] -> [التقييم]
    |         |           |           |           |           |
  يسمع عن   يبحث في   يقارن     يختار    يستخدم    يقيّم
  المنصة    المنصة    الخيارات  الأفضل   الخدمة    تجربته
```

### تفاصيل كل مرحلة

| المرحلة | أنشطة المستخدم | نقاط التواصل | المشاعر |
|---------|---------------|-------------|--------|
| **الوعي** | يسمع عن المنصة من صديق أو إعلان | واتساب، فيسبوك | فضول |
| **البحث** | يفتح المنصة، يكتب كلمة في البحث | التطبيق، الموقع | حماس |
| **المقارنة** | يفتح عدة خيارات، يقارن الأسعار | التطبيق | تركيز |
| **الاختيار** | يختار الخدمة المناسبة، يتصل أو يحجز | التطبيق | ارتياح |
| **الاستخدام** | يستخدم الخدمة، يتواصل مع مقدم الخدمة | هاتف، واتساب | رضا |
| **التقييم** | يكتب تقييمًا، يشارك التجربة | التطبيق | رغبة في المشاركة |

## 7.3 احتياجات المستخدمين (User Needs)

| الاحتياج | الأولوية | الحل المقترح | مؤشر النجاح |
|----------|---------|-------------|-------------|
| معلومات دقيقة ومحدثة عن الخدمات | عالية | قاعدة بيانات محدثة باستمرار مع توثيق | دقة المعلومات > 95% |
| سهولة المقارنة بين مقدمي الخدمة | عالية | واجهة مقارنة واضحة مع جدول | وقت المقارنة < 30 ثانية |
| تقييمات موثوقة من مستخدمين حقيقيين | عالية | نظام تقييم مع توثيق هوية المقيم | نسبة التقييمات الموثقة > 80% |
| سرعة الاستخدام والاستجابة | متوسطة | واجهة بسيطة وسريعة التحميل | زمن التحميل < 2 ثانية |
| دعم فني سريع ومتاح | متوسطة | شات مباشر مع دعم فني | زمن الاستجابة < 5 دقائق |
| خيارات دفع متنوعة | متوسطة | دفع نقدي وإلكتروني | نسبة الرضا > 85% |

## 7.4 تحليل الفجوات (User Needs Gap)

| الحاجة | هل تُلبى حاليًا؟ | الفجوة | درجة الإلحاح |
|--------|----------------|--------|-------------|
| دليل موحد للخدمات | جزئيًا (عبر فيسبوك ومجموعات واتساب) | كبيرة - لا توجد منصة مركزية | عاجل |
| تقييمات موثقة ومحققة | لا - التقييمات شفهية | كبيرة - لا يوجد نظام تقييم رقمي | عاجل |
| حجز إلكتروني | لا - الحجز هاتفي أو حضوري | كبيرة - عناء في الحجز | عاجل |
| مقارنة أسعار وخدمات | لا - المقارنة تحتاج جهدًا | كبيرة - صعوبة المفاضلة | مهم |
| دفع إلكتروني | لا - التعامل نقدي بالكامل | متوسطة - الحاجة للنقد الدائم | مهم |

## 7.5 توصيات تصميمية بناءً على البحث

| النتيجة | التوصية |
|---------|---------|
| المستخدمون يفضلون التطبيق على الموقع | تطوير تطبيق أندرويد أولاً مع PWA |
| 70% يستخدمون الإنترنت في المساء | تركيز الإشعارات في الفترة المسائية |
| معظم المستخدمين يبحثون بالاسم | تحسين البحث النصي مع اقتراحات |
| السعر هو العامل الأهم لـ 60% | إظهار الأسعار بوضوح في بطاقات النتائج |
| التوصيات من الأصدقاء هي المصدر الأول | تضمين ميزة مشاركة ومشاركة التقييمات |
