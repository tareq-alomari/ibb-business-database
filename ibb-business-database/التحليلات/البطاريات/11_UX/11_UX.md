## 11.1 مبادئ تجربة المستخدم

| المبدأ | التطبيق في المشروع |
|--------|-------------------|
| **البساطة** | أقل عدد من الخطوات (3 خطوات كحد أقصى) |
| **السرعة** | تحميل سريع حتى على شبكات 3G |
| **الوضوح** | أيقونات عربية واضحة، نصوص كبيرة |
| **الثقة** | تقييمات حقيقية، صور، معلومات دقيقة |
| **التخصيص** | توصيات حسب الاستخدام السابق |

## 11.2 User Flows

### تدفق البحث عن خدمة

```
[الصفحة الرئيسية]
    |
    +-- [بحث] ---- يكتب كلمة ---- [نتائج] ---- اختيار
    |
    +-- [تصنيفات] ---- يختار قسم ---- [قائمة] ---- اختيار
    |
    +-- [قريبة مني] ---- [القائمة] ---- اختيار
            |
            V
    [صفحة التفاصيل]
        |
        +-- [المعلومات] ---- وصف، صور، بيانات اتصال
        |
        +-- [التقييمات] ---- قراءة مراجعات الآخرين
        |
        +-- [اتصل/احجز] ---- تواصل مباشر
```

## 11.3 مبادئ التصميم لظروف إب

| التحدي | الحل التصميمي |
|--------|--------------|
| **إنترنت بطيء** | تحميل تدريجي (Lazy loading) |

| **بطارية ضعيفة** | وضع Dark mode |
