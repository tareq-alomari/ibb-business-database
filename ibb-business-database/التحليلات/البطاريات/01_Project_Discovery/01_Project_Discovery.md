# المرحلة الأولى: Project Discovery - قطاع البطاريات في محافظة إب

> **التاريخ**:  يوليو 2026  
> **الملف**: 01_Project_Discovery.md

---

## 1.1 المشكلة (Problem Statement)

يعاني قطاع البطاريات في محافظة إب من تحديات كبيرة رغم كونه قطاعًا حيويًا. لا توجد منصة موحدة تتيح للمستفيدين اكتشاف الخدمات أو مقارنتها. المشكلات الرئيسية:

1. **ارتفاع أسعار البطاريات الأصلية**
2. **انتشار البطاريات المغشوشة**
3. **صعوبة التخلص من البطاريات التالفة**
4. **نقص خدمة الفحص المجاني**
5. **ضعف الضمانات**

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لقطاع البطاريات في محافظة إب** تتكون من:

- **دليل البطاريات**: قائمة بأنواع البطاريات المتوفرة
- **مقارنة الأسعار**: مقارنة أسعار البطاريات بين المحلات
- **دليل الأنواع**: أنواع بطاريات السيارات والطاقة الشمسية
- **مراكز الفحص**: قائمة بمراكز فحص البطاريات
- **الإرجاع والضمان**: أماكن الضمان والخدمة

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستهلك/المواطن** | سهولة الوصول للمعلومات، مقارنة الخدمات، تقييمات حقيقية |
| **مزود الخدمة/البطاريات** | وصول لشريحة أكبر، تحسين السمعة، إدارة رقمية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات، عمولات، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، مكاتب البطاريات المحلية |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| حصر الجهات/البطاريات | عدد المسجلين | 70++ |
| دقة البيانات | نسبة المعلومات المؤكدة | 90%+ |
| سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| رضا المستخدمين | تقييم المنصة | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن تكون المنصة الرقمية لقطاع البطاريات في محافظة إب المرجع الأول الذي يعتمد عليه كل مواطن، محولة تجربة البطاريات إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مزودي خدمات البطاريات والمستفيدين في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - طلب ثابت (سيارات وطاقة) | - انتشار الغش التجاري |
| - تجار محليون متمرسون | - عدم تنظيم أسعار |
| - انتشار السيارات | - نقص إعادة التدوير |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - التحول للطاقة الشمسية | - الوضع الاقتصادي |
| - زيادة عدد السيارات | - انقطاع الاستيراد |
| - التجارة الإلكترونية | - الكهرباء المتقطعة تزيد الاستهلاك |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: عدم استقرار سياسي | خطر على استمرارية الأعمال |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | ارتفاع التكاليف، حساسية السعر |
| **S - Social**: كثافة سكانية عالية، شرائح متنوعة | فرصة كبيرة، تنوع الاحتياجات |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم رقمي | فرصة لتوحيد المعايير |
| **E - Environmental**: تحديات بيئية مختلفة | فرصة لنشر التوعية |
