## 10.1 هيكل المعلومات العام

تطبيق ألعاب إب → [الصفحة الرئيسية | قائمة الجهات | صفحة جهة | العروض | لوحة التحكم]

## 10.2 نظام التصنيف

| المستوى | التصنيف |
|---------|---------|
| حسب النوع | محلات ألعاب أطفال | تخصص محلات ألعاب أطفال |
| حسب النوع | مراكز ترفيه | تخصص مراكز ترفيه |
| حسب النوع | ألعاب إلكترونية | تخصص ألعاب إلكترونية |
| حسب النوع | ألعاب تعليمية | تخصص ألعاب تعليمية |
| حسب النوع | مدن ألعاب | تخصص مدن ألعاب |

## 10.3 Sitemap

/ ← الصفحة الرئيسية
/list ← قائمة الجهات
/list/:id ← صفحة جهة
/list/:id/reviews ← تقييمات
/favorites ← المفضلة
/offers ← العروض

## 10.4 User Flow

فتح التطبيق → بحث/تصفح → اختيار جهة → عرض التفاصيل → تواصل → تقييم
