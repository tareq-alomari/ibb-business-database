# هندسة البرمجيات: نظام شركات الصرافة في إب

## البنية المعمارية المقترحة
نظام قائم على بنية الخدمات المصغرة (Microservices Architecture):

### 1. خدمة إدارة الشركات (Company Service)
- إدارة بيانات شركات الصرافة
- تحديث حالة التراخيص
- إدارة الفروع

### 2. خدمة أسعار الصرف (Exchange Rate Service)
- تحديث أسعار الصرف لحظياً
- حساب فروقات الأسعار
- تقديم تغذية سعرية عبر API

### 3. خدمة المعاملات (Transaction Service)
- معالجة الحوالات الواردة والصادرة
- تسجيل عمليات الصرف
- طباعة الإيصالات

### 4. خدمة العملاء (Customer Service)
- إدارة بيانات العملاء
- التحقق من الهوية
- سجل المعاملات

### 5. خدمة التقارير (Reporting Service)
- تقارير يومية وأسبوعية وشهرية
- تحليل البيانات المالية
- تصدير التقارير بصيغ مختلفة

### 6. خدمة الإشعارات (Notification Service)
- إشعارات واتساب للعملاء
- تنبيهات بتغيرات الأسعار
- إشعارات استلام الحوالات

## مكونات البنية التحتية
- قاعدة بيانات PostgreSQL مركزية
- Redis للتخزين المؤقت لأسعار الصرف
- Nginx كخادم عكسي (Reverse Proxy)
- Docker للحاويات والتوزيع

## التكامل مع الأنظمة الخارجية
- واجهة مع Western Union API
- بوابة دفع إلكترونية (اختياري)
- نظام البنك المركزي للتسجيل
