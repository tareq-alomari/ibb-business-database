# تصميم واجهات API: قطاع الصرافة في إب

## نقاط النهاية (Endpoints)

### 1. قائمة شركات الصرافة
```
GET /api/companies
```
- الاستعلام: ?district=السدة&status=نشط
- الاستجابة: قائمة بشركات الصرافة في إب
- الحقول: الاسم، العنوان، الهاتف، الحالة

### 2. أسعار الصرف
```
GET /api/exchange-rates
```
- الاستعلام: ?company_id=1&currency=SAR
- الاستجابة: أسعار البيع والشراء لكل العملات
- تحديث: كل دقيقة

### 3. إنشاء حوالة
```
POST /api/transactions
```
- البيانات: نوع الحوالة، المبلغ، العملة، بيانات العميل والمستلم
- الاستجابة: تأكيد الحوالة مع رقم مرجعي

### 4. استعلام عن حوالة
```
GET /api/transactions/{reference}
```
- الاستجابة: حالة الحوالة والتفاصيل

### 5. تسجيل عميل
```
POST /api/customers
```
- البيانات: الاسم، رقم الهوية، الهاتف
- الاستجابة: تأكيد التسجيل

### 6. تاريخ المعاملات
```
GET /api/customers/{id}/transactions
```
- الاستعلام: ?from=2024-01-01&to=2024-12-31
- الاستجابة: سجل معاملات العميل

## أمان API
- مصادقة عبر API Key لكل شركة صرافة
- تشفير HTTPS لجميع الاتصالات
- تسجيل جميع طلبات API في سجل التدقيق
- تحديد معدل الطلبات (Rate Limiting)

## تنسيق الاستجابات
- جميع الاستجابات بتنسيق JSON
- رسائل خطأ واضحة بالعربية
- استخدام رموز HTTP قياسية (200, 201, 400, 401, 404, 500)
