# الرصة التقنية المقترحة: نظام شركات الصرافة في إب

## الواجهة الخلفية (Backend)
- **اللغة**: Python (FastAPI) أو Node.js (Express)
- **قاعدة البيانات**: PostgreSQL
- **التخزين المؤقت**: Redis
- **خادم التطبيق**: Gunicorn / PM2

## الواجهة الأمامية (Frontend)
- **إطار العمل**: React.js مع Next.js
- **مكتبة UI**: Ant Design (يدعم العربية)
- **إدارة الحالة**: Redux Toolkit
- **التطبيق الجوال**: React Native

## البنية التحتية (Infrastructure)
- **الاستضافة**: خادم خاص (VPS) في اليمن أو السعودية
- **خادم الويب**: Nginx
- **الحاويات**: Docker + Docker Compose
- **SSL**: Let's Encrypt

## أدوات التطوير
- **التحكم بالإصدارات**: Git + GitHub/GitLab
- **إدارة المهام**: Trello أو Jira
- **التوثيق**: Swagger/OpenAPI للـ API
- **الاختبارات**: pytest (Backend)، Jest (Frontend)

## متطلبات الأجهزة
- **الخادم**: 4 نوى معالج، 8 جيجابايت RAM، 100 جيجابايت SSD
- **الشبكة**: اتصال إنترنت مستقر بسرعة 10 ميجابت/ثانية على الأقل
- **الأجهزة الطرفية**: حواسيب للصرافين، طابعات إيصالات حرارية

## متطلبات الأمان
- جدار ناري (Firewall)
- نظام كشف الاختراق (IDS)
- تشفير SSL/TLS
- نسخ احتياطي يومي مشفر

## الميزانية التقنية التقديرية
- الخادم: 50-100 دولار شهرياً
- التراخيص: معظم الأدوات مفتوحة المصدر
- التطوير: حسب نطاق المشروع وعدد المطورين
