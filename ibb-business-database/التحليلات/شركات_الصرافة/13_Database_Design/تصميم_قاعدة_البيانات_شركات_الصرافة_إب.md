# تصميم قاعدة البيانات: قطاع الصرافة في إب

## نموذج البيانات العلائقي

### جدول: companies (شركات الصرافة)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف الشركة |
| name_ar | VARCHAR | الاسم التجاري بالعربية |
| license_no | VARCHAR | رقم الترخيص |
| license_date | DATE | تاريخ الترخيص |
| district | VARCHAR | المديرية |
| address | TEXT | العنوان التفصيلي |
| phone | VARCHAR | رقم الهاتف |
| whatsapp | VARCHAR | رقم واتساب |
| status | ENUM | نشط / متوقف |

### جدول: exchange_rates (أسعار الصرف)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف السعر |
| company_id | INT (FK) | معرف الشركة |
| currency_code | VARCHAR | رمز العملة (SAR, USD, AED) |
| buy_rate | DECIMAL | سعر الشراء |
| sell_rate | DECIMAL | سعر البيع |
| updated_at | TIMESTAMP | وقت التحديث |

### جدول: transactions (المعاملات)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف المعاملة |
| company_id | INT (FK) | معرف الشركة |
| customer_id | INT (FK) | معرف العميل |
| type | ENUM | صرف / حوالة وارد / حوالة صادر |
| amount | DECIMAL | المبلغ |
| currency | VARCHAR | العملة |
| rate | DECIMAL | سعر الصرف |
| fee | DECIMAL | الرسوم |
| total | DECIMAL | الإجمالي |
| created_at | TIMESTAMP | تاريخ المعاملة |

### جدول: customers (العملاء)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف العميل |
| name | VARCHAR | الاسم الكامل |
| id_no | VARCHAR | رقم الهوية |
| phone | VARCHAR | رقم الهاتف |
| created_at | TIMESTAMP | تاريخ التسجيل |

## الفهارس (Indexes)
- فهرس على company_id في جدول exchange_rates
- فهرس على customer_id في جدول transactions
- فهرس على updated_at لأسعار الصرف
