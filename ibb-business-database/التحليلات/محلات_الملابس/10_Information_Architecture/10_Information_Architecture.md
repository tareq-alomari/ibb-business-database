# هيكلة المعلومات: منصة محلات الملابس الرقمية لإب

## خريطة الموقع
```
الصفحة الرئيسية
├── تسوق حسب القسم
│   ├── ملابس رجالية
│   │   ├── بدلات رسمية
│   │   ├── بشوت وجلابيات
│   │   ├── تيشيرتات وقمصان
│   │   └── بناطيل وجينز
│   ├── ملابس نسائية
│   │   ├── فساتين وعباءات
│   │   ├── ملابس محتشمة
│   │   └── إكسسوارات
│   ├── ملابس أطفال
│   │   ├── مواليد
│   │   ├── أطفال (2-12 سنة)
│   │   └── مراهقون
│   └── أقمشة وخياطة
├── تسوق حسب المحل
│   ├── أشهر المحلات
│   └── محلات حسب المديرية
├── العروض والتخفيضات
├── طلباتي
│   ├── الطلبات الحالية
│   ├── سجل الطلبات
│   └── تقييماتي
└── لوحة التحكم (للمحلات)
    ├── إدارة المنتجات
    ├── إدارة الطلبات
    ├── التقارير
    └── الإعدادات
```

## هيكل المحتوى
```
صفحة منتج
├── اسم المنتج + المحل
├── صور متعددة للمنتج
├── السعر + المقاسات المتاحة
├── وصف المنتج (نوع القماش، اللون)
├── سياسة الإرجاع الخاصة بالمحل
└── زر الطلب

صفحة محل
├── اسم المحل + شعار
├── معلومات الاتصال والموقع
├── قائمة المنتجات المتاحة
├── تقييمات العملاء
└── ساعات العمل
```

## التنقل
- شريط تنقل علوي (الأقسام الرئيسية)
- قائمة جانبية للتخصصات
- بحث نصي مع فلاتر (سعر، مقاس، لون)
- روابط سريعة للمواسم والعروض
