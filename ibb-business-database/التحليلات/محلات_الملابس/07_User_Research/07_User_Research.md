# بحث المستخدمين: شخصيات مشتري الملابس في إب

## الشخصية 1: سمير - موظف حكومي
| الصفة | القيمة |
|-------|--------|
| العمر | 38 سنة |
| المهنة | موظف في إدارة محلية |
| المؤهل | بكالوريوس |
| الموقع | مدينة إب |
| مستوى التقنية | متوسط (يستخدم واتساب، فيسبوك) |

### الأهداف
- شراء ملابس العيد للعائلة بأفضل سعر
- إيجاد بدلات رسمية مناسبة للدوام

### نقاط الألم
- قلة الوقت للتسوق خاصة في المواسم
- الأسعار مرتفعة في المحلات الكبيرة
- لا توجد خدمة توصيل للمنزل

## الشخصية 2: أمل - ربة منزل
| الصفة | القيمة |
|-------|--------|
| العمر | 45 سنة |
| المهنة | ربة منزل |
| المؤهل | ثانوية عامة |
| الموقع | مدينة إب |

### الأهداف
- شراء ملابس لثلاثة أطفال بأسعار معقولة
- أقمشة عالية الجودة للخياطة المنزلية

### نقاط الألم
- صعوبة التنقل مع الأطفال
- احتياج لرؤية الملابس وتجربتها قبل الشراء
- محدودية خيارات ملابس الأطفال الجيدة

## الشخصية 3: ياسر - شاب جامعي
| الصفة | القيمة |
|-------|--------|
| العمر | 22 سنة |
| المهنة | طالب جامعي |
| المؤهل | طالب |
| الموقع | سكن جامعي - إب |

### الأهداف
- ملابس عصرية بأسعار مناسبة
- معرفة صيحات الموضة الجديدة

### نقاط الألم
- لا يوجد محلات متخصصة في الملابس الشبابية
- يضطر لشراء الملابس من محلات متعددة
- الرغبة في مقارنة الأسعار قبل الشراء
