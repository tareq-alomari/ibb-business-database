# لوحة التحكم: منصة محلات الملابس الرقمية

| العنصر | النوع |
|--------|-------|
| إجمالي المحلات المسجلة | Card Number |
| إجمالي المنتجات المتاحة | Card Number |

## إدارة المحلات
- قائمة المحلات (جدول + بحث + فلتر حسب المديرية)
- إضافة محل جديد
- تفاصيل المحل (منتجاته، طلباته، تقييمه)
- تفعيل أو تعطيل المحل

## إدارة المنتجات
- قائمة جميع المنتجات
- مراجعة المنتجات الجديدة المضافة
- تعديل أسعار وتفاصيل المنتجات
- حذف منتجات مخالفة أو غير مناسبة

## إدارة الطلبات
- قائمة الطلبات المعلقة والجارية
- تفاصيل الطلب (منتجات، عميل، عنوان)
- متابعة حالة التوصيل
- التواصل مع المحل أو العميل

## التقارير والإحصائيات
| التقرير | الوصف |
|---------|-------|
| تقرير المبيعات | مبيعات يومية/أسبوعية/شهرية |
| تقرير المحلات | أداء المحلات (ترتيب، تقييم) |
| تقرير المنتجات | المنتجات الأكثر مبيعًا |
| تقرير المديريات | توزيع الطلبات حسب المديرية |
| تقرير المواسم | مبيعات موسم العيد والمواسم الأخرى |
