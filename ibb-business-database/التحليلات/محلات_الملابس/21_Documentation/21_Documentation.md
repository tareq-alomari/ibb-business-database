## دليل المستخدم (مختصر)
### للعملاء
1. تسجيل حساب عبر رقم الهاتف
2. تصفح الأقسام أو البحث عن منتج
3. فلترة النتائج حسب السعر والمقاس واللون
4. إضافة المنتجات إلى سلة التسوق
5. إدخال عنوان التوصيل واختيار الدفع
6. تأكيد الطلب وانتظار الإشعار

### استلام الطلب
1. التواصل مع المحل عبر واتساب للتأكيد
2. استلام المنتج خلال 24 ساعة
3. فحص المنتج عند الاستلام
4. إمكانية الإرجاع خلال 3 أيام

## دليل المحل (مختصر)
1. تسجيل المحل في المنصة (اسم، موقع، صور)
2. إضافة المنتجات (صور، أسعار، مقاسات)
3. استقبال الطلبات وتأكيدها
4. تجهيز الطلب للتوصيل
5. تحديث حالة الطلب (توصيل / تم التسليم)

## معايير التوثيق
- جميع الوثائق باللغة العربية
- استخدام لغة بسيطة تناسب جميع المستويات
- إرفاق لقطات شاشة توضيحية
- تحديث الوثائق مع كل إصدار جديد
