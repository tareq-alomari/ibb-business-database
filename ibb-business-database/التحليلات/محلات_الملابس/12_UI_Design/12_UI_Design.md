# تصميم واجهة المستخدم: منصة محلات الملابس الرقمية

## نظام التصميم

### لوحة الألوان
| الاستخدام | اللون | الكود |
|-----------|-------|-------|
| Primary | أزرق تجاري | #1976D2 |
| Secondary | برتقالي | #F57C00 |
| Accent | ذهبي موسمي | #FFB300 |
| Background | أبيض | #FFFFFF |
| Text Primary | أسود | #212121 |
| Text Secondary | رمادي | #757575 |
| Discount | أحمر تخفيض | #D32F2F |
| Success | أخضر متاح | #388E3C |

### الخطوط
| الاستخدام | الخط | الحجم |
|-----------|------|-------|
| العناوين الرئيسية | Noto Kufi Arabic (Bold) | 28-40px |
| عناوين المنتجات | Noto Kufi Arabic (Medium) | 18-24px |
| الأسعار والتفاصيل | Noto Sans Arabic (Regular) | 14-18px |
| التوضيحات | Noto Sans Arabic (Light) | 12-13px |

### المسافات
- الوحدة الأساسية: 8px
- Padding: 16px (افتراضي)، 24px (كبير)
- مسافة بين بطاقات المنتجات: 16px
- Margin بين الأقسام: 32px

### دعم RTL
- تصميم كامل للغة العربية بمحاذاة لليمين
- عكس اتجاه أيقونات السهم والتنقل

### مكونات الواجهة
- بطاقات منتج (صورة + اسم + سعر + زر شراء)
- معرض صور متحرك (Swiper)
- شريط تصفية جانبي
- سلة تسوق عائمة (أسفل الشاشة للموبايل)
- نموذج طلب سريع متعدد الخطوات
- شارة "تخفيض" و"جديد" على المنتجات
