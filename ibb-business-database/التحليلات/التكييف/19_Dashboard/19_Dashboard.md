## 19.3 مؤشرات الأداء في لوحات التحكم (Dashboard KPIs)

### لمقدم الخدمة

| المؤشر | الوصف |
|--------|-------|
| الحجوزات اليومية | عدد الحجوزات المستلمة |
| الإيرادات | إجمالي المبيعات |
| متوسط قيمة الحجز | إجمالي المبيعات / عدد الحجوزات |
| معدل التحويل | الحجوزات المكتملة / الإجمالية |
| أكثر الخدمات طلبًا | Top 5 خدمات |
| تقييم مقدم الخدمة | متوسط التقييمات |

### للإدارة

| المؤشر | الوصف |
|--------|-------|
| إجمالي مقدمي الخدمة المسجلين | نشط، معلق، موقوف |
| إجمالي المستخدمين | عملاء، مقدمي خدمة |
| إجمالي الحجوزات | يومي، أسبوعي، شهري |
| إجمالي الإيرادات | من العمولات والإعلانات |
| معدل نمو المستخدمين | شهريًا |
| الأكثر نشاطًا | Top 10 مقدمي خدمة |

## 19.4 تقنيات بناء لوحات التحكم

| المكون | التقنية |
|--------|---------|
| **UI Framework** | React + Material UI / Tailwind |
| **الرسوم البيانية** | Chart.js / Recharts / ApexCharts |
| **الجداول** | AG Grid / React Table |
| **التقارير المباشرة** | WebSocket + Real-time charts |
| **التصدير** | CSV, PDF (jsPDF) |
| **RTL** | دعم كامل للغة العربية |
