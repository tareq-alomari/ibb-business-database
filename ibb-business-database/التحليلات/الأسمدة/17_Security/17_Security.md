## 17.2 إجراءات الأمان

### المصادقة والتفويض
- JWT (15 دقيقة) + Refresh Token (7 أيام)
- OTP عبر الهاتف
- bcrypt لكلمات المرور
- RBAC: customer, entity_owner, admin

### حماية البيانات
- TLS 1.3 للاتصالات
- AES-256 للتخزين
- Parameterized queries لمنع SQL Injection
- Input validation (Zod)

### حماية API
- Rate limiting: 100 طلب/دقيقة
- CORS مقيد
- IP Whitelisting للوحة الإدارة
