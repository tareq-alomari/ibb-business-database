# تصميم واجهة المستخدم (UI) - قطاع الحضانات في إب

## الهوية البصرية

### الألوان الأساسية
- الرئيسي: أزرق فاتح (#4A90D9) - يرمز للثقة والطمأنينة
- الثانوي: برتقالي (#F5A623) - يرمز للدفء والنشاط
- الخلفية: أبيض (#FFFFFF) وأوف وايت (#F8F9FA)
- النصوص: رمادي غامق (#333333)

### الخطوط
- الخط العربي: أميري / Cairo
- الأحجام: العناوين 24-32px، النصوص 14-16px

### الأيقونات
- أيقونات بسيطة وواضحة
- أيقونات مخصصة للأطفال (نجوم، أشكال مرحة)
- ألوان زاهية للأقسام المختلفة

## واجهات رئيسية

### الصفحة الرئيسية
- شريط بحث في الأعلى
- بطاقات حضانات مميزة
- قسم إحصائيات سريع
- أزرار دعوة للإجراء (CTA)

### صفحة الحضانات
- grid بعرض 3 أعمدة (سطح مكتب)
- عمود واحد (جوال)
- فلترة حسب المنطقة والسعر والفئة العمرية
- صورة + اسم + تقييم + سعر

### ملف الحضانة
- معرض صور
- معلومات أساسية
- الخدمات المقدمة
- جدول الأسعار
- موقع على الخريطة
- قسم التقييمات

### لوحة تحكم ولي الأمر
- أطفال مسجلين
- جدول الحضور
- الفواتير
- التواصل مع الحضانة

### لوحة تحكم الإدارة
- إحصائيات ورسوم بيانية
- قوائم إدارية
- تقارير قابلة للتصدير
- إدارة المستخدمين
