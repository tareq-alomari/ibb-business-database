# لوحة التحكم والإحصائيات - قطاع الحضانات في إب

## لوحة التحكم الرئيسية (Admin Dashboard)

### مؤشرات الأداء (KPIs)
- عدد الحضانات المسجلة (نشط / موقف / قيد الترخيص)
- عدد الأطفال المسجلين إجمالاً
- نسبة الإشغال الإجمالية
- إجمالي الإيرادات الشهرية
- تقييم الرضا العام

### الرسوم البيانية
- منحنى نمو عدد الحضانات (سنوي)
- توزيع الحضانات حسب الأحياء (خريطة حرارية)
- نسبة الإشغال لكل حضانة (مخطط شريطي)
- اتجاهات التسجيل الشهرية (خط زمني)
- مقارنة الأسعار بين الحضانات

## لوحة تحكم الحضانة (Nursery Dashboard)

### المؤشرات
- عدد الأطفال المسجلين
- نسبة الحضور اليومية
- المدفوعات المستلمة والمتأخرة
- تقييم الحضانة
- طلبات التسجيل الجديدة

### الإدارة
- قائمة الأطفال مع حالة الحضور
- جدول الموظفين
- الفواتير والمدفوعات
- إعلانات وتنبيهات لأولياء الأمور
- تقارير أسبوعية / شهرية

## لوحة تحكم ولي الأمر (Parent Dashboard)

### المعلومات
- حالة حضور الطفل اليوم
- سجل المدفوعات
- الفواتير المستحقة
- تقارير الطفل (سلوك، نشاط)
- التواصل مع الإدارة

### التنبيهات
- إشعارات الحضور والانصراف
- تذكير بدفع الرسوم
- إعلانات الحضانة
- مواعيد الأنشطة والمناسبات

## التقارير المتقدمة
- تقارير قابلة للتصدير (PDF, Excel, CSV)
- تقارير دورية آلية (أسبوعي / شهري)
- تحليل مقارن بين الحضانات
- تنبؤات الطلب والإشغال (باستخدام AI)

## إعدادات التحكم
- صلاحيات المستخدمين
- تخصيص الإشعارات
- إعدادات الفواتير والأسعار
- إدارة اللغات (عربي / إنجليزي)
