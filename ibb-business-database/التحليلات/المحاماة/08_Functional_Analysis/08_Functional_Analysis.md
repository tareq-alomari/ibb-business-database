## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: ملف محام
- **F10**: إدارة القضايا
- **F11**: جدولة المواعيد
- **F12**: فواتير
- **F13**: مكتبة قانونية
- **F14**: تقارير

### للعملاء

- **F1**: تسجيل
- **F2**: بحث عن محام
- **F3**: استشارة قانونية
- **F4**: حجز موعد
- **F5**: رفع مستندات
- **F6**: متابعة
- **F7**: دفع
- **F8**: تقييم

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
