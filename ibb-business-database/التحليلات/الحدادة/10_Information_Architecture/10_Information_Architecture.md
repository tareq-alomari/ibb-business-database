## 10.1 هيكل المعلومات العام

```
تطبيق الحدادة إب
│
├── الشاشات الرئيسية (غير مسجل)
│   ├── الصفحة الرئيسية
│   │   ├── البحث
│   │   ├── التصنيفات السريعة
│   │   ├── مقدمي الخدمة المميزين
│   │   └── العروض الحالية
│   ├── قائمة الخدمات
│   │   ├── فلترة (نوع، موقع، سعر، تقييم)
│   │   └── ترتيب (الأعلى تقييمًا، الأقرب، الأحدث)
│   ├── صفحة مقدم الخدمة
│   │   ├── معلومات (اسم، موقع، تقييم، ساعات العمل)
│   │   ├── الخدمات (قائمة مع أسعار)
│   │   ├── معرض الأعمال
│   │   ├── التقييمات والمراجعات
│   │   └── العروض المتاحة
│   └── تسجيل الدخول
│
├── الشاشات الرئيسية (مسجل دخول)
│   ├── الصفحة الرئيسية (مخصصة)
│   ├── الحجوزات
│   ├── سجل الخدمات السابقة
│   ├── المفضلة
│   └── إعدادات الحساب
│       ├── معلومات شخصية
│       ├── العناوين المحفوظة
│       ├── طرق الدفع
│       └── الإشعارات
│
├── لوحة تحكم مقدم الخدمة
│   ├── لوحة الإحصائيات (حجوزات اليوم، الإيرادات، التقييم)
│   ├── إدارة الخدمات (إضافة، تعديل، حذف)
│   ├── إدارة الحجوزات (جديدة، قيد التنفيذ، مكتملة)
│   ├── معرض الأعمال (إضافة صور وأعمال سابقة)
│   ├── العروض
│   ├── التقارير (يومي، أسبوعي، شهري)
│   └── الإعدادات
│
└── لوحة الإدارة (Admin)
    ├── لوحة الإحصائيات
    ├── إدارة مقدمي الخدمة
    ├── إدارة المستخدمين
    ├── مراجعة المحتوى
    ├── إدارة الإعلانات
    ├── التقارير العامة
    └── الإعدادات
```

## 10.2 نظام التصنيف (Taxonomy)

| المستوى الأول | المستوى الثاني | أمثلة |
|--------------|---------------|-------|
| حسب نوع الخدمة | خدمات أساسية | أبواب حديد |
| | خدمات متخصصة | شبابيك حديد |
| | خدمات متميزة | درابزين |
| حسب السعر | اقتصادي | أقل من 20,000-200,000 ريال للمشروع |
| | متوسط | متوسط السعر |
| | مرتفع | أعلى من المتوسط |
| حسب الموقع | وسط المدينة | مدينة إب |
| | الأحياء | الربوة، السحول، النصر |
| | المديريات | جبلة، يريم، العدين |

## 10.3 User Flow الرئيسي

### تدفق حجز الخدمة

```
فتح التطبيق → الصفحة الرئيسية
    → بحث / تصفح → اختيار مقدم خدمة
    → عرض التفاصيل والأعمال السابقة
    → اختيار الخدمة والموعد
    → تأكيد الحجز ← إشعارات التحديث
    → استلام الخدمة ← تقييم التجربة
```

## 10.4 Sitemap للتطبيق

```
/                           ← الصفحة الرئيسية
/services                   ← قائمة الخدمات
/services/:id               ← صفحة خدمة
/provider/:id               ← صفحة مقدم الخدمة
/provider/:id/portfolio     ← معرض الأعمال
/provider/:id/reviews       ← التقييمات
/bookings                   ← حجوزاتي
/bookings/:id               ← تفاصيل الحجز
/favorites                  ← المفضلة
/offers                     ← العروض
/profile                    ← الملف الشخصي
/notifications              ← الإشعارات
```
