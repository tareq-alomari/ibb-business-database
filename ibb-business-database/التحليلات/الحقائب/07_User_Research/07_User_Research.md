# بحث المستخدمين - مستهلكي الحقائب في إب

## الشخصيات الرئيسية للمستخدمين

### شخصية ١: الطالب
- الاسم: أحمد (١٨ سنة)
- الاستخدام: حقائب مدرسية وحقيبة ظهر
- الميزانية: ٥,٠٠٠ - ١٠,٠٠٠ ريال
- الأولوية: المتانة والسعر المناسب
- قناة الشراء: المتجر التقليدي أو واتساب

### شخصية ٢: الموظف المحترف
- الاسم: محمد (٣٥ سنة)
- الاستخدام: حقيبة لابتوب، حقيبة جلدية
- الميزانية: ٢٠,٠٠٠ - ٥٠,٠٠٠ ريال
- الأولوية: الجودة والمظهر الأنيق
- قناة الشراء: متاجر متخصصة أو طلب عبر الإنترنت

### شخصية ٣: ربة الأسرة
- الاسم: فاطمة (٤٠ سنة)
- الاستخدام: حقيبة يد، حقيبة تسوق
- الميزانية: ١٠,٠٠٠ - ٢٥,٠٠٠ ريال
- الأولوية: الأناقة والمساحة الداخلية
- قناة الشراء: متاجر المدينة القديمة

### شخصية ٤: صاحب متجر
- الاسم: عبدالله (٤٥ سنة)
- الاستخدام: شراء جملة لإعادة البيع
- الميزانية: ٢٠٠,٠٠٠ - ٥٠٠,٠٠٠ ريال
- الأولوية: السعر المنافس والتنوع
- قناة الشراء: اتصال مباشر مع الموردين

## رحلة المستخدم
١. البحث عن منتج (جوجل، فيسبوك، واتساب)
٢. المقارنة بين الخيارات المتاحة
٣. الاستفسار عن السعر والمواصفات
٤. اتخاذ قرار الشراء
٥. الدفع (نقداً أو حوالة)
٦. استلام المنتج (توصيل أو استلام شخصي)

## نقاط الألم
- صعوبة المقارنة بين المنتجات
- عدم وجود معلومات موثوقة عن الجودة
- قلة خيارات التوصيل
- عدم وجود سياسة إرجاع واضحة
