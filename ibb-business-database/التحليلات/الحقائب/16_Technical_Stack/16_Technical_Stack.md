# التقنيات المستخدمة - منصة الحقائب في إب

## الواجهة الأمامية (Frontend)
- Next.js 14 (React Framework)
- Tailwind CSS (تصميم متجاوب)
- Shadcn/UI (مكونات واجهة)
- React Query (إدارة حالة الخادم)
- Zod (التحقق من صحة النماذج)
- Framer Motion (حركات وانتقالات)

## الواجهة الخلفية (Backend)
- Node.js مع NestJS (إطار العمل الرئيسي)
- TypeScript (لغة البرمجة)
- Express.js (للخدمات البسيطة)
- Prisma ORM (التفاعل مع قاعدة البيانات)
- Bull Queue (إدارة المهام الخلفية)
- Socket.io (التواصل الفوري)

## قاعدة البيانات
- PostgreSQL (قاعدة البيانات الرئيسية)
- Redis (تخزين مؤقت وجلسات)
- MinIO (تخزين الصور والملفات)

## البنية التحتية
- Docker + Docker Compose (حاويات التطوير)
- Kubernetes (إدارة الحاويات في الإنتاج)
- Nginx (خادم وكيل عكسي)
- GitHub Actions (CI/CD)
- AWS / DigitalOcean (استضافة سحابية)

## الأمان
- Helmet.js (حماية HTTP)
- JWT + OAuth 2.0 (مصادقة)
- bcrypt (تشفير كلمات المرور)
- Rate Limiting (تحديد المعدل)
- CORS (مشاركة الموارد)

## التحليلات والمراقبة
- Google Analytics 4
- Sentry (تتبع الأخطاء)
- Prometheus + Grafana (مراقبة)
- ELK Stack (سجلات)

## أدوات التطوير
- Git + GitHub (إدارة الإصدارات)
- ESLint + Prettier (جودة الكود)
- Jest + Cypress (اختبارات)
- Storybook (توثيق المكونات)
- Swagger (توثيق API)

## تحسين محركات البحث
- Next.js SSR/SSG
- structured data (JSON-LD)
- sitemap.xml, robots.txt
- Open Graph tags
- تحسين الصور (WebP, Lazy Loading)
