# تصميم واجهة المستخدم (UI) - منصة الحقائب في إب

## هوية العلامة التجارية
- الألوان الأساسية: أزرق داكن (#1B3A4B) وذهبي (#C9A84C)
- الألوان الثانوية: أبيض (#FFFFFF) ورمادي فاتح (#F5F5F5)
- الخط: Tajawal للعربية، خط حديث ونظيف
- الشعار: تصميم بسيط لحقيبة بأناقة عصرية

## تصميم الصفحات الرئيسية

### الصفحة الرئيسية
- شريط علوي مع شعار وروابط التنقل
- بانر دوار للعروض والتخفيضات
- أقسام التصنيفات الرئيسية بصورة بطاقة
- المنتجات الأكثر مبيعاً
- عروض خاصة ومحدودة
- تذييل مع معلومات التواصل والروابط

### صفحة التصنيفات
- عرض شبكي للتصنيفات الرئيسية
- صورة تعبر عن كل تصنيف
- عدد المنتجات المتاحة في كل تصنيف

### صفحة المنتجات
- فلتر جانبي (السعر، اللون، الحجم، التقييم)
- عرض المنتجات بشكل شبكي أو قائمة
- صورة المنتج، السعر، التقييم، اسم المتجر
- زر إضافة إلى السلة

### صفحة تفاصيل المنتج
- صور متعددة للمنتج مع معرض صور
- اسم المنتج والوصف التفصيلي
- السعر والخصومات المتاحة
- معلومات الشحن والتوصيل
- تقييمات العملاء
- منتجات مشابهة

### سلة التسوق
- قائمة بالمنتجات المختارة مع الصور
- تعديل الكميات أو حذف المنتجات
- إجمالي السعر والضرائب
- كود خصم
- زر متابعة الشراء

## أيقونات ورموز
- أيقونات مختلفة لأنواع الحقائب
- رموز حالة الطلب (قيد المعالجة، تم الشحن، تم التوصيل)
- أيقونات التقييم والتقارير
