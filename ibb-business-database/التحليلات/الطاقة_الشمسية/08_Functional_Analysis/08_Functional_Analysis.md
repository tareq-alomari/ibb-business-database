## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: متجر مورد
- **F10**: إدارة مخزون
- **F11**: إدارة مشاريع
- **F12**: شهادات جودة
- **F13**: كتالوج
- **F14**: تقارير

### للعملاء

- **F1**: تسجيل
- **F2**: حاسبة احتياجات
- **F3**: تصفح منتجات
- **F4**: مقارنة عروض
- **F5**: طلب تركيب
- **F6**: متابعة تنفيذ
- **F7**: دفع
- **F8**: ضمان

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
