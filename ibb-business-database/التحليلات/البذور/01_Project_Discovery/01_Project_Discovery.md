# المرحلة الأولى: Project Discovery - قطاع البذور في محافظة إب

> **التاريخ**:  يوليو 2026  
> **الملف**: 01_Project_Discovery.md

---

## 1.1 المشكلة (Problem Statement)

يعاني قطاع البذور في محافظة إب من تحديات كبيرة رغم كونه قطاعًا حيويًا. لا توجد منصة موحدة تتيح للمستفيدين اكتشاف الخدمات أو مقارنتها. المشكلات الرئيسية:

1. **ندرة البذور المحسنة**
2. **ارتفاع أسعار البذور المستوردة**
3. **ضعف جودة البذور المحلية**
4. **غياب فحص الجودة**
5. **توزيع غير منظم**

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لقطاع البذور في محافظة إب** تتكون من:

- **دليل البذور**: قاعدة بيانات بأنواع البذور المتوفرة
- **مقارنة الأسعار**: مقارنة أسعار البذور بين الموزعين
- **التوفر الموسمي**: جدول توفر البذور حسب الموسم
- **تقييم المزارعين**: تقييمات لمصادر البذور
- **طلب بذور**: تقديم طلبات شراء بذور أونلاين

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستهلك/المواطن** | سهولة الوصول للمعلومات، مقارنة الخدمات، تقييمات حقيقية |
| **مزود الخدمة/البذور** | وصول لشريحة أكبر، تحسين السمعة، إدارة رقمية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات، عمولات، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، مكاتب البذور المحلية |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| حصر الجهات/البذور | عدد المسجلين | 100++ |
| دقة البيانات | نسبة المعلومات المؤكدة | 90%+ |
| سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| رضا المستخدمين | تقييم المنصة | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن تكون المنصة الرقمية لقطاع البذور في محافظة إب المرجع الأول الذي يعتمد عليه كل مواطن، محولة تجربة البذور إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مزودي خدمات البذور والمستفيدين في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - أرض زراعية خصبة في إب | - غياب الرقابة على الجودة |
| - خبرة زراعية كبيرة | - توزيع غير منظم |
| - طلب عالٍ على البذور | - تأخر في تبني التقنيات |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - تحسين الأمن الغذائي | - تغير المناخ |
| - دعم حكومي للقطاع الزراعي | - شح المياه |
| - الزراعة العضوية | - ارتفاع تكاليف الاستيراد |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: عدم استقرار سياسي | خطر على استمرارية الأعمال |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | ارتفاع التكاليف، حساسية السعر |
| **S - Social**: كثافة سكانية عالية، شرائح متنوعة | فرصة كبيرة، تنوع الاحتياجات |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم رقمي | فرصة لتوحيد المعايير |
| **E - Environmental**: تحديات بيئية مختلفة | فرصة لنشر التوعية |
