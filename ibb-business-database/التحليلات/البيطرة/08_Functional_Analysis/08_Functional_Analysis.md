## 8.2 حالات الاستخدام (Use Cases)

### UC1: دليل الأطباء البيطريين

**الممثل**: مستخدم
**الوصف**: قاعدة بيانات بالعيادات والبيطريين

سيناريو النجاح:
1. يسجل المستخدم الدخول
2. يتصفح القائمة المتاحة
3. يبحث ويستخدم الفلاتر
4. يختار الخدمة المناسبة
5. يقيم التجربة

### UC2: حجز موعد بيطري

**الممثل**: مزود الخدمة
**الوصف**: حجز مواعيد للكشف على الحيوانات

سيناريو النجاح:
1. يسجل مزود الخدمة الدخول
2. يدخل إلى لوحة التحكم
3. يضيف/يعدل بياناته
4. ينشر التحديثات
