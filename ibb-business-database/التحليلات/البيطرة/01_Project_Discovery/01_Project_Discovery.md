# المرحلة الأولى: Project Discovery - قطاع البيطرة في محافظة إب

> **الملف**: 01_Project_Discovery.md

## 1.1 المشكلة (Problem Statement)

يعاني قطاع البيطرة في محافظة إب من تحديات كبيرة رغم كونه قطاعًا حيويًا. لا توجد منصة موحدة تتيح للمستفيدين اكتشاف الخدمات أو مقارنتها. المشكلات الرئيسية:

1. **نقص الأطباء البيطريين المؤهلين**
2. **غلاء اللقاحات والأدوية البيطرية**
3. **ضعف الوعي الصحي الحيواني**
4. **صعوبة الوصول للمناطق الريفية**
5. **غياب سجل صحي موحد**

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لقطاع البيطرة في محافظة إب** تتكون من:

- **دليل الأطباء البيطريين**: قاعدة بيانات بالعيادات والبيطريين
- **حجز موعد بيطري**: حجز مواعيد للكشف على الحيوانات
- **دليل اللقاحات**: معلومات عن اللقاحات وجدول التحصين
- **استشارة بيطرية عن بعد**: استشارات فورية مع أطباء
- **سجل الثروة الحيوانية**: سجل صحي لكل حيوان

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستهلك/المواطن** | سهولة الوصول للمعلومات، مقارنة الخدمات، تقييمات حقيقية |
| **مزود الخدمة/البيطرة** | وصول لشريحة أكبر، تحسين السمعة، إدارة رقمية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات، عمولات، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، مكاتب البيطرة المحلية |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| حصر الجهات/البيطرة | عدد المسجلين | 40++ |
| دقة البيانات | نسبة المعلومات المؤكدة | 90%+ |
| سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| رضا المستخدمين | تقييم المنصة | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن تكون المنصة الرقمية لقطاع البيطرة في محافظة إب المرجع الأول الذي يعتمد عليه كل مواطن، محولة تجربة البيطرة إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مزودي خدمات البيطرة والمستفيدين في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - ثروة حيوانية كبيرة | - توزيع غير متساو للخدمات |
| - طلب متزايد على الخدمات البيطرية | - قلة التجهيزات الحديثة |
| - خبرات بيطرية محلية | - ضعف التوعية الصحية |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - مشاريع الأمن الغذائي | - الأمراض الوبائية |
| - دعم المنظمات الدولية للثروة الحيوانية | - الجفاف وشح المراعي |
| - الاستشارات عن بعد | - ارتفاع تكاليف الاستيراد |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: عدم استقرار سياسي | خطر على استمرارية الأعمال |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | ارتفاع التكاليف، حساسية السعر |
| **S - Social**: كثافة سكانية عالية، شرائح متنوعة | فرصة كبيرة، تنوع الاحتياجات |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم رقمي | فرصة لتوحيد المعايير |
| **E - Environmental**: تحديات بيئية مختلفة | فرصة لنشر التوعية |
