## 3.1 معلومات أساسية عن القطاع

| العنصر | القيمة |
|--------|--------|
| **عدد المنشآت التقديري** | 60+ في كامل المحافظة |
| **النسبة الأكبر** | كافتيريات مدرسية وجامعية (33%) |
| **المنطقة الأكثر كثافة** | شارع الجيش، وسط المدينة، قرب المدارس والجامعات، السحول |
| **عدد العمالة التقديري** | 200-400 عامل |
| **حجم السوق التقديري السنوي** | ~1-2 مليار ريال |
| **متوسط الإنفاق الشهري للفرد** | 5,000 - 15,000 ريال |

## 3.4 الشركاء المحتملون

| الشريك | دور الشراكة |
|--------|------------|
| **غرفة تجارة وصناعة إب** | دعم تسويقي، توفير قاعدة بيانات تجارية |
| **المنشآت الكبرى** | شركاء أساسيون، محتوى حصري |
| **الجهات المختصة** | تراخيص، تصنيف رسمي |
| **مؤسسات الدفع الإلكتروني** | تكامل الدفع |
| **مؤسسات القطاع الخاص** | إعلانات، رعاية |

## 3.5 الفجوات في السوق

| الفجوة | الوصف | التأثير |
|--------|-------|---------|
| **لا يوجد دليل موحد** | معلومات المنشآت مبعثرة | صعوبة على المستخدم في الاختيار |
| **غياب التقييمات الموثوقة** | تقييمات شفهية فقط | عدم شفافية |
| **حجز غير منظم** | كل منشأة بنظامها الخاص | بطء، أخطاء |
| **محتوى رقمي محدود** | معظم المنشآت بدون محتوى إلكتروني | وصول محدود |
| **لا يوجد دفع إلكتروني** | نقدي فقط | مخاطر أمنية |

## 3.6 الفرص الرقمية للقطاع

| الفرصة | الوصف | العائد المحتمل |
|--------|-------|---------------|
| **منصة حجز ذكية** | ربط المستخدم بالمنشأة في تطبيق واحد | عمولة لكل حجز |
| **إعلانات مستهدفة** | إعلانات للمنشآت ضمن التطبيق | إيرادات إضافية |
| **تقارير وتحليلات** | بيانات وإحصائيات للمنشآت | خدمة مدفوعة |
| **برنامج ولاء متكامل** | نقاط لكل حجز | ولاء المستخدمين |
