## 6.1 قائمة الجهات المعنية (Stakeholders)

### أ. الجهات الأساسية (Primary Stakeholders)

| الجهة | الوصف | الدور في المشروع | مستوى التأثير | مستوى الاهتمام |
|-------|-------|------------------|--------------|---------------|
| **طلاب** | المستفيدون النهائيون | المستخدمون النهائيون للمنصة | عالي | عالي |
| **أصحاب كافتيريات** | مالكو المنشآت | مزودو الخدمة، شركاء المنصة | عالي | عالي |
| **عمال** | العاملون في القطاع | مزودو الخدمة | متوسط | عالي |

### ب. الجهات الداعمة (Secondary Stakeholders)

| الجهة | الوصف | الدور | مستوى التأثير |
|-------|-------|-------|--------------|
| **غرفة تجارة وصناعة إب** | دعم تجاري، تسهيلات | شريك استراتيجي | عالي |
| **السلطة المحلية في إب** | المحافظ، المجلس المحلي | دعم سياسي | متوسط |
| **الجهات المختصة** | تراخيص، تنظيم | جهة تنظيمية | متوسط |

### ج. الجهات المساندة (Tertiary Stakeholders)

| الجهة | الوصف | الدور |
|-------|-------|-------|
| **شركات الدفع الإلكتروني** | باي موب، MTN Money | تكامل الدفع |
| **مزودو خدمة الإنترنت** | يمن نت، MTN، سبأفون | البنية التحتية |
| **المؤسسات الإعلامية المحلية** | إذاعة إب، صحف محلية | تغطية إعلامية |
| **الجامعات المحلية** | جامعة إب، جامعة جبلة | دعم بحثي |
| **المستثمرون المحليون** | رجال أعمال في إب | تمويل واستثمار |

## 6.2 تحليل المصلحة والتأثير

```
تأثير عالي
    │
    │   أبقي راضيًا              │   أدر بإحكام
    │   • غرفة تجارة إب          │   • طلاب
    │   • السلطة المحلية         │   • أصحاب كافتيريات
    │                            │   • عمال
────┼────────────────────────────┼─────
    │                            │
    │   راقب (Monitor)           │   أبق على اطلاع
    │   • شركات الدفع            │   • وسائل الإعلام
    │   • مزودو الإنترنت         │   • الجامعات
    │                            │   • المستثمرون
    │                    مصلحة عالي
```

## 6.3 استراتيجية التواصل

| الجهة | قناة التواصل | التكرار | المحتوى |
|-------|-------------|---------|---------|
| **طلاب** | إشعارات التطبيق، واتساب | يومي | عروض، منشآت جديدة، تقييمات |
| **أصحاب كافتيريات** | اتصال مباشر، واتساب | أسبوعي | تحديثات، إحصائيات، دعم فني |
| **غرفة تجارة إب** | اجتماعات شهرية | شهري | تقدم المشروع، إحصائيات |

## 6.4 متطلبات كل جهة

| الجهة | المتطلبات الرئيسية |
|-------|-------------------|
| **طلاب** | سهولة الاستخدام، معلومات دقيقة، أسعار محدثة |
| **أصحاب كافتيريات** | وصول لشريحة أكبر، تقارير، إدارة سهلة |
| **غرفة تجارة إب** | إحصائيات القطاع، مساهمة في التنمية المحلية |
