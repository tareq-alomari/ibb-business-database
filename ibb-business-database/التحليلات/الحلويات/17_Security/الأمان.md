# الأمان: منصة الحلويات في إب

## سياسات الأمان العامة
- تطبيق مبدأ أقل صلاحية (Least Privilege)
- فصل صلاحيات الأدمن والمستخدمين والمحلات
- تسجيل جميع العمليات الحساسة (Audit Log)
- مراجعة أمنية دورية للنظام

## أمان المصادقة والتفويض
- تشفير كلمات المرور باستخدام bcrypt
- تفعيل المصادقة الثنائية (2FA) للحسابات المهمة
- جلسات آمنة مع انتهاء صلاحية تلقائية
- إعادة تعيين كلمة المرور عبر البريد أو الرسائل النصية
- حماية من هجمات القوة العمياء (Rate Limiting)

## أمان البيانات
- تشفير البيانات الحساسة في قاعدة البيانات
- تشفير الاتصالات عبر HTTPS/TLS
- عدم تخزين معلومات الدفع الحساسة
- إخفاء البيانات الشخصية في التقارير
- سياسة خصوصية وشفافية في جمع البيانات

## حماية التطبيق
- التحقق من صحة المدخلات (Input Validation)
- منع حقن SQL عبر Prepared Statements
- حماية من XSS بتعقيم المخرجات
- حماية من CSRF باستخدام Tokens
- فحص الملفات المرفوعة (صور المنتجات)

## أمن API
- مصادقة عبر JWT مع فترة صلاحية محدودة
- Refresh Tokens للجلسات الطويلة
- Rate Limiting (100 طلب/دقيقة للمستخدم)
- التحقق من صحة الطلبات (Request Validation)
- API Keys للمتكاملين الخارجيين

## إدارة الثغرات
- فحص دوري للثغرات الأمنية
- خطة استجابة للحوادث الأمنية
- تحديث المكتبات والحزم بشكل دوري
- تقارير أمنية شهرية للإدارة
- تشفير النسخ الاحتياطية للبيانات

## الامتثال والمعايير
- الامتثال لقوانين حماية البيانات المحلية
- معايير PCI DSS للدفع الإلكتروني
- سياسة خصوصية متوافقة مع GDPR
- إشعار المستخدمين عند جمع البيانات
- حق المستخدم في حذف بياناته
