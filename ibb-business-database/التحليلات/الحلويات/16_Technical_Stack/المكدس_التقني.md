# المكدس التقني: منصة الحلويات في إب

## تقنيات الواجهة الأمامية
- إطار العمل: React.js أو Vue.js (مجتمع كبير ودعم عربي)
- إدارة الحالة: Redux Toolkit أو Vuex
- تصميم: Tailwind CSS أو Material UI
- تطبيق جوال: React Native (تكامل مع الويب)
- مكتبات إضافية: Axios للطلبات، React Router للتنقل

## تقنيات الخادم
- لغة البرمجة: Node.js (Express/NestJS) أو Python (Django/FastAPI)
- API: RESTful مع توثيق Swagger
- المصادقة: JWT (JSON Web Tokens)
- البريد الإلكتروني: SendGrid أو SMTP محلي

## قاعدة البيانات والتخزين
- قاعدة بيانات رئيسية: PostgreSQL
- ذاكرة تخزين مؤقت: Redis
- تخزين الملفات: AWS S3 أو MinIO للتخزين المحلي
- محرك بحث: Elasticsearch للبحث في المنتجات والمحلات

## البنية التحتية
- استضافة: خوادم محلية أو AWS/GCP
- حاويات: Docker + Docker Compose
- Orchestration: Kubernetes (عند الحاجة للتوسع)
- CDN: Cloudflare أو CDN محلي
- Domain: نطاق .ye أو نطاق دولي

## أدوات التطوير
- إدارة الكود: Git + GitHub/GitLab
- CI/CD: GitHub Actions أو GitLab CI
- إدارة المشروع: Jira أو Trello
- التوثيق: Swagger API Docs + Markdown
- الاختبارات: Jest (Frontend)، Pytest (Backend)

## التكاملات الخارجية
- بوابات دفع: فوري، يمون كاش، باي بال
- خرائط: Google Maps أو OpenStreetMap
- إشعارات: Firebase Cloud Messaging
- تحليلات: Google Analytics محلي
- رسائل نصية: Twilio أو مزود محلي

## متطلبات الأجهزة
- خادم تطبيقات: 4-8 CPU, 16-32GB RAM
- خادم قاعدة بيانات: 4 CPU, 16GB RAM, SSD
- تخزين: 100-500GB حسب عدد الصور والبيانات
- نطاق ترددي: 1-5 TB شهرياً حسب الطلب
