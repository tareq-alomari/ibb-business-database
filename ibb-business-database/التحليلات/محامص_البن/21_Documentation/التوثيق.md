# التوثيق: منصة محامص البن في إب

## وثائق المشروع

### 1. دليل المستخدم
- كيفية التسجيل وإنشاء حساب.
- كيفية البحث عن محمصة.
- كيفية تقديم طلب شراء بن.
- كيفية تتبع حالة الطلب.
- كيفية تقييم المحمصة.
- كيفية إدارة الملف الشخصي.

### 2. دليل المحمصة (صاحب المحل)
- كيفية تسجيل محمصة على المنصة.
- كيفية إدارة المنتجات والأسعار.
- كيفية استقبال ومعالجة الطلبات.
- كيفية عرض الإحصائيات والتقارير.
- نصائح لتحسين التقييم والظهور.

### 3. دليل المطور
- نظرة عامة على بنية النظام.
- توثيق API الكامل (Swagger/OpenAPI).
- تعليمات تشغيل المشروع محليًا.
- تعليمات النشر والاستضافة.
- إرشادات المساهمة في التطوير.

### 4. وثائق البيانات
- قاموس البيانات (Data Dictionary).
- مخطط قاعدة البيانات (ERD).
- قواعد الأعمال (Business Rules).
- سياسات الخصوصية وأمان البيانات.

## أدوات التوثيق
- Swagger/OpenAPI لتوثيق الـ API.
- Storybook للمكونات البصرية.
- Notion أو Confluence للوثائق العامة.
- README.md لكل جزء من المشروع.

## لغة التوثيق
- اللغة العربية للمستخدمين وأصحاب المحامص.
- اللغة الإنجليزية للمطورين (اختياري مع العربية).
