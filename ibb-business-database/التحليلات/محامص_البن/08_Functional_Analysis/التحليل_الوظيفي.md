# التحليل الوظيفي: نظام محامص البن في إب

## الوظائف الأساسية للنظام المقترح

### 1. إدارة المحامص
- تسجيل محمصة جديدة (الاسم، الموقع، التواصل).
- تحديث بيانات المحمصة.
- عرض قائمة المحامص مع خريطة تفاعلية.

### 2. إدارة المنتجات
- إضافة أنواع البن المتوفرة.
- تحديد أسعار البيع للكيلو والربع والنصف.
- تحديث المخزون بشكل لحظي.

### 3. إدارة الطلبات
- إنشاء طلب شراء جديد.
- متابعة حالة الطلب (قيد التحضير، تم التوصيل).
- إرسال إشعارات للعميل.

### 4. إدارة التوصيل
- تحديد منطقة التوصيل.
- حساب رسوم التوصيل.
- جدولة مواعيد التوصيل.

### 5. التقارير والتحليلات
- تقارير المبيعات اليومية والأسبوعية والشهرية.
- تحليل سلوك العملاء.
- التنبؤ بالطلب.

### 6. نظام المدفوعات
- دفع نقدي عند الاستلام.
- دفع إلكتروني عبر المحافظ.

### 7. نظام التقييمات
- تقييم المحامص من قبل العملاء.
- إضافة تعليقات وتقييمات بالنجوم.
