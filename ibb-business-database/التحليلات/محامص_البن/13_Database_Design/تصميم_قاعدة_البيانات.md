## الجداول الرئيسية

**المحامص (Roasteries):** id, name, address, phone, lat/lng, working_hours, rating, status.

**المنتجات (Products):** id, roastery_id, name, type (حميدي/عدني/برعي), price_per_kg, stock, description.

**المستخدمون (Users):** id, name, phone, password_hash, address.

**الطلبات (Orders):** id, user_id, roastery_id, items (JSON), total, status, delivery_address, created_at.

**التقييمات (Reviews):** id, user_id, roastery_id, rating (1-5), comment.

**عربة التسوق (Carts):** id, user_id, items (JSON), updated_at.

**الإشعارات (Notifications):** id, user_id, title, body, type, is_read, created_at.

**قائمة العناوين (Addresses):** id, user_id, label, full_address, lat, lng, is_default.

## العلاقات
- المحمصة → منتجات (One-to-Many).
- المستخدم → طلبات (One-to-Many).
- المحمصة → تقييمات (One-to-Many).
- المستخدم → عناوين (One-to-Many).
- المستخدم → إشعارات (One-to-Many).

## ملاحظات التصميم
- استخدام UUID للمعرفات لتجنب التصادم.
- فهرسة الحقول التي يتم البحث عنها (name, type, status).
- اعتماد JSON للمصفوفات (مثل items في الطلبات) للمرونة.
- إضافة timestamps (created_at, updated_at) لكل جدول.
- استخدام ENUM للحقول المحدودة (status, type, payment_method).
