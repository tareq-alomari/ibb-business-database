## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: متجر منتج
- **F10**: إدارة مخزون
- **F11**: إدارة طلبات
- **F12**: شهادات جودة
- **F13**: عروض
- **F14**: تقارير مبيعات

### للعملاء

- **F1**: تسجيل
- **F2**: تصفح منتجات
- **F3**: بحث وفلترة
- **F4**: مقارنة أسعار
- **F5**: طلب شراء
- **F6**: توصيل
- **F7**: دفع
- **F8**: تقييم جودة

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
