## 1.1 المشكلة (Problem Statement)

تعاني محافظة إب من **تشتت معلوماتي حاد** فيما يخص المستشفيات العاملة فيها. لا توجد قاعدة بيانات موحدة أو منصة رقمية تتيح للمواطنين والمتخصصين والمنظمات الإنسانية الوصول إلى معلومات دقيقة ومحدثة عن المستشفيات. هذا التشتت يؤدي إلى:

1. **صعوبة وصول المرضى**: المواطن لا يعرف أقرب مستشفى لحالته، ولا التخصصات المتاحة، ولا أرقام الطوارئ
2. **ضعف التخطيط الصحي**: غياب البيانات يعني غياب التحليل وغياب القرارات المبنية على الأدلة
3. **تكرار الجهود**: كل منظمة تدخل إب تبدأ من الصفر في جمع المعلومات
4. **هدر الموارد**: عدم معرفة الفجوات يؤدي إلى توزيع غير متوازن للخدمات

## 1.2 الحل (Proposed Solution)

بناء **نظام معلومات رقمي شامل للمستشفيات في محافظة إب** (Ibb Hospitals Information System) يتكون من:

- **قاعدة بيانات مركزية**: لجميع المستشفيات (حكومية، خاصة، أهلية، ميدانية)
- **منصة بحث وتصفح**: واجهة سهلة بالعربية مع تصنيف حسب التخصص، الموقع، النوع
- **خريطة تفاعلية**: مع إحداثيات GPS ومسارات الوصول
- **نظام تقييم**: تقييمات ومراجعات موثقة للمستشفيات
- **لوحة تحليل وإحصاءات**: للجهات الرسمية والمنظمات
- **API مفتوح**: للتكامل مع أنظمة وزارة الصحة والمنظمات الدولية

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المواطن/المريض** | معرفة المستشفى المناسب، التخصص، الموقع، رقم الطوارئ |
| **المنظمات الإنسانية (WHO, MSF, ICRC)** | بيانات دقيقة لتحديد الفجوات والاحتياجات |
| **وزارة الصحة - مكتب إب** | قاعدة بيانات رسمية للتخطيط واتخاذ القرار |
| **إدارات المستشفيات** | منصة للتعريف بخدماتهم وتحسين الصورة الذهنية |
| **الباحثون والأكاديميون** | بيانات مفتوحة للدراسات والأبحاث الصحية |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | مواطنو محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | منح تنموية (WHO, World Bank, UNOPS)، دعم حكومي، شراكات مع منظمات |
| **نموذج الإيرادات** | خدمة مجانية للمواطنين - خدمات تحليل مدفوعة للمنظمات - إعلانات مستهدفة |
| **القنوات** | منصة ويب (PWA) + تطبيق أندرويد |
| **الشركاء المحتملون** | مكتب الصحة إب، جامعة جبلة، منظمة الصحة العالمية، UNICEF |

## 1.6 Vision & Mission

### Vision
"أن تكون محافظة إب نموذجًا رائدًا في اليمن للشفافية المعلوماتية في القطاع الصحي، حيث يمكن لكل مواطن الوصول إلى معلومات دقيقة وشاملة عن المستشفيات بضغطة زر."

### Mission
"بناء وتشغيل منصة رقمية متكاملة توفر بيانات شاملة ومحدثة عن جميع المستشفيات في محافظة إب، مع أدوات بحث وتصنيف وتقييم وتحليل، تسهم في تحسين الوصول إلى الخدمات الصحية ودعم اتخاذ القرار."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - كثافة سكانية عالية تخلق طلبًا مستمرًا | - ضعف البنية التحتية للإنترنت في الأرياف |
| - وجود مستشفيات رائدة (الثورة، جبلة، المنار) | - انقطاع الكهرباء المتكرر |
| - دعم دولي ومنظمات إنسانية نشطة | - نقص الكوادر التقنية المحلية |
| - انتشار الهواتف الذكية | - ضعف الثقافة الرقمية لدى بعض الفئات |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - تحول رقمي عالمي في القطاع الصحي | - استمرار النزاع المسلح وعدم الاستقرار |
| - تمويل متاح من المنظمات الدولية | - تدهور الوضع الاقتصادي وانخفاض التمويل |
| - شراكة محتملة مع جامعة جبلة ووزارة الصحة | - صعوبة الوصول لبعض المناطق |
| - قابلية التوسع لمحافظات أخرى | - الاعتماد على التمويل الخارجي غير المستقر |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: محافظة إب تحت سيطرة الحوثي، انقسام مؤسسي | خطر على استمرارية المشروع، يحتاج توافق مع جميع الأطراف |
| **E - Economic**: انخفاض الدخل، تدهور العملة، اعتماد على التمويل الخارجي | المستخدمون حساسون للتكلفة، يجب أن تكون الخدمة مجانية |
| **S - Social**: كثافة سكانية، أمية رقمية، احتياج صحي كبير | تصميم بسيط، دعم بالصوت والصورة، واجهة سهلة |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة، لكن هواتف ذكية منتشرة | PWA + دعم Offline-first، تخفيف الاعتماد على الاتصال المستمر |
| **L - Legal**: غياب تشريعات حماية البيانات، ضعف التنظيم الصحي الرقمي | تطبيق أعلى معايير الأمان، توثيق البيانات |
| **E - Environmental**: تلوث مياه، مبيدات مسرطنة، أمراض بيئية متزايدة | فرصة لربط البيانات الصحية بالبيئية، رفع الوعي |
