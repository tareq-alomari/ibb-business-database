## 12.3 Responsive Design

| الشاشة | العرض | التخطيط |
|--------|-------|---------|
| موبايل | < 640px | عمود واحد |
| تابلت | 640-1024px | عمودين |
| ديسكتوب | > 1024px | 3 أعمدة + شريط جانبي |

### Mobile First

```
محتويات الصفحة الرئيسية (موبايل):
1. شريط البحث (Full width)
2. إحصائيات سريعة (صف واحد)
3. تصنيفات (تمرير أفقي)
4. قائمة المستشفيات (عمودي)
5. زر خريطة (ثابت أسفل الشاشة)
```

## 12.5 Accessibility (WCAG 2.1 AA)

| المتطلب | الإجراء |
|---------|---------|
| تباين الألوان | نسبة 4.5:1 على الأقل |
| حجم النص | قابل للتكبير حتى 200% |
| Focus indicators | 2px outline ملون |
| ARIA labels | جميع العناصر التفاعلية |
| Keyboard navigation | Tab order منطقي |
| Screen reader | Announcements للتحديثات |
