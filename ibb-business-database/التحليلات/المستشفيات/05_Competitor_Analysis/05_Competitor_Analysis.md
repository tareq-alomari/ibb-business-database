## 5.2 تحليل كل منافس

### 5.2.1 Google Maps Business Profile

| العنصر | التحليل |
|--------|---------|
| **Business Model** | مجاني |
| **Coverage في إب** | محدود جدًا - بعض المستشفيات فقط |
| **بيانات المستشفيات** | اسم، موقع، هاتف، ساعات العمل (غير مكتملة) |
| **التقييمات** | موجودة لكن غير موثقة |
| **التخصصات الطبية** | غير موجودة |
| **التصنيف** | عام فقط (Hospital) |
| **UX** | واجهة عالمية |
| **SEO** | قوي جدًا |
| **نقاط الضعف الرئيسية** | لا يوجد بحث بالتخصص، بيانات متأخرة، لا خرائط داخلية |

### 5.2.2 Altibbi.com (الدليل الطبي العربي)

| العنصر | التحليل |
|--------|---------|
| **Business Model** | مجاني + إعلانات + خدمات مدفوعة للأطباء |
| **Coverage في إب** | 10-20 إدخال فقط |
| **قوة المحتوى** | معلومات عامة، غير محدثة |
| **التخصصات** | مصنفة بشكل جيد |
| **ALTIBBI IN YEMEN** | تركيزه على الأردن ومصر والسعودية بشكل أساسي |
| **نقطة الضعف** | لا يوجد فريق ميداني في اليمن |

### 5.2.3 Facebook Groups (مجموعات إب الصحية)

| العنصر | التحليل |
|--------|---------|
| **النشاط** | يومي - أسئلة وتوصيات |
| **الجمهور** | نشط جدًا |
| **المصداقية** | منخفضة - آراء شخصية |
| **التنظيم** | غير منظم، التكرار عالي |
| **قابلية البحث** | ضعيفة جدًا |
| **القيمة** | المصدر الوحيد المتاح حاليًا للمواطنين |

### 5.2.4 وزارة الصحة (moh-ye.org)

| العنصر | التحليل |
|--------|---------|
| **Business Model** | حكومي |
| **البيانات** | رسمية - قائمة المرافق الصحية |
| **التحديث** | ربع سنوي |
| **الواجهة** | قديمة، غير متجاوبة مع الموبايل |
| **البحث** | محدود |
| **الخرائط** | غير موجودة |
| **التفاعل** | لا يوجد تقييم أو مراجعات |

## 5.3 أفضل الممارسات المستخلصة (Best Practices)

| الممارسة | الوصف |
|----------|-------|
| **التصنيف الصحي الدقيق** | AN. تصنيف حسب التخصص (قلب، عظام، أطفال...) |
| **التحقق من البيانات** | توثيق رسمي من مكتب الصحة |
| **التقييمات الموثوقة** | مراجعات مرتبطة بمستخدمين حقيقيين |
| **الخرائط التفاعلية** | GPS + اتجاهات + مسارات |
| **تحديث دوري** | فريق ميداني، دورة تحديث ربع سنوية |
| **دعم متعدد الأجهزة** | ويب + موبايل (Android أولوية) |
| **التكامل مع المنظمات** | API للبيانات المفتوحة |
| **لغة عربية بسيطة** | محتوى مفهوم لجميع المستويات |

## 5.4 الميزة التنافسية للمشروع

| الميزة | شرح |
|--------|------|
| **التخصصية** | المنصة الوحيدة المتخصصة بمستشفيات إب فقط |
| **المحتوى المحلي** | فريق ميداني، صور حقيقية، بيانات دقيقة |
| **المجانية** | خدمة مجانية بالكامل للمواطنين |
| **التكامل مع الجهات الرسمية** | شراكة مع مكتب الصحة وجامعة جبلة |
| **البيانات المفتوحة** | API للمنظمات والباحثين |
| **الواجهة العربية** | تصميم يراعي الثقافة المحلية |
