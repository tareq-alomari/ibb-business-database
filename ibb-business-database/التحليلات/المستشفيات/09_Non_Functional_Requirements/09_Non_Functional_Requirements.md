## 9.1 Performance

| المتطلب | الهدف | المقاس |
|---------|-------|--------|
| زمن تحميل الصفحة الرئيسية | < 2 ثانية | Lighthouse |
| زمن البحث | < 1 ثانية | وقت الاستجابة |
| زمن تحميل ملف المستشفى | < 2.5 ثانية | بما في ذلك الصور |
| زمن استجابة API | < 200ms | وقت الاستجابة |
| عدد المستخدمين المتزامنين | 1,000+ | اختبار تحميل |
| حجم الصفحة | < 500KB | بعد الضغط |

## 9.2 Scalability

|---------|-------|

## 9.3 Availability & Reliability

| المتطلب | الهدف |
|---------|-------|
| Uptime | 99.5% (أقل من 44 ساعة توقف سنويًا) |
| وقت التعطل المخطط | < 4 ساعات شهريًا |
| RPO (Recovery Point Objective) | 24 ساعة |
| RTO (Recovery Time Objective) | < 2 ساعة |
| النسخ الاحتياطي | يومي (تلقائي) |
| الاحتفاظ بالنسخ | 30 يوم للنسخ اليومية، 12 شهر للنسخ الشهرية |

| المتطلب | المستوى |
|---------|---------|

| دعم RTL | كامل |

| حجم الخط | قابل للتكبير حتى 200% |
| دعم لوحة المفاتيح | Full keyboard navigation |

## 9.5 Security

| المتطلب | الإجراء |
|---------|---------|
| تشفير الاتصال | HTTPS / TLS 1.3 |
| تشفير كلمات المرور | bcrypt (cost 12) |
| JWT | توكن 24 ساعة + Refresh 7 أيام |
| Rate Limiting | 100 req/min للحسابات المجانية |
| CORS | مقيد بنطاقات محددة |
| CSP | Content Security Policy صارمة |
| XSS Protection | تعقيم المدخلات والمخرجات |
| SQL Injection | Parameterized Queries (Prisma) |
| Audit Log | تسجيل جميع العمليات الحساسة |
| Backup Encryption | AES-256 للنسخ الاحتياطية |

## 9.7 Compliance

| المجال | المتطلب |
|--------|---------|

## 9.8 Technical Requirements

| المجال | المتطلب |
|--------|---------|
