## 6.1 مصفوفة أصحاب المصلحة

| صاحب المصلحة | الدور | الاهتمامات | التأثير | الأولوية |
|--------------|-------|-----------|---------|---------|
| **المريض / المواطن** | مستخدم نهائي | الوصول للمستشفى المناسب، التكلفة، الجودة | عالي | عالية |
| **مرافق المريض** | مستخدم غير مباشر | معلومات دقيقة، سهولة الوصول | متوسط | متوسطة |
| **الطبيب / الاستشاري** | مزود خدمة | السمعة المهنية، وجوده على المنصة | عالي | عالية |
| **مدير المستشفى** | مدير/مالك | سمعة المستشفى، جذب المرضى، تحليلات | عالي | عالية |
| **وزارة الصحة - مكتب إب** | جهة حكومية | بيانات، تقارير، تخطيط | عالي جدًا | حرجة |
| **المنظمات الدولية (WHO, MSF, WB)** | ممول/شريك | فجوات، احتياجات، تقارير تدخل | عالي | عالية |
| **المنظمات المحلية (YFCA, Selah)** | منفذ/شريك | بيانات للتدخلات الميدانية | متوسط | متوسطة |
| **الجامعات (جبلة، إب)** | أكاديمي | بيانات للبحث والتدريب | متوسط | متوسطة |
| **هيئة الزكاة** | ممول | أين تذهب أموال الزكاة للمرضى | متوسط | متوسطة |
| **مطورو التطبيقات** | تقني | API مفتوح للتكامل | منخفض | منخفضة |
| **الإعلام المحلي** | ناقل | أخبار المستشفيات والخدمات | متوسط | منخفضة |

## 6.2 تحليل الاحتياجات لكل Stakeholder

### المريض / المواطن

| الاحتياج | الحل المقترح |
|----------|-------------|
| معرفة أقرب مستشفى | بحث بالموقع الجغرافي |
| معرفة التخصصات المتاحة | تصنيف دقيق حسب التخصص |
| أرقام الطوارئ | عرض واضح على صفحات المستشفيات |
| تقييمات حقيقية | نظام مراجعات موثوق |
| تكلفة الخدمات | معلومات عن الأسعار (إن وجدت) |

### مدير المستشفى

| الاحتياج | الحل المقترح |
|----------|-------------|
| تحسين السمعة | نظام تقييم، صور، معلومات دقيقة |
| جذب المرضى | ظهور في نتائج البحث، SEO محلي |
| تحليلات الأداء | لوحة تحكم بمؤشرات الأداء |
| التواصل مع المرضى | الرد على التقييمات |

### مكتب الصحة - إب

| الاحتياج | الحل المقترح |
|----------|-------------|
| قاعدة بيانات شاملة | جميع المستشفيات مع بياناتها |
| تقارير دورية | تحليلات وإحصائيات أوتوماتيكية |
| تكامل مع أنظمة الوزارة | API متوافق مع معايير الوزارة |
| دقة البيانات | آلية تحقق من البيانات (Verified) |

### المنظمات الدولية

| الاحتياج | الحل المقترح |
|----------|-------------|
| تحديد الفجوات الصحية | تقارير عن المناطق التي تفتقر للمستشفيات |
| بيانات للتدخل | API مفتوح لتصدير البيانات |
| تقييم الاحتياجات | تحليلات عن التخصصات المفقودة |
| متابعة الأثر | تحديث دوري للبيانات |
