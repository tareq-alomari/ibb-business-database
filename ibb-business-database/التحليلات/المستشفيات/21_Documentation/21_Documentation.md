## 21.2 BRD Summary

| العنصر | المحتوى |
|--------|---------|
| **اسم المشروع** | نظام معلومات مستشفيات محافظة إب (Ibb Hospitals Info System) |
| **الرؤية** | منصة رقمية شاملة لمعلومات المستشفيات |
| **الجمهور** | مواطنو إب (~3 مليون)، مكتب الصحة، المنظمات الإنسانية |
| **النطاق** | جميع المستشفيات في محافظة إب (160+) |
| **خارج النطاق** | المراكز الصحية والعيادات (مرحلة ثانية) |
| **الجدول الزمني** | 6 أشهر للتطوير + الإطلاق |
| **الميزانية** | $34,000 - $54,000 |
| **المخاطر الرئيسية** | انقطاع الإنترنت، عدم الاستقرار السياسي |

## 21.3 User Stories

### البحث والتصفح

| الرقم | القصة |
|-------|-------|
| US-01 | كمواطن، أريد البحث عن مستشفى باسمه ليظهر لي جميع معلوماته |
| US-02 | كمواطن، أريد تصفية المستشفيات حسب المديرية لأجد الأقرب إليّ |
| US-03 | كمريض، أريد رؤية المستشفيات على الخريطة لاختيار الأقرب |
| US-04 | كمواطن، أريد معرفة تخصصات كل مستشفى لأختار المناسب لحالتي |
| US-05 | كمستخدم، أريد رؤية تقييمات المستشفيات لأخذ فكرة عن جودة الخدمات |

### التقييمات

| الرقم | القصة |
|-------|-------|
| US-06 | كمستخدم مسجل، أريد تقييم مستشفى زرته لمشاركة تجربتي |
| US-07 | كمستخدم، أريد تعديل أو حذف تقييمي إذا أردت |
| US-08 | كمدير مستشفى، أريد الرد على تقييمات المرضى |

### الإدارة

| الرقم | القصة |
|-------|-------|
| US-09 | كمسؤول في مكتب الصحة، أريد إضافة مستشفى جديد إلى المنصة |
| US-10 | كمسؤول، أريد تعديل بيانات مستشفى إذا تغيرت |
| US-11 | كمسؤول، أريد الموافقة على التقييمات قبل نشرها |
| US-12 | كمسؤول، أريد رؤية تقارير عن توزيع المستشفيات في المحافظة |
| US-13 | كمسؤول، أريد تصدير البيانات إلى Excel أو PDF |

### التقارير

| الرقم | القصة |
|-------|-------|
| US-14 | كمدير مكتب الصحة، أريد رؤية إحصائيات عن المستشفيات في المحافظة |
| US-15 | كمدير منظمة إنسانية، أريد معرفة المديريات التي تفتقر لمستشفيات |

## 21.4 Acceptance Criteria (نموذج)

### US-01: البحث عن مستشفى

| الرقم | المعيار |
|-------|---------|
| AC-01 | شريط البحث يظهر في أعلى الصفحة الرئيسية |
| AC-02 | البحث يعمل فور الكتابة (Auto-complete) |
| AC-03 | البحث بالعربية يدعم الكلمات المفتاحية |
| AC-04 | النتائج تظهر خلال أقل من ثانية |
| AC-05 | البحث لا يتطلب تسجيل الدخول |

### US-06: إضافة تقييم

| الرقم | المعيار |
|-------|---------|
| AC-06 | المستخدم يجب أن يكون مسجل الدخول |
| AC-07 | التقييم يتطلب اختيار نجوم (1-5) إجباري |
| AC-08 | التعليق نص اختياري (حد أقصى 500 حرف) |
| AC-09 | بعد الإرسال، التقييم ينتظر المراجعة |
| AC-10 | رسالة تأكيد تظهر للمستخدم بعد الإرسال |
