## 10.3 Content Hierarchy (صفحة المستشفى)

```
H1: اسم المستشفى  
├── H2: معلومات أساسية  
│   ├── P: العنوان  
│   ├── P: الهاتف  
│   ├── P: البريد الإلكتروني  
│   └── DL: النوع، التصنيف، التقييم  
├── H2: التخصصات والأقسام  
│   └── UL: قائمة التخصصات  
├── H2: الأطباء  
│   └── DIV: بطاقات الأطباء  
├── H2: صور المستشفى  
│   └── DIV: معرض الصور  
├── H2: الموقع  
│   └── DIV: الخريطة  
└── H2: التقييمات  
    └── DIV: قائمة التقييمات + نموذج إضافة تقييم  
```

## 10.4 Taxonomy (تصنيف المستشفيات)

### حسب النوع

| التصنيف | الوصف |
|---------|-------|
| **حكومي** | تابع لوزارة الصحة |
| **خاص** | ملكية خاصة (ربحي) |
| **جامعي** | تابع لجامعة (جبلة) |
| **أهلي** | غير ربحي |
| **ميداني** | تديره منظمات إنسانية |

### حسب التخصص

| التخصص | أمثلة |
|--------|-------|
| عام | ثورة، ناصر، جبلة |
| تخصصي | منار (أورام)، المجد |
| نساء وولادة | الأمومة والطفولة |
| أطفال | أقسام أطفال في المستشفيات العامة |
| قلب | مركز القلب - الثورة |
| عيون | - |
| أورام | الثورة، المنار |

| جبلة | 6+ |
| ذي سفال | 5+ |

## 10.5 Content Strategy

| نوع المحتوى | التكرار | المصدر |
|------------|---------|--------|
| بيانات المستشفيات | تحديث ربع سنوي | فريق ميداني + تقارير رسمية |
| صور المستشفى | عند الإضافة أو التحديث | زيارة ميدانية |
| التقييمات | فور إضافتها | المستخدمون |
| التقارير | شهريًا + ربع سنوي | تحليل آلي |
| أخبار المستشفيات | أسبوعيًا | إعلام محلي |
