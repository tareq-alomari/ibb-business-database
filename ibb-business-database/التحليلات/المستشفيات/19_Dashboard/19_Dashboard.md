## 19.2 Pages

### 19.2.1 إدارة المستشفيات

| العنصر | الوظيفة |
|--------|---------|
| **قائمة المستشفيات** | جدول + بحث + تصفية (نوع، مديرية، تصنيف) |
| **إضافة مستشفى** | نموذج متعدد الخطوات |
| **تعديل مستشفى** | تحرير البيانات |
| **حذف مستشفى** | تأكيد + إشعار |
| **التحقق** | توثيق المستشفيات الحكومية |

### 19.2.2 إدارة التصنيفات

| العنصر | الوظيفة |
|--------|---------|
| قائمة التصنيفات | جدول التخصصات + الأنواع |
| إضافة تصنيف | اسم عربي/إنجليزي + أيقونة |
| ترتيب التصنيفات | Drag and drop |

### 19.2.3 إدارة التقييمات

| العنصر | الوظيفة |
|--------|---------|
| **قيد المراجعة** | تقييمات تنتظر الموافقة |
| **الموافقة/الرفض** | بنقرة واحدة |
| **مقبول** | التقييمات المنشورة |
| **مرفوض** | مع سبب الرفض |
| **الإبلاغات** | تقييمات مبلّغ عنها |

### 19.2.4 إدارة المستخدمين

| العنصر | الوظيفة |
|--------|---------|
| قائمة المستخدمين | جدول + بحث |
| تعديل صلاحيات | تغيير الدور |
| تعليق/تفعيل | حظر أو تفعيل مستخدم |

### 19.2.5 التقارير

| التقرير | المحتوى | التنسيق |
|---------|---------|---------|
| **تقرير المستشفيات** | جميع المستشفيات + بياناتها | PDF / Excel |
| **تقرير المديريات** | توزيع المستشفيات حسب المديرية | PDF / Excel |
| **تقرير التقييمات** | إحصائيات التقييمات | PDF |
| **تقرير التخصصات** | المستشفيات حسب التخصص | Excel |
| **تقرير الفجوات** | المديريات التي تفتقر لمستشفيات | PDF |

## 19.3 Key Charts

| الرسم البياني | النوع | البيانات |
|--------------|-------|----------|
| المستشفيات حسب النوع | Pie Chart | حكومي، خاص، جامعي، ميداني |
| التوزيع حسب المديرية | Bar Chart | كل مديرية بعدد مستشفياتها |
| التقييمات الشهرية | Line Chart | عدد التقييمات خلال 12 شهر |
| المستشفيات حسب التصنيف | Bar Chart | A, B1, B2, C1, C2, D |
| المتوسط العام للتقييم | Gauge | 0-5 |
| النشاط اليومي | Area Chart | زيارات + تقييمات |

## 19.4 Settings (الإعدادات)

| الإعداد | الخيارات |
|---------|---------|
| الموقع | اسم المنصة، وصف، شعار |
| البريد | SMTP إعدادات البريد |
| الإشعارات | تشغيل/إيقاف إشعارات التقييمات |
| الأمان | تغيير كلمة المرور، 2FA |
| API | إنشاء/إلغاء API Keys |
| النسخ الاحتياطي | جدولة النسخ، استعادة |
