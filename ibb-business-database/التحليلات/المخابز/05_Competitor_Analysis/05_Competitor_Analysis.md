# المرحلة الخامسة: تحليل المنافسين - قطاع المخابز في محافظة إب

> **تاريخ التقرير**: يوليو 2026

---

## تصنيف المنافسين

### المستوى الأول: المخابز الكبرى (5-10%)
- أفران حديثة بطاقة إنتاجية عالية
- علامات تجارية معروفة
- خدمة توصيل ومنافذ متعددة

### المستوى الثاني: المخابز المتوسطة (30-40%)
- أفران نصف آلية
- سمعة محلية جيدة
- أسعار متوسطة

### المستوى الثالث: المخابز الصغيرة (40-50%)
- أفران تقليدية
- تغطي حارة أو حيين
- أسعار منخفضة

### المستوى الرابع: المخابز غير الرسمية (10-15%)
- منزلية أو متنقلة
- غير مرخصة
- أسعار أقل وجودة متغيرة

## تحليل SWOT للمخابز في إب

| النقطة | الوصف |
|--------|-------|
| القوة | الطلب المرتفع، السلعة الأساسية |
| الضعف | ارتفاع التكاليف، نقص العمالة |
| الفرص | التوسع الرقمي، التنويع |
| التهديدات | تقلب أسعار الدقيق، انقطاع الكهرباء |

## الميزة التنافسية

| العامل | التأثير |
|--------|---------|
| الجودة والنظافة | تمييز قوي |
| السعر | حساسية عالية |
| الموقع | عامل حاسم |
| سرعة الخدمة | مهم جداً |
| التنوع | ميزة إضافية |
