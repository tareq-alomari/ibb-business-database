## محتوى دليل المستخدم

1. **مقدمة**: ما هو الموقع وكيف يعمل
2. **البحث عن مخبز**: خطوات البحث والتصفية
3. **عرض التفاصيل**: معلومات المخبز والمنتجات
4. **التقييم**: كيفية تقييم المخبز
5. **الخريطة**: استخدام الخريطة التفاعلية
6. **الحساب الشخصي**: إنشاء وإدارة الحساب

## محتوى دليل المطور

| القسم | المحتوى |
|-------|---------|
| الإعداد المحلي | تشغيل المشروع محلياً |
| هيكل المشروع | شرح المجلدات والملفات |
| إضافة مخبز جديد | خطوات إضافة بيانات |
| نقاط النهاية | توثيق API كامل |
| الاختبارات | كيفية تشغيلها |
| النشر | خطوات النشر للإنتاج |

## أداة التوثيق

- **Docosaurus**: منصة التوثيق

- **JSDoc**: توثيق الكود
- **Storybook**: توثيق المكونات
