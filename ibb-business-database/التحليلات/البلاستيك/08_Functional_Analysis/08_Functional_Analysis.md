## 8.2 حالات الاستخدام (Use Cases)

### UC1: دليل المصانع

**الممثل**: مستخدم
**الوصف**: قاعدة بيانات بمصانع البلاستيك

سيناريو النجاح:
1. يسجل المستخدم الدخول
2. يتصفح القائمة المتاحة
3. يبحث ويستخدم الفلاتر
4. يختار الخدمة المناسبة
5. يقيم التجربة

### UC2: المنتجات البلاستيكية

**الممثل**: مزود الخدمة
**الوصف**: فهرس المنتجات البلاستيكية المتوفرة

سيناريو النجاح:
1. يسجل مزود الخدمة الدخول
2. يدخل إلى لوحة التحكم
3. يضيف/يعدل بياناته
4. ينشر التحديثات
