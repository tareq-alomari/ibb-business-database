# المرحلة الأولى: Project Discovery - قطاع البلاستيك في محافظة إب

> **التاريخ**:  يوليو 2026  
> **الملف**: 01_Project_Discovery.md

---

## 1.1 المشكلة (Problem Statement)

يعاني قطاع البلاستيك في محافظة إب من تحديات كبيرة رغم كونه قطاعًا حيويًا. لا توجد منصة موحدة تتيح للمستفيدين اكتشاف الخدمات أو مقارنتها. المشكلات الرئيسية:

1. **ندرة المواد الخام البلاستيكية**
2. **ارتفاع تكاليف الاستيراد**
3. **ضعف إعادة التدوير**
4. **تلوث بيئي**
5. **منافسة المنتجات المستوردة الرخيصة**

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لقطاع البلاستيك في محافظة إب** تتكون من:

- **دليل المصانع**: قاعدة بيانات بمصانع البلاستيك
- **المنتجات البلاستيكية**: فهرس المنتجات البلاستيكية المتوفرة
- **أسعار المواد الخام**: أسعار الحبيبات البلاستيكية
- **مشتريات بلاستيك**: طلب منتجات بلاستيكية بالجملة
- **مصانع التدوير**: شركات إعادة تدوير البلاستيك

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستهلك/المواطن** | سهولة الوصول للمعلومات، مقارنة الخدمات، تقييمات حقيقية |
| **مزود الخدمة/البلاستيك** | وصول لشريحة أكبر، تحسين السمعة، إدارة رقمية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات، عمولات، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، مكاتب البلاستيك المحلية |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| حصر الجهات/البلاستيك | عدد المسجلين | 60++ |
| دقة البيانات | نسبة المعلومات المؤكدة | 90%+ |
| سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| رضا المستخدمين | تقييم المنصة | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن تكون المنصة الرقمية لقطاع البلاستيك في محافظة إب المرجع الأول الذي يعتمد عليه كل مواطن، محولة تجربة البلاستيك إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مزودي خدمات البلاستيك والمستفيدين في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - وجود منطقة صناعية | - اعتماد على الاستيراد |
| - طلب محلي عال | - تقنيات قديمة |
| - خبرة صناعية متراكمة | - تلوث بيئي مرتفع |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - التوجه للتدوير | - ارتفاع الدولار |
| - البدائل الصديقة للبيئة | - قيود استيراد |
| - الصادرات للأسواق المجاورة | - منتجات بديلة (زجاج، ورق) |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: عدم استقرار سياسي | خطر على استمرارية الأعمال |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | ارتفاع التكاليف، حساسية السعر |
| **S - Social**: كثافة سكانية عالية، شرائح متنوعة | فرصة كبيرة، تنوع الاحتياجات |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم رقمي | فرصة لتوحيد المعايير |
| **E - Environmental**: تحديات بيئية مختلفة | فرصة لنشر التوعية |

## 1.10 Risk Analysis

| الخطر | الاحتمالية | التأثير | خطة التخفيف |
|-------|-----------|---------|------------|
| انقطاع الإنترنت والكهرباء | عالية | عالي | PWA مع دعم Offline |
