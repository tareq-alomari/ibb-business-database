## 9.1 متطلبات الأداء (Performance Requirements)

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| PERF1 | زمن تحميل الصفحة الرئيسية | < 1.5 ثانية |
| PERF2 | زمن تحميل قائمة الخدمات | < 1 ثانية |
| PERF3 | زمن تأكيد الحجز | < 2 ثانية |
| PERF4 | استجابة البحث | < 500ms |
| PERF5 | معالجة 50 حجز متزامن | خطأ < 1% |
| PERF6 | رفع الصور | < 3 ثوانٍ لصورة 1MB |

## 9.2 متطلبات التوفر (Availability Requirements)

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| AVAIL1 | uptime النظام | 99.5% (حد أقصى 3.6 ساعات توقف شهريًا) |
| AVAIL2 | النسخ الاحتياطي | يومي، احتفاظ بـ 30 يومًا |
| AVAIL3 | دعم الأوفلاين (PWA) | تصفح الخدمات ومقدمي الخدمة بدون إنترنت |
| AVAIL4 | تخزين مؤقت للحجوزات | الحجز يُخزن محليًا حتى استعادة الاتصال |

## 9.3 متطلبات الأمان (Security Requirements)

| المعرف | المتطلب | التفاصيل |
|--------|---------|---------|
| SEC1 | تشفير البيانات | TLS 1.3 للاتصالات، AES-256 للتخزين |
| SEC2 | المصادقة | JWT + OTP عبر الهاتف |
| SEC3 | حماية API | Rate limiting (100 طلب/دقيقة لكل مستخدم) |
| SEC4 | صلاحيات الأدوار | RBAC (عميل، مقدم خدمة، مشرف) |

## 9.4 متطلبات الاستخدامية (Usability Requirements)

| المعرف | المتطلب | التفاصيل |
|--------|---------|---------|
| USE1 | الواجهة | عربية 100%، تدعم العامية اليمنية في البحث |
| USE2 | حجم الخط | قابل للتكبير، مناسب لكبار السن |
| USE3 | الإشعارات | صوتية + مرئية (حتى لو التطبيق مغلق) |
| USE4 | تجربة المستخدم الجديد | < 3 خطوات لحجز أول خدمة |

## 9.5 متطلبات التوافق (Compatibility Requirements)

| المعرف | المتطلب |
|--------|---------|
| COMP1 | Android 8.0+ (98% من الأجهزة في اليمن) |
| COMP2 | iOS 13+ |
| COMP3 | PWA متوافقة مع Chrome 80+ |
| COMP4 | إنترنت 3G/4G (بطيء أحيانًا) |
| COMP5 | هواتف ذاكرة 2GB RAM وأقل |

## 9.6 متطلبات قابلية التوسع (Scalability Requirements)

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| SCALE1 | عدد المستخدمين | 20,000 مستخدم نشط شهريًا (Year 1) |
| SCALE2 | عدد مقدمي الخدمة | 90+ (Year 1) |
| SCALE3 | عدد الحجوزات اليومية | 50+ (Year 1) |
| SCALE4 | بنية قابلة للتوسع | Modular Monolith |
| SCALE5 | قاعدة بيانات | PostgreSQL |
