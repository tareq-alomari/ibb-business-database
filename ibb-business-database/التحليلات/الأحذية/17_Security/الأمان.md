# الأمان: منصة الأحذية في إب

## سياسات الأمان العامة

### المصادقة والتفويض
- استخدام JWT (JSON Web Tokens) للمصادقة
- تطبيق OAuth 2.0 للتسجيل عبر وسائل التواصل
- نظام صلاحيات قائم على الأدوار (RBAC)
- توثيق ثنائي العامل للتجار والمشرفين
- جلسات آمنة مع وقت انتهاء محدد

### حماية البيانات
- تشفير البيانات الحساسة في قاعدة البيانات (AES-256)
- تشفير الاتصالات عبر HTTPS (SSL/TLS)
- عدم تخزين معلومات بطاقات الدفع محلياً
- إخفاء البيانات الحساسة في السجلات

### حماية التطبيق
- حماية من SQL Injection عبر استعلامات معدة مسبقاً
- حماية من XSS عبر تعقيم المدخلات
- حماية من CSRF عبر توكنات خاصة
- Rate Limiting على جميع نقاط API
- التحقق من صحة جميع المدخلات (Validation & Sanitization)

### أمن الملفات والصور
- التحقق من أنواع الملفات المرفوعة
- تحديد حجم الملفات المسموح به
- تخزين الصور خارج المجلد العام
- فحص الملفات ضد البرمجيات الخبيثة

### النسخ الاحتياطي والتعافي
- نسخ احتياطي يومي لقاعدة البيانات
- نسخ احتياطي أسبوعي للملفات والصور
- تخزين النسخ الاحتياطية في موقع منفصل
- خطة تعافي من الكوارث (Disaster Recovery Plan)

### الامتثال والخصوصية
- الامتثال لقوانين حماية البيانات المحلية
- سياسة خصوصية واضحة للمستخدمين
- إتاحة خيار حذف الحساب والبيانات
- إخطار المستخدمين في حال اختراق البيانات

### قائمة تحقق الأمان
- تحديث المكتبات بشكل دوري
- فحص الثغرات الأمنية باستخدام أدوات متخصصة
- تدقيق الكود الأمني قبل النشر
- مراقبة الأنشطة المشبوهة
