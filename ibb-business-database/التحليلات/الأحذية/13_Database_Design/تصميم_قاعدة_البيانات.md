# تصميم قاعدة البيانات: منصة الأحذية في إب

## نظام إدارة قواعد البيانات
MySQL أو PostgreSQL لتخزين جميع بيانات المنصة.

## الجداول الرئيسية

### جدول المستخدمين (users)
- id (PK), name, email, phone, password_hash, address, city, role, created_at, updated_at
- الأدوار: عميل، تاجر، مشرف، مدير

### جدول المنتجات (products)
- id (PK), seller_id (FK), name_ar, description_ar, category_id (FK), brand, material, origin
- base_price, discount_price, images, gender (رجالي/نسائي/أطفال), is_active, created_at

### جدول المقاسات (sizes)
- id (PK), product_id (FK), size, stock_quantity, price_modifier

### جدول الألوان (colors)
- id (PK), product_id (FK), color_name, color_hex, stock_quantity

### جدول الفئات (categories)
- id (PK), name_ar, parent_id (FK), icon, sort_order

### جدول الطلبات (orders)
- id (PK), user_id (FK), seller_id (FK), total_amount, status, payment_method
- delivery_address, delivery_status, created_at, updated_at

### جدول عناصر الطلب (order_items)
- id (PK), order_id (FK), product_id (FK), size, color, quantity, unit_price

### جدول التقييمات (reviews)
- id (PK), user_id (FK), product_id (FK), rating, comment, created_at

### جدول سلة التسوق (cart)
- id (PK), user_id (FK), product_id (FK), size, color, quantity, created_at

### جدول التوصيل (deliveries)
- id (PK), order_id (FK), delivery_person, status, estimated_time, notes

## العلاقات الرئيسية
- كل مستخدم له عدة طلبات (One-to-Many)
- كل منتج يتبع لتاجر واحد (Many-to-One)
- كل منتج له عدة مقاسات وألوان (One-to-Many)
- كل طلب يحتوي على عدة عناصر (One-to-Many)
- كل منتج له عدة تقييمات (One-to-Many)
