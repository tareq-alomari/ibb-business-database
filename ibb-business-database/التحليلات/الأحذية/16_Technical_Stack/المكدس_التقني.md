# المكدس التقني: منصة الأحذية في إب

## تقنيات الواجهة الأمامية
### الأساسية
- React.js 18+ لبناء واجهة المستخدم
- Next.js 14+ للتحسين لمحركات البحث
- TypeScript للأمان النوعي
- Tailwind CSS للتصميم السريع
- Shadcn/ui لمكونات جاهزة

### إضافية
- React Query لإدارة البيانات من الخادم
- Zustand لإدارة الحالة العامة
- React Hook Form للنماذج
- Zod للتحقق من صحة البيانات
- Next.js Image لتحسين الصور

## تقنيات الواجهة الخلفية
### الخيار المفضل: Node.js
- Nest.js كإطار عمل منظم
- Prisma ORM للتعامل مع قاعدة البيانات
- Passport.js للمصادقة
- Bull لإدارة المهام المجدولة

### الخيار البديل: PHP
- Laravel 11 كإطار عمل متكامل
- Eloquent ORM لإدارة البيانات
- Sanctum للمصادقة
- Queue Jobs للمهام الخلفية

## قاعدة البيانات
- PostgreSQL لقاعدة البيانات الرئيسية
- Redis للتخزين المؤقت والجلسات
- Elasticsearch للبحث المتقدم (اختياري)

## البنية التحتية والاستضافة
### الخيار المحلي
- خادم VPS محلي في اليمن
- Nginx كخادم ويب
- PM2 لإدارة تطبيقات Node.js
- Docker للحاويات

### الخيار السحابي
- AWS أو DigitalOcean أو Vercel
- S3 أو Cloudinary لتخزين الصور
- Cloudflare CDN
- GitHub Actions للتكامل المستمر

## أدوات التطوير
- Git و GitHub لإدارة الكود
- VS Code كمحرر رئيسي
- Postman لاختبار API
- Figma للتصميم
- Sentry لمراقبة الأخطاء
