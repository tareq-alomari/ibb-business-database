# لوحة التحكم: منصة الأحذية في إب

## لوحة تحكم المدير العام

### المؤشرات الرئيسية (KPIs)
1. إجمالي المستخدمين المسجلين
2. عدد المتاجر النشطة
3. إجمالي الطلبات اليومية/الأسبوعية/الشهرية
4. إجمالي الإيرادات مع رسم بياني
5. متوسط قيمة الطلب
6. المنتجات الأكثر مبيعاً

### الرسوم البيانية
- مبيعات آخر 30 يوماً (رسم خطي)
- توزيع المبيعات حسب الفئة (رسم دائري)
- الطلبات حسب الحالة (رسم شريطي)
- أداء المتاجر (جدول ترتيب)
- حركة الزوار على المنصة

## لوحة تحكم التاجر

### نظرة عامة
1. عدد المنتجات المنشورة
2. الطلبات الجديدة (غير المقروءة)
3. إجمالي مبيعات اليوم
4. آخر الطلبات (5 طلبات)
5. إشعارات وتنبيهات

### إدارة المنتجات
- إضافة منتج جديد (نموذج مع صور وأسعار)
- تعديل المنتجات الحالية
- إدارة المخزون والمقاسات
- تفعيل/إيقاف المنتجات
- عروض وتخفيضات

### إدارة الطلبات
- الطلبات الجديدة (تحتاج تأكيد)
- الطلبات قيد التجهيز
- الطلبات التي تم شحنها
- الطلبات المكتملة
- الطلبات الملغاة أو المرتجعة

### التقارير
- تقرير المبيعات اليومية
- تقرير المبيعات الشهرية
- تقرير المخزون
- تقرير المنتجات الأكثر والأقل مبيعاً
- تقرير أرباح وتكاليف

## لوحة تحكم العميل

### ملفي الشخصي
1. معلومات الحساب الشخصية
2. عناوين التوصيل المحفوظة
3. طرق الدفع المفضلة

### طلباتي
- الطلبات الحالية مع حالة التتبع
- سجل الطلبات السابقة
- إمكانية إعادة الطلب بضغطة واحدة
