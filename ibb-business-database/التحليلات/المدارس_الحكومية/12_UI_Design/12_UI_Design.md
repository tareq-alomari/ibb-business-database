# تصميم واجهة المستخدم

## توجه التصميم
تصميم بسيط وعملي مع التركيز على سهولة القراءة وسرعة الوصول للمعلومات. استخدام الألوان الهادئة التي تتناسب مع السياق التعليمي الرسمي.

## لوحة الألوان
- اللون الرئيسي: أزرق داكن #1B4F72 – يرمز للثقة والجدية
- اللون الثانوي: أخضر زيتوني #7DCEA0 – يرمز للنمو والتعليم
- لون الخلفية: أبيض مصفر #FDFEFE
- لون النص الرئيسي: رمادي داكن #2C3E50
- لون التنبيهات: برتقالي #E67E22

## الخطوط
- الخط الرئيسي: أميري (Amiri) للنصوص العربية
- حجم الخط الأساسي: 16px
- العناوين: 24-32px

## مكونات الواجهة

### الشاشة الرئيسية (لوحة التحكم)
- شريط جانبي بالقائمة الرئيسية
- بطاقات ملخص الإحصائيات (عدد المدارس، الكوادر، الطلاب)
- رسم بياني لأعداد الطلاب حسب المديرية
- آخر الإشعارات والتحديثات

### صفحة المدرسة
- بطاقة تعريفية بالصور والموقع
- جدول الكوادر التعليمية
- إحصائيات الطلاب
- حالة البنية التحتية

### صفحة المعلم
- الملف الشخصي مع الصورة
- سجل الوظيفي والراتب
- العقود والإجازات

## أيقونات وأزرار
استخدام أيقونات واضحة من مكتبة Font Awesome بالنسخة العربية. أزرار ذات زوايا قليلة الانحناء (border-radius: 8px).
