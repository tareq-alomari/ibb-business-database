# الأمن السيبراني – حماية النظام

## تهديدات الأمن الرئيسية
- هجمات الحقن (SQL Injection) على قاعدة البيانات
- هجمات XSS (Cross-Site Scripting) عبر إدخال المستخدم
- هجمات CSRF (Cross-Site Request Forgery)
- هجمات القوة العمياء على كلمات المرور
- تسرب البيانات الشخصية للمعلمين والطلاب

## إجراءات الحماية

### طبقة التطبيق
- تعقيم جميع المدخلات ومنع الحقن
- استخدام ORM بدلاً من استعلامات SQL المباشرة
- تفعيل CSP (Content Security Policy)
- استخدام CSRF tokens في جميع النماذج
- تحديد معدل الطلبات (Rate Limiting)

### طبقة المصادقة والصلاحيات
- كلمات مرور مشفرة باستخدام bcrypt
- تسجيل الدخول بطبقتين (2FA)
- صلاحيات وصول دقيقة (RBAC)
- جلسات محدودة المدة مع تحديث تلقائي
- تسجيل جميع محاولات الدخول والخروج

### طبقة البيانات
- تشفير البيانات الحساسة في قاعدة البيانات
- تشفير الاتصال عبر HTTPS باستخدام TLS 1.3
- نسخ احتياطي مشفر
- فصل صلاحيات قاعدة البيانات حسب الدور

### طبقة الشبكة
- جدار ناري (Firewall) لمنع الوصول غير المصرح به
- VPN للوصول الداخلي
- مراقبة الاختراقات (IDS/IPS)
- تحديث أمني دوري لجميع المكونات

## الامتثال والمعايير
- التوافق مع قانون حماية البيانات الشخصية اليمني
- معايير ISO 27001 لإدارة أمن المعلومات
- سياسة خصوصية واضحة للمستخدمين
