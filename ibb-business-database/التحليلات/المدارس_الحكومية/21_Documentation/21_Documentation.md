# التوثيق – دليل النظام

## وثائق المشروع

### 1. وثيقة المتطلبات
- متطلبات وظيفية مفصلة
- متطلبات غير وظيفية
- قصص المستخدم (User Stories)
- حالات الاستخدام (Use Cases)

### 2. دليل المستخدم
- دليل مدير المدرسة: كيفية إدارة بيانات المدرسة والكوادر
- دليل المعلم: كيفية الاطلاع على الملف الشخصي والراتب
- دليل مسؤول مكتب التربية: كيفية استخدام لوحة التحكم والتقارير
- دليل فني: كيفية صيانة النظام ومراقبته

### 3. التوثيق الفني
- دليل التثبيت والنشر (Deployment Guide)
- دليل API (مستند Swagger/OpenAPI)
- مخطط قاعدة البيانات (ERD)
- دليل المساهمة في التطوير (Contributing Guide)

### 4. وثائق التشغيل
- خطة الصيانة الدورية
- دليل النسخ الاحتياطي واستعادة البيانات
- خطة الاستجابة للحوادث الأمنية

## أدوات التوثيق
- GitHub Wiki للمستندات الفنية
- GitBook أو ReadTheDocs لدليل المستخدم
- Swagger UI لتوثيق API
- Markdown للمستندات الأساسية
- PDF للتقارير الرسمية

## تحديث التوثيق
- مراجعة شهرية للوثائق
- تحديث بعد كل إصدار رئيسي
- توثيق أي تغيير في الكود عبر Git commit messages
- توفير نماذج جاهزة للتقارير المدرسية

## لغة التوثيق
- جميع وثائق المستخدم: اللغة العربية الفصحى
- الوثائق الفنية: اللغة العربية مع المصطلحات الإنجليزية التقنية
- تعليقات الكود: العربية أو الإنجليزية حسب الاتفاق
