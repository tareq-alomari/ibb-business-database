# الرصة التقنية – التقنيات المستخدمة

## الواجهة الأمامية (Frontend)
- إطار العمل: React.js 18 أو Vue.js 3
- إدارة الحالة: Redux Toolkit أو Pinia
- التصميم: Tailwind CSS + MUI (Material UI)
- الخط: أميري (Amiri) للعربية
- الرسوم البيانية: Chart.js أو Recharts
- دعم اللغة العربية: react-intl أو vue-i18n

## الواجهة الخلفية (Backend)
- الخيار الأول: Node.js مع Express.js أو NestJS
- الخيار الثاني: Django (Python) مع Django REST Framework
- الخيار الثالث: Laravel (PHP)
- المصادقة: JWT (JSON Web Tokens)
- التوثيق: Swagger/OpenAPI

## قاعدة البيانات
- PostgreSQL 15 (مفضل للبيانات العلائقية المتقدمة)
- MySQL 8.0 (بديل)
- Redis للتخزين المؤقت

## الاستضافة والبنية التحتية
- خادم: Ubuntu 22.04 LTS
- حاوية: Docker + Docker Compose
- خادم ويب: Nginx
- HTTPS: Let's Encrypt
- CDN: Cloudflare

## أدوات التطوير
- إدارة الكود: Git + GitHub/GitLab
- CI/CD: GitHub Actions
- إدارة المهام: Jira أو Trello
- التواصل: Slack أو Telegram

## اختبارات
- الوحدة: Jest أو Vitest
- التكامل: Cypress أو Playwright
- الأداء: Lighthouse
