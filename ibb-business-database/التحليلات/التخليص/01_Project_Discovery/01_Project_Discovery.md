# المرحلة الأولى: Project Discovery - قطاع التخليص في محافظة إب

> **التاريخ**:  يوليو 2026  
> **الملف**: 01_Project_Discovery.md

---

## 1.1 المشكلة (Problem Statement)

يعاني قطاع التخليص في محافظة إب من تحديات كبيرة رغم كونه قطاعًا حيويًا. لا توجد منصة موحدة تتيح للمستفيدين اكتشاف الخدمات أو مقارنتها. المشكلات الرئيسية:

1. **تعقيد الإجراءات الجمركية**
2. **تأخر إنهاء المعاملات**
3. **ارتفاع رسوم التخليص**
4. **غياب الشفافية**
5. **نظام إلكتروني غير مكتمل**

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لقطاع التخليص في محافظة إب** تتكون من:

- **حاسبة الرسوم الجمركية**: حساب الرسوم المتوقعة للبضائع
- **تتبع الشحنة**: متابعة حالة الشحنات الجمركية
- **دليل الفئات الجمركية**: تصنيف السلع وفئاتها الجمركية
- **طلب تخليص إلكتروني**: تقديم مستندات التخليص أونلاين
- **مكتبة المستندات**: نماذج المستندات المطلوبة

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستهلك/المواطن** | سهولة الوصول للمعلومات، مقارنة الخدمات، تقييمات حقيقية |
| **مزود الخدمة/التخليص** | وصول لشريحة أكبر، تحسين السمعة، إدارة رقمية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات، عمولات، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، مكاتب التخليص المحلية |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| حصر الجهات/التخليص | عدد المسجلين | 35++ |
| دقة البيانات | نسبة المعلومات المؤكدة | 90%+ |
| سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| رضا المستخدمين | تقييم المنصة | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن تكون المنصة الرقمية لقطاع التخليص في محافظة إب المرجع الأول الذي يعتمد عليه كل مواطن، محولة تجربة التخليص إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مزودي خدمات التخليص والمستفيدين في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - موانئ قريبة نسبيًا | - بيروقراطية |
| - خبرة تخليص محلية | - غياب التوثيق الرقمي |
| - علاقات مع الجمارك | - قلة التخصص |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - التحديث الجمركي الإلكتروني | - تغير اللوائح الجمركية |
| - نمو الاستيراد | - توقف الموانئ |
| - المنصات الرقمية للتخليص | - تدهور العملة |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: عدم استقرار سياسي | خطر على استمرارية الأعمال |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | ارتفاع التكاليف، حساسية السعر |
| **S - Social**: كثافة سكانية عالية، شرائح متنوعة | فرصة كبيرة، تنوع الاحتياجات |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم رقمي | فرصة لتوحيد المعايير |
| **E - Environmental**: تحديات بيئية مختلفة | فرصة لنشر التوعية |

| الخطر | الاحتمالية | التأثير | خطة التخفيف |
