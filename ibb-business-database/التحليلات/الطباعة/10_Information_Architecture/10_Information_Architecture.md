## 10.1 هيكل المعلومات

```
[تطبيق الطباعة]
├── الصفحة الرئيسية
│   ├── بحث سريع
│   ├── خدمات مقترحة
│   └── إحصائيات
├── الخدمات
│   ├── تصنيفات رئيسية
│   └── تفاصيل الخدمة
├── مقدم الخدمة
│   ├── بروفايل
│   ├── معرض أعمال
│   └── تقييمات
├── الحجوزات
│   ├── حجز جديد
│   └── حجوزاتي
├── الملف الشخصي
│   ├── معلوماتي
│   └── إعدادات
└── لوحة التحكم
    ├── إحصائيات
    ├── إدارة الخدمات
    └── إدارة الطلبات
```

## 10.2 خريطة الموقع

| المستوى | الصفحة |
|---------|-------|
| 1 | الرئيسية |
| 2 | نتائج البحث |
| 2 | تفاصيل الخدمة |
| 3 | ملف مقدم الخدمة |
| 3 | صفحة الحجز |
| 1 | لوحة التحكم |

## 10.3 نظام التصنيف

| المستوى | المثال |
|---------|-------|
| الفئة الرئيسية | نوع الخدمة الأساسي |
| الفئة الفرعية | تخصص دقيق |
| الموقع | المنطقة/المديرية |
| السعر | اقتصادي/متوسط/متميز |
| التقييم | 1-5 نجوم |

## 10.4 تدفق المستخدم

### تدفق العميل:
فتح التطبيق -> بحث/تصفح -> اختيار مزود -> حجز -> تقييم

### تدفق مزود الخدمة:
تسجيل الدخول -> لوحة التحكم -> إدارة الطلبات -> تقارير
