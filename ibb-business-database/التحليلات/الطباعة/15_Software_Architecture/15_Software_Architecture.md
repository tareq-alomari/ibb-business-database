## 15.2 مكونات النظام

| المكون | التقنية |
|--------|---------|
| تطبيق الجوال | Flutter / React Native |
| تطبيق الويب | React.js + Next.js |
| API Gateway | Nginx / Kong |
| المصادقة | Node.js / Express |
| الخدمات | Node.js / Express |
| قاعدة البيانات | PostgreSQL 15 |
| التخزين | AWS S3 / MinIO |
| CDN | Cloudflare / CloudFront |

## 15.3 تدفق البيانات

Client -> API Gateway -> Service -> Database

## 15.4 استراتيجية التوسع

| المستوى | الاستراتيجية |
