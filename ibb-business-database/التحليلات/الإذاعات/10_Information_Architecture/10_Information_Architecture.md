## 10.1 هيكل المعلومات العام

تطبيق إذاعات إب → [الصفحة الرئيسية | قائمة الجهات | صفحة جهة | العروض | لوحة التحكم]

## 10.2 نظام التصنيف

| المستوى | التصنيف |
|---------|---------|
| حسب النوع | إذاعات حكومية | تخصص إذاعات حكومية |
| حسب النوع | إذاعات خاصة | تخصص إذاعات خاصة |
| حسب النوع | إذاعات مجتمعية | تخصص إذاعات مجتمعية |
| حسب النوع | إذاعات عبر الإنترنت | تخصص إذاعات عبر الإنترنت |

## 10.3 Sitemap

/ ← الصفحة الرئيسية
/list ← قائمة الجهات
/list/:id ← صفحة جهة
/list/:id/reviews ← تقييمات
/favorites ← المفضلة
/offers ← العروض

## 10.4 User Flow

فتح التطبيق → بحث/تصفح → اختيار جهة → عرض التفاصيل → تواصل → تقييم
