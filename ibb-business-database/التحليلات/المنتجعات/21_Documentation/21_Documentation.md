### محتوى دليل المستخدم (نموذج)

```
# دليل استخدام التطبيق

## 1. تسجيل الدخول
- افتح التطبيق
- أدخل رقم هاتفك
- أدخل رمز التحقق

## 2. البحث عن منشأة
- استخدم شريط البحث
- اكتب اسم المنشأة أو نوع الخدمة
- استخدم الفلترة

## 3. حجز خدمة
- اختر منشأة
- تصفح الخدمات
- اختر الخدمة والموعد
- أرسل الحجز

## 4. تقييم الخدمة
- بعد الاستفادة من الخدمة، قيم تجربتك
- اكتب تعليقًا
- أضف صورًا
```
