# التقنيات المقترحة: قطاع مراكز اللغات في إب

## Frontend

### ويب (Web)
- **Framework**: Next.js 14 (React) - مع SSR لتحسين SEO
- **Styling**: Tailwind CSS + Shadcn/ui
- **State Management**: React Query + Zustand
- **Forms**: React Hook Form + Zod
- **I18n**: next-intl (دعم عربي/إنجليزي)

### تطبيق جوال (Mobile)
- **Framework**: Flutter 3.x
- **State Management**: Riverpod
- **Local DB**: SQLite (للعمل دون إنترنت)
- **Push Notifications**: Firebase Cloud Messaging

## Backend

### Server
- **Runtime**: Node.js 20 LTS
- **Framework**: NestJS (TypeScript)
- **API**: RESTful + GraphQL (للإحصائيات)
- **Validation**: class-validator + Joi

### قاعدة البيانات
- **Primary**: PostgreSQL 16
- **Cache**: Redis 7
- **Search**: Elasticsearch (للبحث في الدورات والمحتوى)

### ORM
- **Prisma** أو TypeORM
- **Migration**: Prisma Migrate

## DevOps
- **Hosting**: VPS في اليمن أو AWS Bahrain
- **Container**: Docker + Docker Compose
- **CI/CD**: GitHub Actions
- **Monitoring**: Sentry + Grafana
- **Backup**: pg_dump يومي + S3

## أدوات إضافية
- **Maps**: OpenStreetMap (مجاني، يعمل بدون API Key)
- **SMS**: محلي ( Yemen Mobile API )
- **WhatsApp**: WhatsApp Business Cloud API
- **Payment**: كاش (أساسي) + محفظة إلكترونية لاحقاً
- **CDN**: Cloudflare (مجاني، تحسين سرعة التحميل)

## اعتبارات خاصة باليمن
1. **استضافة محلية** أو قريبة (السعودية، مصر) لسرعة التحميل
2. **دعم وضع عدم الاتصال** بسبب ضعف الإنترنت
3. **حجم منخفض للصور والفيديوهات** (WebP، ضغط)
4. **دعم الطاقة الشمسية** للمراكز
5. **حلول دفع نقدية** كخيار رئيسي مع الدفع الإلكتروني كخيار ثانوي

## خطة التنفيذ
1. MVP: Next.js + NestJS + PostgreSQL (4-6 أسابيع)
2. الإصدار الثاني: إضافة التطبيق الجوال (8-10 أسابيع)
3. الإصدار الثالث: تحليلات متقدمة وذكاء اصطناعي
