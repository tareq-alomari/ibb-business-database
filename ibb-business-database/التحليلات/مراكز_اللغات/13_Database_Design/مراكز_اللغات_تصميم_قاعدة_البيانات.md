# تصميم قاعدة البيانات: قطاع مراكز اللغات في إب

## نموذج العلاقات

### جدول: Centers (المراكز)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف المركز |
| name_ar | VARCHAR(200) | الاسم بالعربية |
| name_en | VARCHAR(200) | الاسم بالإنجليزية |
| district | VARCHAR(100) | المديرية |
| address | TEXT | العنوان التفصيلي |
| phone | VARCHAR(20) | رقم الهاتف |
| email | VARCHAR(100) | البريد الإلكتروني |
| license_no | VARCHAR(50) | رقم الترخيص |
| status | ENUM | نشط / متوقف |

### جدول: Courses (الدورات)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف الدورة |
| center_id | INT (FK) | معرف المركز |
| name | VARCHAR(200) | اسم الدورة |
| language | ENUM | اللغة (English، Arabic، Turkish...) |
| level | ENUM | مبتدئ، متوسط، متقدم |
| duration_weeks | INT | المدة بالأسابيع |
| hours_per_week | INT | ساعات أسبوعياً |
| price | DECIMAL(10,2) | السعر |
| max_students | INT | الحد الأقصى للطلاب |

### جدول: Students (الطلاب)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف الطالب |
| name | VARCHAR(150) | الاسم الكامل |
| phone | VARCHAR(20) | رقم الهاتف |
| email | VARCHAR(100) | البريد |
| gender | ENUM | ذكر / أنثى |
| age | INT | العمر |
| education_level | VARCHAR(100) | المستوى التعليمي |
| registered_date | DATE | تاريخ التسجيل |

### جدول: Enrollments (التسجيلات)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف التسجيل |
| student_id | INT (FK) | معرف الطالب |
| course_id | INT (FK) | معرف الدورة |
| enrolled_date | DATE | تاريخ التسجيل |
| status | ENUM | مستمر / منتهي / منسحب |
| final_grade | DECIMAL(5,2) | الدرجة النهائية |

### جدول: Payments (المدفوعات)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف الدفع |
| enrollment_id | INT (FK) | معرف التسجيل |
| amount | DECIMAL(10,2) | المبلغ |
| paid_date | DATE | تاريخ الدفع |
| method | ENUM | نقدي / حوالة |
| notes | TEXT | ملاحظات |

### جدول: Exams (الاختبارات)
| الحقل | النوع | الوصف |
|-------|------|-------|
| id | INT (PK) | معرف الاختبار |
| course_id | INT (FK) | معرف الدورة |
| type | ENUM | IELTS/TOEFL/تحديد مستوى |
| date | DATE | التاريخ |
| total_score | DECIMAL(5,2) | الدرجة الكلية |

## مخطط ER (مبسط)
```
Center 1--* Course
Course 1--* Enrollment
Student 1--* Enrollment
Enrollment 1--* Payment
Course 1--* Exam
Student 1--* Exam
```
