# لوحة التحكم: قطاع مراكز اللغات في إب

## نظرة عامة
لوحة تحكم تفاعلية لإدارة مراكز اللغات وعرض المؤشرات الرئيسية والإحصائيات.

## المؤشرات الرئيسية (KPIs)

### قسم الإدارة العليا
- **إجمالي الطلاب**: 1,250 (نشط)
- **عدد الدورات النشطة**: 34
- **الإيرادات الشهرية**: 12,450,000 ريال
- **معدل الاحتفاظ بالطلاب**: 76%
- **عدد المدربين**: 48 (16 أجانب، 32 محليون)

### قسم العمليات
- **نسبة الحضور اليومي**: 82%
- **معدل إكمال الدورة**: 68%
- **متوسط تقييم المدربين**: 4.2/5
- **عدد الشهادات المصدرة (شهرياً)**: 95
- **طلاب جدد (هذا الأسبوع)**: 23

### قسم المالية
- **الإيرادات**: 12,450,000 ريال
- **المصروفات**: 8,200,000 ريال
- **صافي الربح**: 4,250,000 ريال
- **نسبة التحصيل**: 89%
- **المتأخرات**: 1,800,000 ريال

## رسوم بيانية مقترحة
1. خط زمني للإيرادات الشهرية (آخر 12 شهراً)
2. توزيع الطلاب حسب المديرية (خريطة أو Bar Chart)
3. مقارنة أداء المراكز (متوسط الدرجات، عدد الطلاب)
4. توزيع الطلاب حسب اللغات المستهدفة (Pie Chart)
5. اتجاهات التسجيل الموسمية (Line Chart)
6. أداء المدربين (تقييم، عدد الطلاب، نسبة النجاح)

## صفحات لوحة التحكم

### صفحة الرئيسية (Overview)
ملخص المؤشرات الرئيسية + أسرع 5 دورات نمواً

### صفحة الطلاب
بحث، تصفية، إضافة، تعديل، حذف + سجل الحضور والمدفوعات

### صفحة الدورات
إدارة الدورات، الجداول، التسجيلات، التقييمات

### صفحة التقارير
تقارير مالية، أكاديمية، إدارية قابلة للتصدير (PDF/Excel)

### صفحة الإعدادات
إدارة المستخدمين، صلاحيات، إعدادات النظام

## ميزات خاصة
- دعم الوضع المظلم (Dark Mode)
- إشعارات فورية للطلاب الجدد والمدفوعات المتأخرة
- تصدير التقارير بصيغ متعددة
- دعم العمل دون اتصال مؤقت
- تقارير آلية ترسل عبر البريد الإلكتروني أسبوعياً
