# الأمان: قطاع مراكز اللغات في إب

## تهديدات أمنية محتملة

### تهديدات رقمية
1. **سرقة بيانات الطلاب**: أسماء، أرقام هواتف، عناوين
2. **اختراق حسابات الدفع**: الوصول لبيانات الدفع
3. **هجمات DDoS**: تعطيل الموقع (نادر في اليمن)
4. **حقن SQL**: عبر نماذج التسجيل
5. **XSS**: عبر تعليقات أو تقييمات
6. **التصيد (Phishing)**: انتحال هوية المركز

### تهديدات مادية
1. **سرقة أجهزة الحاسوب**: في المركز
2. **انقطاع الكهرباء**: فقدان بيانات غير محفوظة
3. **حرائق أو كوارث طبيعية**: تلف السجلات الورقية

## إجراءات الحماية

### على مستوى التطبيق
- تشفير كلمات المرور باستخدام bcrypt
- استخدام HTTPS حصراً (SSL/TLS)
- التحقق من صحة المدخلات (Input Validation)
- CSRF Tokens لجميع النماذج
- Rate Limiting على نقاط API
- JWT مع وقت صلاحية قصير
- 2FA للحسابات الإدارية

### على مستوى قاعدة البيانات
- تشفير البيانات الحساسة (أرقام الهواتف، عناوين)
- Backup يومي في موقعين منفصلين
- Audit Log لجميع العمليات
- فصل صلاحيات الوصول (Admin، Manager، Trainer، Student)
- استخدام Parameterized Queries لمنع SQL Injection

### على مستوى الشبكة
- جدار ناري (Firewall)
- VPN للوصول الإداري
- WAF (Web Application Firewall) إن أمكن

### على مستوى المركز
- كاميرات مراقبة في القاعات
- خزائن للحواسيب والمستندات
- مولد كهربائي احتياطي
- نظام إنذار ضد الحريق

## سياسات أمنية
1. تغيير كلمات المرور دورياً (كل 90 يوماً)
2. تدريب الموظفين على الأمن السيبراني
3. خطة استجابة للاختراقات
4. مراجعة أمنية ربع سنوية
5. الاحتفاظ بالسجلات لمدة 5 سنوات
