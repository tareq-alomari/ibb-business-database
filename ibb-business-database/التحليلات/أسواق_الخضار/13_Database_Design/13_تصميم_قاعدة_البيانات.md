# تصميم قاعدة البيانات لمنصة أسواق الخضار

## نظرة عامة
قاعدة بيانات علائقية (SQL) تدعم العمليات الأساسية للمنصة.

## الجداول الرئيسية

### 1. المستخدمون (users)
- id, name, phone, email, password_hash
- role (farmer, merchant, consumer, admin)
- location, created_at, updated_at

### 2. الأسواق (markets)
- id, name, description, location
- city, operating_hours, created_at

### 3. المنتجات (products)
- id, name, category, description
- unit, price, quantity, farmer_id
- market_id, status, created_at

### 4. الطلبات (orders)
- id, buyer_id, seller_id, total_amount
- status, payment_method, delivery_address
- created_at, updated_at

### 5. المعاملات (transactions)
- id, order_id, amount, type
- status, payment_gateway, created_at

### 6. الأسعار (prices)
- id, product_id, price, market_id
- recorded_at, source

### 7. التقييمات (reviews)
- id, user_id, product_id, rating
- comment, created_at

## العلاقات بين الجداول
- مستخدم → مزارع → منتجات
- مستخدم → تاجر → طلبات
- منتج → سوق
- طلب → معاملة
- منتج → سعر (تاريخي)

## فهارس (Indexes)
- اسم المستخدم (بحث سريع)
- اسم المنتج (بحث سريع)
- تاريخ السعر (تقارير)
- موقع السوق (خريطة)

## خطة النسخ الاحتياطي
- نسخة يومية كاملة
- نسخة تفاضلية كل 6 ساعات
- احتفاظ بـ 30 يوماً من النسخ
