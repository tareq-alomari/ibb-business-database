# المرحلة السادسة: Stakeholders - قطاع الجامعات في محافظة إب

## 6.1 الجهات المعنية

| الجهة | الدور | مستوى التأثير |
|-------|-------|--------------|
| الطلاب | المستخدمون الأساسيون | عالي |
| الجامعات (إدارات) | مزودو الخدمة | عالي |
| أعضاء هيئة التدريس | محتوى أكاديمي | متوسط |
| وزارة التعليم العالي | جهة تنظيمية | عالي |
| أولياء الأمور | داعمون ماليون | متوسط |
| أصحاب العمل | مخرجات التعليم | متوسط |
| المنظمات الدولية | دعم فني وتمويل | منخفض |

## 6.2 تحليل المصلحة والتأثير

```
تأثير عالي
    │
    │  وزارة التعليم     │  الطلاب
    │  الجامعات          │  أولياء الأمور
    │                    │
────┼────────────────────┼─────
    │                    │
    │  منظمات دولية      │  هيئة التدريس
    │  أصحاب العمل       │  
    │                    │
    │              مصلحة عالي
```
