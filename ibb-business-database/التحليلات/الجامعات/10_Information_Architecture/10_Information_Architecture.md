# المرحلة العاشرة: Information Architecture - قطاع الجامعات في محافظة إب

## 10.1 هيكل المعلومات

```
تطبيق الجامعات
├── الرئيسية
│   ├── بحث عن تخصص/جامعة
│   ├── الجامعات (قائمة)
│   ├── التخصصات (تصنيفات)
│   └── أخبار وإعلانات
├── الجامعات
│   ├── صفحة كل جامعة
│   ├── التخصصات المتاحة
│   ├── شروط القبول والرسوم
│   └── تقييمات الطلاب
├── التخصصات
│   ├── تصنيف (طبي، هندسي، إنساني)
│   ├── مقارنة بين الجامعات
│   └── فرص العمل بعد التخرج
├── التقديم
│   ├── اختيار التخصص
│   ├── تعبئة البيانات
│   ├── رفع المستندات
│   └── متابعة الطلب
├── المكتبة الرقمية
│   ├── أبحاث ورسائل
│   ├── كتب ومراجع
│   └── محتوى تعليمي
└── الملف الشخصي
    ├── بياناتي
    ├── طلباتي
    └── إعداداتي
```

## 10.2 نظام التصنيف

| التصنيف | المستوى الثاني | أمثلة |
|---------|---------------|-------|
| حسب النوع | حكومي | جامعة إب، جامعة جبلة |
| | أهلي | الحكمة، الناصر، المستقبل |
| حسب التخصص | طبي | طب، صيدلة، تمريض |
| | هندسي | مدني، معماري، حاسوب |
| | إنساني | شريعة، آداب، إدارة |

## 10.3 Sitemap

```
/                         ← الرئيسية
/universities             ← الجامعات
/universities/:id         ← صفحة جامعة
/majors                   ← التخصصات
/majors/:id               ← صفحة تخصص
/compare?majors=...       ← مقارنة
/apply                    ← تقديم إلكتروني
/apply/:id                ← متابعة طلب
/library                  ← مكتبة رقمية
/profile                  ← الملف الشخصي
```
