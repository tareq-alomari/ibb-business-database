# المرحلة الثالثة: Business Analysis - قطاع الجامعات في محافظة إب

## 3.1 معلومات أساسية

| العنصر | القيمة |
|--------|--------|
| عدد الجامعات | 8+ (2 حكومية، 6 أهلية) |
| عدد الكليات | 50+ كلية |
| عدد التخصصات | 200+ تخصص |
| إجمالي الطلاب | ~55,000 طالب |
| هيئة التدريس | ~3,000 عضو |
| الرسوم السنوية (حكومي) | 50,000-150,000 ريال |
| الرسوم السنوية (أهلي) | 200,000-800,000 ريال |

## 3.2 الخدمات المقدمة

| الخدمة | الجامعات المقدمة لها |
|--------|---------------------|
| برامج البكالوريوس | جميع الجامعات |
| برامج الماجستير | جامعة إب، جامعة جبلة، جامعة الحكمة |
| برامج الدكتوراه | جامعة إب (محدودة) |
| التعليم عن بعد | جامعة إب، الحكمة، الناصر |
| المختبرات العلمية | الجامعات الطبية والعلمية |
| المكتبات | جميع الجامعات |
| الإسكان الطلابي | محدود جدًا |

## 3.3 الفجوات

| الفجوة | الوصف |
|--------|-------|
| ندرة برامج الدراسات العليا | محدودة جدًا خارج جامعة إب |
| ضعف البحث العلمي | قلة النشر والتمويل |
| قلة التخصصات التطبيقية | تركيز على التخصصات النظرية |
| ضعف الخدمات الطلابية | سكن، صحة، أنشطة |
