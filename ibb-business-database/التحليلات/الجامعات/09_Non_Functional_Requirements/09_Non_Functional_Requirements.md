# المرحلة التاسعة: Non-Functional Requirements - قطاع الجامعات في محافظة إب

## 9.1 متطلبات الأداء

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| PERF1 | تحميل الصفحة الرئيسية | < 2 ثانية |
| PERF2 | نتائج البحث | < 1 ثانية |
| PERF3 | التقديم الإلكتروني | < 3 ثوانٍ |
| PERF4 | معالجة 500 مستخدم متزامن | خطأ < 1% |

## 9.2 متطلبات التوفر

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| AVAIL1 | uptime | 99.5% |
| AVAIL2 | نسخ احتياطي يومي | آمن |
| AVAIL3 | دعم الأوفلاين | تصفح الدليل بدون إنترنت |

## 9.3 متطلبات الأمان

| المعرف | المتطلب |
|--------|---------|
| SEC1 | تشفير البيانات TLS 1.3 |
| SEC2 | مصادقة JWT + OTP |
| SEC3 | RBAC (طالب، جامعة، مشرف) |
| SEC4 | حماية بيانات المستخدمين |
