# المرحلة الخامسة: Competitor Analysis - قطاع الجامعات في محافظة إب

## 5.1 الجامعات في إب

| الجامعة | نقاط القوة | نقاط الضعف |
|---------|-----------|------------|
| جامعة إب | الأقدم، أوسع تخصصات، حكومية | ميزانية محدودة، بنية تحتية متقادمة |
| جامعة جبلة | تخصص طبي متميز، مستشفى جامعي | تخصصات محدودة |
| جامعة الحكمة | جودة تعليم، مرافق حديثة | رسوم مرتفعة |
| جامعة الناصر | تخصصات طبية وهندسية | سمعة متوسطة |
| جامعة المستقبل | تخصصات إدارية مطلوبة | حديثة، قاعدة خريجين صغيرة |

## 5.2 المنافسون الرقميون

| المنافس | الوصف | نقاط القوة |
|---------|-------|-----------|
| مواقع الجامعات | معلومات رسمية | بيانات موثوقة |
| مجموعات واتساب | تواصل طلابي | مجتمع نشط |
| فيسبوك | إعلانات ومراجعات | وصول واسع |

| الميزة | التفاصيل |
