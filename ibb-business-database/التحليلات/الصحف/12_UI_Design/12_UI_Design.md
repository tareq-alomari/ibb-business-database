## 12.2 مكونات الواجهة

| المكون | الوصف |
|--------|-------|
| بطاقة الخدمة | صورة + اسم + تقييم + سعر |
| شريط البحث | إدخال نص + زر بحث |
| زر الحجز | زر رئيسي للحجز |
| نافذة التقييم | نجوم + تعليق |
| القائمة السفلية | أيقونات + تسميات |

## 12.3 شاشات التطبيق

| الشاشة | المحتوى |
|--------|--------|
| الرئيسية | بحث، تصنيفات، مميزون |
| النتائج | قائمة مقدمي الخدمة |
| التفاصيل | معلومات، صور، تقييمات |
| الحجز | تقويم، أوقات، تأكيد |
| الملف الشخصي | بيانات، حجوزات |

## 12.4 نظام التجاوب

| الحجم | التخطيط |
|-------|--------|
| جوال < 768px | عمود واحد |
| لوحي 768-1024px | عمودين |
| سطح مكتب > 1024px | 3 أعمدة |
