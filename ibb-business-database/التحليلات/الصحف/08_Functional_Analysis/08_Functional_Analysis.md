## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: إدارة الإصدارات
- **F10**: رفع المحتوى
- **F11**: إدارة المشتركين
- **F12**: إعلانات
- **F13**: تقارير
- **F14**: تحليلات القراء

### للعملاء

- **F1**: تسجيل
- **F2**: تصفح الصحف
- **F3**: قراءة إلكترونية
- **F4**: بحث في الأرشيف
- **F5**: اشتراك
- **F6**: إشعارات
- **F7**: مشاركة
- **F8**: تقييم

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
