## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: متجر حرفي
- **F10**: إدارة منتجات
- **F11**: توثيق الحرفة
- **F12**: إدارة طلبات
- **F13**: مخزون
- **F14**: تقارير

### للعملاء

- **F1**: تصفح المنتجات
- **F2**: بحث
- **F3**: تفاصيل المنتج
- **F4**: سلة تسوق
- **F5**: طلب مخصص
- **F6**: دفع
- **F7**: تتبع شحن
- **F8**: تقييم

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
