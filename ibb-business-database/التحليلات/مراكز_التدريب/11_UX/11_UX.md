# المرحلة الحادية عشرة: UX Design - قطاع مراكز التدريب في محافظة إب

## 11.1 مبادئ تجربة المستخدم

| المبدأ | التطبيق في المنصة |
|--------|------------------|
| البساطة | واجهة نظيفة، خطوات محدودة، إرشادات واضحة |
| السرعة | تحميل سريع، بحث فوري، نتائج سريعة |
| الوضوح | أيقونات معبرة، نصوص واضحة، ألوان مريحة |
| الاتساق | توحيد التصميم عبر جميع الصفحات |
| التجاوب | تجربة متسقة على الجوال والويب |
| التوجيه | مساعدة المستخدم في كل خطوة (Onboarding) |

## 11.2 تدفق المستخدم الرئيسي (User Flow)

### تدفق متدرب جديد
```
استقبال ← بحث عن دورة ← تصفح نتائج ← اختيار برنامج
    ↓
عرض التفاصيل ← قراءة تقييمات ← مقارنة مع برامج أخرى
    ↓
تسجيل حساب جديد ← تأكيد البريد ← تسجيل في الدورة
    ↓
استلام تأكيد ← إضافة للتذكيرات ← متابعة الموعد
```

### تدفق مركز تدريب
```
تسجيل دخول ← لوحة التحكم ← إضافة برنامج جديد
    ↓
تعبئة بيانات البرنامج (عنوان، محتوى، سعر، مواعيد)
    ↓
مراجعة الإدارة ← نشر ← استقبال طلبات التسجيل
    ↓
إدارة المتدربين ← إصدار شهادات ← عرض التقارير
```

## 11.3 Wireframes الرئيسية

| الصفحة | العناصر الأساسية |
|--------|-----------------|
| الرئيسية | شريط بحث بارز، تصنيفات سريعة، دورات مميزة |
| نتائج البحث | قائمة + عرض خريطة، فلاتر (تخصص، سعر، تقييم) |
| صفحة البرنامج | صور، وصف، محتوى الدورة، المدرب، التقييمات |
| صفحة المركز | معلومات، خريطة، جميع البرامج، تقييمات |
| التسجيل | نموذج بسيط، اختيار موعد، دفع |
| لوحة التحكم | إحصائيات، إدارة برامج، متدربون، تقارير |

## 11.4 تحسينات مستمرة

| المجال | طريقة القياس | الأداة |
