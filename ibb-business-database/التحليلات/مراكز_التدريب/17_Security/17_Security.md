# المرحلة السابعة عشرة: Security - قطاع مراكز التدريب في محافظة إب

## 17.1 تهديدات أمنية محتملة

| التهديد | التأثير | مستوى الخطورة |
|---------|---------|--------------|
| سرقة بيانات المستخدمين | اختراق الخصوصية، استهداف شخصي | عالي |
| هجمات DDoS | تعطيل المنصة، خسارة الثقة | عالي |
| حقن SQL | سرقة أو تدمير قاعدة البيانات | عالي |
| XSS (Cross-Site Scripting) | تنفيذ أكواد ضارة في المتصفح | متوسط |
| CSRF | تنفيذ إجراءات غير مصرح بها | متوسط |
| Brute Force | تخمين كلمات المرور | متوسط |
| انتحال الهوية | استغلال صلاحيات الآخرين | عالي |

## 17.2 إجراءات الحماية

| المجال | الإجراء |
|--------|---------|
| المصادقة | JWT بصلاحية محدودة (24 ساعة)، Refresh Tokens |
| كلمات المرور | تشفير bcrypt (12 rounds)، شرط القوة |
| التحقق بخطوتين | 2FA عبر SMS أو Google Authenticator |
| HTTPS | إجباري على جميع الصفحات (SSL/TLS 1.3) |
| API Security | Rate Limiting، CORS مقيد، Input Validation |
| حماية SQL | استخدام ORM مع Prepared Statements |
| حماية XSS | تنقية المدخلات (DOMPurify)، Content Security Policy |
| حماية CSRF | CSRF Tokens في كل طلب POST |
| الجلسات | HttpOnly Cookies، SameSite Strict |

## 17.3 إدارة الصلاحيات

| الدور | الصلاحيات |
|-------|-----------|
| زائر | تصفح الدليل فقط |
| متدرب | تسجيل، تقييم، ملف شخصي |
| مدرب | إدارة برامجه وجدوله |
| مركز تدريب | إدارة بياناته وبرامجه ومتدربيه |
| مشرف | إدارة كاملة، صلاحيات على جميع الأقسام |

## 17.4 الخصوصية وحماية البيانات

| المعيار | التطبيق |
|---------|---------|
| تشفير البيانات | AES-256 للبيانات الحساسة في قاعدة البيانات |
| إخفاء البيانات | إخفاء أرقام الهواتف والبريد من المستخدمين الآخرين |
| سجل النشاطات | تسجيل جميع الإجراءات المهمة (Logs) |
| حذف الحساب | إمكانية حذف البيانات بالكامل عند الطلب |
| الموافقة | إشعار خصوصية واضح عند التسجيل |
