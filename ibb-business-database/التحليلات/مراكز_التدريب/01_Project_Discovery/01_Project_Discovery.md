# المرحلة الأولى: Project Discovery - قطاع مراكز التدريب في محافظة إب

> **التاريخ**: يوليو 2026  
> **الملف**: 01_Project_Discovery.md

## 1.1 المشكلة (Problem Statement)

يعاني قطاع التدريب والتأهيل في محافظة إب من **تشتت الخدمات التدريبية** وضعف في جودة المخرجات وغياب منصة رقمية موحدة. المشكلات الرئيسية:

1. **عدم وجود دليل موحد**: لا توجد قاعدة بيانات شاملة لمراكز التدريب في المحافظة
2. **ضعف الجودة**: تفاوت كبير في جودة البرامج التدريبية بين المراكز
3. **صعوبة الاختيار**: المتدربون لا يملكون معلومات كافية عن البرامج والتكاليف
4. **غياب التقييم**: لا توجد مراجعات موثوقة عن جودة التدريب
5. **ضعف الربط بسوق العمل**: برامج تدريب لا تلبي احتياجات السوق

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لمراكز التدريب في محافظة إب** (Ibb Training Hub) تشمل:

- **دليل المراكز**: قاعدة بيانات لجميع مراكز التدريب المعتمدة في إب
- **مقارنة البرامج**: أدوات لمقارنة الدورات من حيث المحتوى والتكلفة والمدة
- **نظام التسجيل الإلكتروني**: حجز المقاعد وتتبع التقدم
- **تقييمات ومراجعات**: تقييمات حقيقية من المتدربين السابقين
- **شهادات رقمية**: إصدار وتوثيق الشهادات التدريبية

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المتدربون** | اكتشاف البرامج المناسبة، مقارنة الأسعار والجودة |
| **مراكز التدريب** | منصة تسويقية، إدارة المتدربين، تحسين السمعة |
| **المدربون** | عرض خدماتهم، بناء سمعة مهنية |
| **أصحاب العمل** | توظيف خريجي البرامج التدريبية المؤهلين |
| **الجهات المانحة** | تمويل مستهدف للبرامج ذات الأثر |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | شباب محافظة إب (~500,000 شاب في سن التدريب) |
| **مصادر التمويل** | اشتراكات المراكز، عمولات التسجيل، إعلانات |
| **نموذج الإيرادات** | Freemium للمراكز + خدمات مدفوعة |
| **القنوات** | تطبيق جوال + موقع ويب + واتساب بوت |
| **الشركاء المحتملون** | صندوق التدريب المهني، منظمات دولية، الغرفة التجارية |

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| G1: حصر المراكز | عدد المراكز المسجلة | 50+ مركز |
| G2: البرامج | عدد البرامج الموثقة | 300+ برنامج |
| G3: المتدربون | عدد المستخدمين المسجلين | 20,000+ متدرب |
| G4: التسجيل | عدد الحجوزات عبر المنصة | 5,000+ سنويًا |
| G5: الرضا | تقييم المستخدمين | 4.0+/5 |

## 1.5 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - طلب متزايد على المهارات الرقمية | - ضعف الإنترنت في المناطق الريفية |
| - انتشار الهواتف الذكية | - محدودية المحتوى الرقمي التدريبي |
| - كثافة سكانية شابة | - ضعف الثقافة التدريبية |
| - مراكز تدريب قائمة | - غياب التراخيص لبعض المراكز |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - تحول رقمي في التدريب | - استمرار الأزمة الاقتصادية |
| - دعم المنظمات الدولية | - هجرة الكوادر التدريبية |
| - شراكة مع صندوق التدريب المهني | - انقطاع الكهرباء والإنترنت |

- الجهاز المركزي للإحصاء اليمني
- صندوق التدريب المهني والتقني
- الغرفة التجارية والصناعية بمحافظة إب
- مقابلات مع مدربي ومالكي مراكز التدريب
