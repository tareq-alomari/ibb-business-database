# المرحلة الثالثة: Business Analysis - قطاع مراكز التدريب في محافظة إب

## 3.1 معلومات أساسية

| العنصر | القيمة |
|--------|--------|
| عدد مراكز التدريب | 60+ مركز (حكومي وخاص وأهلي) |
| عدد البرامج التدريبية | 500+ برنامج سنويًا |
| إجمالي المتدربين | ~15,000 سنويًا |
| متوسط الرسوم لكل دورة | 30,000 - 150,000 ريال |
| حجم السوق التقديري | ~1.5 مليار ريال يمني سنويًا |
| المجالات الأكثر طلبًا | IT، إدارة أعمال، مهارات شخصية، لغة إنجليزية |

## 3.2 الخدمات التدريبية المقدمة

| المجال | أمثلة البرامج | عدد المراكز المقدمة له |
|--------|--------------|----------------------|
| تقنية المعلومات | برمجة، شبكات، صيانة حاسوب | 25+ مركز |
| الإدارة والأعمال | محاسبة، تسويق، إدارة موارد بشرية | 20+ مركز |
| المهارات الشخصية | قيادة، تواصل، تفاوض | 15+ مركز |
| اللغات | إنجليزية، تركية | 10+ مركز |
| المهارات المهنية | كهرباء، تبريد، لحام | 8+ مركز |
| الصحة والإسعافات | إسعافات أولية، تمريض | 5+ مركز |

## 3.3 الفجوات في السوق

| الفجوة | الوصف |
|--------|-------|
| ندرة التدريب على البرمجة المتقدمة | قلة برامج Web وMobile Development المتخصصة |
| ضعف برامج اللغة الإنجليزية للمستويات المتقدمة | تركيز على المستويات التمهيدية فقط |
| قلة التدريب على ريادة الأعمال | نادر رغم الطلب المتزايد |
| غياب البرامج المعتمدة دوليًا | شهادات محلية فقط |
| ضعف التدريب عن بُعد | قلة البرامج عبر الإنترنت رغم الحاجة |
