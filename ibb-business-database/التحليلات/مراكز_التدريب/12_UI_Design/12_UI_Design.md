| العنصر | المواصفة |
|--------|----------|
| اسم المنصة | منصة تدريب إب (Ibb Training Hub) |

## 12.3 مكونات الواجهة

| المكون | الوصف |
|--------|-------|
| بطاقة المركز | اسم، تقييم، تخصصات، موقع، صورة مصغرة |
| بطاقة البرنامج | عنوان، سعر، مدة، مواعيد، صورة |
| شريط البحث | بارز في أعلى الصفحة مع فلترة سريعة |
| الفلاتر | تخصص، سعر، منطقة، تقييم، موعد |
| زر CTA | برتقالي، واضح، "سجل الآن" |
| التقييم | 5 نجوم مع عدد التقييمات |
| الخريطة | مواقع المراكز على خريطة تفاعلية |

## 12.4 Responsive Design

| الجهاز | الشاشة | التكيف |
|--------|--------|--------|
| جوال | < 768px | قائمة همبرغر، بطاقات عمودية |
| تابلت | 768px - 1024px | شبكة 2 عمود، قائمة جانبية |
| لابتوب | 1024px - 1440px | شبكة 3-4 أعمدة، شريط جانبي |
| شاشات كبيرة | > 1440px | عرض كامل، مساحات أوسع |

## 12.5 أنماط التحميل

| الحالة | العنصر المرئي |
|--------|--------------|
| تحميل | Skeleton screens بدل Spinner |
| فارغ | أيقونة + رسالة توضيحية |
| خطأ | رسالة خطأ + زر إعادة المحاولة |
| نجاح | تأكيد مرئي + إشعار أخضر |

- Figma لتصميم النماذج الأولية
- مكونات مسبقة من Material UI أو Tailwind
- اختبار على أجهزة حقيقية في إب
