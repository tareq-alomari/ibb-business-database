# المرحلة السادسة: Stakeholders - قطاع مراكز التدريب في محافظة إب

## 6.1 الجهات المعنية

| الجهة | الدور | مستوى التأثير |
|-------|-------|--------------|
| المتدربون (شباب إب) | المستخدمون الأساسيون | عالي |
| مراكز التدريب (إدارات) | مزودو الخدمة التدريبية | عالي |
| المدربون | منفذو البرامج التدريبية | عالي |
| صندوق التدريب المهني | جهة تنظيمية وتمويلية | عالي |
| وزارة التعليم الفني | جهة إشرافية | متوسط |
| الغرفة التجارية بإب | دعم قطاع الأعمال | متوسط |
| منظمات دولية | تمويل ودعم فني | متوسط |
| أصحاب العمل | مستقبلو المخرجات | متوسط |
| مكاتب المحافظات | تسهيل إداري | منخفض |

## 6.2 تحليل المصلحة والتأثير

```
تأثير عالي
    │
    │  صندوق التدريب المهني  │  المتدربون
    │  مراكز التدريب          │  المدربون
    │                          │
────┼──────────────────────────┼─────
    │                          │
    │  وزارة التعليم الفني     │  منظمات دولية
    │  الغرفة التجارية         │  أصحاب العمل
    │                          │
    │              مصلحة عالي
```

## 6.3 استراتيجيات التواصل

| الجهة | استراتيجية التواصل |
|-------|-------------------|
| المتدربون | إعلانات على وسائل التواصل، حوافز تسجيل |
| مراكز التدريب | اجتماعات مباشرة، عرض المزايا المجانية |
| صندوق التدريب المهني | شراكة استراتيجية، تقارير دورية |
| المنظمات الدولية | عروض مشاريع، تقارير أثر |
| أصحاب العمل | قاعدة بيانات للخريجين، توظيف عبر المنصة |
