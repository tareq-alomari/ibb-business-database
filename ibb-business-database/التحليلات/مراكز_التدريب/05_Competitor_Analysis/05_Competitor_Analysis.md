# المرحلة الخامسة: Competitor Analysis - قطاع مراكز التدريب في محافظة إب

## 5.1 مراكز التدريب التقليدية

| المركز | نقاط القوة | نقاط الضعف |
|--------|-----------|------------|
| معهد إب التقني | رسمي، معتمد، رسوم منخفضة | بيروقراطية، مناهج قديمة |
| مركز الحاسوب الآلي | خبرة طويلة، مدربون مؤهلون | تركيز على IT فقط |
| أكاديمية النخبة | برامج متنوعة، مرافق جيدة | رسوم مرتفعة نسبيًا |
| مركز التدريب المهني | تخصصات مهنية عملية | محدودية التخصصات الرقمية |
| معهد اللغة الإنجليزية | متخصص في اللغات | لا يقدم برامج تقنية |
| مركز الخوارزمي | برمجة متقدمة، تقييمات جيدة | طاقة استيعابية محدودة |

## 5.2 المنافسون الرقميون

| المنافس | الوصف | التأثير |
|---------|-------|---------|
| منصات التعليم عبر الإنترنت | يوديمي، كورسيرا | منافسة عالمية لكن باللغة الإنجليزية |
| قنوات يوتيوب تعليمية | محتوى مجاني بالعربية | منافسة قوية في المحتوى المجاني |
| مجموعات واتساب وتلغرام | تدريب غير رسمي عبر المجموعات | مرن لكن غير معتمد |
| مراكز تدريب من خارج إب | مراكز في صنعاء وعدن تقدم تدريب عن بُعد | تستهدف نفس الجمهور |

## 5.3 الميزة التنافسية للمنصة

| الميزة | التفاصيل |
|--------|---------|
| مركزية المعلومات | جميع المراكز والبرامج في منصة واحدة |
| مقارنة البرامج | مقارنة موضوعية من حيث المحتوى والتكلفة |
| تقييمات موثوقة | مراجعات حقيقية لمتدربين سابقين |
| تسجيل إلكتروني | حجز سهل ومتابعة ذكية |
| شهادات رقمية | توثيق وإصدار إلكتروني للشهادات |
| توصيات ذكية | اقتراح برامج تناسب اهتمامات المستخدم |
