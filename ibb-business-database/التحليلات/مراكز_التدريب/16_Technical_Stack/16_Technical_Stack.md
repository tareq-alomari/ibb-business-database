# المرحلة السادسة عشرة: Technical Stack - قطاع مراكز التدريب في محافظة إب

## 16.1 Frontend

| التقنية | الاستخدام | البديل |
|---------|-----------|--------|
| React.js | مكتبة الواجهات الرئيسية | Vue.js |
| Next.js | SSR، تحسين SEO، Routing | Nuxt.js |
| Tailwind CSS | التنسيق السريع والتصميم المتجاوب | Bootstrap |
| PWA (Workbox) | دعم العمل بدون إنترنت | - |
| Axios | التواصل مع API | Fetch API |
| React Query | إدارة حالة الخادم والتخزين المؤقت | Redux Toolkit |

## 16.2 Backend

| التقنية | الاستخدام | البديل |
|---------|-----------|--------|
| Node.js + Express | خادم API الرئيسي | FastAPI (Python) |
| JWT (jsonwebtoken) | مصادقة المستخدمين | Passport.js |
| Prisma ORM | التعامل مع قاعدة البيانات | TypeORM |
| Swagger/OpenAPI | توثيق API | Postman Docs |
| Socket.io | إشعارات فورية | - |

## 16.3 قاعدة البيانات والتخزين

| التقنية | الاستخدام |
|---------|-----------|
| PostgreSQL | قاعدة البيانات الرئيسية (علائقية) |
| Redis | تخزين مؤقت، جلسات، تصنيفات |
| Cloudflare R2 | تخزين الصور والشهادات (S3 متوافق) |
| Elasticsearch | فهرسة وبحث متقدم (اختياري) |

## 16.4 DevOps والنشر

| التقنية | الاستخدام |
|---------|-----------|
| Docker | حزم التطبيق ونشره |
| Docker Compose | إدارة الخدمات المتعددة |
| Nginx | خادم وكيل عكسي، SSL |
| GitHub Actions | CI/CD |
| DigitalOcean / Hetzner | استضافة (قريبة من اليمن) |
| Cloudflare | CDN، حماية DDoS، DNS |

## 16.6 متطلبات خاصة باليمن

| المتطلب | الحل |
|---------|------|
| ضعف الإنترنت | PWA + تصغير الملفات + CDN |
| انقطاع الكهرباء | Offline Mode، عمل على البطارية |
| دفع محلي | نقاط دفع (علي إكسبريس/فوري) |
| سعة خادم محدودة | تحسين قاعدة البيانات، Caching |
- اختيار تقنيات خفيفة لتقليل التكاليف
- دعم اللغة العربية كأولوية (RTL)
- اختبار الأداء على اتصال 3G
