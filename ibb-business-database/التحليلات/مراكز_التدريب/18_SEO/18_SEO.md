## 18.2 تحسين On-Page SEO

| العنصر | التطبيق |
|--------|---------|
| Title Tags | "اسم الصفحة | منصة تدريب إب" |
| Meta Descriptions | وصف دقيق لكل صفحة (150-160 حرف) |
| Headings (H1-H3) | هيكل هرمي، كلمة مفتاحية في H1 |
| URL Structure | /centers/it-training-ibb |
| Alt Text للصور | وصف وصفي للصور يشمل الكلمة المفتاحية |
| Internal Linking | ربط بين المراكز والبرامج والتصنيفات |
| Open Graph Tags | لمشاركة الصفحات على وسائل التواصل |
| Schema Markup | LocalBusiness، Course، Review |

## 18.3 تحسين Technical SEO

| العنصر | الإجراء |
|--------|---------|
| سرعة الموقع | تحسين الصور، Lazy Loading، Cache |
| الموبايل | تصميم متجاوب 100% |
| Sitemap.xml | خريطة موقع ديناميكية محدثة |
| Robots.txt | منع الصفحات الإدارية من الفهرسة |
| SSL | HTTPS إجباري |
| Core Web Vitals | تحسين LCP، FID، CLS |
| Canonical URLs | منع المحتوى المكرر |

## 18.4 تحسين Local SEO

| العنصر | الإجراء |
|--------|---------|
| Google My Business | تسجيل المنصة كعمل تجاري محلي |
| الخريطة | تضمين خريطة تفاعلية للمراكز |
| البيانات المحلية | اسم المدينة والحي في كل صفحة |
| المراجعات | تشجيع المتدربين على كتابة تقييمات |
| الروابط المحلية | روابط من مواقع محلية (الغرفة التجارية، الجامعات) |
