# المرحلة الرابعة عشرة: API Design - قطاع مراكز التدريب في محافظة إب

## 14.1 البنية العامة

| العنصر | المواصفة |
|--------|----------|
| النمط | RESTful API |
| الصيغة | JSON |
| الإصدار | v1 (/api/v1/) |
| المصادقة | JWT Bearer Token |
| التوثيق | Swagger / OpenAPI 3.0 |

## 14.2 Endpoints الرئيسية

### المستخدمون

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | /api/v1/auth/register | تسجيل مستخدم جديد |
| POST | /api/v1/auth/login | تسجيل الدخول |
| GET | /api/v1/auth/profile | بيانات المستخدم |
| PUT | /api/v1/auth/profile | تحديث الملف الشخصي |

### مراكز التدريب

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | /api/v1/centers | قائمة المراكز (بحث، تصفية) |
| GET | /api/v1/centers/:id | تفاصيل مركز |
| POST | /api/v1/centers | إضافة مركز (للمراكز فقط) |
| PUT | /api/v1/centers/:id | تحديث بيانات المركز |
| GET | /api/v1/centers/:id/programs | برامج مركز معين |

### البرامج التدريبية

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | /api/v1/programs | قائمة البرامج |
| GET | /api/v1/programs/:id | تفاصيل برنامج |
| POST | /api/v1/programs | إضافة برنامج جديد |
| GET | /api/v1/programs/search?q=&cat=&price_min=&price_max= | بحث متقدم |

### التسجيلات والتقييمات

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | /api/v1/enrollments | تسجيل في برنامج |
| GET | /api/v1/enrollments/my | تسجيلاتي |
| POST | /api/v1/reviews | إضافة تقييم |
| GET | /api/v1/reviews/:target_id | تقييمات (مركز/برنامج) |

## 14.4 رموز الخطأ

| الرمز | المعنى |
|-------|--------|
| 200 | نجاح |
| 201 | تم الإنشاء |
| 400 | طلب غير صحيح |
| 401 | غير مصرح |
| 403 | ممنوع الوصول |
| 404 | غير موجود |
| 409 | تعارض (مثل بريد مكرر) |
| 422 | بيانات غير صالحة |
| 429 | طلبات كثيرة جدًا |
| 500 | خطأ في الخادم |

- Postman لجمع واختبار الـ API
- Rate Limiting: 100 طلب/دقيقة للمستخدمين العاديين
- 500 طلب/دقيقة للمراكز المسجلة
