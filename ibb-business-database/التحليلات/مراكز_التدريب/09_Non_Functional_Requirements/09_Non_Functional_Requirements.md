# المرحلة التاسعة: Non-Functional Requirements - قطاع مراكز التدريب في محافظة إب

## 9.1 متطلبات الأداء

| المتطلب | المواصفة |
|---------|----------|
| وقت تحميل الصفحة الرئيسية | أقل من 3 ثوانٍ |
| وقت الاستجابة للبحث | أقل من ثانيتين |
| عدد المستخدمين المتزامنين | دعم 1,000+ مستخدم |
| وقت تحميل الصور والوسائط | أقل من 5 ثوانٍ |
| حجم قاعدة البيانات الأولية | ~500 مركز + 2,000 برنامج |

## 9.2 متطلبات الأمان

| المتطلب | الوصف |
|---------|-------|
| تشفير البيانات | HTTPS و TLS 1.3 |
| حماية كلمات المرور | تشفير bcrypt |
| التحقق من الهوية | JWT مع صلاحية محددة |
| أمان API | Rate Limiting و CORS |
| حماية من XSS و CSRF | تنقية المدخلات، Tokens |
| نسخ احتياطي | يومي للبيانات، أسبوعي كامل |

## 9.3 متطلبات التوفر

| المتطلب | الهدف |
|---------|-------|
| نسبة التشغيل (Uptime) | 99.5% |
| وقت التعافي من العطل (RTO) | أقل من 4 ساعات |
| نقطة استعادة البيانات (RPO) | أقل من 24 ساعة |
| الصيانة الدورية | أسبوعية (ليلاً) |

## 9.4 متطلبات التوافق

| المتطلب | المواصفة |
|---------|----------|
| المتصفحات المدعومة | Chrome، Firefox، Safari، Edge (آخر إصدارين) |
| الأجهزة المحمولة | Android 8+، iOS 13+ |
| دعم الشاشات | Responsive لجميع الأحجام |
| سرعة الإنترنت | أداء مقبول حتى 3G |

## 9.5 متطلبات سهولة الاستخدام

| المتطلب | الوصف |
|---------|-------|
| الواجهة | عربية بالكامل مع دعم الإنجليزية |
| الخط | واضح، مناسب للشاشات الصغيرة |
| الألوان | متباينة، مريحة للعين |
| الإشعارات | SMS، إشعارات متصفح، بريد إلكتروني |
| التقارير | PDF، Excel للتصدير |
