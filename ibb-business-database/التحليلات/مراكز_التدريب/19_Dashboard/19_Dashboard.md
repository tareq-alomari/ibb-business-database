# المرحلة التاسعة عشرة: Dashboard - قطاع مراكز التدريب في محافظة إب

## 19.1 لوحة تحكم المتدرب

| العنصر | الوصف |
|--------|-------|
| الدورات المسجلة | قائمة بالدورات الحالية والسابقة |
| المواعيد القادمة | جدول زمني للدورات والاختبارات |
| الشهادات | الشهادات المنجزة، إمكانية التحميل |
| التقييمات | تقييماتي السابقة، إضافة تقييم جديد |
| الإشعارات | تنبيهات التسجيل، التذكيرات، العروض |
| الملف الشخصي | تعديل البيانات، تغيير كلمة المرور |

## 19.2 لوحة تحكم مركز التدريب

| العنصر | الوصف |
|--------|-------|
| الإحصائيات الرئيسية | عدد المتدربين، البرامج النشطة، الإيرادات |
| إدارة البرامج | إضافة، تعديل، حذف البرامج التدريبية |
| إدارة المتدربين | قائمة المسجلين، حالة الدفع، الحضور |
| التقارير | تقارير الأداء، إحصاءات التسجيل |
| الشهادات | إصدار شهادات للمتدربين المكملين |
| الملف الشخصي للمركز | تحديث بيانات المركز والصور |

## 19.3 لوحة تحكم المشرف العام

| العنصر | الوصف |
|--------|-------|
| نظرة عامة | إحصائيات شاملة (مراكز، برامج، متدربين) |
| إدارة المراكز | الموافقة على المراكز الجديدة، تعليق المخالف |
| إدارة البرامج | الموافقة على البرامج، مراجعة المحتوى |
| إدارة المستخدمين | إدارة الحسابات، الصلاحيات، الحظر |
| التقارير المتقدمة | تحليلات الأداء، تقارير مخصصة |
| إدارة المحتوى | المقالات، الإشعارات، الصفحات الثابتة |

## 19.4 مؤشرات الأداء الرئيسية (KPIs)

| المؤشر | الوصف | الهدف |
|--------|-------|-------|
| عدد المراكز النشطة | المراكز المسجلة والنشطة | 50+ |
| عدد البرامج المتاحة | البرامج النشطة حاليًا | 200+ |
| عدد المتدربين المسجلين | إجمالي الحسابات النشطة | 20,000+ |
| معدل الإكمال | نسبة إكمال الدورات المسجلة | 70%+ |
| متوسط التقييم | تقييم المراكز والبرامج | 4.0+/5 |
| الإيرادات الشهرية | أرباح المنصة شهريًا | تحقق الاستدامة |

## 19.5 الرسوم البيانية المقترحة

| الرسم البياني | البيانات |
|---------------|----------|
| خط زمني | نمو عدد المراكز والمتدربين شهريًا |
| دائري | توزيع المتدربين حسب التخصص |
| أعمدة | أشهر البرامج والمراكز |
| خريطة حرارية | توزيع المراكز حسب المناطق |
| Sankey | رحلة المستخدم من البحث إلى التسجيل |

- مكتبة Chart.js أو Recharts للرسوم البيانية
- تصدير التقارير بصيغة PDF و Excel
- تحديث تلقائي للبيانات كل 5 دقائق
- لوحة تحكم متجاوبة للجوال والويب
