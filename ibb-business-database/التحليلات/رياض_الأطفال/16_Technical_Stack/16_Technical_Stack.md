# التقنيات المستخدمة: منصة رياض الأطفال في إب

> **تاريخ التحليل**: يوليو 2026

---

## الواجهة الأمامية (Frontend)

| التقنية | الاستخدام |
|---------|-----------|
| Next.js 14 | Framework React مع SSR |
| TypeScript | لغة البرمجة |
| Tailwind CSS | تصميم الواجهات |
| React Query | إدارة حالة البيانات |
| Leaflet.js | الخرائط التفاعلية |
| NextAuth.js | المصادقة |
| i18next | دعم الترجمة (عربي/إنجليزي) |

## الواجهة الخلفية (Backend)

| التقنية | الاستخدام |
|---------|-----------|
| Node.js + Express | خادم API |
| TypeScript | لغة البرمجة |
| Prisma ORM | التعامل مع قاعدة البيانات |
| Zod | التحقق من صحة البيانات |
| JWT | المصادقة |
| Bull | معالجة المهام الخلفية |

## قاعدة البيانات

| التقنية | الاستخدام |

| Redis | التخزين المؤقت والجلسات |
