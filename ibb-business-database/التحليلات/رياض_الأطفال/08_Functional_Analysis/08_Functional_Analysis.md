## قائمة الميزات

| الرقم | الميزة | الأولوية | الوصف |
|-------|--------|----------|-------|
| F01 | بحث متقدم | عالية | بحث بالاسم، الموقع، المنهج، الرسوم |
| F02 | تصنيف الرياض | عالية | حسب المديرية، المنهج، المستوى |
| F03 | ملف الروضة | عالية | صفحة كاملة بكل المعلومات والصور |
| F04 | الخريطة التفاعلية | عالية | عرض الرياض على الخريطة |
| F05 | مقارنة الرياض | متوسطة | مقارنة جنبًا إلى جنب |
| F06 | التقييم والمراجعات | عالية | تقييم من أولياء الأمور |
| F07 | التقارير والإحصاءات | عالية | تحليلات القطاع |
| F08 | إعلانات الوظائف | متوسطة | توظيف المعلمات والمربيات |
| F09 | إدارة المستخدمين | عالية | تسجيل، أدوار، صلاحيات |
| F10 | API مفتوح | متوسطة | تكامل مع أنظمة أخرى |
