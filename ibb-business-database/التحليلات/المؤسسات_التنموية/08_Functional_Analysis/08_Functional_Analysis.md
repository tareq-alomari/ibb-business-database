## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: ملف المؤسسة
- **F10**: إدارة مشاريع
- **F11**: توثيق المستفيدين
- **F12**: تقارير شفافية
- **F13**: متطوعون
- **F14**: حملات تمويل

### للعملاء

- **F1**: استعراض المؤسسات
- **F2**: تصفح المشاريع
- **F3**: تبرع
- **F4**: تتبع أثر التبرع
- **F5**: طلب مساعدة
- **F6**: متابعة
- **F7**: تواصل
- **F8**: تقييم

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
