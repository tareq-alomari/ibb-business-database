# الأمان: منصة البهارات في إب

## استراتيجية الأمان العامة
حماية بيانات المحلات والزبائن من الاختراق والسرقة، مع ضمان خصوصية المعلومات التجارية والحساسة.

## أمان التطبيق

### حماية API
- معدل الطلبات (Rate Limiting): حد أقصى ١٠٠ طلب لكل دقيقة لكل IP
- التحقق من صحة الإدخال (Input Validation)
- حماية من SQL Injection عبر Prisma ORM
- منع XSS عبر تعقيم المدخلات
- استخدام Helmet.js لأمان HTTP Headers

### المصادقة والتخويل
- JWT مع صلاحية محدودة (ساعة واحدة للوصول، ٧ أيام للتحديث)
- تخزين كلمات المرور بتشفير bcrypt (١٢ جولة)
- صلاحيات مقسمة: مشاهد، محرر، مسؤول
- تسجيل جميع عمليات الدخول والإجراءات الحساسة

## أمان البيانات

### التشفير
- جميع البيانات المخزنة مشفرة AES-256
- قاعدة البيانات مشفرة كاملة (TDE)
- النسخ الاحتياطي مشفر أيضاً

### الخصوصية
- عدم مشاركة أرقام الهواتف دون موافقة
- إخفاء معلومات الاتصال عن الزوار غير المسجلين
- سياسة خصوصية واضحة ومعلنة

## أمان البنية التحتية

### الخادم
- تحديثات أمنية أسبوعية
- جدار ناري (UFW) مع منافذ محدودة
- SSH عبر مفاتيح فقط (بدون كلمة مرور)
- حماية من DDoS عبر Cloudflare

### SSL/TLS
- شهادة SSL من Let's Encrypt
- تجديد تلقائي كل ٩٠ يوماً
- فرض HTTPS عبر Nginx
- استخدام TLS 1.3 فقط
