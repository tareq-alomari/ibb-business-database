# التحليل الوظيفي: منصة البهارات في إب

## الوظائف الأساسية للمنصة

### الوحدة الأولى: إدارة المحلات
- إضافة محل جديد (اسم، موقع، صور، بيانات اتصال)
- تعديل بيانات المحل
- حذف محل
- عرض قائمة المحلات مع التصنيفات
- البحث عن محل بالاسم أو الموقع

### الوحدة الثانية: إدارة المنتجات
- إضافة منتج (اسم، نوع، سعر، وصف)
- تصنيف المنتجات حسب النوع (بهارات كاملة، مطحونة، خلطات)
- تحديث الأسعار دورياً
- عرض تفاصيل المنتج

### الوحدة الثالثة: البحث والتصفية
- بحث عن محل أو منتج
- تصفية حسب المنطقة
- تصفية حسب نوع البهارات
- ترتيب حسب السعر أو التقييم

### الوحدة الرابعة: التقييمات والمراجعات
- إضافة تقييم للمحل (نجوم)
- كتابة مراجعة نصية
- عرض متوسط التقييمات
- رفع صور للمنتجات

### الوحدة الخامسة: الخرائط والملاحة
- عرض المحلات على خريطة تفاعلية
- تحديد المسار إلى المحل
- عرض المناطق والأحياء

### الوحدة السادسة: لوحة التحكم
- إحصائيات عامة
- تقارير الأداء
- إدارة المستخدمين
- تحليل البيانات

## حالات الاستخدام الأساسية
١. مستخدم يبحث عن محل بهارات قريب منه
٢. مستخدم يقارن أسعار منتج معين
٣. صاحب محل يحدث بيانات متجره
٤. مسؤول يضيف محلاً جديداً للمنصة
