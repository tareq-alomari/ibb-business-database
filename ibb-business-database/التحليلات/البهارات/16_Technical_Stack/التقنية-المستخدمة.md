# التقنية المستخدمة: منصة البهارات في إب

## واجهة المستخدم (Frontend)
- Next.js 14 - إطار عمل React مع دعم التقديم من الخادم
- Tailwind CSS - تصميم سريع ومتجاوب
- Leaflet.js - خرائط تفاعلية مجانية
- Axios - مكتبة طلبات HTTP
- React Query - إدارة حالة البيانات من الخادم
- React Hook Form - إدارة النماذج

## الخادم (Backend)
- Node.js 20 - بيئة تشغيل
- Express.js 4 - إطار عمل للخادم
- Prisma ORM - التعامل مع قاعدة البيانات
- JWT - المصادقة والتخويل
- Swagger - توثيق API
- Sharp - معالجة الصور

## قاعدة البيانات
- PostgreSQL 16 - قاعدة البيانات الرئيسية
- Redis - تخزين مؤقت للتحسين الأداء
- PgAdmin - إدارة قاعدة البيانات

## البنية التحتية
- Docker - حاويات التطبيق
- Docker Compose - إدارة الحاويات
- Nginx - خادم ويب وكيل عكسي
- PM2 - إدارة عمليات Node.js
- GitHub Actions - CI/CD

## أدوات التطوير
- VS Code - محرر الكود
- Git - التحكم بالإصدارات
- Postman - اختبار API
- Figma - تصميم الواجهات
- Notion - إدارة المشروع

## متطلبات الخادم
- VPS: 2 CPU, 4GB RAM, 50GB SSD
- نظام تشغيل: Ubuntu 22.04 LTS
- SSL: Let's Encrypt (مجاني)
- Backup: يومي تلقائي
