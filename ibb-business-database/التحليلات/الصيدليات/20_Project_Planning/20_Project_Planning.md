## 20.1 خطة التحقق والنشر

| البوابة | المخرج | شرط الانتقال |
|---|---|---|
| 1. استخراج | مرشحات ببيانات مصدر | اجتياز فحص المعرّفات والمصدر |
| 2. تسوية | إزالة المكرر وتصحيح الاسم والموقع | دليل موثق لقرار الدمج أو الرفض |
| 3. تحقق | حالة تشغيل أو اتصال قابل للنشر | قناة رسمية أو تحقق ميداني مؤرخ |
| 4. نشر محدود | سجلات بدرجة ثقة ظاهرة | مراجعة الخصوصية وحداثة السجل |
| 5. مراجعة دورية | تغييرات وحالات انتهاء | تاريخ تحقق جديد أو وسم `stale` |

## 20.2 الأدوار المطلوبة

يحتاج المسار مالك بيانات، ومراجعًا محليًا مخولًا، ومسؤول جودة بيانات. لا تتضمن الدفعة التزامًا بتطوير تطبيق معاملات أو فريق توصيل أو موازنة قبل توثيق حجم العمل وتكلفة التحقق.

## 20.3 سجل المخاطر

| الخطر | المعالجة |
|---|---|
| اعتبار المرشحات تعدادًا نهائيًا | إبقاء `public_candidate` ظاهرًا وعدم استخدامه كمؤشر سوق |
| تقادم الحالة | تاريخ تحقق إلزامي ووسم السجل المتقادم |
| نشر معلومات صحية أو تجارية حساسة | استبعاد الوصفات والمخزون والأسعار والمعاملات من النطاق |
| مصدر غير مرخص أو غامض | سجل مصدر ورخصة ومراجعة قبل الدمج |
