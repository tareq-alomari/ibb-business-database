# المرحلة الأولى: Project Discovery - قطاع الصيدليات في محافظة إب

> **التاريخ**: يوليو 2026  
> **الملف**: 01_Project_Discovery.md

---

## 1.1 تعريف المشكلة

لا توجد في الحزمة الحالية بيانات عامة كافية لإثبات عدد الصيدليات العاملة أو توافر الأدوية أو الأسعار في محافظة إب. توجد طبقة مواقع مفتوحة قابلة لاستخراج مرشحات أولية، لكن المصدر يذكر أنها غير شاملة ولا تصلح وحدها لقرارات حرجة [1]. المشكلة العملية هي بناء دليل محلي يميز بوضوح بين المرشح العام والسجل المتحقق، بدل نشر بيانات تشغيلية غير مثبتة.

## 1.2 نطاق الحل

يقترح المشروع **سجل اكتشاف وتحقق للصيدليات**. يعرض موقعًا واسمًا مرشحًا ومصدره وتاريخ مراجعته، ثم يضيف حالة التشغيل وبيانات الاتصال فقط بعد تحقق موثق. لا يتضمن نطاق النسخة الأولى مقارنة أسعار أو توافر أدوية أو نظام طلبات أو مراجعات مستخدمين.

| المستفيد | القيمة الواقعية في النسخة الأولى |
|---|---|
| السكان | نقطة بداية للاستدلال على صيدليات مرشحة مع شفافية مستوى الثقة |
| الصيدليات | مسار واضح لتصحيح السجل وتأكيد بيانات عامة قابلة للنشر |
| الجهات المحلية | قائمة مراجعة قابلة للتحديث بدل قوائم رقمية غير مؤرخة |
| الباحثون | بيانات محددة المصدر، لا تقديرات سوقية غير قابلة للتحقق |

## 1.3 أهداف الدفعة

| الهدف | مقياس النجاح | حد القبول |
|---|---|---|
| قابلية التتبع | كل سجل يتضمن مصدرًا وتاريخًا وحالة تحقق | لا سجلات بلا مصدر |
| عدم المبالغة | لا يدّعي السجل الشمول أو التشغيل من مصدر عام | جميع مرشحات OSM = `public_candidate` |
| قابلية التحديث | إعادة تشغيل الاستخراج من الأرشيف الخام | أداة ومخرجات محفوظة |
| حماية المستخدم | عدم جمع وصفات أو بيانات مرضى | لا توجد حقول صحية شخصية |

## 1.4 المخاطر والضوابط

| الخطر | الضابط |
|---|---|
| موقع أو اسم قديم أو مكرر | مطابقة مصدرين أو تحقق ميداني قبل الترقية |
| تعميم توافر الدواء أو السعر | منع هذه الحقول ما لم تكن مؤرخة ومصدرة |
| خلط المرشح بالسجل الموثق | عرض `verification_status` و`updated_at` مع كل سجل |
| بيانات صحية حساسة | عدم تخزين وصفات أو معاملات أو معلومات مرضى |
