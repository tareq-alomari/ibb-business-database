## 8.1 نطاق MVP

| المتطلب | الأولوية | ضابط البيانات |
|---|---|---|
| البحث بالاسم أو المديرية | P1 | عرض المصدر وحالة التحقق وتاريخ المراجعة |
| تصفية حالة التحقق | P1 | فصل المرشح العام عن السجل المراجع |
| صفحة سجل ومصدر | P1 | عدم عرض مخزون أو سعر أو وصفات |
| اقتراح تصحيح | P2 | يدخل قائمة مراجعة ولا ينشر تلقائيًا |
| خريطة المرشحات | P2 | تسمية صريحة بأنها بيانات غير متحققة حيث يلزم |

## 8.2 خارج النطاق الحالي

الحجز والدفع والتوصيل والمراجعات والمقارنة السعرية والاستشارات وإدارة مخزون الأدوية خارج النطاق. فهي تتطلب بيانات وقتية ومسؤوليات صحية وتجارية لا تدعمها الحزمة الحالية.

## 8.3 تدفق التحقق

```text
مصدر عام → سجل مرشح → مراجعة اسم/موقع → تحقق جهة أو ميدان → سجل قابل للنشر
                                      ↘ رفض أو دمج أو وسم stale
```
