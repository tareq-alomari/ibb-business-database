## 8.1 المتطلبات الوظيفية

### لمقدمي الخدمة

- **F9**: إدارة المخزون
- **F10**: تحديث الأسعار
- **F11**: إدارة الحجوزات
- **F12**: صرف إلكتروني
- **F13**: تقارير
- **F14**: تنبيهات نفاد

### للعملاء

- **F1**: تسجيل
- **F2**: بحث عن دواء
- **F3**: توفر الدواء
- **F4**: مقارنة أسعار
- **F5**: حجز دواء
- **F6**: استشارة
- **F7**: توصيل
- **F8**: تذكير دوائي

## 8.2 حالات الاستخدام

### UC1: البحث عن خدمة
- **الممثل**: عميل
- **الوصف**: يبحث العميل عن خدمة باستخدام الكلمات المفتاحية

### UC2: حجز خدمة
- **الممثل**: عميل
- **الوصف**: يقوم العميل بحجز خدمة من مقدم خدمة معين

### UC3: إدارة الطلبات
- **الممثل**: مزود خدمة
- **الوصف**: يستعرض مزود الخدمة الطلبات الواردة

## 8.3 تدفق البيانات

```
عميل -> تطبيق جوال/ويب -> API Gateway
  -> خدمة البحث -> قاعدة البيانات
  -> خدمة الحجز -> قاعدة البيانات
مزود -> تطبيق مزود -> API Gateway
  -> خدمة إدارة الطلبات
```
