## 18.2 تحسين الموقع (On-Page SEO)

| العنصر | التحسين |
|-------|--------|
| **العناوين** | H1 فريد لكل صفحة، H2/H3 للتقسيمات |
| **الوصف** | Meta description 150-160 حرف مع الكلمة المفتاحية
| **الروابط** | روابط داخلية بين الخدمات، Breadcrumbs |
| **الصور** | Alt tags بالعربية، ضغط الصور، WebP |
| **السرعة** | First Contentful Paint < 1.5s, LCP < 2.5s |
| **الجوال** | Mobile-first responsive design |
| **البيانات المنظمة** | Schema.org LocalBusiness لكل مزود |
