## 3.1 نموذج العمل التجاري (Business Model Canvas)

| العنصر | التفاصيل |
|--------|---------|
| **القيمة المقترحة** | منصة رقمية شاملة لـقطاع الدهان في إب |
| **الشرائح المستهدفة** | أصحاب منازل, مقاولون, شركات, مكاتب, محلات |
| **القنوات** | تطبيق جوال، موقع ويب، واتساب بوت |
| **علاقات العملاء** | دعم فني، تقييمات، تواصل مباشر |
| **مصادر الإيرادات** | اشتراكات، عمولات، إعلانات |
| **الموارد الرئيسية** | قاعدة البيانات، التطبيق، فريق الدعم |
| **الأنشطة الرئيسية** | تطوير، تسويق، إدارة محتوى |
| **الشركاء الرئيسيون** | غرفة تجارة إب، الجمعيات المحلية |
| **الهيكل التكاليفي** | تطوير، استضافة، تسويق، رواتب |

## 3.2 تحليل الإيرادات (Revenue Model)

| المصدر | الوصف | النسبة المتوقعة |
|--------|-------|----------------|
| اشتراكات مقدمي الخدمة | خطط شهرية/سنوية | 40% |
| عمولة حجوزات | نسبة من قيمة الخدمة | 30% |
| إعلانات | إعلانات داخل المنصة | 15% |
| خدمات متميزة | تحليلات، ترقية ظهور | 10% |
| شراكات | تعاون مع مؤسسات محلية | 5% |

## 3.3 تحليل التكاليف (Cost Structure)

| البند | التكلفة التقديرية الشهرية |
|-------|-------------------------|
| تطوير وصيانة | 500,000 - 1,000,000 ريال |
| استضافة وخوادم | 200,000 - 500,000 ريال |
| فريق العمل | 500,000 - 1,500,000 ريال |
| تسويق وإعلانات | 300,000 - 700,000 ريال |
| مصاريف تشغيلية | 200,000 - 400,000 ريال |

## 3.4 تحليل التعادل (Break-Even Analysis)

| المؤشر | القيمة |
|--------|-------|
| التكلفة الثابتة التقديرية | 2,000,000 ريال/شهر |
| متوسط الإيراد لكل عميل | 50,000 ريال/شهر |
| عدد العملاء لتحقيق التعادل | 40 عميلاً |
| فترة التعادل المتوقعة | 6-8 أشهر |

## 3.5 KPIs المالية

| المؤشر | الهدف |
|--------|------|
| ARPU (متوسط الإيراد لكل مستخدم) | 20,000-150,000 ريال للمشروع |
| CAC (تكلفة اكتساب العميل) | < 10,000 ريال |
| LTV (القيمة الدائمة للعميل) | > 200,000 ريال |
| معدل النمو الشهري | 15% |
| هامش الربح الإجمالي | 60%+ |
