## 9.1 متطلبات الأداء (Performance Requirements)

| المعرف | المتطلب | الهدف | طريقة القياس |
|--------|---------|-------|-------------|
| PERF1 | زمن تحميل الصفحة الرئيسية | < 1.5 ثانية | Google Lighthouse، WebPageTest |
| PERF2 | زمن تحميم المنيو | < 1 ثانية | وقت استجابة API |
| PERF3 | زمن تأكيد الطلب | < 2 ثانية | من ضغط "أرسل الطلب" إلى تأكيد المطعم |
| PERF4 | زمن تحديث حالة الطلب | < 3 ثوانٍ | WebSocket latency |
| PERF5 | معالجة 100 طلب متزامن | خطأ < 1% | اختبار تحميل (Load Testing) |
| PERF6 | استجابة البحث | < 500ms | Elasticsearch أو Full-text search |
| PERF7 | رفع الصور | < 3 ثوانٍ لصورة 1MB | تحسين الصور، CDN |

## 9.2 متطلبات التوفر (Availability Requirements)

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| AVAIL1 | uptime النظام | 99.5% (حد أقصى 3.6 ساعات توقف شهريًا) |
| AVAIL2 | وقت الاستجابة للانقطاع | < 15 دقيقة للاستجابة الأولية |
| AVAIL3 | النسخ الاحتياطي | يومي، احتفاظ بـ 30 يومًا |
| AVAIL4 | دعم الأوفلاين (PWA) | تصفح المطاعم والمنيو بدون إنترنت |
| AVAIL5 | تخزين مؤقت للطلبات | الطلب يُخزن محليًا حتى استعادة الاتصال |

## 9.3 متطلبات الأمان (Security Requirements)

| المعرف | المتطلب | التفاصيل |
|--------|---------|---------|
| SEC1 | تشفير البيانات | TLS 1.3 للاتصالات، AES-256 للتخزين |
| SEC2 | المصادقة | JWT + OTP عبر الهاتف |
| SEC3 | حماية API | Rate limiting (100 طلب/دقيقة لكل مستخدم) |
| SEC4 | حماية بيانات المستخدمين | الامتثال لقوانين الخصوصية |
| SEC5 | مكافحة الاحتيال | التحقق من الطلبات المشبوهة |
| SEC6 | صلاحيات الأدوار | RBAC (زبون، مطعم، سائق، مشرف) |

## 9.4 متطلبات الاستخدامية (Usability Requirements)

| المعرف | المتطلب | التفاصيل |
|--------|---------|---------|
| USE1 | الواجهة | عربية 100%، تدعم العامية اليمنية في البحث |
| USE2 | حجم الخط | قابل للتكبير، مناسب لكبار السن |
| USE3 | الألوان | تباين عالي، وضع النهار والليل |
| USE4 | الإشعارات | صوتية + مرئية (حتى لو التطبيق مغلق) |
| USE5 | تجربة المستخدم الجديد | < 3 خطوات لطلب أول وجبة |
| USE6 | دعم الأمية | أزرار كبيرة، أيقونات واضحة، إرشادات صوتية |

## 9.7 متطلبات قابلية التوسع (Scalability Requirements)

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| SCALE1 | عدد المستخدمين | 50,000 مستخدم نشط شهريًا (Year 1) |
