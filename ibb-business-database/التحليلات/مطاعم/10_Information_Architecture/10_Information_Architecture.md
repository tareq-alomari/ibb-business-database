## 10.2 نظام التصنيف (Taxonomy)

### تصنيف المطاعم

| المستوى الأول | المستوى الثاني | أمثلة |
|--------------|---------------|-------|
| حسب النوع | شعبي يمني | مندي، مظبي، سلته، فحسة |
| | وجبات سريعة | برجر، شاورما، بيتزا، دجاج مقلي |
| | مشاوي | كباب، أوصال، شيش طاووق |
| | سمك | سمك مشوي، روبيان |
| | عائلي | صالونات خاصة، جلسات |
| | فندقي | بوفيه، مطعم فندق |
| | أكلات عالمية | هندي، صيني، إيطالي |
| حسب السعر | اقتصادي | أقل من 1,500 ريال |
| | متوسط | 1,500 - 4,000 ريال |
| | مرتفع | 4,000 - 10,000 ريال |
| | فاخر | أكثر من 10,000 ريال |
| حسب الموقع | وسط المدينة | شارع الجيش، جولة السحول |
| | الأحياء | الربوة، النصر، حراثة |
| | المديريات | جبلة، يريم، العدين |

### تصنيف المنيو

| التصنيف | أمثلة |
|---------|-------|
| مقبلات | شوربة، سلطة، حمص |
| وجبات رئيسية | مندي، مظبي، برجر، مشاوي |
| مشروبات | عصير، بيبسي، ماء |
| حلويات | بانت الصحن، كريم كراميل، كنافة |

## 10.3 نظام التصفح والبحث

| الميزة | الوصف |
|--------|-------|
| **البحث الرئيسي** | بحث نصي حر (اسم مطعم، اسم أكلة) |
| **فلترة** | نوع المطعم، الموقع، السعر، التقييم، مفتوح الآن |
| **ترتيب** | الأقرب إليك، الأعلى تقييمًا، الأكثر طلبًا، الأحدث |
| **خريطة تفاعلية** | عرض المطاعم على الخريطة مع تفاصيل |

## 10.4 User Flow الرئيسي

### تدفق طلب الطعام

```
فتح التطبيق → الصفحة الرئيسية
    → بحث / تصفح → اختيار مطعم
    → عرض المنيو → إضافة إلى السلة
    → عرض السلة → تأكيد العنوان
    → اختيار الدفع → إرسال الطلب
    → شاشة التتبع ← اشعارات التحديث
    → استلام الطلب → تقييم المطعم
```

### تدفق تسجيل مطعم جديد

```
تسجيل الدخول → إنشاء حساب المطعم
    → إضافة بيانات المطعم (اسم، موقع، نوع، صورة)
    → إضافة المنيو (تصنيفات + أصناف)
    → تحديد مناطق التوصيل
    → تفعيل الحساب (مراجعة من الإدارة)
    → استقبال الطلبات
```

## 10.5 Sitemap للتطبيق

```
/                           ← الصفحة الرئيسية
/restaurants                ← قائمة المطاعم
/restaurants/:id            ← صفحة مطعم
/restaurants/:id/menu       ← قائمة طعام
/restaurants/:id/reviews    ← تقييمات
/cart                       ← سلة الطلبات
/checkout                   ← إتمام الطلب
/orders                     ← سجل الطلبات
/orders/:id                 ← تتبع طلب
/favorites                  ← المفضلة
/offers                     ← العروض
/profile                    ← الملف الشخصي
/profile/addresses          ← العناوين
/profile/payment            ← طرق الدفع
/notifications              ← الإشعارات
```

### لوحة تحكم المطعم

```
/restaurant/dashboard       ← لوحة الإحصائيات
/restaurant/menu            ← إدارة المنيو
/restaurant/menu/add        ← إضافة صنف
/restaurant/orders          ← إدارة الطلبات
/restaurant/offers          ← العروض
/restaurant/reports         ← التقارير
/restaurant/drivers         ← إدارة السائقين
/restaurant/settings        ← الإعدادات
```

### Admin Panel

```
/admin/dashboard            ← لوحة الإحصائيات
/admin/restaurants          ← قائمة المطاعم
/admin/users                ← المستخدمون
/admin/drivers              ← السائقون
/admin/reports              ← تقارير شاملة
/admin/content              ← مراجعة المحتوى
/admin/ads                  ← الإعلانات
```
