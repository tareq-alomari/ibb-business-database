## 5.1 التحليل التنافسي للمنصة (أي منصة مطاعم مقترحة)

### المنافسون المباشرون

| المنافس | الوصف | نقاط القوة | نقاط الضعف |
|---------|-------|-----------|------------|
| **تطبيق كركس (Kraaz)** | منصة توصيل طلبات يمنية | تواجد في عدن وصنعاء، تقنية جاهزة | غير نشط في إب، تركيز على مدن محدودة |
| **تطبيق طلبات (Talabat)** | منصة توصيل إقليمية | علامة تجارية قوية، استثمار كبير | لا تغطي اليمن أساسًا |
| **مجموعات فيسبوك** | "مطاعم إب" وغيرها | مجتمع نشط، تفاعل عالي | غير منظمة، معلومات مبعثرة، لا توصيل |
| **واتساب بزنس للمطاعم** | تواصل مباشر مع الزبائن | بسيط، مباشر | محدودية، لا منيو مرئي، لا بحث |

### المنافسون غير المباشرين

| المنافس | الوصف |
|---------|-------|
| **Google Maps + Search** | البحث عن مطاعم عبر جوجل - مجاني لكن بياناته غير كاملة |
| **الإعلانات في الجرائد المحلية** | وسيلة تقليدية، جمهور محدود |
| **التوصيل المباشر من المطعم** | الزبون يتصل بالمطعم مباشرة - مستخدم حاليًا |

## 5.2 تحليل SWOT للمنصة مقابل المنافسين

| | الفرصة |
|---|--------|
| **S (القوة)** | - تركيز حصري على إب (سوق متخصص)<br>- فهم عميق للسياق المحلي والعادات الغذائية<br>- دعم المجتمع المحلي والغرفة التجارية<br>- دعم اللغة العربية الفصحى والعامية اليمنية |
| **W (الضعف)** | - تقنية محدودة مقارنة بالمنافسين الإقليميين<br>- ميزانية أصغر<br>- فريق أصغر<br>- لا علامة تجارية معروفة مسبقًا |
| **O (الفرص)** | - لا منافس محلي في إب حاليًا<br>- طلب متزايد على التوصيل الرقمي<br>- شراكات محلية قوية محتملة<br>- إمكانية التوسع لقطاعات أخرى (السياحة، الخدمات) |
| **T (التهديدات)** | - دخول كركس لإب مستقبلًا<br>- ظهور منافس محلي آخر<br>- تغير العادات الاستهلاكية |

## 5.3 Competitive Advantage (الميزة التنافسية)

| الميزة | التفاصيل |
|--------|----------|
| **محلية كاملة** | منصة مخصصة لمحافظة إب فقط - تفهم التفاصيل المحلية |
| **محتوى شامل** | أكثر من مجرد توصيل - دليل كامل مع تقييمات ومنيو وصور |
| **مجانية للمطاعم (basic)** | نموذج Freemium يشجع التسجيل السريع |
| **دعم المجتمع** | شراكة مع غرفة تجارة إب والجهات المحلية |
| **ميزات غير متوفرة** | برنامج ولاء، عروض ذكية، تقارير للمطاعم |

## 5.4 تحليل المطاعم المنافسة فيما بينها

### أكثر 10 مطاعم تنافسية في إب (بناءً على السمعة)

| المطعم | نقاط القوة | نقاط الضعف | استراتيجية التميز |
|--------|-----------|------------|-------------------|
| المندي الملكي | سمعة قوية، جودة عالية | أسعار مرتفعة قليلاً | الجودة والثبات |
| كينجز برجر | برجر ممتاز، شريحة شبابية | قائمة محدودة | التخصص |
| مطعم الأصيل | أكل يمني أصيل، زبائن أوفياء | لا توصيل منظم | الأصالة |
| شاورما العرب | خبرة طويلة، سعر مناسب | ديكور قديم | السعر والسرعة |
| مطعم الأندلس | مشاوي ممتازة، جلسات جميلة | موقع غير مركزي | الجودة |
| فندق إب الدولي | فخامة، خدمة راقية | أسعار عالية جدًا | الفخامة |
| مطعم السمك السلطاني | سمك طازج، تخصص | بعيد عن المركز | التخصص النادر |
| بيتزا هت إب | علامة تجارية، بيتزا جيدة | أسعار مرتفعة | العلامة التجارية |
| مطعم الجنة | جلسات عائلية، خصوصية | قائمة محدودة | العائلات |
| مطعم الفيحاء (جبلة) | موقع استراتيجي في جبلة | لا توصيل | الموقع |

## 5.5 استراتيجية المنافسة للمنصة المقترحة

| الاستراتيجية | التطبيق |
|--------------|---------|
| **First Mover Advantage** | الدخول أولاً في سوق إب قبل أي منصة أخرى |
| **Local Focus** | التركيز على إب فقط وتقديم خدمة مخصصة |
| **Free Basic Listing** | تسجيل المطعم مجانًا مع منيو أساسي |
| **التوسع التدريجي** | البدء بمدينة إب ثم التوسع للمديريات |
| **User Generated Content** | تشجيع الزبائن على إضافة تقييمات وصور |
| **الشراكات المحلية** | التعاون مع غرفة التجارة والمطاعم الكبرى |
