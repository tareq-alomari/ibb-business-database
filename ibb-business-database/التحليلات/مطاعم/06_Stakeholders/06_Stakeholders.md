## 6.1 قائمة الجهات المعنية (Stakeholders)

### أ. الجهات الأساسية (Primary Stakeholders)

| الجهة | الوصف | الدور في المشروع | مستوى التأثير | مستوى الاهتمام |
|-------|-------|------------------|--------------|---------------|
| **زبائن المطاعم** | سكان إب من مختلف الفئات | المستخدمون النهائيون للمنصة | عالي | عالي |
| **أصحاب المطاعم** | 500+ مطعم في المحافظة | مزودو الخدمة، شركاء المنصة | عالي | عالي |
| **سائقو التوصيل** | عمال توصيل الطعام | مزودو خدمة التوصيل | متوسط | عالي |

### ب. الجهات الداعمة (Secondary Stakeholders)

| الجهة | الوصف | الدور | مستوى التأثير |
|-------|-------|-------|--------------|
| **غرفة تجارة وصناعة إب** | دعم تجاري، تسهيلات | شريك استراتيجي | عالي |
| **مكتب الصناعة والتجارة - إب** | تراخيص، تنظيم | جهة تنظيمية | متوسط |
| **مكتب السياحة - إب** | تراخيص سياحية للمطاعم | جهة تنظيمية | منخفض |
| **مكتب الصحة - إب** | رقابة صحية على المطاعم | جهة تنظيمية | متوسط |
| **السلطة المحلية في إب** | المحافظ، المجلس المحلي | دعم سياسي | متوسط |
| **وزارة الاتصالات** | تنظيم الإنترنت والاتصالات | بيئة تشغيل | منخفض |

### ج. الجهات المساندة (Tertiary Stakeholders)

| الجهة | الوصف | الدور |
|-------|-------|-------|
| **شركات الدفع الإلكتروني** | باي موب، MTN Money | تكامل الدفع |
| **مزودو خدمة الإنترنت** | يمن نت، MTN، سبأفون | البنية التحتية |
| **شركات الإعلان المحلية** | وكالات إعلان، مطابع | إعلانات ورقية ورقمية |

| **الجامعات المحلية** | جامعة إب، جامعة جبلة | دعم بحثي، تدريب طلاب |
| **المستثمرون المحليون** | رجال أعمال في إب | تمويل واستثمار |
| **الجمعيات الخيرية** | دعم فئات محدودة الدخل | شراكات مجتمعية |

## 6.2 تحليل المصلحة والتأثير (Power-Interest Grid)

```
تأثير عالي
    │
    │   أبقي راضيًا              │   أدر بإحكام
    │   (Keep Satisfied)         │   (Manage Closely)
    │                            │
    │   • غرفة تجارة إب          │   • زبائن المطاعم
    │   • مكتب الصناعة           │   • أصحاب المطاعم
    │   • السلطة المحلية         │   • سائقو التوصيل
    │                            │
────┼────────────────────────────┼─────
    │                            │
    │   راقب (Monitor)           │   أبق على اطلاع
    │                            │   (Keep Informed)
    │   • شركات الدفع            │   • وسائل الإعلام
    │   • مزودو الإنترنت         │   • الجامعات
    │   • الجمعيات الخيرية       │   • المستثمرون
    │                            │
    │                            │
    │                    مصلحة عالي
```

## 6.3 استراتيجية التواصل مع كل جهة

| الجهة | قناة التواصل | التكرار | المحتوى |
|-------|-------------|---------|---------|
| **زبائن المطاعم** | إشعارات التطبيق، واتساب، فيسبوك | يومي | عروض، مطاعم جديدة، تقييمات |
| **أصاحب المطاعم** | اتصال مباشر، واتساب بزنس، لقاءات | أسبوعي | تحديثات، إحصائيات، دعم فني |
| **سائقو التوصيل** | تطبيق السائقين، واتساب | يومي | طلبات، جداول، أرباح |
| **غرفة تجارة إب** | اجتماعات شهرية، تقارير رسمية | شهري | تقدم المشروع، إحصائيات، شراكات |
| **مكتب الصناعة** | خطاب رسمي، اجتماع | ربع سنوي | تراخيص، التزام بالقوانين |
| **مكتب الصحة** | تنسيق مشترك | نصف سنوي | تصنيف صحي للمطاعم |
| **وسائل الإعلام** | بيانات صحفية، مقابلات | شهري | أخبار المنصة، إنجازات |

## 6.4 متطلبات كل جهة من المنصة

| الجهة | المتطلبات الرئيسية |
|-------|-------------------|
| **الزبائن** | سهولة الاستخدام، معلومات دقيقة، توصيل سريع، أسعار محدثة |
| **أصحاب المطاعم** | وصول لزبائن جدد، تقارير مبيعات، إدارة سهلة للمنيو، عروض |
| **سائقو التوصيل** | طلبات كافية، جدول مرن، أرباح عادلة، دعم فني |
| **غرفة تجارة إب** | إحصائيات القطاع، مساهمة في التنمية المحلية |
| **مكتب الصناعة** | التزام بالتراخيص واللوائح |
| **مكتب الصحة** | معايير صحية، تصنيف صحي للمطاعم |

## 6.5 إدارة التوقعات (Expectation Management)

| التوقع | الجهة | كيفية الإدارة |
|--------|-------|--------------|
| "التطبيق سيحل جميع مشاكلنا" | أصحاب المطاعم | توضيح أن المنصة أداة مساعدة وليست حلًا سحريًا |
| "التوصيل مجاني دائمًا" | الزبائن | توضيح سياسة التوصيل، عروض توصيل مجاني محدودة |
| "سنحصل على آلاف الطلبات فورًا" | المطاعم الجديدة | شرح مرحلة بناء الجمهور، نمو تدريجي |
| "البيانات ستكون فورية ودقيقة دائمًا" | جميع الجهات | توضيح أن التحديث يعتمد على المطاعم أيضًا |
