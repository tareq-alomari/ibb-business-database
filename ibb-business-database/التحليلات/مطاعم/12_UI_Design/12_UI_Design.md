## 12.4 Responsive Design

| الجهاز | الشاشة | التصميم |
|--------|--------|---------|
| **هاتف** | < 768px | عمودي، بطاقات كاملة العرض |
| **تابلت** | 768-1024px | شبكة من عمودين |
| **ويب** | > 1024px | شبكة 3-4 أعمدة، شريط جانبي |

## 12.6 رحلة تطوير UI

| المرحلة | المخرجات | الوقت التقديري |
|---------|---------|---------------|
| 1. Mood Board | لوحة إلهام بالألوان والأنماط | 2 يوم |
| 2. Design System | دليل الألوان، الخطوط، المكونات | 3 أيام |
| 3. Low-fi Wireframes | رسومات تخطيطية لكل شاشة | 3 أيام |
| 4. Hi-fi Mockups | تصميم كامل لكل شاشة (Figma) | 7 أيام |
| 5. Prototype | نموذج تفاعلي (Figma) | 3 أيام |
| 6. User Testing | اختبار مع 5-10 مستخدمين | 3 أيام |
| 7. Iterations | تحسينات بناءً على الملاحظات | 3 أيام |
| 8. Handoff | تسليم للمطورين (تصاميم + assets) | 2 يوم |
