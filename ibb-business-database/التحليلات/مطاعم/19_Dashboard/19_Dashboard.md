## 19.4 تقنيات بناء لوحات التحكم

| المكون | التقنية |
|--------|---------|
| **UI Framework** | React + Material UI / Tailwind |
| **الرسوم البيانية** | Chart.js / Recharts / ApexCharts |
| **الجداول** | AG Grid / React Table |
| **التقارير المباشرة** | WebSocket + Real-time charts |
| **التصدير** | CSV, PDF (jsPDF + html2canvas) |
| **تصميم متجاوب** | Mobile-first, يدعم الأجهزة اللوحية |
| **RTL** | دعم كامل للغة العربية (RTL) |

## 19.5 مؤشرات الأداء في لوحات التحكم (Dashboard KPIs)

### للمطعم
| المؤشر | الوصف |
|--------|-------|
| الطلبات اليومية | عدد الطلبات المستلمة |
| الإيرادات | إجمالي المبيعات |
| متوسط قيمة الطلب | إجمالي المبيعات / عدد الطلبات |
| معدل التحويل | الطلبات المكتملة / الإجمالية |
| أكثر الأصناف طلبًا | Top 5 أصناف |
| وقت التحضير المتوسط | من استلام الطلب إلى تجهيزه |

### للإدارة
| المؤشر | الوصف |
|--------|-------|
| إجمالي المطاعم المسجلة | نشطة، معلقة، موقوفة |
| إجمالي المستخدمين | زبائن، مطاعم، سائقين |
| إجمالي الطلبات | يومي، أسبوعي، شهري |
| إجمالي الإيرادات | من العمولات والإعلانات |
| معدل نمو المستخدمين | شهريًا |
| المطاعم الأكثر نشاطًا | Top 10 |
