## 11.1 مبادئ تجربة المستخدم

| المبدأ | التطبيق في المشروع |
|--------|-------------------|
| **البساطة** | أقل عدد من الخطوات للطلب (3 خطوات كحد أقصى) |
| **السرعة** | تحميل سريع حتى على شبكات 3G، أوفلاين للمنيو |
| **الوضوح** | أيقونات عربية واضحة، نصوص كبيرة، تباين عال |
| **الثقة** | تقييمات حقيقية، صور حقيقية، معلومات دقيقة |
| **التخصيص** | توصيات حسب الطلبات السابقة، المطاعم القريبة |
| **إمكانية الوصول** | دعم ضعاف البصر، خط قابل للتكبير |

## 11.2 User Flows التفصيلية

### تدفق طلب الطعام (تفصيلي)

```
[الصفحة الرئيسية]
    │
    ├── [بحث] ── يكتب اسم مطعم أو أكلة ── [نتائج البحث] ── اختيار مطعم
    │
    ├── [تصنيفات] ── يختار نوع ── [قائمة مصفاة] ── اختيار مطعم
    │
    └── [قريبة مني] ── [قائمة المطاعم القريبة] ── اختيار مطعم
            │
            ▼
    [صفحة المطعم]
        │
        ├── [عرض المنيو] ── يتصفح الأصناف ── [يضيف صنفًا إلى السلة]
        │                         │
        │                         └── يعدل الكمية (1, 2, 3...)
        │
        ├── [عرض التقييمات] ── يقرأ مراجعات الآخرين
        │
        └── [عرض العروض] ── يرى العروض الحالية للمطعم
                │
                ▼
        [السلة]
            │
            ├── [تأكيد الأصناف والكميات]
            │
            ├── [اختيار عنوان التوصيل] ─── جديد؟ ← [إضافة عنوان جديد]
            │
            ├── [اختيار طريقة الدفع] ─── نقدي / إلكتروني
            │
            └── [إرسال الطلب]
                    │
                    ▼
            [تأكيد الطلب] ← إشعار "تم استلام الطلب"
                    │
                    ▼
            [شاشة التتبع]
                │
                ├── 1. قيد الانتظار (المطعم لم يؤكد بعد)
                ├── 2. قيد التحضير (المطعم يجهز الطلب)
                ├── 3. في الطريق (السائق في طريقه إليك)
                └── 4. تم التوصيل (استلمت طلبك)
                        │
                        ▼
                [تقييم التجربة] ── نجوم + تعليق + صور
```

## 11.4 أنماط التفاعل (Interaction Patterns)

| النمط | الوصف |
|-------|-------|
| **Swipe لإزالة** | إزالة صنف من السلة |
| **Long press** | عرض تفاصيل الصنف |
| **Pull to refresh** | تحديث المنيو والطلبات |
| **Infinite scroll** | تصفح لا نهائي للمطاعم |
| **Bottom sheet** | عرض خيارات إضافية |
| **Snackbar** | إشعارات غير مزعجة |
| **Push notifications** | تحديثات حالة الطلب |

## 11.5 إدارة الأخطاء والحالات الاستثنائية

| الحالة | التصميم المقترح |
|--------|----------------|
| **لا يوجد إنترنت** | عرض رسالة "لا يوجد اتصال بالإنترنت" مع المنيو المخزن محليًا |
| **مطعم مغلق** | عرض "المطعم مغلق حاليًا، يفتح الساعة 4 م" |
| **منطقة خارج التوصيل** | "عذرًا، هذا المطعم لا يوصل إلى منطقتك" |
| **الطلب فشل** | "حدث خطأ في إرسال الطلب، حاول مرة أخرى" مع زر إعادة المحاولة |
| **سلة فارغة** | "سلة التسوق فارغة، تصفح المطاعم..." مع زر للتصفح |
| **لا نتائج بحث** | "لا توجد نتائج بحث مطابقة، جرب كلمات أخرى" |
| **حساب غير مفعل** | "الرجاء تفعيل حسابك عبر الرقم المرسل إلى هاتفك" |

## 11.6 قياس تجربة المستخدم (UX Metrics)

| المقياس | الهدف | طريقة القياس |
|---------|-------|-------------|
| **وقت إتمام أول طلب** | < 3 دقائق | تحليلات التطبيق |
| **معدل نجاح الطلب** | 95%+ | عدد الطلبات المكتملة / عدد الطلبات المبدوءة |
| **معدل التخلي عن السلة** | < 20% | عدد السلات المتروكة |
| **معدل الاحتفاظ** | 40%+ بعد 30 يومًا | تحليلات المستخدمين |
| **NPS (Net Promoter Score)** | 40+ | استبيان داخل التطبيق |
| **وقت تحميل الشاشة** | < 2 ثانية | Google Analytics |
