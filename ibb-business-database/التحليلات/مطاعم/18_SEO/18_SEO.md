## 18.1 استراتيجية SEO

### أ. SEO محلي (Local SEO) - الأهمية القصوى

| العنصر | الاستراتيجية |
|--------|-------------|
| **Google My Business** | إنشاء حساب لكل مطعم وتوثيقه |
| **Google Maps** | تسجيل المطاعم على الخريطة مع بيانات دقيقة (اسم، موقع، هاتف، ساعات عمل) |
| **Apple Maps** | تسجيل المطاعم على Apple Maps |
| **المراجعات** | تشجيع الزبائن على ترك مراجعات على Google |
| **الكلمات المفتاحية المحلية** | "مطعم في إب"، "أفضل مطعم في إب"، "مندي إب"، "برجر إب" |

### ب. SEO للموقع (PWA/Website)

| العنصر | الاستراتيجية |
|--------|-------------|
| **الكلمات المفتاحية** | بحث عن مصطلحات البحث المحلية في إب |
| **العناوين (Title Tags)** | "أفضل مطاعم إب - دليل مطاعم محافظة إب" |
| **الوصف (Meta Description)** | "دليلك الشامل لمطاعم إب... قوائم طعام، أسعار، تقييمات، توصيل" |
| **العناوين (H1, H2)** | استخدام الكلمات المفتاحية في العناوين |
| **الروابط الداخلية** | ربط المطاعم المتشابهة، الصفحات ذات الصلة |
| **الصور** | Alt text وصفي للصور، ضغط الصور (WebP) |
| **السرعة** | تحسين Core Web Vitals (LCP < 2.5s, FID < 100ms, CLS < 0.1) |
| **البيانات المنظمة (Schema)** | Schema.org للمطاعم (Restaurant, Menu, Review) |

  "image": "https://...",

  "servesCuisine": ["مشاوي", "مأكولات يمنية"],

    "@type": "PostalAddress",
    "streetAddress": "شارع الجيش",
    "addressLocality": "إب",
    "addressRegion": "محافظة إب",
    "addressCountry": "YE"
  },
  "aggregateRating": {
    "@type": "AggregateRating",

## 18.4 استراتيجية المحتوى (Content Strategy)

| نوع المحتوى | التكرار | المثال |
|-------------|---------|--------|
| **صفحات المطاعم** | لكل مطعم | صفحة مطعم مع منيو، صور، تقييمات |
| **المدونة** | شهريًا | "أفضل 10 مطاعم مشاوي في إب" |
| **المقالات الموسمية** | موسميًا | "أفضل مطاعم إب في الصيف" |
| **قوائم وتصنيفات** | شهريًا | "أفضل 5 مطاعم برجر في إب" |
| **فيديوهات** | أسبوعيًا | جولات في المطاعم، مقابلات مع الطهاة |

## 18.5 بناء الروابط (Link Building)

| الاستراتيجية | الوصف |
|-------------|-------|
| **الدلائل المحلية** | التسجيل في دلائل الأعمال اليمنية |
| **الشراكات المحلية** | روابط من غرفة تجارة إب، مواقع محلية |
| **وسائل التواصل الاجتماعي** | فيسبوك، تيك توك، يوتيوب - كلها ترتبط بالموقع |
| **المقالات الضيفية** | كتابة مقالات عن المطاعم في مواقع إخبارية محلية |
| **التقييمات** | صفحات المطاعم على Google My Business |
| **الإشارات المحلية** | ذكر المطعم في منتديات ومجموعات إب |

## 18.6 تحسين أداء الموقع (Technical SEO)

| العنصر | الهدف | الطريقة |
|--------|-------|---------|
| **السرعة** | LCP < 2.5s | Server-side rendering (Next.js) |
| **الصور** | WebP + Lazy loading | تحويل الصور إلى WebP، تحميل بطيء |
| **التخزين المؤقت** | التحميل الفوري للصفحات المتكررة | CDN + Service Worker (PWA) |
| **الهاتف أولاً** | محتوى متجاوب بالكامل | تصميم Mobile-first |
| **Sitemap** | إرسال XML sitemap لجوجل | إنشاء sitemap ديناميكي لجميع المطاعم |
| **robots.txt** | التحكم في فهرسة المحتوى | منع فهرسة الصفحات الداخلية |
| **SSL** | HTTPS إجباري | Cloudflare SSL |

## 18.7 مراقبة وتحليل SEO
