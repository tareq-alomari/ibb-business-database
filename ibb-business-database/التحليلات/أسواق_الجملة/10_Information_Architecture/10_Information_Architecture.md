# المرحلة العاشرة: Information Architecture - قطاع أسواق الجملة في محافظة إب

## 10.1 هيكل المعلومات

```
منصة أسواق الجملة
├── الرئيسية
│   ├── بحث عن منتج/تاجر
│   ├── قائمة الأسعار اليومية
│   ├── المنتجات الأكثر طلبًا
│   └── آخر العروض والتخفيضات
├── المنتجات
│   ├── تصنيف المنتجات (خضار، فواكه، حبوب، مواد غذائية، دواجن، لحوم)
│   ├── صفحة كل منتج (السعر، الكمية، التاجر)
│   └── مقارنة أسعار المنتج بين التجار
├── التجار
│   ├── قائمة تجار الجملة
│   ├── صفحة كل تاجر (منتجاته، تقييماته)
│   └── متجر التاجر (جميع منتجاته)
├── الطلبات
│   ├── إنشاء طلب جديد
│   ├── سلة المشتريات
│   ├── متابعة حالة الطلب
│   └── سجل الطلبات السابقة
├── التوصيل
│   ├── تتبع الشحنة
│   ├── جداول التوصيل
│   └── تقييم خدمة التوصيل
└── الملف الشخصي
    ├── بياناتي
    ├── محفظتي (للدفع الإلكتروني)
    ├── طلباتي
    └── إعداداتي
```

## 10.2 نظام التصنيف

| التصنيف | المستوى الثاني | أمثلة |
|---------|---------------|-------|
| حسب النوع | خضار وفواكه | طماطم، خيار، بصل، موز |
| | حبوب وبقوليات | أرز، قمح، عدس، فول |
| | مواد غذائية | سكر، زيت، معلبات، مكرونة |
| | دواجن وبيض | دجاج مجمد، بيض، أعلاف |
| | لحوم | لحم بقري، لحم غنم |
| حسب المصدر | محلي | خضار إب، فواكه موسمية |
| | مستورد | أرز هندي، زيت نباتي |

## 10.3 Sitemap

```
/                         ← الرئيسية
/products                 ← المنتجات
/products/:id             ← صفحة منتج
/traders                  ← قائمة التجار
/traders/:id              ← صفحة تاجر
/orders                   ← الطلبات
/orders/new               ← طلب جديد
/orders/:id               ← تفاصيل طلب
/delivery                 ← التوصيل
/delivery/:id             ← تتبع شحنة
/profile                  ← الملف الشخصي
/prices/daily             ← أسعار اليوم
```
