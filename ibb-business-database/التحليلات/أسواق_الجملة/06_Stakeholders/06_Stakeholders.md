# المرحلة السادسة: Stakeholders - قطاع أسواق الجملة في محافظة إب

## 6.1 الجهات المعنية

| الجهة | الدور | مستوى التأثير |
|-------|-------|--------------|
| تجار الجملة | مزودو المنتجات والمستخدمون الأساسيون | عالي |
| تجار التجزئة (محلات وبقالات) | المشترون الأساسيون | عالي |
| الموردون والمستوردون | مصدر السلع المستوردة | عالي |
| المزارعون المحليون | مصدر الخضار والفواكه الطازجة | متوسط |
| غرفة تجارة وصناعة إب | جهة تنظيمية وداعمة | عالي |
| مكتب الصناعة والتجارة | جهة رقابية وتراخيص | متوسط |
| شركات النقل والتوصيل | خدمة لوجستية | متوسط |
| البنوك وشركات التمويل | تمويل التجار | منخفض |

## 6.2 تحليل المصلحة والتأثير

```
تأثير عالي
    │
    │  مكتب الصناعة    │  تجار الجملة
    │  غرفة التجارة    │  تجار التجزئة
    │                   │
────┼───────────────────┼─────
    │                   │
    │  شركات النقل      │  المزارعون
    │  البنوك           │  الموردون
    │                   │
    │             مصلحة عالي
```

## 6.3 استراتيجية التواصل مع الجهات

| الجهة | قناة التواصل | التكرار |
|-------|-------------|---------|
| تجار الجملة | لقاءات مباشرة، مجموعات واتساب | أسبوعيًا |
| غرفة التجارة | اجتماعات رسمية | شهريًا |
| مكتب الصناعة | خطابات رسمية | ربع سنويًا |
| شركات النقل | عقود شراكة | عند التأسيس |
