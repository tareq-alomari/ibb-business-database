# المرحلة السابعة عشرة: Security - قطاع أسواق الجملة في محافظة إب

## 17.1 المخاطر الأمنية

| الخطر | الاحتمالية | التأثير | مستوى الخطورة |
|-------|-----------|---------|--------------|
| تسرب بيانات التجار والطلبات | منخفضة | عالي جدًا | عال |
| اختراق حسابات التجار | متوسطة | عالي | عال |
| احتيال في الطلبات (طلبات وهمية) | عالية | متوسط | عال |
| هجمات DDoS | متوسطة | متوسط | متوسط |
| سرقة صور المنتجات | عالية | منخفض | منخفض |

## 17.2 إجراءات الأمان

| الإجراء | التفاصيل |
|---------|---------|
| تشفير TLS 1.3 | جميع الاتصالات بين التطبيق والخادم |
| OTP Authentication | التحقق برقم الهاتف لكل جلسة |
| JWT Tokens | توكنات قصيرة المدى (30 دقيقة) |
| RBAC | أدوار: تاجر جملة، تاجر تجزئة، سائق، مشرف |
| Rate Limiting | 100 طلب/دقيقة لكل مستخدم |
| تشفير敏感 البيانات | AES-256 للبيانات الحساسة |

## 17.3 قائمة التحقق الأمني

- [ ] HTTPS إجباري لجميع الصفحات والنقاط
- [ ] مصادقة ثنائية (OTP) لتسجيل الدخول
- [ ] التحقق من أرقام الهواتف (توثيق التجار)
- [ ] سجل تدقيق لجميع العمليات المالية
- [ ] حماية من SQL Injection (Prisma ORM)
- [ ] حماية من XSS (تعقيم المدخلات)
- [ ] حماية من CSRF (توكنات)
- [ ] نسخ احتياطي يومي مشفر
- [ ] مراقبة النشاط المشبوه (تسجيل دخول غير معتاد)
- [ ] سياسة الخصوصية وشروط الاستخدام
