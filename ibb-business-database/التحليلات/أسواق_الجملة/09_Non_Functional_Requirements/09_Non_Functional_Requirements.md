# المرحلة التاسعة: Non-Functional Requirements - قطاع أسواق الجملة في محافظة إب

## 9.1 متطلبات الأداء

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| PERF1 | تحميل قائمة المنتجات | < 2 ثانية |
| PERF2 | نتائج البحث عن منتج | < 1 ثانية |
| PERF3 | تقديم طلب شراء | < 3 ثوانٍ |
| PERF4 | معالجة 1000 طلب متزامن | خطأ < 1% |
| PERF5 | تحديث الأسعار بشكل فوري | < 0.5 ثانية |

## 9.2 متطلبات التوفر

| المعرف | المتطلب | الهدف |
|--------|---------|-------|
| AVAIL1 | uptime | 99.5% |
| AVAIL2 | نسخ احتياطي يومي للبيانات | آمن |
| AVAIL3 | دعم الأوفلاين لعرض آخر الأسعار | تصفح بدون إنترنت |
| AVAIL4 | استرجاع البيانات بعد انقطاع | خلال 1 ساعة |

## 9.3 متطلبات الأمان

| المعرف | المتطلب |
|--------|---------|
| SEC1 | تشفير البيانات TLS 1.3 |
| SEC2 | مصادقة OTP للتحقق من رقم الهاتف |
| SEC3 | RBAC (تاجر جملة، تاجر تجزئة، سائق، مشرف) |
| SEC4 | حماية بيانات العملاء والمعاملات المالية |
| SEC5 | سجل تدقيق لجميع العمليات |

## 9.4 متطلبات الاستخدامية

| المعرف | المتطلب |
|--------|---------|
| USE1 | واجهة عربية 100% |
| USE2 | متجاوب مع الهواتف الذاتية (أندرويد أساسيًا) |
| USE3 | واجهة بسيطة تناسب التجار ذوي الخبرة الرقمية المحدودة |
| USE4 | دعم الصوت لكتابة اسم المنتج (اختياري) |
| USE5 | دعم الإشعارات الفورية للطلبات والعروض |
