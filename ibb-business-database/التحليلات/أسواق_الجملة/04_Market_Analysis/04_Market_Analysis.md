# المرحلة الرابعة: Market Analysis - قطاع أسواق الجملة في محافظة إب

## 4.1 Market Size

| المؤشر | القيمة |
|--------|--------|
| عدد سكان المحافظة | ~3 مليون نسمة |
| عدد الأسر | ~400,000 أسرة |
| الإنفاق الشهري على الغذاء لكل أسرة | ~120,000 ريال |
| إجمالي سوق المواد الغذائية شهريًا | ~48 مليار ريال |
| حصة تجارة الجملة من السوق | ~35% (16.8 مليار ريال/شهر) |
| النمو السنوي المقدر | 5-8% |

## 4.2 Target Segments

| الشريحة | الحجم | الاحتياج |
|---------|-------|---------|
| تجار جملة (مواد غذائية) | ~450 تاجر | منصة عرض منتجات، إدارة مخزون |
| تجار جملة (خضار وفواكه) | ~250 تاجر | أسعار حية، توصيل سريع |
| تجار جملة (دواجن ولحوم) | ~150 تاجر | تبريد، نقل مبرد |
| محلات تجزئة (بقالات) | ~3,000 محل | طلب جملة، مقارنة أسعار |
| محلات تجزئة (خضار) | ~1,500 محل | شراء يومي، توصيل |

## 4.3 Opportunities

| الفرصة | الوصف |
|--------|-------|
| منصة B2B للأسواق | لا يوجد حل رقمي مماثل في إب |
| خدمة التوصيل للبقالات | شبكة توزيع تغطي جميع المديريات |
| تمويل تجار الجملة | شراكة مع بنوك وشركات تمويل |
| تحليل الأسعار والتنبؤ | بيانات تفيد التجار وصناع القرار |

## 4.4 Threats

| التهديد | التحليل |
|---------|---------|
| تدهور العملة | يرفع أسعار السلع المستوردة ويقلص الطلب |
| انقطاع الكهرباء | يؤثر على التبريد وحفظ المواد الغذائية |
| عدم الاستقرار الأمني | يعطل سلاسل التوريد والإمداد |
| المنافسة غير الرسمية | الباعة الجائلون وأسواق الشارع |
