# المرحلة العشرون: Project Planning - قطاع أسواق الجملة في محافظة إب

## 20.1 خطة المشروع

| العنصر | القيمة |
|--------|--------|
| المدة الإجمالية | 6 أشهر (MVP في 3 أشهر) |
| الفريق | 4-5 أشخاص |
| الميزانية التقديرية (MVP) | $15,000 - $25,000 |
| الجمهور المستهدف الأولي | تجار الجملة في مدينة إب |

## 20.2 المراحل

| المرحلة | المدة | المخرجات |
|---------|-------|---------|
| التخطيط والبحث | 3 أسابيع | PRD، Wireframes، دراسات الجدوى |
| التصميم (UI/UX) | 4 أسابيع | Design System، شاشات التطبيق |
| التطوير (MVP) | 10 أسابيع | API + تطبيق أندرويد + PWA |
| الاختبار التجريبي | 4 أسابيع | Beta مع 20 تاجر جملة + 50 بقالة |
| الإطلاق | 3 أسابيع | Launch رسمي + حملة تسويقية |
| التطوير الإضافي | 6 أسابيع | توصيل، محفظة رقمية، تحليلات |

## 20.3 الفريق

| الدور | العدد | الوصف |
|-------|-------|-------|
| مدير مشروع | 1 | إدارة المهام، التواصل مع الجهات |
| مطور Backend | 1-2 | Node.js API، PostgreSQL، Redis |
| مطور Frontend/Mobile | 1-2 | Flutter (أندرويد)، React (PWA) |
| مصمم UI/UX | 1 | واجهات التطبيق، تجربة المستخدم |
| مسوق رقمي | 1 (مؤقت) | تسويق للتجار، حملات إعلانية |
