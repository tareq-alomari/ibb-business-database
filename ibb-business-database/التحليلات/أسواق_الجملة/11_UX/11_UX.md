# المرحلة الحادية عشرة: UX - قطاع أسواق الجملة في محافظة إب

## 11.1 مبادئ تجربة المستخدم

| المبدأ | التطبيق |
|--------|---------|
| البساطة | 3 خطوات لإنشاء طلب شراء (اختر ← أضف ← أرسل) |
| السرعة | تحميل سريع للصور والأسعار |
| الثقة | معلومات تاجر موثقة، أسعار حقيقية |
| التكيف | واجهة تعمل على أضعف شبكات الإنترنت (2G/3G) |

## 11.2 User Flows

### تدفق شراء منتج

```
الرئيسية ← بحث ← "أرز بسمتي"
    → نتائج (قائمة تجار يبيعون أرز بسمتي)
    → مقارنة الأسعار بين 3 تجار
    → اختيار الأقل سعرًا
    → تحديد الكمية (5 كيلو)
    → إضافة إلى السلة
    → إرسال الطلب
    → تأكيد الطلب
    → تتبع التوصيل
```

### تدفق إضافة منتج (لتاجر الجملة)

```
تسجيل دخول ← لوحة التحكم
    → إضافة منتج جديد
    → إدخال الاسم والكمية والسعر
    → إضافة صورة (تصوير بالكاميرا)
    → نشر المنتج
    → يظهر فورًا في قائمة المنتجات
```
