## 12.1 دليل الهوية البصرية

| العنصر | القيمة |
|--------|--------|
| **اللون الأساسي** | `#27AE60` (أخضر تجاري) |

## 12.2 مكونات الواجهة

### بطاقة المنتج

```
┌──────────────────────────────────┐
│ 📦 أرز بسمتي                     │
│ السعر: 1,400 ريال/كجم           │
│ الكمية: 500 كيلو متوفرة         │
│ 🏪 مؤسسة الغيث للتجارة           │
│ 📍 القاع - مستودع 5             │
│ [إضافة إلى السلة]  [مقارنة]    │
└──────────────────────────────────┘
```

### بطاقة تاجر الجملة

```
┌──────────────────────────────────┐
│ 🏪 مؤسسة الغيث للتجارة          │
│ ✅ موثق (غرفة تجارة إب)         │
│ منتجات: 25    تقييم: ⭐ 4.5    │
│ ⏰ 6 صباحًا - 6 مساءً           │
│ [عرض المنتجات]  [اتصال]        │
└──────────────────────────────────┘
```

### شريط الأسعار اليومية

```
┌──────────────────────────────────────────────┐
│ 📊 أسعار اليوم - سوق الجملة المركزي          │
│ طماطم:500▲ | خيار:400▶ | بصل:350▶ | أرز:1,500▶ │
└──────────────────────────────────────────────┘
```

## 12.3 تصميم متجاوب

| الجهاز | العرض | التصميم |
|--------|-------|---------|
| هاتف (أندرويد) | < 480px | قائمة رأسية، أزرار كبيرة |
| جهاز لوحي | 480-768px | شبكة من عمودين، شريط جانبي |
| ويب (حاسوب) | > 768px | شبكة 3-4 أعمدة، لوحة تحكم كاملة |
