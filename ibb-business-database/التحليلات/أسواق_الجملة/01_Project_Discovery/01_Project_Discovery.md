# المرحلة الأولى: Project Discovery - قطاع أسواق الجملة في محافظة إب

## 1.1 المشكلة (Problem Statement)

تعاني أسواق الجملة في محافظة إب من **تشتت المعلومات وغياب منصة رقمية موحدة** تربط بين تجار الجملة، الموردين، وتجار التجزئة. المشكلات الرئيسية:

1. **صعوبة معرفة أسعار الجملة اليومية**: لا توجد منصة موحدة للإعلان عن أسعار الخضار والفواكه والمواد الغذائية
2. **ضعف التنسيق بين التجار**: كل سوق يعمل بشكل منعزل، لا توجد شبكة تواصل B2B
3. **غياب المعلومات عن توفر المنتجات**: التجار لا يعرفون المخزون المتاح في الأسواق الأخرى
4. **مشاكل في النقل والتوزيع**: عدم وجود نظام لوجستي موحد لنقل البضائع بين المديريات
5. **تعدد الوسطاء والسماسرة**: ارتفاع التكاليف بسبب كثرة الوساطة

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لأسواق الجملة في محافظة إب** (Ibb Wholesale Market Hub) تشمل:

- **منصة إلكترونية للعرض والطلب**: قوائم أسعار حية للمنتجات بالجملة
- **دليل تجار الجملة**: قاعدة بيانات لجميع تجار ومستوردي المواد الغذائية
- **نظام التوصيل والتوزيع**: شبكة لوجستية لنقل البضائع بين المديريات
- **لوحة تحكم للأسعار**: إحصائيات ومتوسطات أسعار المنتجات الأساسية

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **تجار الجملة** | منصة لعرض المنتجات، الوصول لعدد أكبر من المشترين |
| **تجار التجزئة** | مقارنة الأسعار، طلب كميات بسهولة |
| **المستهلكون** | استقرار الأسعار، تقليل حلقات الوساطة |
| **الناقلون** | عقود نقل منتظمة، جداول موحدة |
| **البلدية** | بيانات الأسواق، تنظيم القطاع |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | تجار الجملة والتجزئة في محافظة إب (~5,000 تاجر) |
| **مصادر التمويل** | اشتراكات شهرية، عمولات على المبيعات، إعلانات |
| **نموذج الإيرادات** | Freemium + عمولة 1-2% على المعاملات |
| **القنوات** | تطبيق أندرويد + PWA للهواتف + موقع ويب |

## 1.6 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - إب مركز تجاري رئيسي | - ضعف البنية الرقمية |
| - كثافة سكانية عالية | - مقاومة التغيير لدى التجار |
| - موقع استراتيجي وسط اليمن | - ضعف الثقة في المعاملات الإلكترونية |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - تحول رقمي في التجارة | - انعدام الاستقرار الأمني |
| - طلب متزايد على الخدمات اللوجستية | - تقلب العملة وارتفاع التضخم |
| - شراكة مع غرفة التجارة | - نقص الكهرباء والإنترنت |
