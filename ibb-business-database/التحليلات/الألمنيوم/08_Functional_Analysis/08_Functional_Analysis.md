## 8.2 حالات الاستخدام

### UC1: البحث عن جهة والتواصل
1. يفتح العميل التطبيق
2. يبحث عن جهة حسب النوع أو الموقع
3. يختار جهة ويشاهد التفاصيل
4. يتواصل مع الجهة عبر الهاتف أو الرسائل
5. يقيم التجربة بعد الخدمة

### UC2: إدارة بيانات الجهة
1. يسجل صاحب الجهة الدخول
2. يحدث بيانات الجهة
3. يضيف خدمات/منتجات جديدة
4. ينشر التحديثات
