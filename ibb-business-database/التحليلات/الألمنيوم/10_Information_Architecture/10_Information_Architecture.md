## 10.1 هيكل المعلومات العام

تطبيق ألمنيوم إب → [الصفحة الرئيسية | قائمة الجهات | صفحة جهة | العروض | لوحة التحكم]

## 10.2 نظام التصنيف

| المستوى | التصنيف |
|---------|---------|
| حسب النوع | محلات ألمنيوم (نوافذ وأبواب) | تخصص محلات ألمنيوم (نوافذ وأبواب) |
| حسب النوع | واجهات زجاجية | تخصص واجهات زجاجية |
| حسب النوع | مطابخ ألمنيوم | تخصص مطابخ ألمنيوم |
| حسب النوع | درابزين وقبانيات | تخصص درابزين وقبانيات |
| حسب النوع | مصانع ألمنيوم | تخصص مصانع ألمنيوم |

## 10.3 Sitemap

/ ← الصفحة الرئيسية
/list ← قائمة الجهات
/list/:id ← صفحة جهة
/list/:id/reviews ← تقييمات
/favorites ← المفضلة
/offers ← العروض

## 10.4 User Flow

فتح التطبيق → بحث/تصفح → اختيار جهة → عرض التفاصيل → تواصل → تقييم
