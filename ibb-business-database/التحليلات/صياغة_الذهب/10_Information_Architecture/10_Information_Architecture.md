## 10.1 هيكل المعلومات
```
التطبيق الرئيسي
├── الصفحة الرئيسية (بحث، فئات، مميزون)
├── دليل مقدمي الخدمة (تصفح، فلترة، نتائج)
├── صفحة مقدم الخدمة (معلومات، معرض، حجز)
├── حساب المستخدم (طلباتي، حجوزاتي، تقييماتي)
├── لوحة تحكم مقدم الخدمة (طلبات، خدمات، تقارير)
└── المساعدة (أسئلة شائعة، تواصل، سياسة)
```

## 10.2 خريطة الموقع
| المستوى | الصفحة |
|---------|--------|
| 1 | الرئيسية |
| 2 | قائمة الخدمات |
| 3 | تفاصيل الخدمة |
| 4 | الحجز والدفع |
| 5 | حساب المستخدم |
| 6 | لوحة التحكم |

## 10.3 تدفقات المستخدم
**العميل**: رئيسية ← بحث ← اختيار ← حجز ← دفع ← تأكيد
**مقدم الخدمة**: تسجيل دخول ← لوحة تحكم ← طلبات ← قبول ← إنجاز
