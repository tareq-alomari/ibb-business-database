## 10.1 هيكل المعلومات العام

تطبيق إطارات إب → [الصفحة الرئيسية | قائمة الجهات | صفحة جهة | العروض | لوحة التحكم]

## 10.2 نظام التصنيف

| المستوى | التصنيف |
|---------|---------|
| حسب النوع | محلات إطارات سيارات | تخصص محلات إطارات سيارات |
| حسب النوع | بطاريات وكهرباء | تخصص بطاريات وكهرباء |
| حسب النوع | زيوت وشحوم | تخصص زيوت وشحوم |
| حسب النوع | مراكز خدمة إطارات | تخصص مراكز خدمة إطارات |
| حسب النوع | محلات إطارات شاحنات | تخصص محلات إطارات شاحنات |

## 10.3 Sitemap

/ ← الصفحة الرئيسية
/list ← قائمة الجهات
/list/:id ← صفحة جهة
/list/:id/reviews ← تقييمات
/favorites ← المفضلة
/offers ← العروض

## 10.4 User Flow

فتح التطبيق → بحث/تصفح → اختيار جهة → عرض التفاصيل → تواصل → تقييم
