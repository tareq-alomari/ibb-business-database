## 21.2 دليل المستخدم (User Guide)

### للعميل:
1. تحميل التطبيق من المتجر أو فتح الموقع
2. إنشاء حساب باستخدام رقم الهاتف
3. تفعيل الحساب عبر رمز OTP
4. البحث عن الخدمة المطلوبة
5. استعراض مقدمي الخدمة ومقارنتهم
6. حجز موعد وتأكيد الدفع
7. متابعة حالة الحجز
8. تقييم الخدمة بعد الانتهاء

### لمزود الخدمة:
1. التسجيل كمزود خدمة (يتطلب توثيق)
2. إضافة الخدمات وتحديد الأسعار
3. استقبال وإدارة الطلبات
4. تحديث حالة الطلبات
5. عرض التقارير والإحصائيات
6. إدارة الملف الشخصي ومعرض الأعمال

## 21.3 دليل النشر (Deployment Guide)

```bash
# 1. تثبيت المتطلبات
npm install

# 2. إعداد متغيرات البيئة
cp .env.example .env
# تعديل قواعد البيانات والمفاتيح

# 3. تشغيل قاعدة البيانات
docker-compose up -d postgres redis

# 4. تشغيل الترحيلات
npx prisma migrate dev

# 5. تشغيل التطبيق
npm run dev
```
