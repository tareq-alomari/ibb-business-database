# الأمان - قطاع العصائر في إب

## حماية البيانات الشخصية
- تشفير جميع البيانات الحساسة (AES-256)
- عدم تخزين كلمات المرور بنص واضح (bcrypt)
- إخفاء معلومات الدفع الحساسة
- سياسة خصوصية واضحة للمستخدمين

## المصادقة والصلاحيات
- JWT مع توكن منعش (Refresh Token)
- صلاحيات متدرجة (Admin / Shop / User / Delivery)
- التحقق بخطوتين (2FA) للحسابات الإدارية
- تسجيل جميع عمليات الدخول (Audit Log)

## أمن التطبيق (OWASP Top 10)
- حماية من SQL Injection (ORM + parameterized queries)
- منع XSS (تعقيم المدخلات، CSP Header)
- منع CSRF (توكنات عشوائية)
- Rate Limiting لمنع هجمات Brute Force
- Secure Headers (HSTS, X-Frame-Options)

## أمن المدفوعات
- تشفير جميع معاملات الدفع
- عدم تخزين بيانات البطاقات البنكية
- التوافق مع معايير PCI DSS
- تسجيل جميع معاملات الدفع للتدقيق

## أمن الشبكة
- HTTPS إلزامي (Let's Encrypt)
- Cloudflare WAF لحماية DNS
- حظر IPs مشبوهة تلقائياً
- تحديث دوري للأنظمة والتبعيات

## النسخ الاحتياطي
- نسخ احتياطي يومي للقاعدة
- تخزين النسخ في موقعين مختلفين
- اختبار استرجاع البيانات شهرياً
- تشفير النسخ الاحتياطية

## الامتثال
- الالتزام بقوانين حماية البيانات اليمنية
- سياسة خصوصية وتعهد بمعالجة البيانات
- تقارير أمن دورية
- تدريب الموظفين على أمن المعلومات
