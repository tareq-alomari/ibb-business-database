# لوحة التحكم والإحصائيات - قطاع العصائر في إب

## لوحة التحكم الرئيسية (Admin Dashboard)

### مؤشرات الأداء (KPIs)
- عدد المحلات المسجلة (نشط / موقف / قيد الترخيص)
- إجمالي الطلبات اليومية / الأسبوعية / الشهرية
- إجمالي الإيرادات
- متوسط تقييم المحلات
- عدد المستخدمين النشطين

### الرسوم البيانية
- منحنى نمو عدد المحلات (سنوي)
- توزيع المحلات حسب الأحياء (خريطة حرارية)
- مبيعات العصائر حسب النوع (مخطط دائري)
- اتجاهات الطلب الشهرية (خط زمني)
- مقارنة أسعار العصائر بين المحلات
- أفضل 10 عصائر مبيعاً

## لوحة تحكم المحل (Shop Dashboard)

### المؤشرات
- عدد الطلبات اليومية
- الإيرادات اليومية / الأسبوعية / الشهرية
- متوسط تقييم المحل
- المنتجات الأكثر طلباً
- الطلبات المعلقة

### الإدارة
- إدارة قائمة المنتجات والأسعار
- إدارة الطلبات (جديد / قيد التحضير / تم)
- تحديث حالة الطلبات
- إدارة العروض والخصومات
- تقارير المبيعات اليومية

## لوحة تحكم المستخدم (User Dashboard)

### المعلومات
- سجل الطلبات السابقة
- حالة الطلبات الحالية
- المحلات المفضلة
- نقاط الولاء والمكافآت
- تقييماتي السابقة

### التنبيهات
- إشعارات حالة الطلب
- عروض وخصومات من المحلات المفضلة
- تذكير بإعادة الطلب
- توفر نكهات موسمية جديدة

## التقارير المتقدمة
- تقارير قابلة للتصدير (PDF, Excel, CSV)
- تقارير دورية آلية (أسبوعي / شهري)
- تحليل سلوك المستهلكين
- تنبؤات الطلب الموسمي
- تحليل الفجوات السوقية

## إعدادات التحكم
- صلاحيات المستخدمين والأدوار
- تخصيص الإشعارات
- إعدادات الدفع والتوصيل
- إدارة اللغات (عربي / إنجليزي)
