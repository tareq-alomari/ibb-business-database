# تصميم واجهة المستخدم (UI) - قطاع العصائر في إب

## الهوية البصرية

### الألوان الأساسية
- الرئيسي: برتقالي (#FF6B35) - يرمز للحيوية والحمضيات
- الثانوي: أخضر (#2ECC71) - يرمز للطبيعة والنضارة
- الخلفية: أبيض (#FFFFFF) وكريمي (#FFF8F0)
- النصوص: رمادي غامق (#2D3436) وأسود (#1A1A1A)

### الخطوط
- الخط العربي: Cairo / Tajawal
- الأحجام: العناوين 22-30px، النصوص 14-16px

### الأيقونات
- أيقونات فواكه مخصصة لكل نوع
- أيقونات بسيطة وواضحة
- رسوم توضيحية للعصائر بأنواعها

## واجهات رئيسية

### الصفحة الرئيسية
- شريط بحث مع اقتراحات النكهات
- بطاقات محلات مميزة مع صور العصائر
- عروض اليوم والأكثر طلباً
- أزرار دعوة للإجراء (طلب الآن)

### صفحة المحلات
- grid بعرض 3 أعمدة (سطح مكتب)
- عمود واحد (جوال)
- فلترة حسب المنطقة والسعر والتقييم
- صورة المحل + اسمه + تقييمه + نطاق السعر

### قائمة العصائر
- صورة مشهية لكل عصير
- اسم العصير والمكونات
- السعر والأحجام المتاحة
- زر إضافة إلى السلة

### صفحة الطلب
- سلة المشتريات
- اختيار عنوان التوصيل
- طرق الدفع (نقدي / إلكتروني)
- تأكيد الطلب

### لوحة تحكم المحل
- إدارة القائمة والمنتجات
- إدارة الطلبات الواردة
- إحصائيات المبيعات
- إدارة العروض
