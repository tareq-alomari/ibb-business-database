# المرحلة الأولى: Project Discovery - قطاع الإنترنت في محافظة إب

> **التاريخ**:  يوليو 2026  
> **الملف**: 01_Project_Discovery.md

## 1.1 المشكلة (Problem Statement)

يعاني قطاع الإنترنت في محافظة إب من تحديات كبيرة رغم كونه قطاعًا حيويًا. لا توجد منصة موحدة تتيح للمستفيدين اكتشاف الخدمات أو مقارنتها. المشكلات الرئيسية:

1. **ضعف سرعة الإنترنت**
2. **انقطاع الخدمة المتكرر**
3. **ارتفاع الأسعار مقارنة بالجودة**
4. **نقص الدعم الفني**
5. **عدم وجود منصة لمقارنة الخدمات**

## 1.2 الحل (Proposed Solution)

بناء **منصة رقمية شاملة لقطاع الإنترنت في محافظة إب** تتكون من:

- **مقارنة العروض**: مقارنة باقات الإنترنت من جميع المزودين
- **اختبار السرعة**: قياس سرعة الإنترنت الفعلية
- **خريطة التغطية**: خريطة تفاعلية لتغطية الشبكات
- **الإبلاغ عن انقطاع**: نظام للإبلاغ عن انقطاع الخدمة
- **تقييم المزودين**: تقييمات المستخدمين لجودة الخدمة

## 1.3 القيمة المضافة (Value Proposition)

| المستفيد | القيمة المضافة |
|----------|---------------|
| **المستهلك/المواطن** | سهولة الوصول للمعلومات، مقارنة الخدمات، تقييمات حقيقية |
| **مزود الخدمة/الإنترنت** | وصول لشريحة أكبر، تحسين السمعة، إدارة رقمية |
| **الاقتصاد المحلي** | تنشيط الحركة التجارية، تحسين جودة الخدمات |

## 1.4 Business Model

| العنصر | الوصف |
|--------|-------|
| **المستفيد الأساسي** | سكان محافظة إب (~3 مليون نسمة) |
| **مصادر التمويل** | اشتراكات، عمولات، إعلانات |
| **نموذج الإيرادات** | Freemium + خدمات متميزة مدفوعة |
| **القنوات** | تطبيق أندرويد + iOS + موقع ويب (PWA) |
| **الشركاء المحتملون** | غرفة تجارة إب، مكاتب الإنترنت المحلية |

## 1.5 أهداف المشروع (Project Goals)

| الهدف | مؤشر القياس | القيمة المستهدفة |
|-------|------------|-----------------|
| حصر الجهات/الإنترنت | عدد المسجلين | 15++ |
| دقة البيانات | نسبة المعلومات المؤكدة | 90%+ |
| سهولة البحث | متوسط وقت الاكتشاف | < 20 ثانية |
| رضا المستخدمين | تقييم المنصة | 4.3+/5 |

## 1.6 Vision & Mission

### Vision
"أن تكون المنصة الرقمية لقطاع الإنترنت في محافظة إب المرجع الأول الذي يعتمد عليه كل مواطن، محولة تجربة الإنترنت إلى تجربة رقمية متكاملة."

### Mission
"بناء منصة رقمية تربط بين مزودي خدمات الإنترنت والمستفيدين في محافظة إب، وتوفر معلومات دقيقة ومحدثة عن الخدمات والأسعار والتقييمات، لنعزز الشفافية والتنافسية في القطاع."

## 1.8 SWOT Analysis

| الإيجابي | السلبي |
|----------|--------|
| **S (القوة)** | **W (الضعف)** |
| - انتشار واسع للهواتف الذكية | - بنية تحتية ضعيفة |
| - طلب متزايد على الإنترنت | - انقطاع الكهرباء |
| - شريحة شبابية كبيرة | - احتكار السوق |

| **O (الفرص)** | **T (التهديدات)** |
|---------------|-------------------|
| - التحول الرقمي للحكومة | - ارتفاع تكاليف التشغيل |
| - زيادة العمل عن بُعد | - الوضع الأمني |
| - انتشار الألياف البصرية | - رسوم التراخيص |

## 1.9 PESTLE Analysis

| العامل | التأثير على المشروع |
|--------|-------------------|
| **P - Political**: عدم استقرار سياسي | خطر على استمرارية الأعمال |
| **D - Economic**: تدهور العملة، انخفاض القوة الشرائية | ارتفاع التكاليف، حساسية السعر |
| **S - Social**: كثافة سكانية عالية، شرائح متنوعة | فرصة كبيرة، تنوع الاحتياجات |
| **T - Technological**: إنترنت ضعيف، كهرباء متقطعة | PWA مع دعم Offline-first |
| **L - Legal**: غياب تنظيم رقمي | فرصة لتوحيد المعايير |
| **E - Environmental**: تحديات بيئية مختلفة | فرصة لنشر التوعية |
