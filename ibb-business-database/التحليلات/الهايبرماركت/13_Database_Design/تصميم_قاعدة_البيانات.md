# تصميم قاعدة البيانات - منصة الهايبرماركت

## نظام إدارة قواعد البيانات
MySQL / MariaDB مع إمكانية الترقية إلى PostgreSQL عند الحاجة.

## الجداول الرئيسية

### 1. users (المستخدمون)
- id (PK, INT)
- name, email, phone, password
- role (admin, manager, cashier, customer)
- created_at, updated_at

### 2. branches (الفروع)
- id (PK, INT)
- name, address, phone, location_lat, location_lng
- manager_id (FK -> users)
- status (active, inactive)

### 3. categories (الفئات)
- id (PK, INT)
- name_ar, name_en (اختياري)
- parent_id (FK -> categories, self)
- image, sort_order

### 4. products (المنتجات)
- id (PK, INT)
- name_ar, description
- category_id (FK -> categories)
- price, cost_price
- unit (kg, liter, piece, box)
- barcode, image
- min_stock_level

### 5. inventory (المخزون)
- id (PK, INT)
- product_id (FK -> products)
- branch_id (FK -> branches)
- quantity, expiry_date

### 6. orders (الطلبات)
- id (PK, INT)
- user_id (FK -> users)
- branch_id (FK -> branches)
- total_amount, discount, final_amount
- status (pending, preparing, shipped, delivered)
- payment_method, delivery_address
- created_at

### 7. order_items (تفاصيل الطلب)
- id (PK, INT)
- order_id (FK -> orders)
- product_id (FK -> products)
- quantity, unit_price, total

### 8. suppliers (الموردون)
- id (PK, INT)
- name, phone, email
- address, tax_number
- contract_start, contract_end

## العلاقات
- المستخدم -> عدة طلبات
- الطلب -> عدة منتجات
- المنتج -> فئة واحدة
- الفرع -> مخزون متعدد
- المورد -> عدة منتجات
