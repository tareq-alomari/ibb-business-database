# هيكلة المعلومات - منصة الهايبرماركت

## هيكل التنقل الرئيسي

### المستوى الأول (الواجهة الرئيسية)
- الرئيسية
- المنتجات
- العروض
- الفروع
- اتصل بنا
- تسجيل الدخول

### المستوى الثاني (المنتجات)
- جميع المنتجات
- مواد غذائية
- مشروبات
- منظفات
- مستحضرات تجميل
- منتجات الأطفال
- إلكترونيات

### المستوى الثالث (التفاصيل)
- صفحة المنتج (وصف، سعر، كمية، صور)
- تقييمات العملاء
- منتجات مشابهة
- إضافة إلى السلة

## هيكل قاعدة البيانات (المفاهيم الرئيسية)

### الكيانات الأساسية
- مستخدم (User)
- منتج (Product)
- فئة (Category)
- طلب (Order)
- فاتورة (Invoice)
- مورد (Supplier)
- فرع (Branch)
- مخزون (Inventory)

### العلاقات
- كل منتج ينتمي إلى فئة واحدة
- كل طلب يحتوي على عدة منتجات
- كل فاتورة مرتبطة بمستخدم وفرع
- كل فرع لديه مخزون منفصل
