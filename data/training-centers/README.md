# بيانات مراكز التدريب في محافظة إب

توثق هذه الحزمة مركزًا تدريبيًا مؤسسيًا مصدره صفحة جامعة إب، وتفصل عنه مرشحات المواقع التي تحمل إشارات تدريب أو مركز في بيانات HOT/OSM. ولا تمثل نتائج البحث فهرسًا كاملاً لمقدمي التدريب في المحافظة.

| الملف | المحتوى | حد الاستخدام |
|---|---|---|
| `official-institutions.json` | مركز ذو صفحة مؤسسية مباشرة | الهوية والوظيفة العامة فقط |
| `ibb_training_center_location_candidates_osm_2026-08-07.geojson` | مواقع مرشحة من مصدر مفتوح | ليست دليلاً على التشغيل أو الترخيص |
| `ibb_training_center_location_candidates_osm_2026-08-07.summary.json` | ملخص فني للتصفية | لا يعبر عن حجم القطاع |

يحتاج نشر الدورات والرسوم والمواعيد وأرقام الاتصال إلى إعلان رسمي مؤرخ أو تحقق مباشر يوثق تاريخه ومصدره.

|---|---:|---|
