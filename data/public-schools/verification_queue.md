# قائمة تحقق المدارس الحكومية

تدير هذه القائمة انتقال مرشح المدرسة من بيانات عامة إلى سجل قابل للاعتماد. لا تضاف أي معلومة عن التلاميذ أو الأطفال أو الموظفين على مستوى فردي إلى ملفات المستودع.

| خطوة التحقق | الدليل المطلوب | نتيجة السجل |
|---|---|---|
| المطابقة الأساسية | اسم وموقع من مكتب التربية أو وثيقة رسمية أو زيارة موثقة | دمج التكرارات أو الاحتفاظ بمرشح منفصل |
| الملكية | تأكيد مكتوب أو سجل رسمي يحدد حكومية المدرسة | `government_verified` أو `private_verified` |
| المرحلة التعليمية | تأكيد الجهة المالكة للمراحل التي تقدمها المنشأة | إضافة `education_stages` مع المصدر |
| حالة التشغيل | رد حديث موثق أو زيارة ميدانية | `field_verified` أو `official_verified` |
| السلامة وWASH | أداة تقييم مؤسسية لا بيانات شخصية | تسجل كمعلومة مقيدة المصدر والتاريخ |
| المراجعة | كل 90 يومًا أو قبل العام الدراسي الجديد | إبقاء السجل أو تحويله إلى `stale` |

## الحقول المطلوبة من فريق التحقق

| الحقل | القاعدة |
|---|---|
| الاسم الرسمي | يطابق وثيقة أو تأكيدًا مباشرًا؛ لا يغير الاسم التاريخي بلا ملاحظة |
| المديرية والموقع | تؤكد باسم المديرية وإحداثيات أو وصف وصول |
| الملكية | لا تستنتج من الاسم أو التسمية الجغرافية |
| حالة التشغيل | تحدد بتاريخ التحقق فقط |
| المصدر | رابط أو مرجع وثيقة أو سجل زيارة مع طريقة التحقق |
| حماية البيانات | يمنع نشر أسماء التلاميذ أو أرقامهم أو سجلاتهم التعليمية |
