# بيانات قطاع الجامعات في محافظة إب

يفصل هذا المجلد بين مصدرين مختلفين للدليل: سجل مؤسسات مدعوم بصفحة رسمية مباشرة، وطبقة مرشحات جغرافية من HOT/OSM. لا يدمج الملفان آليًا لأن تشابه الاسم أو قرب الموقع لا يثبت العلاقة المؤسسية.

| الملف | الوظيفة | حدود الاستخدام |
|---|---|---|
| `official-institutions.json` | كيانات جامعية دعمتها صفحة مؤسسية رسمية | ليس سجلًا شاملاً لجميع الجامعات ولا يحتوي إحصاءات حالية غير منشورة |
| `ibb_university_location_candidates_osm_2026-08-07.geojson` | مواقع جامعية مرشحة من المصدر العام | لا تثبت الملكية أو التشغيل أو علاقتها بسجل رسمي |
| `ibb_university_location_candidates_osm_2026-08-07.summary.json` | ملخص التصفية | مخرج تقني لا تعداد قطاع |

## قاعدة الربط

لا يربط الموقع المرشح بسجل رسمي إلا بعد مطابقة اسم وموقع موثقة أو تحقق ميداني. وتبقى رسوم الدراسة والقبول وأعداد الطلاب والبرامج الفعلية غير مدرجة إلى أن تراجع من مصدر مؤسسي مؤرخ لكل معلومة.
