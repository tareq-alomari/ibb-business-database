| الملف | المصدر الأساسي | حالة السجل |
|---|---|---|
| `official-units.json` | صفحات وحدات جامعة إب الرسمية | `official_verified` لهوية الوحدة والصفحة فقط |
| `ibb_college_location_candidates_osm_2026-08-07.geojson` | HOT/OSM عبر HDX | `public_candidate` ولا يربط آليًا بالسجل الرسمي |
| `ibb_college_location_candidates_osm_2026-08-07.summary.json` | مخرج أداة التصفية | ملخص تقني لا تعداد للكليات |

لا يضاف إلى هذه الملفات عدد الطلاب أو الرسوم أو برامج القبول أو طاقة الاستيعاب ما لم يكن له مصدر رسمي مؤرخ ومخصص للبيان.
