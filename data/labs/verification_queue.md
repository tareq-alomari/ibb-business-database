# قائمة تحقق المختبرات المرشحة

| خطوة التحقق | الدليل المطلوب | قرار النشر |
|---|---|---|
| مطابقة الاسم والموقع | مصدران مستقلان أو تأكيد مباشر | دمج أو تثبيت مرشح |
| حالة التشغيل | اتصال/زيارة موثقة وتاريخ مراجعة | نشر حالة مؤقتة قابلة للتقادم |
| ترخيص أو اعتماد معلن | وثيقة أو تأكيد من جهة مخولة | إضافة نوع التحقق فقط |
| الخدمات والأسعار | إعلان رسمي مؤرخ وموافقة نشر | لا يعمم على نتائج أو جودة الفحوص |

يحظر إدخال نتائج مختبرية أو بيانات مريض أو إحالات أو تفاصيل طبية شخصية.
