# قائمة تحقق الصيدليات المرشحة

| خطوة التحقق | الدليل المطلوب | النتيجة |
|---|---|---|
| مطابقة الاسم والموقع | مصدران مستقلان أو تأكيد مباشر | دمج المكرر أو تثبيت سجل مرشح |
| الترخيص أو الإشراف | وثيقة أو تأكيد من جهة مخولة | تحديث حالة التحقق فقط |
| حالة التشغيل | اتصال/زيارة حديثة موثقة بالتاريخ | نشر الحالة لفترة صلاحية محددة |
| بيانات التواصل | قناة منشأة رسمية أو موافقة مباشرة | إضافة بيانات اتصال عامة قابلة للنشر |
| بيانات الأدوية والأسعار | مصدر منشأة مؤرخ وموافقة نشر | لا تنشر كحكم على التوفر الدائم |

لا تجمع أو تنشر بيانات مرضى، وصفات، أو معلومات طلبات شخصية ضمن هذا القطاع.
