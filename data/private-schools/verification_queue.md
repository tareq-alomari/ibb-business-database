# قائمة تحقق المدارس الأهلية

| خطوة التحقق | الدليل المطلوب | نتيجة السجل |
|---|---|---|
| الاسم والموقع | مصدر رسمي أو اتصال/زيارة موثقة | تثبيت الاسم الرسمي ومنع التكرار |
| الترخيص والملكية | سجل مكتب التربية أو إفادة موثقة من الجهة المالكة | تحويل `private_candidate` إلى `private_verified` |
| المراحل والخدمات | مصدر مباشر مؤرخ من المدرسة | إضافة حقول المرحلة والخدمات فقط عند التحقق |
| الرسوم | إعلان رسمي حديث من المدرسة وبنطاق زمني واضح | لا تنشر دون التاريخ والسنة الدراسية |
| التشغيل | تأكيد حديث من الجهة أو زيارة ميدانية | تحديث `verification_status` |
| حماية البيانات | منع أي معلومات فردية للطلاب أو الموظفين | لا تسجل ولا تنشر بيانات شخصية |

لا تستخدم «أهلية» في الاسم وحدها لتأكيد الترخيص أو لتقييم الجودة أو الرسوم.
