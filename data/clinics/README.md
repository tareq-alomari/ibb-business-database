| حالة السجل | الاستخدام |
|---|---|
| `public_candidate` | استدلال أولي ومراجعة اسم وموقع فقط |
| `field_verified` أو `official_verified` | يتطلب دليلًا مباشرًا مؤرخًا قبل النشر |
| `stale` | يستخدم عند تعذر تحديث الحالة ضمن دورة المراجعة |

يحظر إضافة مواعيد، وصفات، نتائج، بيانات مرضى، أو تفاصيل طبية شخصية إلى هذه الحزمة.
