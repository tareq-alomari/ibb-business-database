## 📋 نظرة عامة

**IBB Business Database** هو مشروع يهدف إلى بناء قاعدة تحليل شاملة ومنظمة لجميع المؤسسات والمحلات التجارية والخدمية في **محافظة إب**، اليمن. يعتمد المشروع على هيكل قطاعي موحد يضم **22 قطاعًا رئيسيًا** وأكثر من **150 مجالًا فرعيًا**، مما يسهل عملية البحث والتحليل والإحصائيات.

تم تصميم هذا المشروع ليكون أداة فعالة للمواطنين والباحثين والمنظمات والجهات الحكومية، مع إمكانية إضافة قطاعات ومجالات جديدة مستقبلًا دون التأثير على بنية قاعدة البيانات.
